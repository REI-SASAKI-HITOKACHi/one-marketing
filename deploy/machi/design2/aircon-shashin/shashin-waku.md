# 写真の枠の一覧（デザイン②「写真が主役」エアコン・下書き）

2026-11-01 ／ LP・サイト担当（下書き・未配信）

いまの写真は**手元にあったものを仮に入れたもの**。写真が届いたら、この表の「欲しい写真」に合うものと差し替える。

## 差し替え方

1. 新しい写真を `img/` の**同じファイル名**で置く（縦横比が変わってもよい。枠は `object-fit: cover` で埋める）
2. `_katachi.html` で `data-waku="枠の名前"` を探し、その中の `<img>` の `alt`・`width`・`height` を写真に合わせて直す。
   写真のどこを見せるかは `style="object-position: 横% 縦%"`（スマホは縦に切り抜かれるので、主役が真ん中に来るように）
3. `tools/` ではなく、このフォルダの `tsukuru.py` を実行して `index.html` を作り直す（点検も同時に走る）
4. **施工前と施工後を並べる枠（`-ba`）は、同じ物・同じ場所と確かめた組だけ**（景品表示法。別物の組は禁止。`docs/photo-inventory.md` の 2026-09-06 の節）。
   確かめた根拠を下の表の「前後の確認」に書いてから入れる
5. 人の顔・表札・本舗のロゴ・住所や名前が読める物（伝票・ラベル・郵便物）・型番シールが写った写真は使わない。EXIF は消す（`tsukuru.py` が残っていないか見る）

## 手元にある、差し替えの候補（参考）

- **web-inflow のブランチ（`origin/claude/web-inflow`）の `assets/photos/` に 136枚**（IMG_8003〜8041 など 1600×1200、Drive から取り込んだ `ph-NNN.jpg`）。仕分けの表は同じブランチの `data/photo-catalog.json`（Drive「施工写真_一次格納」の **838枚** を1枚ずつ判定。エアコン ○302枚）と `docs/blog/写真割り当て表.md`。**オーナーの「素材は十分揃ってるはず」はこれと思われる**
  - 例：IMG_8016（洗浄後の熱交換器）、IMG_8029・IMG_8034（ブログ 10-14 で「吹き出し口の前後」として使用）、ph-417・ph-428・ph-445・ph-474（吹出口の黒カビ・施工前）
  - web-inflow の持ち物なので、ここでは使っていない。使うときは **前後の組は1組ずつ拡大して同じ物か確かめる**（ブログで「前後」とされていても、同じ吹出口かは未確認）
- いずれも **800〜1600px の横位置**。全画面の縦の枠には、原寸（iPhone の 4032×3024）か、縦で撮った写真が欲しい
