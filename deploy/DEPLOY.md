# LPの公開手順（ロリポップ！レンタルサーバー）

公開先： **https://lp.one-hitter.jp/**

| URL | 中身 |
|---|---|
| `https://lp.one-hitter.jp/aircon/` | 案A：エアコンクリーニング |
| `https://lp.one-hitter.jp/mizumawari/` | 案B：水まわりセット |
| `https://lp.one-hitter.jp/` | `/aircon/` へ自動転送 |

作業は **4ステップ・30〜40分** です。①②はDNSの反映待ちがあるので、
先に始めてしまってください。

---

## ① ムームードメイン側で、サブドメインをロリポップに向ける

one-hitter.jp を管理しているDNSに、レコードを1つ足すだけです。
**one-hitter.jp 本体（AWS上のCMS）には一切影響しません。** 触るのは `lp` の行だけです。

1. ムームードメイン（またはドメインを管理しているサービス）にログイン
2. 「ムームーDNS」→ one-hitter.jp の「変更」
3. 「カスタム設定」の空き行に、次を入力して保存

   | サブドメイン | 種別 | 内容 |
   |---|---|---|
   | `lp` | A | `118.27.125.166` |

   ※ この値は `one-hitter.her.jp` が現在向いているIPです。
   ロリポップの管理画面で別のIPが案内された場合は、そちらを優先してください。

4. 反映まで数分〜最大1時間ほどかかります。

---

## ② ロリポップ側に、独自ドメインとして登録する

1. ロリポップ管理画面 →「サーバーの管理・設定」→「独自ドメイン設定」
2. **設定する独自ドメイン**： `lp.one-hitter.jp`
3. **公開（アップロード）フォルダ**： `lp.one-hitter.jp`
   （フォルダ名は何でも構いませんが、この手順書はこの名前で進めます）
4. 「独自ドメインをチェックする」→「設定する」

①のDNSが反映される前だとチェックに失敗します。その場合は少し待って再度。

---

## ③ 無料の独自SSLを有効にする

**フォームで名前と電話番号をお預かりするので、この作業は必須です。**
先に④のアップロードを済ませてしまうと、`.htaccess` のhttps転送が空回りするので、
**SSLを先に有効化してください。**

1. ロリポップ管理画面 →「セキュリティ」→「独自SSL証明書導入」
2. 一覧の `lp.one-hitter.jp` に **チェックを入れて**、
   「独自SSL（無料）を設定する」を押す
3. 「SSL設定作業中」→ 5〜15分ほどで「SSL保護有効」に変われば完了

---

## ④ ファイルをアップロードする（ロリポップ！FTP）

`one-hitter-lp.zip` を解凍すると、この形になっています。
**この中身を、②で作った `lp.one-hitter.jp` フォルダの直下に置きます。**

```
.htaccess              ← 隠しファイル。見えない場合は下の「注意」を参照
index.html
robots.txt
favicon.ico
apple-touch-icon.png
aircon/
    index.html
    thanks.html
    img/  （10ファイル）
mizumawari/
    index.html
    thanks.html
    img/  （14ファイル）
form/
    send.php
    config.php
```

### 手順

1. ロリポップ管理画面 →「サーバーの管理・設定」→「ロリポップ！FTP」
2. `lp.one-hitter.jp` フォルダを開く
3. 画面上の「アップロード」から、**まず直下の5ファイル**を選んで上げる
   （`.htaccess` / `index.html` / `robots.txt` / `favicon.ico` / `apple-touch-icon.png`）
4. 「新規フォルダ作成」で `aircon` を作り、その中に入って
   `index.html` と `thanks.html` を上げる
5. `aircon` の中に `img` フォルダを作り、`aircon/img/` の10ファイルを上げる
6. `mizumawari` も同じ手順（`index.html` / `thanks.html` / `img` の14ファイル）
7. `form` フォルダを作り、`send.php` と `config.php` を上げる

### 注意：`.htaccess` について

- Windowsだと `.htaccess` が「名前のないファイル」に見えたり、
  エクスプローラーで隠れていたりします。表示設定で「隠しファイルを表示」にしてください。
- ロリポップ！FTPは `.htaccess` を**編集**もできます。アップロードでうまくいかない場合は、
  FTP画面で「新規ファイル作成」→ 名前を `.htaccess` にして、
  ZIP内の `.htaccess` の中身をコピー＆ペーストしてください。

## ⑤ 動作確認（ここまでやって完了です）

ブラウザで順に開いて、次を確認してください。**スマホで見るのがおすすめです。**

- [ ] `https://lp.one-hitter.jp/aircon/` が開く（**鍵マークが付いている**）
- [ ] `http://` で開いても `https://` に飛ぶ
- [ ] 写真がすべて表示される（グレーの箱になっていない）
- [ ] 料金シミュレーターで、選ぶと金額が変わる
- [ ] 下のバーの「電話」を押すと発信画面になる
- [ ] **フォームにご自身の名前と番号を入れて送信 → 完了画面が出る**
- [ ] **k-watanabe@one-hitter.her.jp と info@one-hitter.her.jp にメールが届く**
- [ ] `https://lp.one-hitter.jp/mizumawari/` でも同じことを確認

### メールが届かないときは

`form/config.php` の `from` に指定しているアドレスが、
**ロリポップ上に実在するメールアドレスである必要があります。**

1. ロリポップ管理画面 →「メール」→「メール設定/ロリポップ！Webメール」
2. `info@one-hitter.her.jp` と `k-watanabe@one-hitter.her.jp` があるか確認
3. 無ければ「新規作成」で作る
4. 迷惑メールフォルダも確認してください

宛先を変えたくなったら、`form/config.php` の3行を書き換えるだけです。

## あとから変えたくなったら

| やりたいこと | 触る場所 |
|---|---|
| 予約メールの宛先を変える | `form/config.php` |
| ASP・広告の計測タグを入れる | 各 `index.html` の `</head>` の直前。目印のコメントがあります |
| 検索結果にも載せたい | 各 `index.html` の `<meta name="robots" content="noindex,follow">` を削除 |
| 文言や写真を差し替える | このリポジトリの `lp/` を直して `python3 tools/build-site.py`、再アップロード |

## いま検索避けにしている理由

両LPには `noindex` を入れてあります。広告の受け皿なので、
公式サイト（one-hitter.jp）と「ワンヒッター」などの指名検索で
食い合わないようにするためです。SEOでも集客したい方針に変えるなら、
上の表のとおり1行消せば外れます。
