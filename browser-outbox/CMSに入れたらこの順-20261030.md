# CMSにログインが入ったら、この順でやる（browser・2026-10-30 時点）

CMSのセッションは**1時間ほどで切れる**。入ったら探索を後回しにして、上から止まらずに流す。
1件ごとに保存を確定させる（まとめて最後に保存しない）。

**CMSの保存ボタンは JavaScript の `.click()` が実行環境に弾かれる。**
`computer` の実際のクリックを使う。ボタンの座標を JS で測るのも弾かれることがあるので、
そのときはスクリーンショットから読む。

## 1. 出張費の言い切りが残っている2本を直す

**記事IDは公開URLの数字と一致しない。** `/_sys/contents/article/561/` の一覧で**題名を照合**してから開く。

### A. 題名「江戸川区のエアコンクリーニング事例｜作業の前に、壁と床と家具を覆います」（公開URL `20260924-1703`）

いまの文（「駐車について」の節）：

> お車を停める場所がない場合、コインパーキング代が実費になります。お見積りのときに金額の目安を出します。**出張費はいただいていません。**

**置換するのは最後の1文だけ。** `出張費はいただいていません。` を、次に差し替える：

```
対応エリアは東京都・千葉県・神奈川県です。遠方（目安：高速道路を使う地域）は、交通費をいただく場合があります。お見積りのお電話でご案内します。
```

### B. 題名「対応エリアと、ご依頼から作業までの流れ｜東京都・千葉県・神奈川県」（公開URL `20260924-1717`）

いまの文（「駐車について」の節）：

> **出張費はいただいていません。**ただし、お車を停める場所がない場合は、コインパーキング代が実費になります。お見積りのときに、金額の目安を出します。

**この記事は題名も本文も「対応エリアは東京都・千葉県・神奈川県」が主題**なので、
CMOの文の1文目をそのまま入れると同じことを二度言うことになる。**後半だけを入れる**：

```
遠方（目安：高速道路を使う地域）は、交通費をいただく場合があります。お見積りのお電話でご案内します。
```

→ 「駐車について **遠方（目安：高速道路を使う地域）は、交通費をいただく場合があります。お見積りのお電話でご案内します。**ただし、お車を停める場所がない場合は…」となり、
「ただし」の前後がつながらない。**Bは語順を入れ替える必要がある**ので、次の形にする：

> お車を停める場所がない場合は、コインパーキング代が実費になります。お見積りのときに、金額の目安を出します。遠方（目安：高速道路を使う地域）は、交通費をいただく場合があります。お見積りのお電話でご案内します。

**Bの扱いは cmo に出してある。** 返事があればそれに従う。無ければ上の形で入れて、入れた文をそのまま報告する。

- 数字と、それ以外の文は触らない
- 置換の前後で、古い文が0件・新しい文が1件あることを確認してから保存する
