# 売上台帳シートのアップグレード手順

対象スクリプト: `tools/sheet-upgrade.gs`
対象シート: **2026_売上/顧客情報管理**（今後も使うシート。過去年のシートは対象外）

## なぜスクリプトなのか

接続しているGoogle Driveツールは**読み取り・コピー・新規作成のみ**で、
既存スプレッドシートのセルを編集する機能がない（`update_file` はファイル名と保存先のみ変更可能）。
権限の問題ではない（2025年シートの権限を確認：`case.foot.kid@gmail.com` が owner）。

そのため、当方がスクリプトを書き、オーナーが実行する形をとる。
実行内容はすべてコードに書いてあるので、事前に読んで確認できる。

## 安全のための設計

1. **過去の記録を書き換えない。**
   プルダウンは「現在の最終行より下」にだけ設定する。既存行のセルには一切触れない。
   壊れている集計タブも削除せず、正しい版を**別タブ**として新規作成する。
2. **実行前にバックアップコピーを自動作成する。**
   `【バックアップ】<元の名前> <日時>` という名前で同じフォルダに作られる。
3. **2段階で動かす。** まず `shindan()` は読み取りのみ。検出結果を見てから `jikkou()`。

## 手順

1. 対象のスプレッドシートを開く
2. メニューの **拡張機能 → Apps Script**
3. エディタの中身を全部消して、`tools/sheet-upgrade.gs` の内容を貼り付け、保存（Ctrl+S）
4. 上部の関数リストで **`shindan`** を選び、**実行**
   - 初回は「承認が必要です」→ 自分のアカウントを選択 → 「詳細」→「（安全でないページ）に移動」→ 許可
   - ダイアログに検出結果が出る。月次タブの枚数・件数・列の検出状況を確認する
   - 「見つからない列」が出ていたら、そのまま `jikkou()` せずに連絡してください
5. 問題なければ、関数リストで **`jikkou`** を選び、**実行**
6. 確認ダイアログで OK → 完了ダイアログに結果が出る

## `jikkou()` が行うこと

| # | 内容 | 既存データへの影響 |
|---|---|---|
| 1 | バックアップコピーを作成 | なし |
| 2 | 各月次タブの最終行より下 600 行にプルダウンを設定 | なし（既存行には設定しない） |
| 3 | 「売上分析_v2」タブを新規作成 | なし（既存「売上分析」タブは未変更） |
| 4 | 「再販リスト」タブを新規作成 | なし |

### 2. プルダウンの中身

| 列 | 選択肢 |
|---|---|
| ＯＨ打診 | 未打診 ／ 打診済 ／ 反応あり ／ 成約 ／ 対象外 |
| フォローコール | 未 ／ SMS送信 ／ LINE送信 ／ 電話 ／ 返信あり ／ 再依頼 |
| 流入経路 | 既存の選択肢すべて ＋ LP(アフィリエイト) ／ 地図検索 ／ LINE/SMS再販 ／ Google口コミ |

自由入力も許可してあるので、選択肢にない値を入れてもエラーにならない。

**ＯＨ打診とフォローコールを TRUE/FALSE から選択式に変える理由：**
TRUE/FALSE だと「やったか、やっていないか」しか残らない。
打診は現場が様子を見て判断する属人的な行為なので、
「打診したが反応がなかった」と「そもそも対象外だった」を区別できないと、
何が効いたのかが後から分からない。

### 3. 売上分析_v2

月次タブの明細から毎回そのまま集計する。既存の「売上分析」タブとの違い：

- **9月を含む**（既存タブは9月の行が集計から丸ごと抜けている）
- **「早期予約」を「リピート」に合算しない**（既存タブは合算しているため早期予約の効果が見えない）
- `#REF!` などのエラーが残らない

既存タブは消さないので、数字を突き合わせてから、どちらを使うか判断できる。

### 4. 再販リスト

顧客ごとに最終施工日をまとめ、メニュー別の推奨サイクルで「そろそろ案内すべき人」に **★いま** を付ける。

| メニュー | サイクル |
|---|---|
| おそうじ定期便・定期清掃 | 1ヶ月 |
| トイレ・洗面台 | 6ヶ月 |
| それ以外（エアコン・浴室・換気扇・洗濯機 など） | 12ヶ月 |

推奨時期の2ヶ月前から ★いま が付く。「案内した日」列は手入力用に空けてある。

サイクルを変えたい場合は、スクリプト冒頭の `SAIHOU_CYCLE` と `SAIHOU_CYCLE_KITEI` を編集する。

## 元に戻したいとき

- プルダウン … 該当範囲を選択 → データ → データの入力規則 → すべて削除
- 追加されたタブ … 「売上分析_v2」「再販リスト」を右クリックして削除
- それでも不安な場合 … 手順1で作られたバックアップコピーを開く

## 注意

- `jikkou()` は何度実行しても構わない。「売上分析_v2」「再販リスト」は毎回作り直される
  （その2タブに手入力した内容は消えるので、「案内した日」を使う場合は別途控えを取ること）
- スクリプトは月次タブを **タブ名が「〇月」で始まり「売上」または「顧客」を含む** もので判定している。
  タブ名の付け方を変えている年に使う場合は `tsukiTabKa_()` の調整が必要。
