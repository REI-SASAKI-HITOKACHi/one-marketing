## 1 🔴 `C_ハウスクリーニング`（9語・CPC300）には、着地先が存在しない

**いま飛ぶ先**：`lp.onehitter.jp/mizumawari/`
**そのLPの1行目**：「**水まわりは、まとめて頼むほど安い。**」
**主役の価格**：浴室＋キッチンの2箇所で 33,660円

対象キーワード：`ハウスクリーニング` `ハウスクリーニング 江戸川区` `〜西葛西` `〜葛西` `〜浦安` `〜市川` `〜江東区` `〜墨田区` `〜葛飾区`

### なぜ駄目か

**「ハウスクリーニング」で検索する人は、何を頼みたいか決まっていない。**
家全体、引っ越し前後、水まわり、エアコン、レンジフード——**どれの可能性もある。**

そこに**「水まわり2箇所セット」の1枚ページ**を出すと、

- 家全体を考えていた人 … **自分の求めているものが無いと判断して帰る**
- エアコンだけ考えていた人 … **同上**（エアコンLPは別にあるのに、そこへは行けない）

**当社には「ハウスクリーニング全般」を受け止めるLPが無い。**
`lp/` にあるのは `aircon`（エアコン単品）と `mizumawari`（水まわりセット）の2枚だけ。

### 決定

**`C_ハウスクリーニング` は一時停止のまま、配信しない。**

`ハウスクリーニング` は単語として**いちばん検索数が多く、いちばん競合が高い**帯でもある。
**受け止める場所が無いまま買うのは、いちばんもったいない買い方。**

**再開の条件**：メニュー全体を見せて、そこから各LPへ分岐させるページを1枚作る。
（公式サイトがその役割だが、**計測タグと予約フォームがLP側にしか無い**ので、LPとして作るほうが早い）

## 2 🔴 LINEで申し込まれると、コンバージョンが0になる

### 事実

両LPが、ファーストビューでLINEを推している。

| LP | 文言 | LINEへの導線 |
|---|---|---|
| `mizumawari` | 「**LINEからご予約・ご相談いただいた方には、防カビコーティングを無料**でお付けしています」 | 5箇所 |
| `aircon` | 「**LINEご登録の方には、防カビコート（通常3,630円）を無料**でお付けしています」 | 4箇所 |

そして `aircon` のファーストビューのボタンは **2つ並んでいる**：

```
[ かんたん5項目でWEB予約する ]  [ LINEで無料クーポンを受け取る ]
```

### 何が起きるか

**計測しているコンバージョンは2つだけ**（計測担当が 9/15 に実測）。

- 申込（フォーム送信） `AW-18450975194/e-nVCPqV2PccENqTjt5E`
- 電話タップ `AW-18450975194/2qAcCOiw3fccENqTjt5E`

**LINEタップは計測されていない。**

つまり、**無料特典で LINE へ誘導しておきながら、そこから来た申し込みは
Google広告の成果として1件も記録されない。**

### なぜこれが「金を溶かす」なのか

**10月1日に、CPAと受注単価で継続・停止・増額を決める**ことになっている。
そのとき、**LINE経由の受注が数字に入らない。**

- 実際は効いているのに「CVが少ない」と見える
- **効いている広告を止める判断をしかねない**
- 逆に、CV0を理由に予算を絞ると、**当たっていたキーワードを捨てる**

**広告費より、判断を誤ることのほうが高くつく。**

### 決定

**`LINEタップ` のコンバージョンを足す。**電話タップと同じ作りでできる。

- **主要コンバージョンにはしない。**LINE登録＝受注ではないので、
  申込・電話と同じ重みにすると CPA が実態より良く見える
- **サブアクションとして計測だけする。**「LINE経由が何件あったか」が分かれば、
  10/1 の判断のときに**申込・電話の数字に足して考えられる**

**これが入るまで、配信は開始しない。**

## 6 🟢 除外キーワード18語：妥当。**ただし初週に足す前提**

```
自分で／やり方／方法／DIY／洗浄スプレー／求人／バイト／募集／資格／開業／
フランチャイズ／業務用／賃貸 退去／空室／原状回復／
おそうじ本舗／くらしのマーケット／ユアマイスター
```

- **DIY系**（自分で・やり方・方法・DIY・洗浄スプレー）… 買う気が無い人。正しい
- **求人系**（求人・バイト・募集・資格・開業・フランチャイズ）… 客ではない。正しい
- **空室・原状回復・賃貸 退去** … **オーナー決定（9/14）「完全なる悪手。超薄利で下手したら逆鞘」**で受けない。正しい
- **競合指名**（おそうじ本舗・くらしのマーケット・ユアマイスター）…
  **本舗は自社名義の入口を作る目的に反する。**他社指名は単価が合わない。正しい

### 足すかもしれないもの（**初週の検索語句を見てから**）

`相場` `口コミ` `評判` `ランキング` `比較` `安い 順` — **情報収集の段階**で、まだ買わない。

**いま足さない理由**：フレーズ一致なので、そもそも流入が限られる。
**推測で削ると、当たっていたかもしれない語まで消える。**
**実際に何で来たかを見てから足すのが正しい順番。**
