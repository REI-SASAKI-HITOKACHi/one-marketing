# `info@one-hitter.her.jp` のメールを、スレッドからも読めるようにする

作成 2026-09-11 ／ 計測担当（職務5）
**結論：できます。ロリポップの管理画面で5分。費用0円。元に戻せます。**

---

## なぜ要るのか

**いま、先方からのメールがスレッドから読めません。**

レントラックス（西村様）・KDDI（内野様）・リアライズからの連絡は、すべて
`info@one-hitter.her.jp` に届きます。このアドレスはロリポップのメールで、
スレッド側からは中身が見えません。

実際、2026-09-11 に「レントラックスからメールが届いている」とオーナーから
依頼を受けましたが、**渡されたのはKDDIのメールでした。**
こちらで原本を確認できていれば、その場で気づけた取り違えです。

**Googleアカウント `case.foot.kid@gmail.com` に届くようになれば、スレッドから読めます。**

---

## やり方は2つ。おすすめは A

| | 仕組み | 反映の速さ | 懸念 |
|---|---|---|---|
| **A（推奨）** | ロリポップ側で**転送**する | **即時** | ロリポップは外部転送を「非推奨」としている（後述） |
| B | Gmail側が**取りに行く**（POP取得） | 数分〜数十分の遅れ | 遅い。ただし懸念なし |

**Aで始めて、問題が出たらBに切り替える**のがよいと思います。
**どちらも、いつでも元に戻せます。**

---

# A. ロリポップで転送する（5分）

## 手順

1. ロリポップの **ユーザー専用ページ** にログインする
   - ログイン情報は、Googleドキュメント「ワンヒッター_認証情報（ここだけ）」にあります
2. **[メール設定／ロリポップ！webメーラー]** を開く
3. 一覧から **`info@one-hitter.her.jp`** の行を探し、**[確認・変更]** をクリック
4. **転送先のメールアドレス**の欄に、次を入力する

   ```
   case.foot.kid@gmail.com
   ```

5. **[サーバーに残す]** を **有効（残す）** にする ← **ここが重要**
6. **[更新]** をクリック

## ⚠️ 手順5を必ず有効にしてください

**「サーバーに残す」を無効にすると、転送した時点でロリポップ側からメールが消えます。**
Gmail側で迷惑メール判定されたり、受信に失敗したりすると、**原本がどこにも残りません。**

有効にしておけば、これまでどおり `info@` でも読めます。**転送は「複製を送る」だけ**になります。

## 補足

- **転送先は5件まで**登録できます。渡辺さんのアドレスなどを足すことも可能です
- 解除は、転送先の欄を**すべて空欄にして [更新]** するだけです

## ロリポップが「非推奨」としている理由と、その対処

ロリポップの公式マニュアルには、外部への転送について次の趣旨の注意があります。

> 受け取ったスパムメールを含む**すべてのメール**が転送先に送られるため、
> 送信元としての評価が下がり、転送先のサーバーに受信拒否される可能性がある

**対処：**

- **手順5（サーバーに残す）を有効にしておけば、拒否されても原本は失われません**
- Gmail側の迷惑メールフィルタが効くので、実用上の問題はほぼ出ません
- もし Gmail が受け取らなくなったら、**Bに切り替えてください**

# B. Gmail が取りに行く（POP取得）

**転送ではないので、送信元の評価が下がる心配がありません。**
そのかわり、届くまでに数分〜数十分の遅れが出ます。

## 事前に要るもの

`info@one-hitter.her.jp` の **メールパスワード**と、**受信サーバー名（POP3）**。
どちらもロリポップの **[メール設定／ロリポップ！webメーラー]** で確認できます。

## 手順

1. `case.foot.kid@gmail.com` で Gmail を開く
2. 右上の**歯車** → **[すべての設定を表示]**
3. **[アカウントとインポート]** のタブを開く
4. **[他のアカウントのメールを確認]** の **[メールアカウントを追加する]** をクリック
5. `info@one-hitter.her.jp` を入力して **[次へ]**
6. **[他のアカウントからメールを読み込む（POP3）]** を選んで **[次へ]**
7. ユーザー名・パスワード・POPサーバー・ポートを入力
   - **[受信したメッセージのコピーをサーバーに残す]** に**チェックを入れる**
   - **[メールの取得にセキュリティで保護された接続（SSL）を使用する]** に**チェックを入れる**
8. **[アカウントを追加]** をクリック

---

# どちらでも、そのあとに効いてくること

**設定が済むと、スレッド側から次ができるようになります。**

- レントラックス・KDDI・リアライズからのメールを、**原本で**確認できる
- 「メールが届いた」と言われたときに、**どのメールかを取り違えない**
- 先方への返信案を、**引用つきで**正確に作れる
- やり取りの記録（`docs/アフィリエイト-レントラックス.md` 末尾）を、**こちらで追記できる**

## 実行の判断について

**この設定は元に戻せる**（転送先を空欄にして更新するだけ）ので、
CMOの判断で実行してよい範囲だと理解しています（`20260911-04-measurement` の職務5）。

**ログイン情報はこちらに書き戻していません。** 認証情報ドキュメントを参照してください。
