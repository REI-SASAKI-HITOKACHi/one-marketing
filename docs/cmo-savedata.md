- **コピーして使うテキスト（メール文面・貼り付け原稿など）は、必ずコードブロックに入れる。**

  番号を避けるのではなく、コードブロックに入れて番号を守るのが正解

- **Outlookは操作できない。** このセッションにOutlook／Microsoft 365のツールは無い

  **KDDIとのやり取りはGmailに存在しない**（2回検索して0件）。Outlook側にある

  **Gmailに取り込める見込みがある**

### 進め方（オーナーの明示的な指示）

- **承認を求める回数を最小化する。労力よりも成果を優先する。**

## 3. 実行環境でできること・できないこと（実測済み）

### ブラウザが使えるかは「クラウドかローカルか」で決まる（2026-09-07 確認）

- このスレッドを含む `anthropic_cloud` の環境では、**ブラウザが外部に出られない**
  （curl・API・DNSは通る。Chromiumだけ `ERR_CONNECTION_RESET`）
- `bridge`（オーナーのPC上で動くClaude Code）のスレッドでは**ブラウザが使える**。
  ConoHaやGitHubのログインを画面で対応してもらえていたのは、すべてこちら
- **実行環境はセッション作成時に決まり、あとから切り替えられない**
- 管理画面へのログインが要る作業は、その分だけローカルのスレッドを立てること
- 詳細は `docs/スレッドの実行環境とブラウザ.md`


| | 可否 |
|---|---|
| HTTPS（curl / API） | **○** |
| WebFetch / WebSearch | ○（ただしJSレンダリングのページは中身が取れない） |
| Chromiumで外部サイト | **×** 接続リセット。google.comもexample.comも不可 |
| 素のTCP（FTP:21 / SSH:22） | **×** タイムアウト |
| ブラウザ画面をオーナーに見せて操作してもらう | **×** そもそも画面を送る仕組みがない |
| `.claude/settings.json` への書き込み | **×** 分類器がブロック（自己権限付与の禁止） |

**画面が必要な作業は、オーナーが別環境でやる。** それ以外はAPIで到達できる。

- **防止策（実装済み）**：①`build-sms-list.py` が1行ずつ台帳の最新名義と照合し、食い違い・不明は送信可にしない（`meigi_hyou()`）②文面の両方向検査（自社にワンヒッターの名乗りが無い／本舗にワンヒッターが混ざる）③規則を `CLAUDE.md` 禁止・`docs/org/README.md` 4.5・crm役割に明記 ④crmの `sms_build.py --check` にも同じ照合を入れる依頼
- **送信済み3名**：取り消せない。返信が来たら本舗として対応（和真さんに伝達済み）
- **教訓**：**派生した列は、元データから作り直せる形（コード）で持ち、使う直前に元データと照合する。** 「以前そう作った」を信じない。

### 教訓

> **「できない」と言う前に、別プロトコル・別API・権限の見直しまで潰す。**
> ブラウザが使えないことは、その手段が使えないというだけで、目的が達成できない理由にはならない。

その他の失敗：

- 子エージェントの作業ディレクトリが衝突し、別の年のデータが返ってきた
  → **必ず独立したディレクトリを指定し、検証ステップを入れる**
- QRを「ラミネートして携行」と誤解 → 実際は**スマホ画面で見せる運用**
- 年末LPのレンジフードの組写真が、**別物のフィルターをBEFORE/AFTERとして並べていた**
  （BEFOREは白い樹脂枠、AFTERは金属枠）。組写真をやめて単独写真に変更した。
  → **組写真は必ず1組ずつ拡大して同一箇所か確かめること**
- 09/03の店舗床の写真を「店舗が判別できないので使える」と棚卸ししていたが、
  **什器に Off-White のロゴが読み取れた**。→ **「特定できない」と書く前に拡大して確かめること**
- 画像の表示確認で `naturalWidth===0` を見て「19枚が壊れている」と誤判定した。
  原因は **lazy 読み込みの画像がまだ読まれていなかっただけ**。
  → **lazy を解除してスクロールさせてから判定すること**
- アンケートの配信設計を「完了報告と連動してSMS」と誤解
  → 実際は**現場で直接依頼**（完了報告は帰りの車の中で、別タイミング）
- スプレッドシートに数値として書き込み、電話番号の先頭0が800件消えた
  → **書き込む前に表示形式をテキストにする**
