# パンフレット価格は税込か税抜か（調査結果）

調査日: 2026-09-06 ／ 調査者: CMO（Claude）
対象データ: 2026年 1〜12月_売上/顧客 タブ 全319取引、見積ルールタブ、パンフレットPDF

## 結論

**パンフレットの価格は「税込」です。** 以前「税抜」と判断して
「10,780円（税抜9,800円を併記）に統一する」と決めましたが、**その判断は誤りでした。**
実際の請求データを全件で見直したところ、逆の結論になりました。

このまま10,780円に統一すると、**気づかないうちに全メニューを10%値上げする**ことになります。

## 根拠1：早期予約割引の計算が、パンフレット価格を「最終価格」として扱っている

これが決定的です。早期予約チャネルの請求額は、パンフレット価格から
**そのまま割引率を掛けた金額**になっていて、消費税を足す処理がどこにも入っていません。

| 実際の請求額 | 件数 | 計算式 |
|---|---|---|
| 13,430円 | 8件 | 15,800 × 1台 × 0.85（15%引き） |
| 14,280円 | 8件 | 16,800 × 1台 × 0.85 |
| 16,660円 | 5件 | 9,800 × 2台 × 0.85 |
| 8,330円 | 5件 | 9,800 × 1台 × 0.85 |
| 26,860円 | 4件 | 15,800 × 2台 × 0.85 |
| 28,560円 | 2件 | 16,800 × 2台 × 0.85 |
| 24,990円 | 2件 | 9,800 × 3台 × 0.85 |
| 41,650円 | 2件 | 9,800 × 5台 × 0.85 |
| 14,220円 | 2件 | 15,800 × 1台 × 0.90（10%引き） |

上位12パターンのうち9パターンが、この式で1円単位まで一致します。
1件の備考には「15%引きノーマル1」と手書きで残っており、8,330円と対応しています。
**もしパンフレット価格が税抜なら、ここは 9,800×1.1×0.85＝9,163円 になっていたはずです。**

## 根拠2：オプション価格の11項目が、そもそも「税込の形」をしている

パンフレットのオプション欄には、**きりのいい数字の1.1倍**がそのまま並んでいます。
税込で価格表を作ったときに出る典型的な数字です。

| 掲載価格 | 税抜に戻すと |
|---|---|
| 1,100円（防虫キャップ） | 1,000円 |
| 3,300円（防カビコート・浴室換気扇・鏡の水垢 ほか） | 3,000円 |
| 5,500円（室外機セット・コンロセット） | 5,000円 |
| 7,700円（エプロン内部高圧洗浄） | 7,000円 |
| 19,800円（お掃除時短コーティング） | 18,000円 |
| 52,800円（空室清掃） | 48,000円 |

**これらをさらに1.1倍すると、二重に消費税を乗せることになります**
（例：防カビコート 3,300円 → 3,630円）。

## 10,780円は何だったのか

10,780円（＝9,800×1.1）の請求は実在しますが、**全319件中5件だけ**です。
うち3件は「楽ラクーン」（マッチングプラットフォーム経由）で、
プラットフォーム側の価格体系です。自社直販は2件（2026/08）のみでした。

自社直販の主力価格帯はむしろ **11,000円・12,100円・13,200円・14,300円・17,600円・19,800円** で、
これらは 10,000円・11,000円・12,000円・13,000円・16,000円・18,000円 という
**きりのいい税抜額の1.1倍**です。つまり現場は「税抜のきりのいい額を決めて1.1倍する」
やり方と、「パンフレット価格をそのまま使う」やり方を、**チャネルごとに使い分けています。**

## 総額表示義務との関係（ここは変わらず対応が必要）

2021年4月1日から、消費者向けの価格表示は**税込の総額表示が義務**です
（財務省・国税庁で確認済み。財務省の適合例そのものが「10,780円」という表記）。

パンフレットが税込なら、**金額そのものは変えなくてよい**のですが、
**「（税込）」の表記がどこにも無い**のは今のままだと不親切で、誤解のもとです。
いま起きている社内の混乱そのものが、その証拠と言えます。

## 推奨する対応

1. **金額は変えない。** 9,800円のままにする。値上げは、やるなら値上げとして別途判断する。
2. **表記だけ直す。** 「9,800円（税込）」と全メニューに明記する。
   パンフレット・公式サイト・LP・見積書のすべてで統一する。
3. **繁忙期加算も税込で明記。** 「5〜7月・12月は +3,300円（税込）」
4. **見積ルールタブに1行足す。** 「掲載価格はすべて税込。割引は税込価格に対して掛ける」
   — チャネルごとの使い分けが起きている原因は、この1行が無いことです。
5. 過去の請求は**書き換えない**。記録は記録として残す。

## この調査で分かった副産物

- 見積ルールタブの早期予約割引（1-2月:15%／3-4月・8-10月:10%）は、
  アンケートに実装した割引バンドと**一致していました**。実装は正しい。
- 紹介料の規定も別にあります（1-2月:5%／その他:10%）。
  これは「紹介した人への還元」で、アンケートに入れた「次回1,000円割引」とは別枠です。
  **どちらが正なのか、または併存するのかは要確認。**
