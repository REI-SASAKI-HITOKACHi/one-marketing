## 2. 前の版（9/27）のイマイチだったところ

### チラシ（`print/chirashi/`）
1. **「近所でやった」が弱い。** 上の帯の小さな一文だけで、主役は「分解洗浄」のメニュー名。ポストから出した3秒で「なぜうちに入っているのか」が伝わらない
2. **主役が無い。** 写真・料金表・QR が同じ強さで3段に並び、目が止まる場所がない
3. **写真の力が弱い。** 吹き出し口とフィルターのアップで、小さく暗い。養生テープの緑が目立ち、汚れの「量」が伝わらない
4. **信頼の材料が足りない。** Googleクチコミ★5.0 が入っていない。98.6% は注記が長く、数字の意味が後ろに回っている
5. **メニューが3つだけ。** キッチン・洗濯機が無い。12月の加算は小さな注記に埋もれ、「今のうちに」の理由になっていない

### 紹介カード（`print/shokai-card/`）
1. 表の半分が「ハウスクリーニングのワンヒッターです」で、いちばん大事な **1,000円引き が小さい**
2. **何を頼めるか・いくらかが無い。** 渡された人が値段の見当をつけられない
3. 写真も図も無く、名刺のような事務的な見た目。渡された人の記憶に残らない
4. 左の青い帯は飾りで、何も伝えていない

## 3. 作り直した案（`print/an/`）

| 案 | 狙い（1行） |
|---|---|
| **チラシA「施工のお知らせ」**（片面） | 近所の掲示物の形にして、和真さんが日付とチェック1つで「今日この近くで○○を掃除した」を示す。**近所の証拠を最優先** |
| **チラシB「料金表」**（片面） | 6つのメニューを前後写真＋価格の札にして、**何がいくらかを3秒で**。まとめ頼みの 15,180円 を大きく |
| **チラシC「1枚の写真」**（両面） | 表は「エアコンを洗ったあとの水」の写真1枚で**手を止めさせ**、裏で料金・証拠（ATP測定・98.6%・★5.0）・頼み方を全部 |
| ~~紹介カードA・B~~ | 10/3 オーナー「全然ダメ」→ 下の C・D に差し替え |
| **紹介カードC「チケット」** | 券の形（左が券面・右が名前を書く控え）。**2秒で「1,000円引きの券」と分かる** |
| **紹介カードD「ひと言」** | 表の主役を紹介する人の言葉「わたしが頼んで、よかったお掃除屋さんです。」に。**友だちから手渡される物として自然に** |

紹介カードの裏はC・D共通：「ご予約は、この2つのどちらかで」①QRで空き日を選ぶ ②「ご要望」に紹介者名／電話（14pt）／4メニューの価格／紹介した方も次回1,000円引き／★5.0。

### 紹介カードA・B がダメだった理由（design-critique の枠組みで）
| 観点 | A・B の問題 | C・D での直し |
|---|---|---|
| 最初の2秒 | 濃紺の面に小さな文字と大きな空白。何のカードか分からない（A）。汚れた洗濯槽の写真は、友だちから渡される物として気持ちよくない（B） | 券の形／紹介する人の言葉を主役に。写真は使わない |
| 読む順番 | 割引・名前欄・社名が同じ強さで散らばる | 券面は「初回のお掃除が → 1,000円引き」の1本道 |
| 読みやすさ | 裏の文字が 5〜6pt、QR 17mm、電話が小さい | 最小 6.4pt、QR 20mm、電話 14pt |
| 誰に向けた文か | 受け取る人と渡す人への文が混ざる | 表＝受け取る人、裏の一番下＝渡す人 |

### 共通で直したこと
- 書体：見出しは丸ゴシック（Zen Maru Gothic。近所の人に硬すぎない）、本文はUD書体（BIZ UDPゴシック。年配の方にも読みやすい）、数字は詰めた欧文（Barlow Semi Condensed）
- 色：LP v2 と同じ濃紺 `#0D3B5C`・価格の赤 `#C0300C`・黄マーカー。LPに飛んだときに同じ会社に見えるように
- QR：独自ドメインの予約ページ。**案ごとに cid を変えた**（`?src=chirashi&cid=a/b/c`、`?src=shokai&cid=c/d`）。合格した案だけ刷るが、複数案を刷り分けたときにも、どれが効いたかを数えられる
- 写真：LPで公開済みのもの。黒い水（エアコン）・洗濯槽・浴室の床下（エプロン内）・ATPの数値表示。本舗のロゴ・社名・番号、お客様の名前は写っていない

### 守ったこと（前の版と同じ）
- 金額は `data/prices.json` から読む（price-master が正）。手で打っていない。12月の加算（3,300円）は明記し、**早期予約の割引率は載せていない**（10/3 のMTGで確定するため。確定したらA・Cの「11月中のご予約がおすすめ」の行に足せる）
- 98.6%（209名中206名）・Googleクチコミ★5.0（23件・2026年9月時点）。98.8% は使っていない
- 電話 080-8043-8259
- 「出張費込み」は書かない（LPと同じ。裏付けの記録が無い）
- 追い焚き配管の 42,194 → 409 は「実際の測定例。数値は条件で変わる」と添えた（LPと同じ扱い）
- 範囲の書き方はLPの施工内容に合わせた（キッチン＝シンク・天板・壁面。コンロは別メニュー）

### 検査（`make-print-an.py` が毎回する）
- 3書体が読み込めているか（代替フォントの見た目で判断しないため）
- 文字が仕上がり線から内側にあるか（チラシ 5mm以上・カード 3mm以上）／枠からあふれていないか
- QRを読み取って、5案とも予約ページの正しいURLになることを確認（10/3）。飛び先は `check-public-page.py` OK

## 4. 気になっている点（合否の前に知っておいてほしいこと）
- **チラシCの表の写真は、元が1200pxで少しブレている。** A5いっぱいに伸ばすと約200dpiで、刷ると甘く見える。Cが選ばれたら、和真さんに黒い水の写真を明るい場所で撮り直してもらうのが確実
- **チラシAは、和真さんが配る前に日付とチェックを手書きする前提**（1枚5秒ほど）。手間なら、空欄のまま配っても成り立つ作りにしてある
- 両面（C）は片面より印刷代が上がる。予算（2点合計¥5,000以内）に収まるかは、発注先の見積りで確認が要る
