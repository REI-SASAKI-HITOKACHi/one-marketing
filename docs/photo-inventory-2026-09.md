## 型ごとの推し

### 型A（ビフォーアフター）— 上の組から3つ

1. **IMG_8033 → IMG_8038**（吹き出し口。黒カビの筋 → 白）
2. **IMG_8031 → IMG_8039**（熱交換器。灰色 → 銀色）
3. **IMG_8029 → IMG_8034**（ルーバー。前をトリミングして寄せる）

### 型B（汚水）— 今回は2枚しか無い

1. **IMG_8041**（9/9）。黒い水に泡。バケツだけに寄せれば強い
2. **IMG_8023**（9/8）。上端を切る。どの台の汚水かは分からないので、添える文は「エアコン1台ぶん」のような断定を避け「この日の作業で出た水」に留める

## 再現方法

Drive MCP の `download_file_content` は base64 のJSONを返す。3MB超は自動でファイルに退避されるので、
それをデコードして `assets/photos-raw/2026-09/` に置き、Pillow で `exif_transpose → 長辺1600 → q85（EXIFなし）` で保存した。
サービスアカウント鍵があるときは `python3 tools/drive_client.py sync 1m4XvurFi1vZh6YAoQ6S5xeHxcq4nApLh assets/photos-raw/2026-09` のほうが速い。
