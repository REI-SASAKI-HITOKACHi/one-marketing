## 1. 何のための10本か

**「107件に出して、人からの返事が1件も来ていない」理由を知るため**です。売り込みではありません。

いまの記録から分かるのは、ここまでです。

| | |
|---|---|
| 出した先 | 107件（フォーム57・メール50） |
| 生きている接触 | **101件** |
| 人が書いた返事 | **1件**（断り。「当社店舗ではございません」） |
| 機械の自動受付 | 9件 |
| 設置OK | **0件** |

**メールとフォームの記録からは、「届いていないのか／届いて興味が無いのか」が永久に分かりません。**
返信率が2%だとしても、101件で0件は**8回に1回は起きます**。だから**数字を積んでも分かれません。**
**10本の電話でしか取れない情報です。**

## 5. かけたあとに、この3つだけ控えてください

紙でもメモアプリでも構いません。**あとで私が台帳に入れます。**

1. **届いていたか**（届いていた／届いていない／分からない）
2. **出た人が、決められる人だったか**（店長・院長が出た／アルバイトが出た／不在）
3. **相手が言ったことを、そのまま一言**（「そういうのは本部が決めるので」など。**要約せず、言われたとおりに**）

**3番がいちばん大事です。**理由がここにしか出ません。

## 6. 決めごと

- **かける時間**：平日の **10:00〜12:00 か 14:00〜17:00**。12〜13時は外す。動物病院は診療時間中なので、**午後の早い時間**が通りやすい
- **売り込みにしない。** 目的は「届いたかを確かめること」です。断られたら引く
- **金額を言わない。** 今回の案内は「置いてもらうお願い」で、費用はこちら持ちです
- **「点検」「無料点検」を口にしない。** 無料点検は洗濯槽と追い焚き配管の別企画で、この話とは関係ありません
- **折り返し先を聞かれたら 080-8043-8259。** この10件は本舗の取引先ではないので、**本舗の番号は出しません**
- **今後の案内が不要と言われたら、その場で承諾する。** 私が台帳を「対象外（断り）」にします
- **10本かけきらなくて構いません。** A群4本だけでも、いちばん知りたいことは分かります

## 7. この10本で決まること

| 結果 | 読み方 | 次にやること |
|---|---|---|
| **A群も「届いていない」** | 送信の仕組みが壊れている | フォーム送信の検証をやり直す |
| **届いているが、覚えていない／読んでいない** | 件名か差出人で捨てられている | 件名と差出人名を変えて、次の50件で比べる |
| **読んだが、置く気にならない** | **企画そのものが弱い** | カードの見た目と「何が得か」を作り直す |
| **本部の許可が要る** | 個店に出しても決まらない | チェーンの本部に1社ずつ出す形に変える |
| 1〜2件でも「置いてもいい」 | **文面の問題ではない**（単に量が足りない） | 残りのメール68件を出し切る |

**どれになっても、いまより進みます。**
