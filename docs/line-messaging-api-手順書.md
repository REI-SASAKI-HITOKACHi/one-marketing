## 0. 最初に必ず読んでください（元に戻せないこと）

この作業には、**あとから取り消せない部分が1つだけ**あります。

| 項目 | 内容 |
|---|---|
| プロバイダーの紐づけ | LINE公式アカウントと「プロバイダー」の組み合わせは、**一度決めると二度と変更できません。** 別のプロバイダーに移すことも、紐づけを解除することもできません。 |

そのため、**プロバイダー名は必ず次のとおりにしてください。**

> ### プロバイダー名: `ワンヒッター株式会社`

理由は2つです。

- プロバイダー名は、場面によって利用者（お客様）の画面に表示されることがあります。個人名や「ささき」「テスト」などにすると、そのままお客様に見えてしまう可能性があります。
- 代理店やツール会社が用意したプロバイダーの下に作ってしまうと、あとで自社に移せません。**必ず自分で新規作成**してください。

これ以外の設定（トークンの発行、Webhookのオンオフなど）は、あとからいくらでもやり直せます。

## 1. 準備するもの

- **パソコン**を使ってください。スマホの「LINE公式アカウント」管理アプリからはこの設定はできません。
- LINE公式アカウントの**管理者権限**を持つLINEアカウント（＝いつも管理画面にログインしているアカウント）
- スクリーンショットを保存するための Googleドライブ

## 2. 有効化する前に、今の状態を写真に残す（手順1〜10）

Messaging APIを有効にすると、あいさつメッセージや自動応答の設定が変わってしまう可能性があります。
公式のマニュアルには「既存のアカウントの設定がどうなるか」がはっきり書かれていません（`docs/line-api-setup.md` §7で「要確認」としている点です）。

**万一変わってしまっても元に戻せるように、先に今の状態をスクリーンショットで残します。**
ここを飛ばすと、変わったことにすら気づけません。5分で終わるので必ずやってください。

1. パソコンのブラウザで https://manager.line.biz/ を開く。
2. いつも使っているLINEアカウントでログインする。
3. アカウントの一覧から「**ワンヒッター**」（ご自身の公式アカウント名）をクリックする。
4. 画面の上のほうにある「**設定**」をクリックする。
5. 左側のメニューから「**応答設定**」をクリックし、**画面全体のスクリーンショットを撮る**。
   - 「あいさつメッセージ」「応答メッセージ」「チャット」などのオン・オフのスイッチが写るようにしてください。
6. 左側または上部のメニューから「**あいさつメッセージ**」を開き、**今の文面が全部写るようにスクリーンショットを撮る**。
7. 同じように「**自動応答メッセージ**」を開き、**登録されている内容が全部写るようにスクリーンショットを撮る**。
   - 複数登録されている場合は、面倒でも全部撮ってください。
8. 撮った画像をGoogleドライブに保存する。フォルダ名は `LINE_有効化前_2026-09` のように、日付が分かる名前にする。
9. 「**設定**」＞「**利用と請求**」を開き、**今の料金プラン名をメモする**（例: コミュニケーションプラン）。
10. 「**ホーム**」または「**分析**」を開き、**今の友だちの人数をメモする**。

> 補足: 手順9と10は、あとで「通数が足りるかどうか」を判断するために使います。
> 手順5〜7のメニュー名は、LINE側の画面更新で少し違う表記になっている場合があります。
> 見当たらないときは「設定」の中を上から探してください（**要確認**: 現行画面の正確な項目名までは公式マニュアルで確認できていません）。

## 3. Messaging APIを有効にする（手順11〜18）

ここが本番です。**手順15のプロバイダー名の入力だけ、特に慎重に**お願いします。

11. 引き続き LINE公式アカウントマネージャー（https://manager.line.biz/）の画面で、上部の「**設定**」をクリックする。
12. 左側のメニューから「**Messaging API**」をクリックする。
13. 「**Messaging APIを利用する**」というボタンをクリックする。
14. **（初回だけ）**「開発者情報の登録」という画面が出たら、**名前**と**メールアドレス**を入力して次へ進む。
    - ここで登録するのは「LINE Developers」という開発者向けサイトのアカウントです。無料です。
    - 名前は `佐々木` などご自身の名前、メールアドレスはいつも使っているもので構いません。
15. 「プロバイダー」を選ぶ画面が出るので、「**新規作成**」（または「プロバイダーを作成」）を選び、名前の入力欄に次のとおり**一字一句そのまま**入力する。

    ```
    ワンヒッター株式会社
    ```

    - **ここは二度と変更できません。** 入力したら、送信する前にもう一度読み直してください。
    - 既存のプロバイダーが一覧に出てきても、**選ばないでください**（心当たりのないものは、過去に業者が作ったものの可能性があります）。
16. 内容を確認して「**同意する**」をクリックする。
17. 確認画面が出るので「**OK**」をクリックする。
18. 画面のステータスが「**利用中**」に変わったことを確認する。→ これで有効化は完了です。

## 4. 鍵（チャネルアクセストークン）を発行する（手順19〜27）

CMO側からクーポン配布などを自動で動かすには、「**チャネルアクセストークン**」という長い文字列が必要です。
これは**この公式LINEアカウントの合鍵**だと思ってください。持っている人は、友だち全員にメッセージを送れてしまいます。

19. ブラウザで https://developers.line.biz/console/ を開く。
20. **手順2でログインしたのと同じLINEアカウント**でログインする。
    - 違うアカウントでログインすると、作ったチャネルが表示されません。
21. 画面に表示されたプロバイダー「**ワンヒッター株式会社**」をクリックする。
22. その中にある**Messaging APIのチャネル**（公式アカウント名が付いているもの）をクリックする。
23. 「**チャネル基本設定**」タブをクリックし、「**チャネルID**」と「**チャネルシークレット**」がどこに書いてあるかを確認しておく（この時点ではまだコピーしません）。
24. 「**Messaging API設定**」タブをクリックする。
25. 画面を下までスクロールして、「**チャネルアクセストークン（長期）**」という欄を探す。
26. その欄にある「**発行**」ボタンをクリックする。
    - **要確認**: 公式ドキュメントには「Messaging API設定タブから発行できる」とだけ書かれており、ボタンの正確な文言までは記載がありません。「発行」または「Issue」といった表示のボタンです。
27. 長い英数字の文字列が表示されたことを確認する。**この画面は開いたまま**にして、次の第5章に進む。

> このトークンは**無期限**で使えます。1つのチャネルにつき1つだけ持てます。
> 再発行すると、前のトークンは使えなくなります（万一漏れたときは再発行すれば無効化できる、ということです）。

## 5. 鍵の渡し方（手順28〜36）

**絶対にやってはいけないこと: トークンをチャットやメールの本文に貼り付けること。**

理由: チャットやメールの履歴は消せません。あとから誰の目に触れるか分からない場所に、合鍵をそのまま置くのと同じだからです。
代わりに、**オーナーのGoogleドライブに「限定公開」の文書を作り、そこに貼り、URLだけを共有します。** URLだけなら、閲覧を許可された人以外は開けません。

28. 新しいタブで https://drive.google.com/ を開く。
29. 左上の「**新規**」＞「**Googleドキュメント**」をクリックする。
30. 文書のタイトルを次のとおりに変更する。

    ```
    LINE_チャネルアクセストークン
    ```

31. 右上の「**共有**」をクリックし、「一般的なアクセス」が「**制限付き**」になっていることを確認する。
    - 「リンクを知っている全員」になっていたら、必ず「**制限付き**」に変更してください。ここが一番大事です。
32. 「共有」画面の「ユーザーやグループを追加」に、次のアドレスを入力して「**閲覧者**」で追加する。

    ```
    claude-sheets@one-hitter-sheets.iam.gserviceaccount.com
    ```

    - これはCMO（AIエージェント）が読み取りに使っている、既存のGoogle連携用アドレスです。Netlifyトークンなどと同じ運用です。
    - 「通知」のチェックは外して構いません。
33. 「**送信**」または「**保存**」をクリックして共有設定を閉じる。
34. 手順27の画面に戻り、トークンの文字列をコピーして、この文書に貼り付ける。
35. 同じ文書に、手順23で確認した「**チャネルID**」と「**チャネルシークレット**」も貼り付ける。
    - 3つを、それぞれ何なのか分かるように見出しを付けて書いてください。

      ```
      チャネルID:
      チャネルシークレット:
      チャネルアクセストークン（長期）:
      ```

36. ブラウザのアドレス欄に出ている**この文書のURLだけ**をコピーして、CMOに伝える。
    - 繰り返しますが、**トークンそのものはチャットに貼らないでください。**

## 6. 有効化のあとで確認する（手順37〜41）

第2章で撮ったスクリーンショットと見比べます。ここまでやって、はじめて作業完了です。

37. https://manager.line.biz/ に戻り、「**設定**」＞「**応答設定**」を開き、**手順5のスクリーンショットと見比べる**。
38. 「**あいさつメッセージ**」を開き、**手順6のスクリーンショットと見比べる**。
39. 「**自動応答メッセージ**」を開き、**手順7のスクリーンショットと見比べる**。
40. もし違っているところがあれば、スクリーンショットのとおりに戻して保存する。
    - 設定が変わっていても、元の内容が写真に残っているので必ず戻せます。
41. ご自身のスマホでLINEアプリを開き、公式アカウントのトーク画面に**過去のやりとりが残っていること**を確認する。

### 友だちとトーク履歴は消えません

- 今回の作業は「既存のアカウントに機能を追加する」操作であって、アカウントを作り直すものではありません。**友だちの人数も、過去のトーク履歴も、そのまま残ります。**
- リッチメニュー、クーポン、これまでの配信設定も残ります。
- LINEチャット（手動で返信する機能）も、これまでどおり使えます。
- ただし公式ドキュメントに「一切影響しません」と明言した文章までは見つけられなかったため（**要確認**）、念のため第2章のスクリーンショットを撮っていただいています。

## 7. 料金について

**現在の料金プラン（コミュニケーションプラン）のままなら、Messaging APIを有効にしても追加費用はかかりません。**
月200通までは無料、それを超えて配信したい場合はライトプラン（月額5,500円・税込／月5,000通まで）への変更が必要になります。Messaging API自体の利用料はありません。

- 通数は「送信した**人数**」で数えます。友だち100人に1回配信すれば100通です。
- お客様からの問い合わせに自動で返信する分（応答メッセージ）は、**通数にカウントされません**。
- 紹介者割引クーポンのように「該当する人だけ」に送る使い方なら、月に数通〜数十通で済みます。
- 有効化した時点でプランが自動的に変わることはありません。プラン変更は、必要になったときにオーナーが明示的に行う操作です。

## 8. これができると、何が自動になるか

- **紹介者割引クーポンの自動配布** — ご紹介いただいた方に、1,000円割引クーポンをその場で自動で送れます（クーポンの作成から配布までAPIで完結します）。
- **アンケート回答者への自動フォロー** — ご利用後アンケートに答えてくださった方へ、お礼メッセージと次回のご案内を自動で送れます。
- **次回予約割引の案内** — 前回の施工から一定期間が経ったお客様へ、割引付きの再依頼案内を自動で送れます。

いずれも、今は手作業で送っているか、そもそも送れていないものです。トークンを受け取った時点でCMO側の実装に入れます。

## 9. うまくいかないときは

| 症状 | 対処 |
|---|---|
| 「Messaging API」のメニューが見当たらない | ログインしているアカウントに**管理者権限**がない可能性があります。権限を確認してください。 |
| スマホの管理アプリに設定項目がない | 仕様です。**パソコンのWeb版**から操作してください。 |
| LINE Developersにチャネルが表示されない | 手順2と違うアカウントでログインしています。一度ログアウトして、同じアカウントで入り直してください。 |
| プロバイダー名を間違えて作ってしまった | **変更できません。** 作業を止めて、CMOに連絡してください。対処方針を一緒に考えます。 |
| トークンを誤ってチャットに貼ってしまった | すぐに手順19〜26をやり直して**再発行**してください。再発行した時点で、貼ってしまった古いトークンは無効になります。 |
