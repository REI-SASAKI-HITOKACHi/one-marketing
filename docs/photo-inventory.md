## 2026-09-06 ビフォーアフター組写真の検証

年末LP（`lp/nenmatsu/`）で BEFORE / AFTER として並べていた6組を、拡大して1組ずつ確認しました。
**別々の現場の写真を組にして「ビフォーアフター」と称するのは景表法上まずい**ためです。

| 組 | 判定 | 根拠 |
|---|---|---|
| 鏡（mirror） | ✅ 同一 | 浴槽・手すり・タイル・鏡枠がすべて一致 |
| 防水パン（pan） | ✅ 同一 | 配線の取り回し、背景の青い袋と黄色い物の位置が一致 |
| シンク（sink） | ✅ 同一 | 水栓・ワイヤーカゴ・楕円のフタ・天板が一致 |
| ATP測定（atp） | ✅ 同一 | 測定器の通し番号が **#0196 → #0197** と連番。同一機での連続測定 |
| **レンジフード（hood）** | ❌ **別物だった** | **BEFOREは白い樹脂枠、AFTERは金属枠。** 枠の素材が違い、目の細かさ・セル数も一致しない |
| 洗濯槽（drum） | ⚠️ **未確定** | 底面のリブとツメの形状が違って見える。汚れで隠れているだけの可能性もあり、断定できない |

### 対応

- **レンジフード**：組写真をやめ、施工前の1枚だけを「実際の施工前」として掲載する形に変更しました。
  `hood-after.jpg` は誤用を防ぐため削除しています。
  レンジフードの訴求は、新しい「直近の現場から」ギャラリー（シロッコファン・本体）が担います。
- **洗濯槽**：`[要確認]` として残しています。**オーナーに確認してください。**
  同一の洗濯機なら現状のままで問題ありません。**違うなら組写真をやめる必要があります。**
