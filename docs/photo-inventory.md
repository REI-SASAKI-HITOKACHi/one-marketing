# 施工写真の棚卸し（2026-09-05 時点）

渡辺さんが一次格納フォルダに入れてくれた **162枚** を、全数JPEGに変換して中身を確認しました。

## 前提

| | |
|---|---|
| 取得元 | Drive `施工写真_一次格納 / 02_過去分` |
| 枚数 | **162枚**（375MB、すべてHEIC） |
| 撮影端末 | iPhone 13（全数同一） |
| **EXIFの撮影日時** | **162枚すべてに残っている** |
| 撮影期間 | 2026/08/10 〜 2026/09/05 |

**EXIFが全数生きていたので、ファイル名の変更は不要です。** 撮影日時から施工日を割り出して、
売上シートの `施工日付` と突き合わせれば、どの現場かは機械的に特定できます。

**注意：この162枚はLINE経由ではありません。** カメラロールから直接入れた分です
（LINEは送信時にEXIFを削るため、残っていること自体が根拠になります）。
LINEアルバムから落とした分が今後入ってきた場合は、撮影日時が消えている可能性があります。

### 掲載できる範囲についての注意

- **密着カット**（エアコン内部、レンジフードのファン、汚水、シンク、便器）は
  **お宅が特定できないので、実務上ほぼ問題ありません。** 上の1〜4はすべてこれに該当します
- **08/20 の医療機関**は診療機器と待合室が写っており、施設が特定される可能性があります。
  **法人のお客様なので、使うなら先方の許可が必要です**
- **09/03 の店舗**も什器の配置で特定される可能性があります。同じく要許可。
  ただし床の寄りのカット（7917・7922・7932・7939）は店舗が判別できないので使えます
- 作業員の手や足が写っているものが複数ありますが、むしろ現場感が出るので問題ありません

## この先の運用

**新アンケートのQ8で、写真掲載の許可を取ります**（実名／イニシャル／匿名／不可、＋写真の可否）。
今後のぶんはこれでクリアになります。

**作業完了フォーム（MTG #21）ができれば、施工直後に写真を上げるだけで
アップロード時刻＝施工日になり、突き合わせが完全に自動化されます。**

## 再現方法

```bash
export GOOGLE_SHEETS_SA_KEY="（サービスアカウントの鍵）"
python3 tools/drive_client.py sync <フォルダID> <保存先>
```

HEICの読み込みには `pillow-heif` が必要です（`pip3 install pillow-heif`）。
