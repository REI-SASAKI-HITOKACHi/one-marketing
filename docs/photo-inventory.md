## 結論

### 1. これは「作業記録」であって「販促素材」ではない

型式プレートの撮影が含まれていることからも分かるとおり、施工の証跡として撮られたものです。
LPのBefore/Afterに耐えるのは、**法人B社員寮のIMG_8298（汚れたファン）とIMG_8301（洗浄後）のペアくらい**。

### 2. 案件がすべて法人・寮・店舗・共用部で、一般家庭がほぼない

LP案A（家庭用エアコン）・案B（家庭の水まわり）のターゲットと合いません。
一方で、**法人向けLP（案C-2）の素材としては使えます**。

### 3. 水まわりの写真が1枚もない

案Bで必要な、洗濯槽の裏側・浴室のカビ・追い焚き配管の湯垢が**ゼロ**です。
案BのBefore/After枠は、このフォルダでは埋まりません。

### 4. afterが空のフォルダが2件ある

法人Aの2案件。撮り忘れか、別の場所に保存されている可能性があります。

## 提案

1. **撮影同行が必要**、という当初の見立ては変わりません。特に案B（水まわり）は素材ゼロです。
2. 法人B社員寮のペアは、案Aの「Before/After」枠に暫定で入れられます。ただし
   **法人の寮なので「ご家庭の事例」としては出せません**。「施工事例」として出すなら可。
3. **今後の撮影ルールを決めたほうがよい**（現場スタッフ向け）:
   - 記録用とは別に、**販促用のカットを毎回1〜2枚**撮る
   - before/afterは**同じ位置・同じ画角**から撮る（今回はバラバラ）
   - afterは**乾いてから**撮る（濡れていると汚れて見える）
   - 明るさを確保する（暗いと「綺麗になった」が伝わらない）
   - HEICではなくJPEGで保存する
4. **Driveのフォルダ名に顧客名が入っています。**
   このメモでは伏せましたが、フォルダ共有の範囲にも注意が必要です。

## 技術メモ

- HEICは変換すれば読める（`pillow-heif`）。作業手順は確立済み。
- 元画像は4032×3024。LP用には1600px程度に縮小して使う。

## 撮影ルール（前回の提案の再掲＋追加）

2回目のアップロード分は、1回目より明らかに質が上がっています。以下を続けてください。

- before/afterは**同じ位置・同じ画角**から撮る（今回、送風ファンと熱交換器はきれいに揃っていました）
- afterは**乾いてから**撮る
- **型式プレートを画角に入れない**（後でトリミングすると構図が崩れます）
- 玄関の靴・私物が入らない向きから撮る
- 記録用とは別に、**販促用のカットを毎回1〜2枚**
