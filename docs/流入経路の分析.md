# どこから来たお客様が、いくらの価値になっているか

分析日: 2026-09-06 ／ 対象: 2026年1〜12月_売上/顧客タブ 全319件 ＋ 顧客管理台帳

## 結論を先に

**マッチングプラットフォームは、35%の手数料を払って「二度と戻ってこないお客様」を借りています。**
一方、**自社経由で来たお客様は1.5倍の価値があり、18倍の確率で戻ってきます。**
その自社経由が、いま**年間28件しかありません。**

これが「ネット経由が落ちている」の中身です。

**「まだ日が浅いから戻ってきていないだけ」ではありません。**
観察期間を3か月以上確保するため1〜6月の施工分だけで計算し直しても、結果は変わりませんでした。

| 初回の入口 | 対象数 | 平均施工回数 | リピート率 |

**マッチングPF経由のお客様は、100人いて2人しか戻ってきません。**

## 3. マッチングPFの手数料

案件の備考に「回収¥◯◯-日当¥◯◯-」と両方記録されている**60件**から実額を集計しました。

- **当社の取り分は中央値で 65.0%**（平均 64.2%）。**手数料はおよそ 35%**
- この60件だけで、お客様の支払い 1,596,763円 に対し当社の受取は 1,021,883円。
  **差額 574,880円** が手数料として出ています
- マッチングPF経由の全100件（売上 2,725,283円）に当てはめると、
  **年間およそ 95万円** が手数料に出ている計算になります

## 4. だから、広告費はいくらまで出せるのか

ここが実務上いちばん大事な数字です。

マッチングPF経由の1件は、平均27,250円の売上に対して**約9,500円を手数料として払っています**。
そして、そのお客様は**戻ってきません**（リピート率2%）。

**つまり、広告で新規1件を9,500円以内で獲れるなら、マッチングPFより確実に有利です。**
しかも自社経由のお客様はリピート率36%なので、2回目以降の売上がまるごと上乗せされます。

| | マッチングPF | 自社の広告 |
|---|---|---|
| 1件あたりのコスト | 約9,500円（手数料35%） | **9,500円までなら互角以上** |
| お客様の平均LTV | 28,172円 | 42,823円 |
| リピート率 | 2% | 36% |
| お客様の連絡先 | 規約次第で使えない | **自社の資産になる** |

**広告予算の判断基準：獲得単価（CPA）9,500円。** ここを上限に置けば、
少なくとも今のマッチングPFより損はしません。

## 5. 打ち手（優先順）

1. **自社経由の新規を増やす。** LPと広告はここに効きます。CPA 9,500円が上限の目安。
   いま自社直販は年28件。**これを100件にできれば、マッチングPFへの依存を半分にできます。**
2. **マッチングPF経由の100人を、2回目につなげる。** リピート率が2%から10%になるだけで
   年間およそ 28万円（10人×28,172円）が上乗せされます。
   手段はすでに用意してあります ―― アンケート（現場でQR）、公式LINE、SMS。
   **ただし規約の確認が先です（下記）。**
3. **業務提携を増やす。** LTV 186,272円・リピート率59%と、他の入口とは桁が違います。
   件数は40件しかありません。ここは営業の話であって広告の話ではありません。

## 6. 正直に書いておく限界

- **マッチングPFの規約で、そこ経由のお客様と直接取引することが禁じられている可能性があります。**
  打ち手2を実行する前に、必ず契約書を確認してください。**これが分からないうちは動かせません。**
- 台帳の「回数」は通算値です。2026年に初めて来たお客様の観察期間は最長でも8か月なので、
  リピート率は今後上振れする余地があります。ただし1〜6月に絞った再計算でも
  マッチングPFは2%のままでした
- 手数料の集計に使った60件は、備考の書き方が案件ごとに揺れています
  （「回収→日当」の順が逆のものがある）。金額の大きい方をお客様の支払いとみなしました
- 業務提携のLTVには法人・寮・店舗の大型案件が含まれます。個人のお客様と単純比較はできません
- おそうじ本舗（フランチャイズ）経由の分は、送信主体が異なるため自社直販に含めていません
