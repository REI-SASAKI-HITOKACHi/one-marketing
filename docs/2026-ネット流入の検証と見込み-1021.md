# ネット流入の検証と見込み（2027年計画 ④自社ネット新規に対して）

- 作成：経営企画室（planning）2026-10-21 ／ オーナー指示（10/21）：「この計画値は不変で必達だよ。ネット流入についてのみ絞って現状の検証（現時点までの実績分析）と今後の見込みを報告して」
- 物差し：**2027年の計画（2026-09-14・和真さん向け資料）の ④自社ネット新規＝年500万・143件（月12件）・1件¥34,965・広告費 年80万・CPA上限 ¥9,500**。値は動かさない
- 実績の出どころ：着地集計 10/21 09:43（`data/chakuchi/2026Q4-20261021-0943.json`）、measurement の 10/9 判定表、GA4 の経路別4段（10/1〜14・10/11〜15）、CMO の広告点検（〜10/19）。**一部の日の広告費は点検の値が無く概算**（下に明記）
- 数え方：予約ページ・LP・HP のフォームから申し込んだ受注（入口が広告・LINE・SMS でも数える。10/18 規則）。計画の ④ も「LP・SNS・地図検索・アフィリエイト・LINE/SMS再販」なので同じ範囲

## 結論（3行）

1. **件数は計画のペースに近づいた（10月 8件→着地 9〜10件・計画は月12件）。ただし中身は計画と違う。8件中7件が広告で買った受注で、無料の経路（SNS・ブログ・地図検索・アフィリエイト・年末LP）はほぼ0件。**
2. **金額が足りない。1件の平均は ¥14,251 で、計画の ¥34,965 の41%。** このままでは月12件取っても月 約¥17万で、計画の月 約¥42万に届かない。**件数より単価がいちばんの差。**
3. **広告の1件あたりの費用は 約¥17,000 で、計画の上限 ¥9,500 の約1.8倍。** 143件を今の率で広告だけで取ると広告費は 約¥243万（計画 ¥80万）。**計画の値を守るには、「単価を上げる」「無料の経路で件数の半分を取る」「広告の1件の費用を ¥9,500 以下に下げる」の3つが全部要る。**

- **計画書の「月のCPAが9,500円を超えたら、その月で止める」と、10/9 のオーナー発言「単体赤字でもLTVで回収」は食い違っている。** 今は後者で運用している（受注1件 ¥30,500 までは「次の1回までで回収」の線で続ける）

### 何が分かったか

1. **広告は申込を取れる。** 9/20 からの1か月で受注8件。計画の「パターンA（月2〜3件）」は抜けた
2. **ただし広告の客は小口。** エアコン1〜2台・浴室単品が中心で、平均 ¥14,251。計画の ¥34,965 は「平均単価」で置いていたが、**広告で来る新規客の初回は平均の4割**
3. **無料の経路がまだ1件も効いていない。** 計画の「パターンB（月5〜8件）」は「年末LPから月4〜5件、地図検索から月2件、SMS再販とアフィリエイトで数件」を前提にしていた。**今の8件は、その前提とは違う経路（広告）で出ている**
4. **入口で落ちている。** LPを見た人の92〜95%が予約ページに進まない。ここが直れば、同じ広告費で件数が増える

### 2027年の計画（月12件・¥42万）に対して

いまの延長で置いたもの（10月の実績の形がそのまま続く場合）：

| | 計画 | いまの延長 | 差 |
|---|--:|--:|--:|
| 月の件数 | 12 | 9〜11 | −1〜−3 |
| 1件の平均 | ¥34,965 | ¥14,251 | **−59%** |
| 月の売上 | 約¥42万 | 約¥13万〜16万 | **−約¥27万** |
| 年の売上 | 500万 | 約¥150万〜190万 | **−約¥310万〜350万** |
| 年の広告費（143件を広告で取る場合） | 80万 | 約¥243万（¥17,000×143） | **+約¥163万** |

**このままでは ④ は 500万に届かない。** 足りない約¥330万のうち、**約¥300万分は単価**（143件取れても1件 ¥14,251 なら約¥204万）。件数の不足は小さい。広告の効率は売上ではなく経常利益を削る（+約¥163万の費用）。

### 計画の値を守るために要る3つ（どれか1つでは届かない）

| | いま | 要る水準 | 手（持ち主） |
|---|---|---|---|
| ① 1件の単価を上げる | ¥14,251 | **¥30,000以上**（計画 ¥34,965） | 広告の着地を「複数台・水まわりセット・カビの完全分解（+¥8,800）」へ寄せる（lp・measurement）。現場で「次の1箇所」（和真さん）。10/4 の広告客は当日に完全分解を追加して初回 ¥18,502 |
| ② 無料の経路で件数の半分 | 月1件（LINE） | **月6件**（143件のうち約70件） | SMS再販を確実に送る（crm）・年末LP／ブログ／GBP は検索が育つまで6〜12か月（web-inflow）・アフィリエイトの配信確認（measurement） |
| ③ 広告の1件の費用 | 約¥17,000 | **¥9,500以下**（80万で約84件） | 入口の直し（LP→予約ページ 8%→15%）・入札の切り替えの効果（10/23 判定）（measurement・lp） |

- ③ だけ達成しても、①が今のままなら 84件×¥14,251＝約¥120万にしかならない。**①がいちばん効く**
- ② は時間がかかる経路が多い。**2027年1〜3月は広告と SMS 再販で件数を支え、4月以降に無料の経路が育つ前提**で見る
