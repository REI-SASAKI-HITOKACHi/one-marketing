依頼の4番「C群が日予算を食っていないか」は、**レポートで最初に見るべきところ**です。

## 3. 迷う（cmo へ）

**無理に決めていません。**どちらに転ぶかは、実際の検索語句を見ないと分かりません。

| 語 | 迷う理由 |
|---|---|
| **相場・料金・値段・比較** | 価格を調べている人は、**頼む直前の人**でもあります。外すと当たりを削る可能性があります |
| **おすすめ・ランキング** | 同上。比較サイトを探している可能性もあります |
| **ダイキン・パナソニック・三菱・日立・東芝**（メーカー名） | 「自分のダイキンのエアコンを洗いたい」なら当たり、「ダイキンのクリーニングサービス」なら外れ |
| **ヤマダ・ビックカメラ・ヨドバシ・ケーズ・エディオン**（量販店名） | 量販店のクリーニングを探している可能性が高いが、比較の途中のことも |
| **水漏れ** | ドレンの詰まりなら、クリーニングで直ることがあります。故障なら外れ |
| **修理・故障・エラー・異音** | ほぼ外れですが、「においがする」「風が弱い」を修理と表現する人もいます |
| **業務用・天井・埋め込み** | 段0では「業務用」を除外していますが、**料金表には業務用エアコン（¥27,280〜）があります**。個人向けに絞る方針のままでよいか |
| **設置** | **当社のメニューに「洗濯機 設置枠（防水パン）」があります。**「洗濯機 設置枠 掃除」は客です。エアコンの設置工事を探す人は外れ。語だけでは分けられない |
| **イオン** | 他社サービスを探す人もいますが、**葛西・南砂などのイオンは目印として検索されます**（「イオン葛西 近く エアコンクリーニング」） |
| **コツ** | 「掃除のコツ」はDIYで外れ、「業者の選び方 コツ」は頼む直前の客 |
| **即日・今日・当日** | 急いでいる人。受けられるかどうか次第です |

## 4. レポートが届いたら

ブラウザ担当に取ってもらうもの（9/20〜今日）：

1. **検索語句レポート**（語・表示回数・クリック数・費用・コンバージョン）
2. **地域レポート**（ユーザーの所在地別のクリック）
3. **地域設定の画面**（「地域にいる」だけか、「関心がある」も含むか）
4. **広告グループ別の費用**（C群の消化を見るため）

届いたら、この順で判定します。

1. **費用の大きい順に並べる**。上から見る
2. 各語を**当たり／外れ／迷う**に振り分ける
   - 当たり：江戸川・江東・墨田・葛飾・浦安・市川の地名入り、メニュー名＋「業者」「クリーニング」
   - 外れ：上の2章の類型
   - 迷う：上の3章の類型
3. **外れの費用の合計**と、**全費用に占める割合**を出す（「外れが過半なら、まず除外・地域の修正」が planning の目安）
4. 地域レポートで、**6市区の外からのクリックの割合**を出す
5. **C群の費用が日予算の何割か**を出す

**指名検索（「ワンヒッター」など）が出てきたら、別に数えます。**GBP・読本・SNSから来た人が広告を押している可能性があり、その場合は広告費で自社の無料経路を買い戻していることになります。
