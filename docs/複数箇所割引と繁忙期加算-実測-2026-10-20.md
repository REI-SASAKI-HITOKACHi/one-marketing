## 結論：2つはまったく別の計算です

| | 何に効くか | 向き |
|---|---|---|
| **複数箇所割引** | 2箇所目以降を「**セット価格**」に置き換える | 引く |
| **繁忙期加算** | **1箇所あたり ¥3,300 × 箇所数**（5・6・7・12月） | 足す |

**併用されます。**12月に2箇所頼めば、セット割引が引かれたうえで ¥6,600 が足されます。
一方、**早期予約割引（10〜15%）は1箇所のときだけ**で、複数箇所では効きません。

## 1. 複数箇所割引の正体は「セット価格」

メニューごとに **単品価格** と **セット価格** の2本を持っていて、
**2箇所以上を同じ日に頼むと、2箇所目以降がセット価格に変わります。**

| メニュー | 単品 | セット価格 | 差（1箇所あたり） |
|---|---:|---:|---:|
| エアコン（ノーマル） | 10,780 | 10,780 | **0** |
| エアコン（お掃除機能付き） | 17,380 | 17,380 | **0** |
| 洗濯機 | 17,380 | 17,380 | **0** |
| レンジフード | 18,480 | 15,180 | **−3,300** |
| レンジフード（プロペラ式） | 10,780 | 10,780 | **0** |
| キッチン | 18,480 | 15,180 | **−3,300** |
| 浴室 | 18,480 | 15,180 | **−3,300** |
| 追い焚き配管 | 19,910 | 16,610 | **−3,300** |
| **コンロ** | 10,780 | **5,500** | **−5,280**（※キッチンと一緒のときだけ） |
| トイレ | 10,780 | 10,780 | **0** |
| 洗面台 | 10,780 | 7,480 | **−3,300** |
| お掃除時短コーティング | 19,800 | 19,800 | **0** |

### 🔴 ここが大事：一律「◯円引き」ではありません

- **水まわり系（レンジフード・キッチン・浴室・追い焚き・洗面台）は 1箇所あたり −3,300円**
- **エアコン・洗濯機・トイレ・プロペラ式・コーティングは、セットでも1円も下がりません**
- **コンロだけ別格で −5,280円。ただし「キッチンクリーニングと一緒のとき」だけ**
  （コンロ単独や、キッチン以外との組み合わせでは単品価格のまま）

### 計算の決まりごと（コードのとおり）

1. **単品のまま残るのは「割引額がいちばん小さい1箇所」。** 残りがセット価格になる
   （いちばん高い箇所を単品にすると割引が消えてしまうため。コード内のコメントに経緯あり）
2. **セット価格の差が1円も出ない組み合わせ**（例：エアコン2台、エアコン＋トイレ）には
   **ネット申込特典 ¥2,200** が代わりに引かれる。**1箇所だけの注文は対象外**（2026-09-08 オーナー決定）
3. **早期予約割引は1箇所のときだけ。** 複数箇所にはかからない

## 2. 繁忙期加算は、割引とは完全に独立

- 対象月：**5月・6月・7月・12月**
- 金額：**1箇所あたり ¥3,300 × 箇所数**
- セット割引を引いたあとに、**足されます**

## 5. 🔴 `docs/price-master.md` との食い違い

price-master L122 には **「複数台割引（ノーマル）：5〜10台 ¥500/台、11〜20台 ¥1,000/台…」** とあります。
これは**エアコンの台数割引**の話で、**ネット予約の「セット価格」とは別のしくみ**です。

| | しくみ | 効き方 |
|---|---|---|
| price-master L122 の複数台割引 | エアコンの**台数**に対する割引 | 5台以上から |
| ネット予約のセット価格 | **別メニューを同じ日に**頼んだときの価格 | 2箇所目から |

**つまり、どちらも間違っていません。別の話が同じ「複数割引」という言葉で呼ばれていました。**
オーナーの「当社も2台（箇所）目からだよ」は、**ネット予約のセット価格（2箇所目から）**のことだと読めます。

ただし、**エアコンだけを2台頼んでもセット価格は下がりません**（ネット申込特典 ¥2,200 のみ）。
大手が「2台目から2,200円引き」などを出している中で、ここは弱いままです。

## 6. CMOに確認したいこと

   大手は2台目から割引があります。ここを変えるかどうかは料金の話なので planning とオーナーの判断
