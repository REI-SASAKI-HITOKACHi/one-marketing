## 3. 広告の設計（CMO 案）

### エリア

**江戸川区を中心に、移動60分で行ける範囲だけ。**

- 第1段：江戸川区・江東区・墨田区・葛飾区・浦安市・市川市
- 広げるのは、CVが出て枠が埋まってから

理由：施工者が実質1人（和真さん＋協力業者）で、移動60分/件が原価に直接効く。遠方のクリックは払い損になる。

### キーワード（非指名・購買意図の高い順）

| 群 | 例 | 狙い |
|---|---|---|
| A 本命 | エアコンクリーニング 江戸川区／西葛西／葛西／浦安／市川 | 今日買う人 |
| A 本命 | エアコン掃除 業者 ＋ エリア | 同上 |
| B 高単価 | レンジフード クリーニング ＋ エリア | 単価が高く競合が薄い |
| B 高単価 | 浴室クリーニング／風呂 クリーニング 業者 ＋ エリア | 同上 |
| C 面 | ハウスクリーニング ＋ エリア | 数は出るが単価が割れる。少額で試す |

> ### ⚠️ 2026-09-15 実測：区名付きの語は、41語中22語が「検索ボリュームが少ない」
>
> グループ別に見ると **B_レンジフードは8語中7語、B_浴室は9語中8語、C_ハウスクリーニングは8語中7語**が該当し、
> **このままだとB系とC系はほぼ在庫が無い**（配信されない）。江戸川区規模の商圏で
> 「浴室クリーニング＋区名」まで絞ると、検索が薄すぎる。
>
> **対処（CMO決定 9/15）：地域語を外した語をフレーズ一致で足し、エリアはキャンペーンの地域設定で担保する。**
> 地域の指定は「**所在地**: 追加した地域にいるユーザー、追加した地域をよく訪れるユーザー」なので、
> 区名をキーワードに入れなくても区外には出ない。**区名付きの語は消さずに残す**
> （配信されないだけで害は無く、検索が増えたときに精度が効く）。
>
> 足した語（`data/ads/段0-追加キーワード（地域語なし）.txt`）：
> - A_エアコン … `エアコンクリーニング` `エアコン掃除 業者`
> - B_レンジフード … `レンジフード クリーニング` `レンジフード 掃除 業者` `換気扇 クリーニング`
> - B_浴室 … `浴室クリーニング` `風呂 クリーニング 業者` `お風呂掃除 業者`
> - C_ハウスクリーニング … `ハウスクリーニング`
>
> **C群だけ上限CPCを 300円に下げる。** 段0のとおり「数は出るが単価が割れる」群で、
> 地域語を外すと最も量が出る。日予算1,667円をこの群に食われないようにするため。

### 除外キーワード（初日から入れる）

`自分で` `やり方` `方法` `DIY` `洗浄スプレー` `求人` `バイト` `募集` `資格` `開業` `フランチャイズ` `業務用` `賃貸 退去` `空室` `原状回復` `おそうじ本舗` `くらしのマーケット` `ユアマイスター`

- **空室清掃は受けない**（オーナー決定 9/14「完全なる悪手。超薄利で下手したら逆鞘」）
- **本舗の名前では出さない**（自社名義の入口を作るのが目的）
- 他社サービス名での指名検索は買わない（単価が合わない）

## 4. 判定のしかた

**最初の2週間（9/16〜9/30）はCPAで切らない。** 見るのはこの3つ。

1. **検索語句レポート** … 想定どおりの言葉で来ているか。ズレていれば除外を足す
2. **CVが1件でも出るか** … 0件なら、原因はLPか計測か広告文かをこの順で切り分ける
3. **電話の着信** … フォームより電話が多い業種なので、電話CVが取れていないと過小評価する

**10月1日に、CPAと受注単価で継続・停止・増額を決める。**

## 5. 同時に動かす無料の手（GBP）

**検索広告と同じ商圏で、無料で今すぐ効くのがGBP。放置しているのが一番もったいない。**

- 未返信のクチコミ **3件**（すべて★5）→ 返信する。返信率はローカル検索の評価に効く
- **最新情報の投稿が0** → 週2本を定例化
- 施工写真24枚（9/14 厳選）を順次追加
- API の承認は 9/25〜9/30 見込み。**それまでは管理画面から手で回す**
