# 1. いちばん重要な判断：**プールの10万円は、発生した月に費用計上する**

> ## **毎月50万円（固定給40万＋プール10万）を費用に立てる。**
> ## **払い出した月（3か月ごとの30万）は、費用に計上しない。現金が出るだけ。**

## なぜか

| 置き方 | 月次の損益 | 問題 |
|---|---|---|
| **発生した月に10万ずつ**（推奨） | **毎月50万でフラット** | なし |
| 払い出した月に30万 | 3か月ごとに**30万の谷** | **月次の利益が3か月周期でギザギザになり、判断を誤らせる。**「今月は赤字」が制度の都合で出る |

**プールは「働いた月に発生している報酬」です。** 支払いのタイミングと、費用が発生したタイミングは別です。
未払いのぶんは**負債（未払費用）**として積み、払い出した月に取り崩します。

## 2027年の計画とも、これで揃います

`tools/plan2027.py` は **`WATANABE_EN_PER_TSUKI = 500000`**（月50万）で組んであります
（年600万＝`販管_人件費_和真`）。**2026年のシートを同じ置き方にすれば、2026年と2027年が同じ物差しになります。**

# 2. シートに入れるもの

## 2.1 `◯月_支出/成績`（9〜12月の4タブ）

**経費の明細に、毎月2行を足します。**

| 日付 | 品目 | 科目 | 金額 | 備考 |
|---|---|---|--:|---|
| その月の支給日 | **和真 固定給** | **人件費** | **400,000** | 新方式（2026-09 MTG決定）。旧「経常利益×45%」は8月分まで |
| その月の支給日 | **和真 プール積立** | **人件費** | **100,000** | **3か月ごとに払い出す分の当月発生額。現金は出ていない** |

> **「プール積立」は現金が出ない行です。** 経費として立てつつ、支払いは別。
> **払い出した月（12月に30万を払うなら12月）には、経費の行を足さないでください。二重計上になります。**
> 払い出しは**プール残高の取り崩し**で、損益には出ません。

※ 2026年のシートは外注費が科目「人件費」に入っている状態です（`docs/2027-数値目標.md` §6）。
　 **2027年版では `固定給(販管費)` と `現場人件費(原価)` と `外注費` を分けてあります。**
　 2026年は科目を増やさず、**品目の名前で見分けられる形**にしました（途中で科目を増やすと集計式が動くため）。

## 2.2 `和真報酬_推移` タブ

**過去の行には一切触りません。** 9月分から**下に新しい行**を足して、**列は末尾に追加**します。

### 足す列（必ず既存列の右端に。途中に入れると集計式の範囲がずれます）

| 列名 | 中身 |
|---|---|
| `方式` | `旧(経常利益×45%)` / `新(固定40万+プール10万)` |
| `固定給` | 400,000（新方式の月のみ） |
| `プール積立` | 100,000（新方式の月のみ） |
| `プール払出` | 払い出した月に 300,000。それ以外は空欄 |
| `プール残高` | `=前月のプール残高 + プール積立 − プール払出` |

### 9月分の行（そのまま貼れます）

| 年月 | 方式 | 固定給 | プール積立 | プール払出 | プール残高 | 当月の費用計 |
|---|---|--:|--:|--:|--:|--:|
| 2026-09 | 新(固定40万+プール10万) | 400,000 | 100,000 | | 100,000 | **500,000** |
| 2026-10 | 新(固定40万+プール10万) | 400,000 | 100,000 | | 200,000 | **500,000** |
| 2026-11 | 新(固定40万+プール10万) | 400,000 | 100,000 | **300,000** | **0** | **500,000** |
| 2026-12 | 新(固定40万+プール10万) | 400,000 | 100,000 | | 100,000 | **500,000** |

> **払い出しの月（上の表では11月）は仮置きです。**
> 「3か月ごと」の起点が**9月分から数えて9・10・11月分を11月末に払う**のか、
> **12月末に払う**のかが、MTGの記録からは読み取れませんでした。**確認してください。**
> **どちらでも損益は毎月50万でフラットなので、計画の数字は動きません。** 動くのは現金の出る月だけです。

# 3. 損益への影響

| | 旧方式（経常利益×45%） | 新方式 |
|---|---|---|
| 月の費用 | 利益に連動して変動 | **固定50万** |
| 年額（9〜12月の4か月） | 実績による | **200万** |

**旧方式は「利益が出た月ほど報酬が増える」ので、損益分岐点が動く仕組みでした。**
**新方式は固定なので、損益分岐点が固定されます。** これは計画を立てる側には扱いやすい変化です。
`docs/2027-数値目標.md` の損益分岐（人1名増で約1,980万）は、**すでに固定50万で計算してあります。**

# 4. 適用の手順（鍵を持っているスレッド向け）

1. **`和真報酬_推移` と `9〜12月_支出/成績` のバックアップを取る**（Driveでタブをコピー）
2. `和真報酬_推移` に **列を末尾に5列追加**（`方式`/`固定給`/`プール積立`/`プール払出`/`プール残高`）
3. **9月・10月・11月・12月の行を下に追加**（上の表のとおり）。**既存行は編集しない**
4. `9月_支出/成績` 〜 `12月_支出/成績` に **上記2行ずつ追加**
5. **追加の前後で、各タブの集計値が変わっていないことを機械で確認**（列の追加は集計式の範囲を動かすため）
6. `docs/sheet-changelog.md` に履歴

**5 を飛ばさないでください。** crm が9/15にテック山口の `法人名` 列で踏んだのと同じ論点です。
