# SMS 2回目（12月向け）：対象の数え方と文面案（下書き・2026-10-21 crm）

1・2便目（11月SMS）で反応が無かった方に、11/20〜27 以降に送る2回目。**送信はオーナー承認（外に出す）。これは下書き。**

## 対象の数え方（`python3 tools/sms-2kaime-kazoeru.py`・表示のみ）
| 順 | 見るところ | 扱い |
|---|---|---|
| 1 | 【1便目】【2便目】タブの E列 | 空欄＝まだ1回目を送っていない → 対象外（1回目が先）／返信あり・不通・エラー・対象外 → 外す／**送信済み → 次へ** |
| 2 | I列（返信メモ） | 何か書いてあれば外す（「不要」など） |
| 3 | 台帳で照合し直し | 名乗り（atesaki_ok＝最新の施工が自社）・クレーム履歴・**1回目の送信日より後の施工や予約** → 外す |
| 4 | 送れる日 | **1回目の送信日＋30日**（オーナーの30日ルール） |

- **1回目の送信日をどう知るか**：両タブに **J列「送った日」（YYYY-MM-DD）** を足し、和真さんに E列と一緒に入れてもらうのを推奨（1行ずつ日が違っても30日が数えられる）。空欄なら A列の予定日（1便目・第1陣 10/20、第2陣 10/27）で仮置きし「仮」と表示する。
- **1便目がまだ送れていない場合**：実際に送った日から30日で自動的にずれる。例：10/22 に送れば 11/21 以降、10/27 なら 11/26 以降。
- 10/21 朝の結果：1便目 17・2便目 83 とも E列空欄 → 2回目の対象 0（1回目がまだ）。
