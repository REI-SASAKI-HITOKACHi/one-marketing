作成 2026-09-21 ／ 作成者 CMO
きっかけ：オーナー指示（2026-09-21）「広告に頼らないWEB集客について、方向性が定まらずに
場当たり的な対応を取っているから、それぞれのチャネル（HP/SNS/LINE/GBPなど）の運用方針と狙いを確立する」

**この文書は自社名義（ONE HITTER）の集客だけを扱う。おそうじ本舗の案件は1件も混ぜない。**
本舗の−27%は計画どおりであることがオーナー回答で確定している（`docs/cmo-savedata.md`
「【オーナー直接回答 2026-09-21 16:0x】」）。本舗は追いかけない。

数字はすべて出典のファイル名を付けた。出典の無い数字は書いていない。
推測にはその旨を明記した。

```
 │   出ない      │      ている     │                 │              │
 └───────────────┴─────────────────┴─────────────────┴──────────────┘
```

**受け渡しの本線は1本だけ。**

```
GBP → 公式HP または LP → 予約フォーム／電話 → 施工 → アンケート
   → クチコミ（GBPへ戻る）＋ SMS／公式LINE（再購入）
```

この輪の入口が GBP、出口が クチコミ。**クチコミが増えると GBP の入口が太る。**
広告費を1円も使わずに回るのはこの輪だけで、**他のチャネルは全部この輪の補助**という位置づけにする。
