## 今日新しく分かった操作の癖（メモリにも書いた）

- **GASはclaspで入れるのが速い**。コンテナバインドでも `clasp clone <スクリプトID>` できる。
  スクリプトIDは「拡張機能→Apps Script」で開いたタブのURLから取る … `[[gas-container-bound-via-clasp]]`
- **GASの関数プルダウンは2段階**。▼を座標で開く → スクショで確かめる → 項目を座標で押す。
  `find` の ref では選べない
- **CMSのインラインstyleは `color` に `!important` が要る** … `[[cms-inline-style-needs-important]]`
- **CMSの旧記事は一覧に出ない。検索で記事IDを引く** … `[[cms-old-articles-search-only]]`
- **CMSの新規記事の file 欄は `find` で拾えない**（`opacity:0; width:0`）。
  JSで `aria-label` を付けて可視化してから `find` する … `[[cms-image-upload]]`
- **Google広告の「要確認」のツールチップは、バッジそのものに `hover` する**（行やコンバージョン名ではない）
