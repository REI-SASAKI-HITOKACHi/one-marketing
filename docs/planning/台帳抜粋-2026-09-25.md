## 4. 「U列（?src=）」について

各月タブの U列は **`法人名`** で、`?src=` ではありません（ヘッダー行のとおり）。`?src=`・注文ID・gclid が入るのは **`予約_Web`** タブ（AB=注文ID、AC=gclid）で、**2026-09-25 時点で 0 行**です。
また、`流入経路` の入力規則に「広告」「GBP」「予約ページ」が無いため、広告経由で電話が来て受注しても台帳では見分けられません。CMO から planning に選択肢の追加を依頼済み（20260925-01-planning）。
