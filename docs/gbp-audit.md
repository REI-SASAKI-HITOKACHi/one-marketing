## 直すべきところ

### 1. 🔴 クチコミ件数が23件。ここが唯一にして最大の差

上位は 60〜94件です。**23件を60件にできれば、この検索で1位を狙えます。**
地図検索の順位は問い合わせ数に直結するので、ここが最も効きます。

**手段はすでに用意してあります。**

- アンケートを公開済み: https://one-hitter-survey.netlify.app/
- 満足された方をGoogleクチコミへ誘導する導線を組み込み済み
- 現場で見せるQR画像も作成済み（`lp/survey/qr/phone-watanabe.png`）

**あとは現場で回すだけです。** 施工は月およそ30件。そのうち2割が投稿してくださるなら
月6件、**半年で23件→60件前後に届きます。**

### 2. ✅ ビジネス説明は設定済み（約700字）— 「未設定」は誤りだった（2026-09-13 訂正）

監査時に Places API の editorialSummary が空だったため「未設定」と書いたが、**管理画面には約700字の説明文が入っている**（ブラウザ担当が 2026-09-13 に確認。冒頭「江戸川区でハウスクリーニングをお探しなら、手が届く、理想の生活を実現する『ワンヒッター株式会社』へ。」）。editorialSummary は Google が生成する要約で、事業者の説明文とは別物。
- 既存文の「エアコン丸洗い（ノーマルタイプ）は60分9,800円から」は 9/6 の価格改定前の税抜額。**「60分10,780円（税込）から」に1文だけ差し替え**（cmo 承認、ブラウザ担当が 2026-09-13 14:28 実施）
- 全文の差し替えは当面しない（cmo 判断 2026-09-13）。下の文案は、将来差し替えるときの候補として残す

### 3. ✅ 営業時間は「24時間営業」のまま（オーナー決定 2026-09-13）

月〜日すべて「Open 24 hours」。電話受付の目安は **8:00〜20:00**（`docs/price-master.md`）だが、オーナー：「24時間は実際稀に夜間の依頼あるからそのままでいいかな」。**変えない。**

### 3b. 🟡 サービス提供地域に埼玉県が入っている（残す）

オーナー決定 2026-09-13：「埼玉県も施工実績あるよ。そのままでいいかな。積極的には開拓しないからLPとかは除外してると思うけど」。GBP は埼玉を残し、**公式サイト・LP・CLAUDE.md の対応エリアは「東京・千葉・神奈川」のまま**。この食い違いは意図したもの。埼玉を本当に受けるかは 9/14 の週次でオーナーに確認する（cmo）。それまで原稿の対応エリアは3都県で書く。

深夜にかけて出られないと、その方はそのまま競合へ行きます。
**実態に合わせてください。** 24時間受付を売りにするなら、それはそれで構いませんが、
その場合は本当に出られる体制が要ります。
