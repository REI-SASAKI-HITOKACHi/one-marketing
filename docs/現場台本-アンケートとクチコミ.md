# 現場の台本（1枚）：汚れの確認 → アンケート → その場でクチコミ → 次回のご予約

T058。第4回MTG（2026-09-26）の決定と、オーナーの指示（9/23）をそのまま手順にしたものです。

- オーナー 9/23：「片付けを少し残したタイミングで汚れの確認 → QR提示 → 片付け中に回答 → 片付け後に次回予約の斡旋」
- オーナー 9/26（第4回 4-4 No.3）：「アンケートの流れでその場で投稿してもらうから、認識を正して。全件依頼するよ。」

**使うのは、ワンヒッター名義の施工だけです。** おそうじ本舗名義の現場では、作業完了フォームにアンケートのQRが出ません（9/27〜）。そのときはこの台本も使いません。

---

## 流れ（所要およそ5分）

| # | いつ | すること | 言うこと（例） |
|---|---|---|---|
| 1 | 片付けを少し残したところ | 外した部品・汚れた水・Before/After の写真をお客様と一緒に見る | 「今日はこれだけ汚れが出ました。こちらが作業前、こちらが作業後です」 |
| 2 | 1のすぐあと | 作業完了フォームの画面に出るQRをお見せする | 「よろしければ、片付けているあいだに1分ほどのアンケートにお答えいただけますか。スマホでこちらを読み取るだけです」 |
| 3 | 片付けのあいだ | お客様に回答していただく。こちらは片付けを続ける | （声をかけすぎない） |
| 4 | 回答が終わったら | 完了画面に出る「Googleに投稿する」のボタンを、その場でお願いする | 「最後の画面に『Googleに投稿する』というボタンがあります。いま書いていただいた文章をそのまま貼り付けられます。小さな会社なので、1件が本当に助かります」 |
| 5 | 片付けが終わったら | 次回のご予約をお聞きする | 「次はいつ頃がよさそうですか。今日決めていただくと早期予約の割引が付きます」 |

## 4（クチコミ）のコツ

- **お客様のスマホの画面に、もう「文章をコピー」→「Googleに投稿する」が出ています。** やり方の説明は画面の3行（コピー → 投稿を押す → 長押しで貼り付けて星を選ぶ）で足ります。
- Googleにログインしていないお客様には、無理にお願いしない。「お手すきのときで大丈夫です」で終える。
- **お礼や割引と引き換えにはしない**（Google の規約違反になります）。お願いするだけです。
- 回答で点数が低かった方にも、画面には「Googleに投稿する」が出ます。気になる点を聞けたら、その場で謝って直せるか相談する。クチコミのお願いはしなくてよい。

## 5（次回予約）の注意

- **割引の率はその場で言わない。** 時期で変わるので、料金表と見積アプリの金額で伝える（11〜12月は早期予約の割引なし。`docs/price-master.md`）。
- 決まったら、その場で**受注フォーム**から入力する（第4回の決定「全件受注フォームで入力」）。
- 迷っている方には「来年の同じ時期にこちらからご連絡してよいですか」だけ聞いて、受注フォームの備考に書く。

## 数え方

- クチコミの件数：Googleマップのクチコミ数（2026年9月時点で23件・5.0）。マーケ部長が週1回数えて、MTGシートの「会社の数字」に載せます。
- アンケートの回答数・次回予約の件数：アンケートの回答と台帳（流入経路「リピート」「早期予約」）から数えます。
