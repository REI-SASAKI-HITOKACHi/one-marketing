# 広告の日予算を上げるとき：上げた分だけを測る形（2026-10-16 計測担当）

オーナー決定（10/16・7-4 No.5 原文）：「上げてもいいが効果を確認できる前提」
planning の判定シート（11/1 に条件を満たしたら増額）に足す部分。**判定シートは planning の持ち物なので、この中身を planning に渡して足してもらう。**

## 0. 上げる前に確かめること（1つ）
**予算が足りずに広告が止まっているか。** Google広告のキャンペーン一覧で「予算による制限」が出ているか、列「検索広告のインプレッション シェア損失率（予算）」が 10% 以上か（browser が見る）。
- 制限されていなければ、日予算を上げても費用もクリックも増えない。上げずに、キーワードや入札を見直す
- 10/10 の実費は ¥5,517（日予算 ¥5,000）で、ほぼ使い切っている

## 1. 期間
- **上げる前の14日（基準）** と、**上げた日から14日（増額期間）** を比べる
- 増額期間中は、**LP の振り分け（C 対 E）以外の変更を入れない**（入口や文言を変えると、増額の効果と混ざる）。入れた場合は日付を判定シートに書く

## 2. 指標（上げた分だけを見る）
| 指標 | 計算 | 出典 |
|---|---|---|
| 増えた費用 | （増額期間の1日平均の費用 − 基準の1日平均の費用）× 14 | 広告_日次 |
| 増えたクリック | 同じ計算 | 広告_日次 |
| 増えた申込 | 増額期間の申込 − 基準の申込 | **予約_Web**（`src=gads_*`。Google広告の CV は使わない） |
| **上げた分の申込1件あたり** | 増えた費用 ÷ 増えた申込 | 上の2つ |
| 受注率 | 受注 ÷ 申込（見張り） | 台帳 |

## 3. 続ける・戻すの条件
- **続ける**：上げた分の申込1件あたりが **¥16,200 以下**（継続の線。planning の許容CPA）
- **戻す**：
  - 14日終わって、増えた申込が **0件以下**
  - または、上げた分の申込1件あたりが **¥16,200 を超えた**
- **途中で戻す（7日目）**：増えた費用が ¥17,500 を超えたのに（日 ¥2,500 × 7日。¥5,000→¥7,500 にした場合）、増えた申込が0件
- 金額は、上げ幅に合わせて planning が直す

## 4. 注意
- 申込の数は1桁なので、**14日で「効いた」と言い切れるのは差がはっきり出たときだけ**。どちらとも言えないときは、さらに14日延ばす（その間も戻す条件は生きている）
- 10月後半〜11月は季節（暖房の切り替え・年末の前）で、増額しなくても申込が増える可能性がある。基準の14日と比べる以上、この分は増額の効果に見えてしまう。**前年の同じ時期の申込（台帳）を並べて、季節の分を目で差し引く**
- 申込から施工までは1〜2週間ずれる。受注の判断は、増額期間の申込が施工まで済んでから
