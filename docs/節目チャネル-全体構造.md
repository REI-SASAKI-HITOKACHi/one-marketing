# 節目チャネル（型②「その瞬間のレジ」）の全体構造 ─ 営業担当ゼロで、地域の施設にQRを置いてもらう

作成 2026-09-11 ／ 担当 ネット流入施策担当（`web-inflow`）／ オーナー指示「販売用QRの設置依頼（メール・問い合わせフォーム）、使い方説明（動画）、週次報告まで自動化。外注網ができるまで地域限定＝中小零細を対象」
根拠：`docs/潜在→顕在の事例研究.md`（アニコム：新規の約7割がペットショップ購入時、産院サンプリング、ヤマダの推奨タイミング「赤ちゃんをお迎えする準備として」「ペットのために」）
**まだ何も送っていません。外部への送信はオーナー承認後。金額の判断はすべてオーナー。** 2026-09-11：読本・承諾フォーム・カード・動画・文面を作成（未公開）。

## 0-1. 2026-09-11 オーナー指摘で組み替えた3点

1. **商品名はシンプルでよい。大事なのはA6カードの見出しと、QRの先のページの題名**
2. **QRの先は「読本」。全体の80〜90%を、プロが説く汚れの話（感情に訴える＋客観的な数字）にする。読んで良かったと思える内容。商品は末尾**
3. **施設への依頼文は「利用者に知ってほしい読本を作ったので置いてほしい」が冒頭・主旨。商品と報酬の仕組みは後段**

### カードの見出し（A6・上半分が見出し、下半分がQRと一言）

| 施設 | 見出し（案。**この1行で読むかどうかが決まる**） | 一言 |
|---|---|---|
| 産院・小児科・子育て支援 | **赤ちゃんが来る前に、エアコンの中を見たことがありますか。** | 江戸川区のハウスクリーニング店が、写真で全部お見せします（読むだけ・無料） |
| ペットショップ・動物病院・トリミング | **この子が来る前に、エアコンの中を見たことがありますか。** | 同上 |

- 「掃除しませんか」とは書かない。**「見たことがありますか」**——読本への入口として、答えられない問いを置く
- 裏面：運営者名・住所・電話（特商法・ステマ規制の表示）

### 読本のページ（QRの先。noindex・施設IDつき）

**題名：** 「赤ちゃんが来る前に知っておきたい、家の中の見えない汚れ」（ペット版は「この子が来る前に…」）
**副題：** 江戸川区のハウスクリーニング店が、実際の現場の写真と数字でお話しします

| 章 | 内容（**すべて当社の実写と、出典のある数字だけ**） | 割合 |
|---|---|---|
| 1. 見えないから、気にならない | 「フィルターは掃除している」お宅のエアコンの中（IMG_7963/7965の実写）。吹き出し口の黒い点は、内部の送風ファンのカビが飛んできたもの | 読本 |
| 2. どれだけ溜まるか | 1台から出た汚水（IMG_7976）。洗浄後の汚水は茶色。レンジフードのシロッコファン（IMG_7877/7880）の油の層 | 読本 |
| 3. 数字で見る | 東京都調査：過去3年にカビが生えた世帯 **33.7%**、発生場所は浴室 **79.7%**（東京都保健医療局 指針No.9）／カビが好む温度 20〜35℃・湿度70%以上／「室内を浮遊するカビの胞子や菌糸の断片を吸い込むと、体質によってはぜん息などを引き起こすことがあります」（同・**原文引用のみ**）／フィルター清掃は年3〜4回（東京都アレルギー情報navi.） | 読本 |
| 4. 自分でできること、できないこと | フィルター・ルーバー・フィルターのつけ置きは自分で。熱交換器・送風ファン・ドレン・シロッコファンは分解が要る。**メーカー（ダイキン・三菱電機）は市販スプレーの使用を推奨していない**（公式FAQの引用）、NITEは業者依頼を推奨 | 読本 |
| 5. 赤ちゃん（この子）が来る家で、私たちが見てきたこと | 現場の所見（渡辺さんの言葉に基づく）。**健康の断定はしない。** 「新生児がいるのでカビの胞子がこわい」という相談が実際にある事実（知恵袋）程度に留める | 読本 |
| 6. いつ、何を | 迎える前の1〜2か月が最も落ち着いて頼める時期／エアコンは冷房前（5〜6月）がピークで予約が取りにくい（Googleトレンド）／自分で見る方法（吹き出し口を懐中電灯で覗く） | 読本 |
| 7. 頼む場合 | 商品（エアコン1台＋浴室 or 換気扇）・税込・追加請求なし・所要時間・**98.6%**・Googleクチコミ★5.0（24件・2026年9月時点）・予約フォーム（src=施設ID）。**または「まず無料で中を見てもらう」（無料点検の申込）** | 10〜20% |

- 読本は1ページの縦長。写真は当社の実写のみ（合成なし・特定できない）。文章は「プロが説く」一人称で、感情（見えない不安）と数字（出典）を交互に置く
- 「除菌」「守る」「病気になる」は書かない。子どもの画像も使わない
- **末尾に無料点検の申込を置く**ことで、商品を買う決心がない人も逃さない（無料点検の流入経路の1つ）

## 1. 商品（瞬間専用。名前を付ける）

アニコムの「0歳専用・1か月100%」に倣い、**通常メニューの流用ではなく、その瞬間の名前を付けた商品**にする。料金は `data/prices.json` の税込価格を組み合わせる（**値引きは価格の判断＝オーナー**）。

| 商品名（案） | 誰の、いつ | 中身（既存メニューの組合せ） | 税込（現行価格の単純合算） | 置く場所 |
|---|---|---|---|---|
| **赤ちゃんを迎える前のエアコン＋浴室** | 出産前後の家庭 | エアコン1台 10,780円 ＋ 浴室（同時施工）15,180円 | 25,960円 | 産院・小児科・子育て支援施設・保育園 |
| **ペットを迎える前のエアコン＋換気扇** | 犬猫を迎える家庭 | エアコン1台 10,780円 ＋ レンジフード（同時施工）15,180円 | 25,960円 | ペットショップ・動物病院・トリミング |
| **入居直後のまるごと**（後日） | 引越し直後 | 水まわりセット | — | 仲介店・管理会社（外注網ができてから） |

- **専用の名前・専用のページ・専用のQR**。通常の予約フォームに `?src=施設ID` を付けるだけで技術的には足りるが、**名前が付いていないと「その瞬間の商品」にならない**（事例の教訓）
- 施設の利用者向け特典を付けるかどうか（例：次回予約割引を初回に適用）は**オーナー判断**。特典なしでも「専用ページ・明朗料金・追加請求なし」で成立させる設計にしておく
- 健康の話は東京都の指針の引用まで。「赤ちゃんを守る」「除菌」は書かない（措置命令の前例）

## 2. 施設への提案（何を渡し、何を求め、何を返すか）

| 施設に求めること | 施設に渡すもの | 施設が得るもの |
|---|---|---|
| レジ横か待合に**QRスタンド1枚**（A6）を置く。それだけ。説明は不要 | QRスタンド（PDFで送る。印刷が面倒な施設には印刷して郵送＝**郵送費はお金**）／説明動画（1分22秒）／施設専用の報告ページ | **利用者への特典**（あれば）／**月次の紹介料**（成約時 施工額の12%＝既存の事業者紹介制度。産院・医療機関には払わず、利用者特典のみにする案も）／**自施設の利用者が何人使ったかの週次報告** |

**報酬の型（2026-09-11 オーナー決定：小規模事業者には原則12%を謳う。受け取れない法人だけ報酬なし）**

| 型 | 対象（**法人名から自動判定**） | 施設への報酬 | 謳い文句 |
|---|---|---|---|
| **12%型（原則）** | 個人事業・株式会社・合同会社の施設すべて：ペットショップ・トリミング・ベビー用品店・**個人開業の動物病院・産院・小児科**・株式会社運営の保育園 | 成約時 施工額の12%（既存の事業者紹介制度）。月末締め・翌月末払い・支払通知自動。施設側は雑収入で計上できる | 「ご紹介いただいたご利用の12%をお支払い」 |
| **報酬なし型** | **医療法人**（「医療法人◯◯会」）・**社会福祉法人**・自治体・学校法人・NPO | 報酬なし。利用者特典のみ | 「患者さま・利用者さまの満足度向上」「退院後・お迎え後のご家庭との接点を延ばす情報提供」 |

- 医療法人が行える業務は本来業務・附帯業務・附随業務に限られ、**収益業務は社会医療法人等にしか認められていない**（厚労省「医療法人の業務範囲」平成26年）。紹介料の受領が問題になりうるので、医療法人には最初から出さない
- 社会福祉法人は公益事業・収益事業に資金使途の制限がある。自治体・公立は不可
- **判定は法人名の文字列で自動**（「医療法人」「社会福祉法人」「学校法人」「特定非営利」「区立・市立・都立」を含めば報酬なし型）。判定に迷う施設は12%型で送り、先方が辞退すれば報酬なし型に切り替える

## 3. 自動化の全体像（人の稼働は施工だけ）

```
 [1 施設リスト]  Google Places API で江戸川区・浦安市の対象施設を抽出
                 種別・住所・電話・サイト・問い合わせフォームURL・メール（公開分のみ）
                 → 「営業お断り」の記載があれば除外（サイトを自動で読む）
   │
   ▼
 [2 設置依頼]    メール（公開アドレス）または問い合わせフォームへ、施設種別ごとの文面を送る
                 ★ 文面と送信対象リストをオーナーが1回承認（外部への連絡）。以後は同じ文面を自動送信
                 送らない：個人アドレス／「営業お断り」／返信で断られた施設（永久に除外）
   │
   ▼
 [3 追跡]        7日後に1回だけ再送（文面違い）。2回で反応がなければ終了（しつこくしない）
   │
   ▼
 [4 承諾]        施設が返信フォーム（1分）で「置く」＋設置場所＋担当者名 → 自動で
                 施設ID発行／専用QR生成／説明動画URL／報告ページURL を返信
                 印刷希望なら、印刷・郵送（外注の印刷サービスへ自動発注＝お金）
   │
   ▼
 [5 利用]        利用者がQR → 専用ページ（商品名・料金・98.6%・予約）→ 予約フォーム（src=施設ID）
                 → 施工（当社。将来は提携職人）
   │
   ▼
 [6 週次報告]    毎週月曜：施設ごとに「QR読取◯回／予約◯件／施工◯件」を施設へメール
                 商業型は月末に紹介料の明細と請求書（施設から当社への請求…ではなく当社からの支払通知）
                 オーナーへは全施設のまとめ1通
   │
   ▼
 [7 補充・撤去]  3か月で読取ゼロの施設には「撤去しますか」を自動で聞く。返信なしなら報告を止める
```

**人が要る工程：施工のみ。** 承認は「2」の文面と対象リストの1回。以後の送信・返信対応・QR発行・報告は全部自動。

## 8. オーナーに決めていただくこと（すべて決めれば、以後は自動）
