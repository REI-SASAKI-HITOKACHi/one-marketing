# 節目チャネル（型②「その瞬間のレジ」）の全体構造 ─ 営業担当ゼロで、地域の施設にQRを置いてもらう

作成 2026-09-11 ／ 担当 ネット流入施策担当（`web-inflow`）／ オーナー指示「販売用QRの設置依頼（メール・問い合わせフォーム）、使い方説明（動画）、週次報告まで自動化。外注網ができるまで地域限定＝中小零細を対象」
根拠：`docs/潜在→顕在の事例研究.md`（アニコム：新規の約7割がペットショップ購入時、産院サンプリング、ヤマダの推奨タイミング「赤ちゃんをお迎えする準備として」「ペットのために」）
**まだ何も送っていません。外部への送信はオーナー承認後。金額の判断はすべてオーナー。**

---

## 0. 一行で

> **「赤ちゃんを迎える前」「ペットを迎える前」の専用クリーニングを、その瞬間に人が立ち寄る地域の施設（ペットショップ・動物病院・産院・子ども向け施設）のレジや待合に、QR1枚で置いてもらう。** 設置依頼から週次報告まで自動。人が要るのは施工だけ。

## 1. 商品（瞬間専用。名前を付ける）

アニコムの「0歳専用・1か月100%」に倣い、**通常メニューの流用ではなく、その瞬間の名前を付けた商品**にする。料金は `data/prices.json` の税込価格を組み合わせる（**値引きは価格の判断＝オーナー**）。

| 商品名（案） | 誰の、いつ | 中身（既存メニューの組合せ） | 税込（現行価格の単純合算） | 置く場所 |
|---|---|---|---|---|
| **赤ちゃんを迎える前のエアコン＋浴室** | 出産前後の家庭 | エアコン1台 10,780円 ＋ 浴室（同時施工）15,180円 | 25,960円 | 産院・小児科・子育て支援施設・保育園 |
| **ペットを迎える前のエアコン＋換気扇** | 犬猫を迎える家庭 | エアコン1台 10,780円 ＋ レンジフード（同時施工）15,180円 | 25,960円 | ペットショップ・動物病院・トリミング |
| **入居直後のまるごと**（後日） | 引越し直後 | 水まわりセット | — | 仲介店・管理会社（外注網ができてから） |

- **専用の名前・専用のページ・専用のQR**。通常の予約フォームに `?src=施設ID` を付けるだけで技術的には足りるが、**名前が付いていないと「その瞬間の商品」にならない**（事例の教訓）
- 施設の利用者向け特典を付けるかどうか（例：次回予約割引を初回に適用）は**オーナー判断**。特典なしでも「専用ページ・明朗料金・追加請求なし」で成立させる設計にしておく
- 健康の話は東京都の指針の引用まで。「赤ちゃんを守る」「除菌」は書かない（措置命令の前例）

## 2. 施設への提案（何を渡し、何を求め、何を返すか）

| 施設に求めること | 施設に渡すもの | 施設が得るもの |
|---|---|---|
| レジ横か待合に**QRスタンド1枚**（A6）を置く。それだけ。説明は不要 | QRスタンド（PDFで送る。印刷が面倒な施設には印刷して郵送＝**郵送費はお金**）／2分の説明動画／施設専用の報告ページ | **利用者への特典**（あれば）／**月次の紹介料**（成約時 施工額の12%＝既存の事業者紹介制度。産院・医療機関には払わず、利用者特典のみにする案も）／**自施設の利用者が何人使ったかの週次報告** |

**2つの型を用意する（施設の性格で自動で切り替える）**

| 型 | 対象 | 施設への報酬 |
|---|---|---|
| **商業型** | ペットショップ・トリミング・ベビー用品店 | 成約時 12%（月末締め・翌月末払い・請求書自動） |
| **公益型** | 産院・小児科・動物病院・保育園・子育て支援施設 | 報酬なし。**利用者特典のみ**。「地域の家庭向けの情報提供」として置いてもらう |

医療機関・保育施設への紹介料は、法令上の禁止が無くても**受け取らない施設が多く、印象を損ねる**。公益型は最初から金銭を出さない。

## 3. 自動化の全体像（人の稼働は施工だけ）

```
 [1 施設リスト]  Google Places API で江戸川区・浦安市の対象施設を抽出
                 種別・住所・電話・サイト・問い合わせフォームURL・メール（公開分のみ）
                 → 「営業お断り」の記載があれば除外（サイトを自動で読む）
   │
   ▼
 [2 設置依頼]    メール（公開アドレス）または問い合わせフォームへ、施設種別ごとの文面を送る
                 ★ 文面と送信対象リストをオーナーが1回承認（外部への連絡）。以後は同じ文面を自動送信
                 送らない：個人アドレス／「営業お断り」／返信で断られた施設（永久に除外）
   │
   ▼
 [3 追跡]        7日後に1回だけ再送（文面違い）。2回で反応がなければ終了（しつこくしない）
   │
   ▼
 [4 承諾]        施設が返信フォーム（1分）で「置く」＋設置場所＋担当者名 → 自動で
                 施設ID発行／専用QR生成／説明動画URL／報告ページURL を返信
                 印刷希望なら、印刷・郵送（外注の印刷サービスへ自動発注＝お金）
   │
   ▼
 [5 利用]        利用者がQR → 専用ページ（商品名・料金・98.6%・予約）→ 予約フォーム（src=施設ID）
                 → 施工（当社。将来は提携職人）
   │
   ▼
 [6 週次報告]    毎週月曜：施設ごとに「QR読取◯回／予約◯件／施工◯件」を施設へメール
                 商業型は月末に紹介料の明細と請求書（施設から当社への請求…ではなく当社からの支払通知）
                 オーナーへは全施設のまとめ1通
   │
   ▼
 [7 補充・撤去]  3か月で読取ゼロの施設には「撤去しますか」を自動で聞く。返信なしなら報告を止める
```

**人が要る工程：施工のみ。** 承認は「2」の文面と対象リストの1回。以後の送信・返信対応・QR発行・報告は全部自動。

## 4. 送る文面の型（施設種別ごとに1本。承認は1回）

```
件名：レジ横にA6のカード1枚を置いていただけませんか（江戸川区のハウスクリーニング店より）

◯◯（施設名）ご担当者さま

江戸川区北葛西でハウスクリーニングをしております、ワンヒッター株式会社の佐々木と申します。
（産院向け）赤ちゃんを迎えるご家庭向けに「赤ちゃんを迎える前のエアコン＋浴室クリーニング」という
専用のメニューを作りました。
（ペット向け）犬猫を迎えるご家庭向けに「ペットを迎える前のエアコン＋換気扇クリーニング」という…

お願いは1つだけです。待合（レジ横）に、A6サイズのカードを1枚置いていただけないでしょうか。
ご説明もお手続きも不要です。カードはこちらでお送りします。

・料金は税込・追加請求なし（エアコン1台＋浴室 25,960円）
・ご利用後のアンケートで98.6%の方が「他の人にすすめたい」（2023年1月〜2025年12月、209名中206名）
・Googleクチコミ ★5.0（2026年9月時点・23件）
・貴院のカードから何名がご利用になったかを、毎週メールでお知らせします
（商業型のみ）・ご紹介いただいたご利用の12%を、月末締めでお支払いします

置いていただける場合は、下のリンクから設置場所だけお知らせください（1分）。
https://…/setti?f=◯◯◯

ご不要の場合は、このメールへ「不要」とご返信ください。以後お送りしません。

ワンヒッター株式会社 佐々木 嶺／〒134-0081 東京都江戸川区北葛西5-14-11／080-8043-8259
```

- **特定電子メール法：** 事業者が営業目的で公開しているアドレスへの送信は同意不要の例外。ただし「送信者名・住所・受信拒否の方法」の表示義務あり（上の文面に入れてある）。**個人アドレスには送らない**
- 問い合わせフォーム経由の送信は、フォームに「営業目的の利用禁止」とあれば送らない（自動で判定）

## 8. オーナーに決めていただくこと（すべて決めれば、以後は自動）

1. 商品名と価格（単純合算25,960円のままか、特典を付けるか）
2. 商業型の紹介料12%でよいか／公益型は報酬なしでよいか
3. 送信文面3種と、最初の送信対象（例：産院5・小児科10・ペットショップ10・動物病院10）の承認 ＝**外部への連絡**
4. QRカードの印刷・郵送費（1施設あたり数百円）を出すか、PDF送付のみにするか
5. サービスアカウントの鍵の受け渡し（施設リストの抽出に要る）

## 9. 守ること

- 送信は公開アドレス・フォームのみ。「営業お断り」は送らない。断られたら永久除外。再送は1回まで
- 医療機関・保育施設には金銭を渡さない
- 健康の断定なし。子どもの画像を使わない
- 施設名は本人の承諾なく公開しない（週次報告は施設ごとに個別）
