## 2. 過去4年の分布 ── 9〜12月は毎年立っていた

`【毎月更新】リピート/業務提携` の提携先18社・記録146件の受注日を、年×月に並べ直したものです。

|---|--:|--:|--:|--:|

| 2025 | 35件 | **9件** | 3件 | **2件** |
| **2026** | **42件**（1〜8月のみ） | **0件** | **0件** | **0件** |

**10〜12月のゼロは、どの年でも9月17日時点では埋まっていないので、情報がありません。**
**公平に比べられるのは最後の列（9/1〜9/17）だけ**で、**2件 → 4件 → 2件 → 0件**です。

- 件数が小さいので、この1列だけでは断定できません（期待値2.3件に対してゼロが出る確率は約10%）
- **ただし「9〜12月に毎年8〜9件ある四半期」であることは確定**しました。**②は秋に立たない経路ではありません**

## 5. cmo の問いへの直接の答え

### 「どちらから来たか」は台帳から分けられません

`◯月_売上/顧客` の21列に、**先方からの依頼か当社からの提案かを記録している列がありません**
（`ＯＨ打診` は本舗のお客様に自社を打診したかの列で、提携の話ではない。5月は48件すべて未記録）。
**さらに `受注日` の列もありません。** 日付は `施工日付` と `フォローコール日` だけです。
→ **リードタイムと停止を区別する手段が、構造的に存在しません。** これは私の持ち物なので直します（§7）。

### そのうえで、「どちらか」に寄せられる材料は3つ出ました

| 材料 | どちらを示すか |
|---|---|
| 通年では2026年が2025年を上回っている（関係は生きている） | **こちら側** |
| 秋の受注が5〜6社**すべて**ゼロ（1社の離脱では説明できない） | **こちら側** |
| 8月に大型案件（BREXA・天カセ51台＋ロスナイ17台・¥1,683,000）を1件こなしている | **こちら側**（手が取られた） |

> **仮説（事実ではありません）：8月の大型案件に手を取られて、9月の小口の提携案件を拾えていない。**
>
> 根拠は上の3つで、**確定はできません。** ただ打ち手の方向は決まります。
> **取引条件や関係の修復ではなく、手数の問題として扱うほうが当たりそうです。**

### 和真さんに聞くべきことも、絞れました

「止まりましたか」ではなく、**この2つだけ**でいいと思います。

1. **才木工業さん。** 2025年は秋に3件（9/07・10/19・11/08）いただいていたのが、2026年は7/02の1件だけです。
   **何か変わりましたか。それとも、こちらから声をかけていないだけですか**
2. **秋に出る提携先は、毎年5〜6社に分散していました。** 今年その全社がゼロです。
   **8月の大型案件のあと、提携先への連絡が止まっていた心当たりはありますか**

**10社全部に聞く必要はありません。** 才木工業1社と、去年の秋に出た残り4社（レジェンド・青山リアルティー・エコハウス・かさい電器）で足ります。

## 6. 2027年の計画への影響 ── **②の月別配分を作る必要があります**

**いちばん実務に効くのはここです。**

`docs/2027-数値目標.md` の②は**年額840万・94件**しか置いていません。月別がない。
**2026年の分布のまま置くと、Q4に②が1件も立たない配分**になります。

| 2027年 ②94件を…… | 1月 | 2月 | 3月 | 4月 | 5月 | 6月 | 7月 | 8月 | 9月 | 10月 | 11月 | 12月 |
|---|--:|--:|--:|--:|--:|--:|--:|--:|--:|--:|--:|--:|
| 2026年の分布で置くと | 7 | 5 | 5 | 16 | 9 | 26 | 19 | 7 | **0** | **0** | **0** | **0** |
| **2023〜2025年の分布で置くと** | | | | | | | | | **9** | | **15**（10〜12月計） | |

過去3年の構成比は **9月が平均10.0%／10〜12月が平均16.3%**。
**②94件なら、9月に約9件、10〜12月に約15件**が実績に即した置き方です。

**Q4の売上目標は674万（中立）**で、いまその中に②が入っていません。
**②がQ4にゼロなら、674万は①（早期予約・リピート）と④（ネット新規47件）だけで作ることになります。**
→ **②の目標に「9〜12月に最低◯件」を明示的に置いてください。** 年額840万を達成しても、四半期の形が崩れます。

**私の推奨：②の月別配分を過去3年の分布で置き直し、Q4に15件（約130万）を明示する。** 今週やります。
