### 数え方
- **広告クリック**：広告のテスト画面の「バリエーション」の実績と「オリジナル比」から出す（画面に元の広告の件数が出ないため。C ＝ E ÷（1＋オリジナル比））。browser が読む
- **LPユーザー**：GA4 の `page_view` のユーザー数（`google / cpc`、ページ /aircon-c/・/aircon-e/）
- **slot_chip_view 率**：E の `slot_chip_view` のユーザー ÷ E の LPユーザー。**90% 未満なら日付ボタンが出ていない人がいる**（空き枠の取得に失敗している）→ 原因を見る
- **予約ページへ進んだ人**：`cta_click` のうち `link_target=yoyaku` のユーザー。**GA4 に `link_target` のカスタムディメンションの登録が要る**（下の「お願い」）。登録までは、予約ページの `page_view`（`lp=aircon-c`／`aircon-e` 付き）で代わりに数える
- **menu=ac1 で着いた数**：予約ページの `page_view` のうち、URL に `menu=ac1` を含むもの（E の日付ボタン経由）
- **申込**：予約_Web の `lp` 列（予約ページ経由は `lp=aircon-c`／`aircon-e`）＋ LP 内フォーム `reserve-aircon-c`／`reserve-aircon-e`
- **受注**：台帳

### 判定の規則（CMO の設計どおり）
- **100**：壊れていないか。E の予約ページへ進んだ率が C の半分未満なら止めて原因を見る
- **200（または 11/30 の早い方）**：E の予約ページへ進んだ率が C の **1.5倍以上**、かつ片側 p<0.10、かつ申込／クリックで E が C を下回らない → **E を採用**。どちらでもなければ「差なし」

## 同じ時期に変わったこと（読み方の注記）
- **10/10 17:5x：C と E の両方に同じ文面の直し**（98.6% の言い回し・脚注）。C と E の違いは空き日の帯だけのまま
