**空いている枠があり、単価の高い経路があり、その経路への入口だけが無い。**

## 柱1：SNSの運用

### 何を目指すか

フォロワー数ではない。**江戸川区・西葛西・浦安の人に届くかどうか。**
ローカル商圏なので、全国の10万フォロワーより、商圏内の1,000人の方が売上になる。

指標はこの順で見る。

1. 予約フォームへの流入（`?src=` を付けて計測する。計測担当と組む）
2. Googleビジネスプロフィールの表示回数・経路検索・電話
3. 保存数・プロフィールアクセス（フォロワー数より先にこちらが動く）

### いちばん強い素材はもう決まっている

**ビフォーアフターと汚水。** ハウスクリーニングはここが最強。
現場写真は Drive の「01_これから撮る分」に集まる運用になっている
（撮影ルールはカレンダーのTODO T007に書いてある。同じ位置・同じ角度で撮ることが最重要）。

素材が足りないときは、現場責任者の渡辺さんに撮影を依頼する。
**ただし渡辺さんは現場で手が塞がっている。** 依頼は「1案件5枚（Before2・After2・汚水1）」のように
その場で判断せず実行できる形にすること。CMO経由で出す。

### 着手前に確認すること

`docs/sns-operation-memo.md` に一覧がある。**まず既存アカウントの実態を調べるところから。**
`@onehitter.jp`（Instagram）と Facebook ページの存在は確認済みだが、
投稿頻度・フォロワー数・誰がログインできるかは未確認。

### 守ること

- **投稿はオーナー承認が要る**（「外に出す」に当たる）。企画・原稿・画像の準備までが担当範囲
- **お客様が特定できる写真は載せない。** 過去写真の掲載は現場担当者が口頭で承諾を得ている
- **アンケート実績は 98.6%（209名中206名）。** パンフレットとサイトにある「98.8%」は
  根拠と一致しないので使わない
- **料金は `docs/price-master.md` が正**（パンフレットPDF）。公式サイトの料金表には誤りがある

## 柱2：メディア製作＋運営（深掘りは後日）

**いまは着手しない。まず「何のためにやるのか」だけ共有しておく。**

狙いは、**自社で受けきれない量の受注を作ること**。
受けきれない分をどうするかは、そこまで行ってから決める（自社の枠を増やす／協力店に回す／
他社に送客する、のいずれか）。オーナーが解説すると言っているので、
**こちらから設計を確定させにいかないこと。**

なぜこの狙いに意味があるかだけ、いまの構図で言える。
ワンヒッターは現在、**成果単価3,000円で見込み客を買う側**にいる
（`docs/アフィリエイト-レントラックス.md`）。買う側は単価も条件も選べない。
入口を自分で持てば、その関係が逆になる。

**担当としてやること：** オーナーから解説を受けられる状態になったら、
聞くべきことを整理してCMOに渡す。それまでは柱1に集中する。
