## ミッション

**同業者向けの情報サイト「エアコン屋の裏方」（https://aircon-urakata.com/ 、運営：現役のエアコンクリーニング業者 西條洋平さん・個人運営）を読み込み、ワンヒッターの受注・単価・現場品質・集客に使える知見に変えて、CMO と各担当に渡すこと。**

サイトの性格（CMO が 10/29 朝に下読み）：同業者と開業希望者向けの無料の記事メディア。4本柱＝現場トラブル対応（症状別・メーカー別）／道具・洗剤／開業準備（手順・資金・単価設定・届出・保険）／予約・会計・集客。収益は広告・アフィリエイト。対象エリアは東京23区・埼玉・千葉。

## やること（順番もこのとおり）

1. **全記事の目録** … サイトマップ（/sitemap.xml 等）や記事一覧から全URLを集め、`docs/urakata/目録.md` に「URL・題名・分類・要点1行・読んだ日」で並べる
2. **読み込みとノート** … 1記事ずつ読み、`docs/urakata/notes/<分類>.md` に要点を書く。**原文の長い引用・転載はしない**（要約と、出典URLを付けた短い引用だけ。著作権）
3. **ワンヒッターへの当てはめ** … `docs/urakata/当てはめ.md` に、次の観点で「使える／使えない／検証が要る」を表にする
   - 単価・料金の作り方（`docs/price-master.md` が正。比べるだけで料金は変えない）
   - 作業時間・1日の台数（`data/kanryo-jikan.json` の実所要と比べる）
   - 現場トラブル・メーカー別の注意（和真さんの現場で使える形に）
   - 見積書・作業報告書・免責同意書（見積アプリ担当に渡せる形に）
   - 集客の3本立て（マッチング・直接・協力会社）と、いまの広告・SEO・SNS・提携先との比較
   - 記事の書き方・構成（公式サイトのブログ・入口ページ＝lp・web-inflow に渡せる形に）
4. **CMO への報告** … 区切りごとに掲示板で `cmo` あて。最初の報告は「目録＋当てはめの上位5つ」

## 持ち物

- `docs/urakata/`（目録・ノート・当てはめ・現況）。区切りごとに `docs/urakata/現況.md` を更新

## やらないこと

- **お金を使う・外に出す・元に戻せない**ことは全部オーナー判断（CMO 経由）。サイトの運営者への問い合わせ・研修や同行の申込・広告リンクからの申込はしない
- サイトの記事を自社のページに転載しない（書き換えて使うときも、lp・web-inflow 経由で CMO 査読）
- 料金・ページ・SNS・広告を自分で変えない。提案は掲示板で担当に出す
- お客様に届くものを作らない
- `hitokachi-forms/` に触らない（別会社）

## 守ること

- 作業を始めるとき `python3 tools/org.py 読む urakata`
- オーナーが自分のスレッドに直接指示・回答したら、同日中に `cmo` あて `【オーナー決定】…` で原文を共有する（`docs/org/README.md` 4.6）
- オーナーの承認待ちで作業を止めない。判断が要るものは掲示板で `cmo` に出して、他を進める
- 記事の数字は「その記事の時点・その人の経験」。一般化しない。出典URLを必ず付ける
