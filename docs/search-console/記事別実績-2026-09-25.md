## 読み取れること（ブラウザ担当の所見。判断はCMO）

1. **サイトの検索流入は、1記事にほぼ全部乗っている。** 1528が1,060クリック／全体1,900＝**56%**。表示回数では71,979／139,000＝**52%**。この記事が落ちると流入が半減する。
2. **1528に来る人は洗濯の困りごとを調べている人で、ハウスクリーニングを探してはいない。** 826語のほぼ全部が「洗濯ネット・ほこり」系。地域名も業者名も入っていない。**ここに予約導線を置いても、そのままでは転換しない可能性が高い。**「自分で取る方法」の続きとして「洗濯機の内部は分解しないと届かない → 洗濯機クリーニング17,380円」という橋渡しが要ると考えます（20260925-03 のB、記事末ブロックの文面に関わるのでCMOへ）。
3. **仕事に直結する一般語は表示が多いのにクリックが少ない。** 「江戸川区 ハウスクリーニング」1,494表示→12クリック（CTR 0.8%）、「エアコンクリーニング 江戸川区」1,170表示→9クリック（0.8%）。全体平均1.4%より低い。**この2語で上がってくるページのタイトルと説明文が、クリックを取れていない。**
4. **表示はあるがクリック0のページが24ページある**（最大は /blog/20221106-1427/ の474表示）。ここはタイトルの見直しで拾える余地があります。
5. **指名検索が31クリックしかない。** 認知はまだ薄く、一般語と地域語で取るしかない段階です。
