# 顧客共有の写真フォルダ：共有範囲の点検（2026-10-10 CMO・読むだけ）

第6回MTG（10/9）で和真さん「お客様と共有している写真フォルダは、親に戻ると他のお客様の写真が見えてしまう」→ 嶺さん「アクセス制限をかければよい」。
Drive コネクタで「【顧客共有】施工写真/onehitter」（16z5jr1…）以下を全部見た。**権限は何も変えていない。**

## 結果
- 直下の子フォルダ 34件（持ち主はすべて和真さん）。親（16z5jr1…）と、その上（1_VkA…）は **嶺さん（持ち主）・和真さん・info.onehitter の3アカウントだけ**。リンク公開なし
- 「リンクを知っている全員」に公開されているのは **現場フォルダ4件だけ**（青山様 松ヶ丘／藤井様／才木工業様の中の川崎様／レジェンド様の中の神奈中商事様）。中身は before/after だけで、他のお客様は入っていない
- **リンクで開いたお客様は、親に戻っても「アクセス権が必要」と出て中は見えない＝外部への漏れは今は起きていない**
- 見えてしまうのは、**3アカウントのどれかでログインした画面をお客様に見せたとき**（スマホでお客様に写真を見せる場面など）。親に戻ると34件全部（個人のお客様の名前入り）が見える。MTGの話はおそらくこれ

## 起きやすい箇所
- 元請の入れ物フォルダ（才木工業様・レジェンド様・プレジャー様）の中に、エンドのお客様（個人名を含む）の現場が入っている。**入れ物ごと共有すると、元請に別のお客様の現場が全部見える**。今は入れ物は非公開なので問題なし
- 江戸前ハーブ様・関西ペイント様・湘南エミネンス寮は、同じお客様の回ごとのフォルダなので、入れ物ごと共有しても問題なし

## 決まり（和真さんへ LINE で共有）
1. お客様に渡すのは **その現場のフォルダのリンクだけ**。入れ物（会社名のフォルダ）や上のフォルダは共有しない
2. お客様の前で写真を見せるときは、**ドライブのアプリで現場のフォルダを開いたまま見せ、上に戻らない**。できればLINEで送った写真か、写真アプリで見せる
3. フォルダ名は **「2026/10/08_お客様名_内容」**（年から、0埋め、区切りは「_」）。入れ物（会社名）だけは日付なしでよい
   - いまそろっていないもの：日付で始まらない現場フォルダ2件（共用部階段 クラスリフォーム様／サンリバー様）、年なし1件（6/12,14 松ヶ丘）、0埋めなし8件、空白区切り3件。**名前を変えてもリンクは切れない**
4. オーナー権：親フォルダ（16z5jr1…）はすでに嶺さんが持ち主。中の34件は和真さんが持ち主（容量は和真さんのアカウントに乗る）
