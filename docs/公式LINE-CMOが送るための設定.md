# 公式LINEをCMOから送れるようにする手順

作成 2026-09-08 ／ オーナー依頼

> **いま持っているトークンでは公式LINEに送れません。**
> CMOが持っているのは、3人グループ（嶺・和真・マーケ部長）用に作った
> **内部用アカウント**のトークンです。友だち330人の**公式アカウントとは別物**で、
> トークンもチャネルも共有されていません。
> 公式LINE側のチャネルアクセストークンを、別途いただく必要があります。

所要 **10分**。内部用アカウントを作ったときと同じ流れです。

---

## 前提（2026-09-08 オーナー確認）

- **いまは無料プラン。200通の無料枠はほぼ空いている**
- 友だち330人のうち **約200件は、初期に業者から購入したアカウント**（オーナー談）
- 購入分の特徴：**ほぼ1日のうちに200件ほどが一気に追加されている**

つまり、**そのまま全員へ一斉配信すると1回で330通**になり、無料枠200通を超えます。
一方で、**購入分を外せば約130通**に収まり、**無料プランのまま配信できます。**

### なので、先に購入アカウントを外します（TODO T038）

追加日が一点に集中しているので、**追加された時期で見分けられます。**
トークンをいただければ、こちらで一覧を出して「この日に追加された○件」という形で
候補をお渡しします。削除（ブロック）はオーナーの操作になります。

> 購入アカウントを外す実利は、通数だけではありません。
> 開封もクリックもしない相手が3分の2を占めていると、**配信の効果が測れません。**
> 130人に絞れば、反応率が実態に近い数字になります。

## 手順1：Messaging API を有効にする（公式アカウント側）

1. **LINE Official Account Manager** を開く
   https://manager.line.biz/
2. **公式アカウント（友だち330人のほう）** を選ぶ
   ※内部用アカウントと間違えないこと
3. 右上 **［設定］** → 左メニュー **［Messaging API］**
4. **［Messaging APIを利用する］** をクリック
5. プロバイダーを選ぶ
   - 内部用アカウントで作ったプロバイダーがあれば、それを選んで構いません
   - 新しく作る場合の名前は `ONE HITTER` などで結構です
6. プライバシーポリシーと利用規約のURLは**未入力のままでOK**（あとから設定できます）
7. **［同意する］→［OK］**

これで、公式アカウントに紐づく **チャネルID** と **チャネルシークレット** が表示されます。

## 手順2：チャネルアクセストークンを発行する

1. **LINE Developers** を開く
   https://developers.line.biz/console/
2. 手順1で選んだプロバイダー → **公式アカウントのチャネル**を開く
3. **［Messaging API設定］** タブ → いちばん下 **［チャネルアクセストークン（長期）］**
4. **［発行］** をクリック
5. 表示された長い文字列をコピー

> **この画面を閉じても再表示できます**（長期トークンの場合）。
> ただし再発行すると古いトークンは無効になるので、**発行は1回だけ**にしてください。

## 手順3：CMOへ渡す

**チャットに直接貼らないでください。**

1. Googleドライブで新しいドキュメントを作る（名前は `line-official-token-2026-09` など）
2. 共有設定は「**制限付き**」のまま
3. 次の3つを貼り付ける

```
チャネルID：
チャネルシークレット：
チャネルアクセストークン（長期）：
```

4. **そのドキュメントのURLだけ**をチャットに貼ってください

## 手順4（任意・通数を減らしたい場合）：送り先を絞れるようにする

全員へのブロードキャストではなく、**相手を指定して送る**には、
送り先のユーザーIDが必要です。ユーザーIDは、その人が公式アカウントに
**何かメッセージを送るか、友だち追加した瞬間**にしか取れません。

つまり **過去に追加しただけで一度も発言していない人のIDは、いまからは取れません。**

現実的な選択肢は3つです。

| 方法 | 通数 | 備考 |
|---|---|---|
| A. 全員にブロードキャスト | 330通 | **無料枠200通を超える。有料プランが必要になる** |
| B. 購入アカウントを外してからブロードキャスト | 約130通 | **無料プランのまま送れる。おすすめ** |
| C. Webhookで今後発言した人のIDを貯める | 少ない | 今回の配信には間に合わない |

**Bで進めます。** 追加日の集中で購入分を特定できるので、
トークンをいただいたら候補一覧を出します（TODO T038）。

## こちらで用意できること

トークンをいただければ、次はすぐ動かせます。

- 配信本文の作成（SMSと同じく、既存の台帳の情報を使った内容）
- 配信の実行（**送信は「外に出す」に当たるので、その都度、嶺の承認を得てから**）
- 配信後の反応（クリック・返信）の記録

送信に使うツールは `tools/line_client.py` です。
公式アカウント用のトークンは、内部用とは**別のファイルに置いて取り違えを防ぎます**。

```
~/.config/one-hitter/line-token.txt           内部用（3人グループ）
~/.config/one-hitter/line-official-token.txt  公式アカウント ← 新規
```

## やらないこと

- **公式アカウントのトークンで、内部用グループへ送らない**（お客様向けの通数を消費してしまう）
- **お客様の個人情報を、内部用グループのLINEに流さない**
  （内部用のwebhookは署名検証ができない経路のため。`tools/line-webhook.gs` の注記）
