## 1. 何が起きているか

MTGで確定した種目別の作業時間と、システムが使っている `data/prices.json` の値が **5か所ちがいます**。
この分数は3か所に効きます。

| 効く先 | 何が変わるか |
|---|---|
| 予約フォーム | お客様に出る**空き枠の長さと本数** |
| 受注フォーム | 終了時刻の自動計算・カレンダー予定の長さ |
| 12月の受付可能件数 | いまの見込み「約47件」 |

## 4. 変えると何が変わるか（数字）

### 1日に入る件数

予約フォームは 9:00〜21:00 の12時間で、現場と現場の間に移動60分を必ず空けます。

| 1件の所要 | 1日に入る件数 |
|--:|--:|
| 60分 | 6件 |
| 90分 | 5件 |
| **120分（いまの浴室）** | **4件** |
| 150分 | 3件 |
| **180分（推奨の浴室）** | **3件** |

**浴室だけを受ける日は、4件 → 3件になります。**
ただし実際には180分かかっているので、**いまは入らない4件目をお客様に出してしまっている**状態です。

### 12月の受付可能件数

いまの見込みは **約47件**（`docs/2026-12月の受付可能件数と締め日.md`。12/29〜31を休む前提で200時間、1件4〜4.5時間）。

| | 1件あたり（作業＋移動60分） | 12月に受けられる件数 |
|---|--:|--:|
| いまの設定 | 260分（4.3時間） | **約47件** |
| 推奨（A〜F＋洗濯機120分） | 281分（4.7時間） | **約43件** |

**▲4件です。** 2025年12月の実績は33件なので、**43件でもまだ10件ぶんの余裕があります。**
年末プラン・LPの訴求・2027年の数値計画は、この変更では**書き換えが要りません**。
