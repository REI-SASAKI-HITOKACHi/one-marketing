## これからやること

**Netlify に回答が入った瞬間に、スプレッドシートへ1行足す。**

```
お客様が送信
  → Netlify Forms が保存（ここが原本。これは変わらない）
  → 送信フック（Webhook）で Apps Script を呼ぶ
  → 「2026_売上/顧客情報管理」の「アンケート回答」タブに追記
```

**スプレッドシートは「見るための写し」です。**Apps Script が止まっても、
回答そのものは Netlify に残るので失われません。

## 手順

### 1. Apps Script を作る（オーナーの操作・5分ほど）

1. `https://script.google.com/` を開いて **新しいプロジェクト**
2. 中身を `tools/gas/survey-to-sheet.gs` の全文に差し替える
3. プロジェクト名を「アンケート → スプレッドシート」などにする
4. **合言葉を決めて保存する。**
   歯車（プロジェクトの設定）→ スクリプト プロパティ → プロパティを追加
   - プロパティ … `AIKOTOBA`
   - 値 … 推測されない文字列（例：`sv-` のあとに英数字20文字くらい）
   **この値はリポジトリにも掲示板にも書かないでください。**
5. **デプロイ → 新しいデプロイ → 種類「ウェブアプリ」**
   - 次のユーザーとして実行 … **自分**
   - アクセスできるユーザー … **全員**
     （Netlify から呼ぶため。合言葉が無いPOSTは弾くようにしてあります）
6. 出てきた **`/exec` で終わるURL** を控える

> 初回のデプロイで「このアプリは確認されていません」と出ます。
> ご自身が作ったスクリプトなので、詳細 →「（プロジェクト名）に移動」で進めて構いません。

### 2. Netlify 側の送信フックを足す（私がやります）

`/exec` のURLと合言葉を教えてください。**私が Netlify 側に登録します。**

```
type=url / event=submission_created
url = https://script.google.com/macros/s/……/exec?key=（合言葉）
```

**URLに合言葉が入るので、掲示板には書かずに、このチャットで直接お伝えください。**

### 3. 動くことを確かめる（私がやります）

テスト送信を1件して、「アンケート回答」タブに行が増えることを確認します。
確認できたらテスト行は削除します。

## タブの列

`アンケート回答` タブは、初回の書き込み時に自動で作られます（見出し行つき・1行目固定）。

```
受信日時／顧客ID／お名前（台帳）／メニュー／担当／施工日／流入元／
NPS／NPS区分／仕上がり／スタッフ／箇所／箇所の感想／良かった点／
次に頼みたい／次の時期／割引希望／紹介／掲載可否／写真掲載／
お客様の声／お名前（回答）／電話（回答）／非公開の指摘／
IP／端末／参照元／その他
```

- **`顧客ID`** は SMS経由の回答に入ります（URLの `?id=`）。**台帳との結合キーです。**
  現場QRからの回答には入りません（誰が答えたか分からないため）
- **設問を増やしたのに列を足し忘れても、`その他` 列に入って消えません。**
  列を足すときは `COLS` の**末尾に足すこと**。途中に挿すと過去の行とずれます

## 個人情報の扱い

このタブには**お名前と電話番号が入ります。**
`2026_売上/顧客情報管理` は既に顧客情報を持っているので置き場所としては同じですが、
**共有範囲を広げないこと。**閲覧者を増やすときは、このタブを別ファイルに分ける方が安全です。

## もう1つのやり方（採らなかった案）

サービスアカウントの鍵（`GOOGLE_SHEETS_SA_KEY`）を作業環境に置けば、
`tools/sheets_client.py` を使って**私が定期的に取り込む**こともできます。

**採りませんでした。** 取り込みは「私が動いているとき」しか走らないので、
記録が遅れます。Apps Script なら回答が入った瞬間に入ります。
鍵を増やさずに済むのも利点です。
