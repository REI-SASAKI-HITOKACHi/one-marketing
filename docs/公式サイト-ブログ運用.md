# 公式サイト ブログ運用

## ブログ本文の写真の置き場（2026-10-08〜）

公式サイトの CMS は本文に画像をアップロードする口が無い（Jodit のアップローダーが無効・記事が持てる画像はアイキャッチ1枚）。
そのため本文の写真は **LPのサイト（Netlify）の `deploy/netlify/blog-photos/`** に置き、`https://lp.onehitter.jp/blog-photos/<ファイル名>` を本文から参照する。

- 写真の出どころ：web-inflow の `assets/photos/`（EXIF除去済み・長辺1600px）。割り当ては web-inflow の `docs/blog/写真割り当て表.md`
- 置く前に lp でも目視（本舗のロゴ・社名・番号／お客様の名前・表札・私物）。GPS などの EXIF が無いことも確認
- **このフォルダのファイル名・パスは変えない**（ブログ本文から直接参照しているので、消すと記事の写真が切れる）
- 配信は LP と同じく `deploy-netlify.py`（サイト全体の差し替え）。フォルダは build-site.py では消えない
