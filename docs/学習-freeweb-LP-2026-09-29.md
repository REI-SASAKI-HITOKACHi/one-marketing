## 先に断っておくこと

- **実績ページには、成果（CVR）の数字が1件も書かれていない。** 学べるのは「型」までで、「その型で申込が増えた」根拠は無い
- デザイン画像には**制作途中の仮原稿**が残っている（IKUSA の声「テキストテキスト…」、運動会「累計〇〇〇箇所」「本文が入ります」）。
  公開版ではなくデザイン案を載せている
- ページの「総合満足度91.2%」は**制作進行への満足度**で、LPの成果ではない

## 学んだこと

### 1. 「LPで最も重要なのは、文字を読んでもらうこと」
ページの主張の中心。ほとんどのLPは流し読みされて閉じられ、二度と戻ってこない。だから読ませる工夫がすべての前提。
実績でも、どのLPも**1画面に言いたいことを1つ**、大きい文字・短い行で置いている。

### 2. 情報設計の4P（何を載せ、何を載せないか）
| | 意味 | 問い |
|---|---|---|
| POP | 同質点・あって当然の条件（機能・価格・対応範囲） | 検討に必要な情報はそろっているか |
| POU | ここにしかない価値（技術・背景） | 自社にしか語れない価値は何か |
| POD | 比べたときに選ばれる違い | その違いはお客様のメリットになるか |
| **POI** | **刺さらない情報＝載せないもの** | **言いたいだけの情報ではないか** |

4つ目の「載せないものを決める」が効いている。

### 3. 12タイプ（価格帯 × 慎重か即決か × 理性か感性か）
商材ごとに勝ち筋が違う、という分類。**うちに当てはめると：**
- 普段のハウスクリーニング（1〜3万円・知らない人を家に入れる）＝**低〜中価格 × 慎重**
  → **09「損しないよね？」＝条件を明確にする**、**10「ちゃんとしてる？」＝最低限の不安を止める**
- 真夏のエアコン（暑くて今すぐ）＝**即決 × 理性** → **11「問題なさそう」＝行動を促す**
- **SANU・Minimal のような世界観で押すLPは、うちの型ではない。** 見た目は美しいが、うちのお客様の判断に要るのは条件と安心

### 4. 実績から取り出した「取り方」の型
| 型 | 実例 | 要点 |
|---|---|---|
| **決め手を形を変えて3回出す** | IKUSA | 買う決め手（KBF）＝「事例」と決め、声・導入事例・イベント例を3回、別の形で出す |
| **見積り例を3つ並べる** | IKUSA運動会 | 「場所・人数・時間・競技 → 約63万円」をA/B/C社で。**計算機を触らない人にも金額の相場が伝わる** |
| **料金に含まれるものを図で** | BBQ | 食事＋飲み放題＋席料をアイコンの足し算で |
| **プランを「誰のためか」で名付ける** | BBQ | 「手軽に楽しみたい」「人気No.1」「特別な日の贅沢」 |
| **先入観を先に言葉にして打ち消す** | KIRAKIRA | 「高機能＝刺激が強そう？ 自然派＝物足りない？ そんなイメージも今日でおしまい」 |
| **代わりの選択肢と比べる（注記つき）** | SANU | ホテル約10.9万 vs 1泊約2.6万。前提は注記に全部書く |
| **ボタンの真下に信頼の数字3つ** | MYTONE／Bee | 「累計3万枚・★4.7・最短1日」「無料体験・口コミ4.9・徒歩5分」 |
| **来る人の顔と経歴** | IKUSA／Bee | メンバー紹介を顔写真＋前職で。「どんな人が来るか」の不安に直接効く |
| **Before→After を課題の数だけ** | NetAttest | 課題ごとに1組。抽象的な機能を具体的な場面に落とす |
| **数字には必ず出典** | NetAttest／SANU | 「*1 2025年1月現在」「*2024年10月自社調べ」 |
| **体験を時系列の物語で** | SANU | 実在の夫婦と愛犬の「1泊2日」。写真と一言で当日を想像させる |
| **ボタンの上に一言** | NetAttest | 「無料」「1分でかんたん入力！」 |

### 5. 公開してからが本番
ABテスト・ヒートマップで「どこで迷ったか」を見る。流入元に合わせて形式を変える
（検索広告は縦型、SNSは**記事型・スワイプ型・診断型**）。

## うちのLPと比べて

**すでにできていること**（本番のエアコンLP・水まわりLPの構成で確認）
- 悩みの言語化から入る（「フィルターを掃除してもカビ臭い」「後回しにしている場所、だいたいこの4つ」）＝KIRAKIRA型
- 「なぜ、この価格でできるのか」＝安すぎる不安の先回り
- 「下請けに出しません。自社の職人が伺います」「誰が来るのか」＝安心確認型の核
- 当日の8工程・料金計算機・満足度98.6%（出典つき）

**足りないこと（効きそうな順）**
1. **お見積り例が無い**（2本とも0件）。昨日の申込フォームの件で、**計算機を触らずに申し込む人がいる**ことが分かっている。
   「よくある頼まれ方」3例（例：エアコン2台＋防カビ／お掃除機能付き1台／浴室＋キッチン）を金額つきで置けば、触らない人にも相場が伝わる
2. **「誰が来るのか」が文字だけ。** 顔写真と一言の経歴があれば、「知らない人を家に上げる」不安に一番効く（写真はオーナー判断）
3. **声が下の方に1回だけ。** 決め手＝「本当にきれいになるか」「感じのいい人か」を、FV直下（★と件数）・中盤（写真つきの声＋「江戸川区・エアコン2台」のような実施内容）・申込直前（短い一言）の3回に分ける
4. **申込ボタンの真下に信頼の数字3つ**（例：満足度98.6%・Googleクチコミ★・最短の空き日）。LP v2 の §5-3（Googleクチコミ）と合わせて入れられる
5. **料金に含まれるもの／含まれないものを図で**（出張費・養生・分解洗浄は込み、コインパーキング代は実費）
6. SNS（Instagram・Facebook）からの流入には、縦長LPではなく**スワイプ型か診断型**（「ひとつでも当てはまったら」のチェックを押せる形に）を試す価値がある

**真似しないこと**
- 世界観で押すブランドページ（SANU・Minimal）。うちのお客様の判断は条件と安心で決まる
- 裏付けの無い数字。free web 自身が注記を徹底しているとおり、うちも 98.6% の出典を外さない
