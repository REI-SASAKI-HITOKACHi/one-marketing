## 制約から決まること

**営業に回せる人がいません。** 和真さんは施工で埋まっていて、オーナーも現場と経営を持っています。
**だから「訪問する」「電話を何本もかける」形の打ち手は、書いた時点で回りません。**

経営企画室の実測が示した必要量：

| | |
|---|---|
| 対象 | アクティブ15社 |
| 接触の頻度 | **月1回**（受注間隔の中央値37日から。代理指標） |
| Q4（3か月） | **45回の接触 → 15件** |

**45回の接触を、人の時間をほとんど使わずに作る形を考えます。**

## 🔑 案：**「今月の空き枠」を月1回送る**

**売り込みではなく、相手が使える情報を送ります。**

> ワンヒッター 佐々木です。10月の空き状況をお送りします。
>
> 　10/2（金） 終日 ／ 10/6（火） 午後 ／ 10/9（金） 終日 …
>
> 急ぎの案件が入りましたら、この日程でお受けできます。
> 埋まり次第この枠は消えますので、目安としてご覧ください。

### なぜこれなら続くか

| | |
|---|---|
| **原稿を毎回考えなくていい** | **中身が毎回変わるのは日付だけ。**「お仕事ありませんか」を月1回送るのは、送るほうが先に嫌になります |
| **相手にとって使える情報** | 提携先は**自分の案件をいつ振れるか**を知りたい。空き枠はそのまま答えになります |
| **データがもう在る** | `tools/build-slots.py` が予約フォーム用に毎時作っています。**B2B向けに使っていなかっただけ** |
| **催促にならない** | 「発注してください」ではなく「空いています」。**断る理由が発生しないので、関係が減りません** |
| **埋まっているときほど効く** | 枠が少ない月は「**もうこれだけしか空いていない**」が自然に伝わります |

### 人の時間

**CMOが原稿を作る（自動）→ オーナーが送信ボタンを押す。月1回・15通で15分程度。**
**訪問も電話も要りません。**

## 測ること（実測が無いのがいまの問題）

**台帳に「接触の記録」の列がありません。**（経営企画室が4列を当たって全滅）
**だから、この打ち手の1回目から記録を取ります。**

| 記録する | なぜ |
|---|---|
| 送った日・送った先 | 接触の回数。**いま誰も知らない数字** |
| 返信の有無 | 反応率 |
| 受注に繋がったか・何日後か | **「接触何回で1件か」の実測。** いまは「3回で1件」と置いているだけ |

**3か月で、推測で置いた 0.33件/回 が実数に置き換わります。**

## 金額の見込み（経営企画室の訂正を反映）

**Q4の②は 130万ではなく 85万です。**
秋の案件の実績平均単価は **¥56,931**（2023〜2025の3年とも58,582／53,000／59,393で安定）。
計画の平均単価8.9万で置くと134万になりますが、**実績は5.7万。**

> **Q4は件数を取る四半期で、金額を取る四半期ではない。**

**15件 × 5.7万 = 85万。** 1社1件で届きます（過去は1社1.5〜2.0件だったので、負荷はむしろ軽い）。
