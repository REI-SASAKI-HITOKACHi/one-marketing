## 🔑 案：**「今月の空き枠」を月1回送る**

**売り込みではなく、相手が使える情報を送ります。**

> ワンヒッター 佐々木です。10月の空き状況をお送りします。
>
> 　10/2（金） 終日 ／ 10/6（火） 午後 ／ 10/9（金） 終日 …
>
> 急ぎの案件が入りましたら、この日程でお受けできます。
> 埋まり次第この枠は消えますので、目安としてご覧ください。

### なぜこれなら続くか

| | |
|---|---|
| **原稿を毎回考えなくていい** | **中身が毎回変わるのは日付だけ。**「お仕事ありませんか」を月1回送るのは、送るほうが先に嫌になります |
| **相手にとって使える情報** | 提携先は**自分の案件をいつ振れるか**を知りたい。空き枠はそのまま答えになります |
| **データがもう在る** | `tools/build-slots.py` が予約フォーム用に毎時作っています。**B2B向けに使っていなかっただけ** |
| **催促にならない** | 「発注してください」ではなく「空いています」。**断る理由が発生しないので、関係が減りません** |
| **埋まっているときほど効く** | 枠が少ない月は「**もうこれだけしか空いていない**」が自然に伝わります |

### 人の時間

**CMOが原稿を作る（自動）→ オーナーが送信ボタンを押す。月1回・15通で15分程度。**
**訪問も電話も要りません。**

## 🔑 この打ち手の位置づけ（2026-09-17 訂正）

> ### これは「15件を作る手」ではありません。**「歩留まりを守る・上げる手」です。**

経営企画室の切り分け：

| 変数 | 空き枠連絡で動くか |
|---|---|
| **歩留まり**（アクティブ1社あたりの件数） | **動く見込みがある。**「思い出してもらう」は歩留まりの打ち手そのもの |
| **社数** | **動かない。** 関係のない相手に空き枠を送っても意味がない |

**そして、届かない理由は社数のほうでした。**

**アクティブ社数を分母にした 10〜12月の実績歩留まり：**

| 年 | アクティブ社数 | 10〜12月の件数 | アクティブ1社あたり |
|---|--:|--:|--:|
| 2023 | 9社 | 5件 | **0.56件** |
| 2024 | 10社 | 5件 | **0.50件** |
| 2025 | 12社 | 6件 | **0.50件** |
| **平均** | | | **0.52件** |

**計画の 15件 ÷ 15社 = 1.00件/社 は、過去平均の1.9倍。軽くありません。**

> ⚠️ **初版で「1社あたりの負荷は軽くなる」と書いたのは誤りでした。**
> **過去の「1社1.5〜2.0件」は "秋に受注した社" の1社あたりで、"アクティブな社" ではなかった。**
> 経営企画室が自分で分母の誤りに気づいて訂正してきたもの。**そのまま使っていたら打ち手を過小に見積もっていました。**

**10社のままなら、歩留まりを計画の水準まで上げきっても10件が上限です。**
**社数を増やすのは、この打ち手の仕事ではありません。新規開拓の仕事です。**

## 金額の見込み（経営企画室の訂正を反映）

秋の案件の実績平均単価は **¥56,931**（2023〜2025の3年とも58,582／53,000／59,393で安定）。

## 本文を作る道具（2026-09-17 実装済み）

```
python3 tools/build-teikei-akiwaku.py
```

**`lp/booking/slots.json`（予約フォーム用に毎時できているもの）から本文を作ります。新しく取るデータはありません。**

### 作るときに決めたこと

| | 判断 | なぜ |
|---|---|---|
| 時刻を並べない | **「終日／午前・午後／夜」に畳む** | 提携先が知りたいのは「その日を押さえられるか」で、30分刻みではない |
| **並べるのは最大8日** | 超えたぶんは「ほか◯日、空きがあります」の1行 | **18日ぶん並べると「暇な会社」に見える。**隠してはいない |
| 既定の期間は**14日** | 28日ではない | 空き枠を見るのは「**急ぎの案件を振れるか**」で、1か月先の話ではない |
| 空きが少ない日は落とす | 既定2枠未満 | 半端な枠が並ぶと読みにくいだけ |
| **空きが無ければ本文を作らない** | 終了コード1で止まる | **「今月は送らない」が正しい判断**なので、無理に文面を作らない |

### 実測（2026-09-17 時点・所要120分・14日）

該当12日のうち8日を掲載。**枠が多い時期なので、上限8日が効いています。**

> ⚠️ **送信はしません。本文を出すだけです。**
> **送るのはオーナー**（外に出るものなので）。
