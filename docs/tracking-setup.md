背景: 成果地点が「作業完了ベース／成果単価3,000円」のため、電話申込も成果に含まれる。
この業種は電話申込の比率が高く、計測がないと「どの流入が成果を生んだか」が半分見えなくなる。

## 何をするのか

LPに表示する電話番号を、**通常の 080-1755-7275 とは別の転送専用番号**に差し替える。
その番号にかかってきた電話は自動的に既存の番号へ転送されるので、受電のオペレーションは変わらない。
一方で「LP経由の電話が何件あったか」「どの流入元からか」が記録される。

```
ユーザー → LPの電話番号（計測用の発番）→ 自動転送 → 080-1755-7275（いつも通り受電）
                     ↓
              通話ログ（日時・発信元・通話時間・流入元）
```

## 導入ステップ

1. **計測方式を決める**
   - 方式A：固定発番（LP1本につき1番号）— 安価、最小構成。まずはこれで十分。
     案A（エアコン）用に1番号、案B（水まわり）用に1番号の計2番号。
   - 方式B：動的発番（訪問者ごとに番号を出し分け）— 流入元まで特定できるが月額が上がる。
     アフィリエイター別の成果を見たくなった段階で検討する。
   - **推奨：まず方式Aで開始。** 案A/案Bどちらが電話を生んでいるかは、これで分かる。

2. **サービスを選定・契約**（コールトラッキング／電話番号発番サービス）
   - 月額は1番号あたり数千円＋通話従量が相場。初期費用がかかる場合もある。
   - チェック項目：転送先の変更が管理画面でできるか／通話ログをCSVで落とせるか／
     録音の有無（録音するなら通話冒頭のアナウンスが必要）／最低契約期間。

3. **番号を取得したら、LPに反映**（こちらで作業します。5分で終わります）
   - ヘッダーの電話番号表示とリンク（`tel:`）
   - フォーム下の「お電話でのご予約は」の箇所
   - 追従フッターに電話ボタンを足すかどうかも、このタイミングで決めましょう

4. **受電時の運用を決める**
   - 電話を受けたときに「どこで当社を知ったか」を必ず聞く運用にすると、
     ツールのログと突き合わせて精度が上がる。
   - 成果地点が作業完了ベースなので、**受電から施工完了までを紐づける台帳**が要る。
     電話番号・氏名・施工日・成果対象かどうかを記録する簡易シートを用意します。

5. **アフィリエイト事業者へ連携**
   - 電話経由の成果をどう報告・承認するかは、事業者側のルールに合わせる必要がある。
   - 「電話経由も成果に含めるのか」「含めるならどう突き合わせるのか」を確認してください。
     （事業者とのやり取りはオーナーが担当）

## 注意点

- **録音する場合は、通話冒頭で告知が必要**（個人情報保護法上の適正な取得）。
- LPに載せる番号を差し替えると、**LP以外からの流入で同じ番号を使い回してはいけない**。
  チラシ・名刺・Googleビジネスプロフィールは今まで通り 080-1755-7275 のままにすること。
  混ざると計測の意味がなくなる。
- 転送サービスの障害＝電話が繋がらない、という単一障害点になる。
  LPには LINE 導線を必ず併設しておく（実装済み）。
