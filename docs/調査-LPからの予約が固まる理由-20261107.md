# LPからの予約は本当に固まっているか・固まるなら何が違うか（2026-11-07 計測担当）

オーナー依頼（11/7・このスレッドで直接）：「LPから予約が入るタイミングが集中している（同じ日や前後数日内だけ多く、他の日が極端に少ない）気がする。原因がわかれば、集中する日と同じ状態を他の日でもつくれる」

## 結論（3行）
1. **今の件数（広告の申込11件・48日）では、固まり方は偶然で起きる範囲。** 広告のクリック数に比例して申込がばらばらに入ったと仮定して2万回試すと、今と同じかそれ以上に固まる確率は 39〜84%（下の§2）。「その日だけの特別な状態」は、数字からは見つからなかった
2. ただし、**申込が入りやすい条件は2つ見えた**（どちらも件数が少なく、確定ではない）：①**土日**（クリックあたりの申込率 3.1%、平日 1.0%・片側 p＝0.048）と**夜 18〜23時**（4.3%、ほか 1.1%・p＝0.05）、②**数日以内に空きがあること**（エアコンの広告の申込は全件、希望日が申込の1〜7日後・真ん中は4日後）
3. **申込が11日止まった 10/21〜31 は、2つの悪条件が重なっていた**：入札方式の切り替えで広告の表示が落ちた（10/21〜25 は1日1〜7クリック）＋和真さんの予定が詰まって「翌日〜3日後の空き」がほぼ0だった（10/22〜28 は 0〜4枠）。**同じ状態を避けることはできる**

## 2. 固まりは偶然を超えているか

| 見たこと | 実際 | 偶然でこれ以上固まる確率 |
|---|---|---|
| 申込のあった日数（11件が何日に入ったか） | 9日 | 39% |
| いちばん長い空白 | 12日（10/20〜11/1） | 67% |
| 3日以内に別の申込がある件数 | 8件 | 84% |

- 試し方：各日のクリック数に比例して、11件を48日にでたらめに配る、を2万回
- **どの見方でも、今の固まり方は「よくあること」**。1日あたりの期待値が 0.2件前後なので、何も起きない日が続き、たまたま2〜3件が近い日に並ぶのは普通に起きる

## 4. 10/21〜31 に11日止まった理由
| 日 | クリック | 翌日〜3日後の空き枠 |
|---|--:|--:|
| 10/21〜25 | 1〜7/日 | 15 → 0 |
| 10/26〜28 | 9〜16/日 | 0〜4 |
| 10/29〜31 | 19〜22/日 | 19〜34 |

- 10/21〜25：入札をコンバージョン数の最大化にしたことで表示が落ちた（`docs/広告-急減の切り分け-20261026.md`）
- 10/22〜28：近い日の予定が詰まり、予約ページに出る近い空きがほぼ無かった
- 10/29〜31：両方戻ったが申込0（3日なら偶然の範囲）。11/1 に申込

## 5. 「同じ状態を他の日でもつくる」ためにできること（案）
1. **広告の量を切らさない**（入札方式の切り替えのような、表示が落ちる変更を避ける）。申込は量に比例してしか増えない
2. **近い日の空きを切らさない**：翌日〜3日後に空きが無くなりそうな週は、和真さんの予定と広告の量を一緒に見る（空きが無い週に広告費を使っても申込になりにくい）。計測担当が毎朝「翌日〜3日後の空き枠」を数えて、0〜4枠の日を知らせることはできる
3. **土日・夜に寄せる試し**：クリック数の最大化では時間帯の入札調整が効かない（CMO 判断 11/1）。試すなら、平日昼の配信を減らす「広告のスケジュール」で、2週間比べる（費用は増やさない）
4. **計測の取りこぼしを直す**：11/1 2:12（公式サイト経由）と 11/5 9:29（広告）の申込は、GA4 に予約ページの送信の記録が無い。件数が少ないので、1件の取りこぼしが分析を大きく狂わせる

## 6. モデルについて
今回の限界は件数（11件）で、考える力ではない。上位のモデルにしても結論は変わらない見込み。**申込が30件ほどたまれば（今のペースで約2か月）**、曜日・時間帯・空き枠の差が本物かを言えるようになる。この表は同じ手順で作り直せる。
