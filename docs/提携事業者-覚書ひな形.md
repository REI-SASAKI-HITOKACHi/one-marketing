# 提携事業者との覚書（ひな形・A4 1枚）

作成 2026-09-11 ／ 担当 ネット流入施策担当 ／ 関連 `docs/職人ネットワーク-候補.md` 3章、`docs/media-構想.md` 案E
**ひな形です。締結前に専門家（行政書士・弁護士）の確認を推奨します。** 金額・料率は `data/prices.json` の「紹介」に合わせてあります。

## 設計の要点（本文の前に）

| 論点 | この覚書の立場 | 理由 |
|---|---|---|
| 契約の型 | **紹介型**。お客様は提携事業者と直接契約し、当社は紹介料を受ける | 当社が施工責任を負わない。下請法の適用を避ける（`docs/media-構想.md` 案E 法令） |
| 紹介料 | **施工額（税込）の12%**。上限15%・下限5%の範囲で個別に定める | 既存の「事業者→顧客 5〜15%・原則12%」を逆向きに使う。新しい料率を作らない |
| お客様への開示 | **確定前に、作業する事業者名と料金をお客様に伝える**。当社が紹介料を受けることも運営者情報に明記 | 景表法（ステマ規制）・信用 |
| 個人情報 | お客様の同意を得た情報だけを渡す。提携先は目的外利用・再提供をしない | 個人情報保護法（第三者提供） |
| 写真の提供 | 提携先は1案件5枚（作業前2・作業後2・汚水1）を当社に提供できる。**お客様の許可は当社が取る** | 図鑑・SNSの素材。提携先の負担を撮影だけにする |
| トラブル | 施工の責任は提携先。当社は窓口として連絡調整に協力する | 紹介型の帰結 |

## 覚書 本文

```
                        業務紹介に関する覚書

ワンヒッター株式会社（以下「甲」）と ＿＿＿＿＿＿＿＿（以下「乙」）は、
甲が運営する相談窓口「洗いどき」（以下「窓口」）を通じたハウスクリーニング業務の紹介について、
次のとおり合意する。

1. 目的
   甲は、窓口に寄せられたハウスクリーニングの依頼のうち、乙の対応地域・対応メニューに合うものを乙に紹介する。

2. 契約の当事者
   紹介された業務の契約は、依頼者と乙との間で直接締結する。甲は業務の当事者とならず、施工の責任を負わない。

3. 紹介の手順
   (1) 甲は、依頼者の同意を得た情報（氏名・連絡先・住所・希望内容・写真）を乙に渡す。
   (2) 乙は、原則として2営業日以内に依頼者へ連絡し、日程と料金を確定する。
   (3) 乙は、確定前に自らの事業者名と料金を依頼者に伝える。甲も、依頼者に対して作業者が乙であることを伝える。
   (4) 乙は、業務完了後 7日以内に、施工日・施工内容・施工額（税込）を甲に報告する。

4. 紹介料
   (1) 乙は甲に対し、紹介された業務の施工額（税込）の 12% を紹介料として支払う。
       ※個別に 5% 以上 15% 以下の範囲で定める場合は、別紙に記載する。
   (2) 支払いは月末締め・翌月末払い。甲が請求書を発行する。
   (3) 依頼者が依頼を取り下げた場合、紹介料は発生しない。
   (4) 紹介された依頼者からの 2回目以降の依頼についても、初回から 1年間は同じ料率を適用する。
       ※ここは論点。1年で切るか、リピートは無料にするかは、提携先との交渉で決める。

5. 個人情報
   乙は、甲から受け取った依頼者の情報を、紹介された業務の遂行にのみ使用し、
   第三者に提供せず、業務完了後は営業目的で使用しない。

6. 写真の提供
   乙は、甲の求めに応じ、施工前後の写真（1案件あたり作業前 2枚・作業後 2枚・汚水 1枚を目安）を甲に提供することができる。
   写真の公開にあたっては、甲が依頼者の許可を得る。依頼者・住居が特定できる写真は公開しない。

7. 品質と苦情
   施工に関する苦情は乙が対応する。甲は、依頼者と乙の連絡調整に協力する。
   甲は、苦情が続く場合その他相当の理由があるときは、紹介を停止できる。

8. 秘密保持・競業
   両者は、本覚書に関して知り得た相手方の営業上の情報を第三者に開示しない。
   乙が窓口以外の経路で自ら獲得した依頼は、本覚書の対象外とする。

9. 期間
   本覚書の有効期間は締結日から 1年とし、いずれかが 1か月前までに書面で申し出ない限り、同条件で 1年ごとに更新する。

10. 協議
   本覚書に定めのない事項は、両者が誠実に協議して定める。

本覚書の成立を証するため、本書 2通を作成し、各自 1通を保有する。

   年　　月　　日

甲　東京都江戸川区北葛西5-14-11
   ワンヒッター株式会社
   代表取締役　佐々木 嶺　　　　　　　印

乙　＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
   ＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
   ＿＿＿＿＿＿＿＿＿＿　　　　　　　印
```

## 別紙（案件ごとに埋める。覚書本体は変えない）

```
別紙：紹介の条件

対応地域：＿＿＿＿＿＿＿＿＿＿（例：江戸川区・江東区・浦安市）
対応メニュー：＿＿＿＿＿＿＿＿（例：エアコン・レンジフード・浴室）
受けないメニュー：＿＿＿＿＿＿
月の受入目安：＿＿件
紹介料率：＿＿%（5〜15%）
写真の提供：可 ／ 不可
```

## 決めていない論点（オーナー判断）

1. 4-(4) リピートの扱い：1年間は同率か、リピートは無料にして提携先の取り分を厚くするか
2. 当社が施工を受けられる案件を、自社優先にするか、提携先に均等に回すか（**自社優先を推奨**。単価が1.86倍）
3. 提携先の品質の見極め方（最初は「クチコミ★4.5以上・件数10以上」等の基準を置くか）
