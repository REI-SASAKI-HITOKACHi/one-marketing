# LP原稿の書き方（お客様向けの文の決まり）

LP・予約ページ・アンケートなど、お客様が読む文に使う。数字や表記の決まりは CLAUDE.md と `docs/price-master.md` が正。

## 言い回し

- **聞かれていない否定や但し書きを、先回りして足さない。**「〜は付けたまま」「〜はしません」「〜のときだけです」のように、お客様が気にしていないことをわざわざ説明すると、かえって不自然になり、AIが書いた文に見える。
  - オーナー（10/18）の原文：「あえて『ファンは付けたまま洗う』なんて表現しなくていいよ。分解して洗うことには変わりないからね。非常にAI感の強い表現だから学習してね」
  - 例：×「送風ファンは付けたまま、専用の機材で奥まで洗います（ファンを外しての洗浄は、完全分解のオプションのときです）」 → ○「カバーとルーバーを外して、分解します」
- 事実と違うことは書かない。直すときは正しい言い方に置き換えるだけにし、言い訳や説明を足さない。
  - 例：ファンを外すのは完全分解のオプションのときだけ（和真さん 10/17）。なので「ファンを取り外します」とは書かない。かといって「外しません」とも書かない
- 「分解して洗う」はそのまま使ってよい（オーナー 10/18）。

## 使わない表記（CLAUDE.md・オーナー決定より）

- 満足度・推奨の数字は 98.6% だけ。98.8% は使わない
- 電話番号は 080-8043-8259 だけ
- Google クチコミの件数は書かない
- 「出張費無料」「一切かからない」は書かない（遠方の例外が要るときは書き添える）
- 背抜き・完全分解は、いまは承っていないので書かない・約束しない
