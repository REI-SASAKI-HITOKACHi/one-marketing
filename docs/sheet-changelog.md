### 変更1: 流入経路（D列）の選択肢を 14 → 19 に拡張

**発見した不具合**: プルダウンが `strict=True`（リスト外を拒否）にもかかわらず、
選択肢に **「紹介」が入っていなかった**。実データには紹介が11件（¥379,460・平均¥34,496）あり、
平均単価の高い経路が正規の手段では入力できない状態だった。

| | 選択肢 |
|---|---|
| 既存14（すべて維持） | 営業／業務提携／チラシ(OH)／チラシ(本舗)／LINE／HP／SMS／早期予約／リピート／スケジュールマッチング／入札案件／その他／楽ラクーン／おそうじ定期便 |
| 追加5 | **紹介**（不具合対応）／**LP(アフィリエイト)**／**地図検索**／**LINE/SMS再販**／**Google口コミ** |

追加4つは、今後のネット施策の成果を台帳で追えるようにするため。これがないと
LP・地図検索・再販の受注が「その他」に埋もれて効果測定できない。

### 変更2〜4: L・M・Q列をチェックボックスから選択式へ

| 列 | 項目 | 変更前 | 変更後の選択肢 |
|---|---|---|---|
| L | 早期予約提案 | チェックボックス | 未記録／未提案／提案済／成約／対象外 |
| M | フォローコール | チェックボックス | 未記録／未実施／SMS送信／LINE送信／電話／返信あり／再依頼 |
| Q | ＯH打診 | チェックボックス | 未記録／未打診／打診済／反応あり／成約／対象外 |

**理由**: TRUE/FALSE では「打診したが反応がなかった」と「そもそも対象外だった」を区別できない。
打診は現場が客ごとに判断する属人的な行為なので、結果まで残らないと何が効いたか分からない。

**既存の値の扱い**: 全行が `FALSE`（＝チェック未入力）だった。オーナー確認により
これは「実施していない」という記録ではなく単なる記録漏れであるため、
**同じ意味の「未記録」に置き換えた**。値の意味は変えていない。
埋め戻し作業は発生せず、無効値の警告マークも出ない。

置き換えたセル: L 313件 ／ M 314件 ／ Q 323件（施工日付のある行のみ）

### 作業中に起きたことと、その修正

チェックボックスは**データのない空行にも敷かれていた**ため、最初の一括置換で
約6,000セル×3列が「未記録」になった。施工日付のない行をすべて空欄に戻して修正済み。
最終状態は施工日付のある323行にのみ値が入っている。

## 2026-09-04 分析タブの作り直しと再販リストの新設

### 変更5: `分析_件数単価流入_v2` タブを新設

既存の `分析_件数単価流入` タブは**削除していない**。数字を突き合わせてから、どちらを使うか判断できる。

旧タブで確認した不具合：

| 不具合 | 内容 |
|---|---|
| 9月が丸ごと欠落 | 月別リストが 1,2,3,4,5,6,7,8,10,11,12月 のみ |
| 「早期予約」が存在しない | 流入経路の項目がなく、リピートに合算されていた |
| `#REF!` 残存 | L1セル |
| 集計全体が古い | 旧310件/¥12,283,131 に対し実データは **323件/¥12,636,141**。9月以外の月もズレていた |

新タブは **月次タブをSUMIFS/COUNTIFSで直接参照する数式**で組んだ。行を追記すれば自動反映され、
ピボットの更新漏れで数字が古くなることが構造的に起きない。

構成：月別サマリ／流入経路別サマリ（19経路・構成比つき）／月×経路の売上クロス／月×経路の件数クロス

直った結果：

| 項目 | 旧 | 新 |
|---|---|---|
| リピート | 127件 / ¥4,374,773 | 69件 / ¥3,130,845 |
| 早期予約 | （項目なし） | **68件 / ¥1,510,138** |
| 9月 | （行ごと欠落） | 9件 / ¥353,010 |
| 年計 | 310件 / ¥12,283,131 | **323件 / ¥12,636,141** |

### 変更6: `再販リスト` タブを新設

顧客ごとに最終施工日をまとめ、メニュー別サイクルで案内時期が来た人に **★いま** を付ける。
サイクル：おそうじ定期便・定期清掃=1ヶ月／トイレ・洗面台=6ヶ月／その他=12ヶ月。推奨時期の2ヶ月前から ★。

生成結果（2026年シートのみ）：ユニーク顧客 **258名**／2回以上の利用 40名（15.5%）／**★いま 2名**

**★が2名しか出ないのは、2026年シートしか見ていないため。** 2026年に施工した顧客は
まだ1年経っていないので当然そうなる。本当の再販プールは **2025年シートの444名**で、
うち9〜12月に施工した160名がちょうど今「1年後」を迎える。
→ **2025年シートをサービスアカウントに共有すれば、300名規模のリストが作れる（共有クリック1回）**
