# 共有の除外キーワードリスト案（2026-11-06 計測担当）

CMO 依頼 20261105-03・20261106-01-measurement。**設計と手順だけ。広告の操作は browser＋嶺さん。**

きっかけ：`tools/ads/ads-script.js` の `tsukauShiji_()` は、指示タブの語を「その時点にあるキャンペーン」に1つずつ足すだけ。11/1 に作った `検索_年末大掃除_段0` には、9/20〜10/31 に足した語が入っていない。

## ① 共有リストの設計

| 項目 | 案 |
|---|---|
| 名前 | **共通_除外語** |
| 語数 | **76語**（指示タブの 77行から「クリニック」を除く。フレーズ 71・部分一致 5） |
| 付けるキャンペーン | **検索_江戸川_段0_v2・検索_年末大掃除_段0・今後のすべてのキャンペーン** |
| 上限 | 1リスト 5,000語・1アカウント 20リスト（Google 広告ヘルプ「除外キーワード リストについて」https://support.google.com/google-ads/answer/2453983?hl=ja）。余裕は十分 |

- **「クリニック」は入れない**：10/26 に CMO が「外す」と決めた語（20261026-02-browser・『エアコン クリニック』で CV 1）。段0_v2 のキャンペーン単位の除外にはまだ残っている可能性がある（外したかの報告は未確認）
- 「相場」は入れる（10/26 CMO 決定でそのまま）
- 段0_v2 に今ある**キャンペーン単位の除外語は消さない**（共有リストと重なっても害は無い。消すと元に戻せない作業が増える）
- 年末の広告グループ単位の除外（自分で／やり方 など）・カビの除外はそのまま。共有リストはアカウント全体で外したい語（他社名・遠方・調べもの）だけ

## ② 今後キャンペーンを足すときに漏れない手順（1行）

**新しいキャンペーンを作った日に、［ツール］→［除外リスト］→「共通_除外語」を［キャンペーンに適用］する。** スクリプトを下の③の版に替えれば、毎日 14:59 にスクリプトが付いていないキャンペーンへ自動で付ける（付け忘れても翌日には付く）。

## スクリプトの差分（tools/ads/ads-script.js → 案）

- 指示タブの新しい語は、キャンペーンごとではなく**共有リストに足す**
- 毎回、**共有リストが付いていないキャンペーンに付ける**。1つのキャンペーンで失敗しても他は止めず、失敗は記録タブに1行残す
- 共有リストが無ければスクリプトが作る（A を先にやれば作らない）
- 使った関数は Google 広告スクリプトの公式リファレンスで確かめた：`AdsApp.negativeKeywordLists()`（条件 `shared_set.name = '…'`）、`AdsApp.newNegativeKeywordListBuilder().withName().build().getResult()`、`NegativeKeywordList.addNegativeKeyword()`、`Campaign.negativeKeywordLists()`・`Campaign.addNegativeKeywordList()`（developers.google.com/google-ads/scripts/docs/reference/adsapp/ の各ページ）
- 構文は確認済み（node --check）。**本物の口座では動かしていない**。貼り替えた日の 14:59 の記録タブで「共有リストに足しました」か「🔴」かを見る
