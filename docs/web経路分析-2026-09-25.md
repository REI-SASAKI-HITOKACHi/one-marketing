# ネット経由の経路分析（2026-09-25）— 広告以外の経路（HP・自然検索・GBP・SNS）の実測と打ち手

オーナー指示（2026-09-25）「広告だけでなく HP や SNS も経路。広告予算は限定的なので、そちらも分析して伸ばすアクションを」。
出所：GA4 プロパティ `one-hitter.jp`（381320625、LP群も同じプロパティ）、2026年シート `◯月_売上/顧客` D列「流入経路」、公式サイトの実物（9/25 取得）。

## 1. 結論（3行）

1. **公式サイトへの流入は月 500〜600 セッションあるが、お客様の受注に結びついた「HP」経路は 2026 年 1〜9月で 4件・¥63,100（自社売上の 0.7%）。** 集客の穴は「来ていない」ではなく**「来ているのに申し込む導線がない」**。
2. 自然検索の着地の **1位は 2023年1月の DIY 記事「洗濯物にホコリがつかないようにする対処法」（90日で154セッション）。** サービスページより記事が読まれているのに、**記事にもトップにも予約ページへのリンクが1本もない**（/contact/ と 080 の電話だけ）。
3. GA4 の「キーイベント 44件」は **/contact/ の完了ページ（PC・直接流入・42件）**で、問い合わせフォームのスパム（9/23 オーナー「対応不要」の件）。**お客様の行動としての CV は月にほぼ 0 と読むのが正しい。** 計測を直さないと、HP の改善効果が測れない。

## 4. なぜ結びつかないか（実物で確認）

1. **トップページに予約ページ（yoyaku.onehitter.jp）へのリンクが無い。** 導線は /contact/（問い合わせフォーム）と Google フォームと電話（080-8043-8259）のみ。予約ボタン（booking_start）はトップに 6回押されているが、遷移先はフォーム。
2. **ブログ記事（旧19本・新19本とも）に予約・LP・点検ページへのリンクが無い。** 記事末は /contact/ と tel だけ。自然検索の 8割が記事着地なので、ここが最大の取りこぼし。
3. **トップに「98.8%」が残っている**（98.6 と混在。`docs/site-audit.md` の未修正項目）。
4. 自然検索が漸減（6月162→9月90）。2022〜23年の記事以降、新規記事が止まっていた。**9/23 からの毎日投稿は正しい手**。ただし新記事にも導線が無い。
5. 計測：キーイベントがスパムで埋まり、**電話タップ・LINE タップ・予約開始がキーイベントになっていない**。
