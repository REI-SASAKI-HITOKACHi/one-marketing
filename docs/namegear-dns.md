# ネームギアで `lp` のAレコードを追加する手順

**所要 5分。オーナー作業。急ぎではないが、これが済むまでLPは独自ドメインで公開できない。**

## 何をするのか

`lp.one-hitter.jp` という住所を1つ作り、LPを置いてあるサーバー（ロリポップ）に向ける。
**本体サイト（one-hitter.jp）には一切影響しない。** 触るのは新しく足す1行だけで、既存の設定は変更しない。

```
lp.one-hitter.jp  →  118.27.125.166（ロリポップ）    ← 今回足すもの
one-hitter.jp     →  35.72.88.173（AWS上のCMS）      ← 触らない
```

## ネームギアとは

`one-hitter.jp` のネームサーバーが `ns1.namegear.co` / `ns2.namegear.co` になっているため、
DNSの設定はネームギアで行う。**ネームギアはドメイン登録サービス**（運営：BRドメイン株式会社／京都）で、
ムームードメインやお名前.comと同じ種類の会社。管理画面にログインできれば自分で設定できる。

ログイン情報が分からない場合は、**ドメインを取得した先**に問い合わせる。
サイト制作を依頼した会社が代理で取得している可能性が高い。

## 手順

1. https://namegear.co/ にログイン
2. ドメイン一覧から `one-hitter.jp` を選ぶ
3. 「DNS設定」「ゾーン編集」「ネームサーバー設定」などの名称のメニューを開く
4. レコードを1件追加する

   | 項目 | 入れる値 |
   |---|---|
   | ホスト名（サブドメイン） | `lp` |
   | 種別（タイプ） | `A` |
   | 値（コンテンツ／IPアドレス） | `118.27.125.166` |
   | TTL | 既定のまま（3600など） |

   ※ ホスト名の入力欄によっては `lp.one-hitter.jp.` とフルで書く形式のものもある。画面の例示に合わせる。
5. 保存する
6. 反映を待つ（数分〜最大1時間）

## 反映されたかの確認

以下のページで `lp.one-hitter.jp` を検索し、`118.27.125.166` が返れば完了。

https://dns.google/query?name=lp.one-hitter.jp&type=A

当方でも確認できるので、設定が終わったら声をかけていただければこちらで確かめる。

## そのあと

1. ロリポップの管理画面で `lp.one-hitter.jp` を独自ドメインとして登録
2. 無料の独自SSLを有効化（**フォームで氏名と電話番号を預かるため必須**）
3. ファイルをアップロード

詳細は `deploy/DEPLOY.md` にある。3以降は当方で作業できる。

## 補足：これを待たずに公開する方法もある

リポジトリには **Netlify用のビルド済みファイル**（`deploy/netlify/`）が入っている。
Netlifyは無料で、フォルダをドラッグ&ドロップするだけで公開でき、**DNSの設定は要らない**。

- URLが `◯◯◯.netlify.app` になる
- **既存のお客様への再販導線としては、これで何の問題もない**
- アフィリエイト掲載は独自ドメインのほうが有利なので、DNSが通ってから移す

年末商戦は10月中旬から動き出すため、**DNSを待つより先にNetlifyで出したほうが早い**。

## ネームギアにログインできない場合（2026-09-05 追記）

オーナーがネームギアにログインしたことがない、という状況が判明したので調べ直しました。

### 事実：ロリポップの管理画面ではこのレコードを足せません

`one-hitter.jp` の権威DNSを実際に引いた結果です。

```
$ dig one-hitter.jp NS
ns1.namegear.co.
ns2.namegear.co.

$ dig one-hitter.jp SOA
ns1.namegear.co. hostmaster.namegear.co. ...
```

**ドメインの名前解決を実際に答えているのはネームギアのサーバーです。**
ロリポップは「サーバー（置き場）」で、ネームギアは「住所録」。
`lp.one-hitter.jp` という住所を新しく載せられるのは住所録を持っている側だけなので、
ロリポップと契約していても、そこには書き込めません。

参考：現在の状態

| ホスト名 | 状態 |
|---|---|
| `one-hitter.jp` | 35.72.88.173 / 3.113.230.91（公式サイト・AWS） |
| `www` | 上と同じ |
| `mail` | 52.197.128.153 |
| **`lp`** | **存在しない（NXDOMAIN）** |

### 選べる道は3つ

#### A. ネームギアのログイン情報を復旧する（本筋）

ドメインの管理権はここに集約されているので、**いずれ必ず必要になります。**
更新・移管・メール設定もすべてここです。今のうちに復旧しておくのが安全です。

- 登録時のメールアドレス宛に「パスワード再設定」を実行
- 分からなければネームギアのサポートに連絡（会社名・ドメイン名で照会できます）
- 前任者や制作会社が取得した可能性があるなら、そちらにも確認

#### B. ネームサーバーごとロリポップに移す

ロリポップ側でDNSを管理できるようになるので、以後は自分で足せます。
**ただし、この変更自体をネームギアの管理画面で行う必要があります。**
つまりAが先に必要です。順番として先には来ません。

#### C. 独自ドメインを使わずに先行公開する（今日から動かせる）

**アンケートQRはスマホ画面で見せる運用なので、URLはあとから変えられます。**
紙に刷らない限り、仮のURLで始めても損はありません。

- Netlifyの無料サブドメイン（`◯◯◯.netlify.app`）で公開する
- QR画像を作り直して現場スマホに入れ直す（1枚差し替えるだけ）
- ネームギアが復旧したら独自ドメインへ移し、QRをもう一度差し替える

**年末商戦に間に合わせることを優先するなら、Cで始めてAを並行して進めるのが現実的です。**

### CMO側で試したこと（できなかったこと）

- **ブラウザでネームギアを操作する** … 不可。このセッションのChromiumは外部サイトに到達できません
  （google.com も example.com も接続リセット。プロキシがブラウザのトンネルを切っています）
- **FTP/SFTPでロリポップに直接アップロードする** … 不可。素のTCP接続が外に出られません
  （github.com:22 も ftp.lolipop.jp:21 もタイムアウト。**通るのはHTTPSのみ**）

**HTTPSのAPIがある相手なら、CMO側で実行できます。**
Netlifyはデプロイ用のHTTPS APIを持っているので、**アクセストークンをいただければ公開・更新はこちらでやれます。**
