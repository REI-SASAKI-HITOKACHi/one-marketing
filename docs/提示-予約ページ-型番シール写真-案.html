予約ページに「エアコンの型番シールの写真（任意）」の欄を足す案

依頼 20261029-01-lp（urakata の提案 #2）。配信はしていません。ねらいは、お掃除機能付きかどうかの申告違いを、伺う前に型番で確かめて減らすこと。本番と同じ予約ページ（防カビ無料の入った版）を元にしています。

手間を増やさない作り

  • 必須にしない。エアコンを選んだときだけ出る（浴室などだけなら出ない）
  • 「写真を撮る・選ぶ」を押すと、スマホのカメラか写真の一覧が開く。選ぶと「選びました（1枚）」と出る
  • 写真は送る前に端末の中で長辺1600px・JPEGに縮める（Netlify の保存容量を食いすぎないため）
  • 写真が無いときの送り方は今までどおり。あるときだけ FormData で同じ所へ送る

確かめたこと（見本の入力・送信は手元で受け止め、本番には送っていない）

  • 写真なし：今と同じ送り方（18項目）で完了画面まで
  • 写真あり：multipart で写真入り（約200KB）・完了画面まで
  • check-public-page OK・スクリプトの構文エラー 0

決めてほしいこと（配信の前に）

  • 写真の届き先：Netlify のフォームの受信一覧と通知メール。予約_Web（台帳）に写真を入れるかは別（取り込みの道具の対応が要る）
  • 保存容量：写真1枚 約200KB。月の件数ぶん、フォームの保存容量を使う（10/23 の容量の件と合わせて判断）
