## 0. 全体（4段階・押す順）

```
① テスト送信 2通（社内）      … IDが届いたらすぐ。5分
② 見え方の確認               … お二人のスマホで。当日中
③ 配布の承認依頼（CMO宛）     … ②が通ってから
```

**③までは「外に出す」に当たりません。**（社内2通＝内部テスト）

## 1. テスト送信（2通）

### 押すもの

```bash
. ~/.config/one-hitter/line.env

# 嶺さん
python3 tools/line_client.py push --to "<嶺さんのuserId>" --internal \
  --text "$(cat docs/原稿/line-test.txt)" \
  --coupon 01M27R6C993BKR6W044VVV7QM4 --confirm SEND

# 和真さん
python3 tools/line_client.py push --to "<和真さんのuserId>" --internal \
  --text "$(cat docs/原稿/line-test.txt)" \
  --coupon 01M27R6C993BKR6W044VVV7QM4 --confirm SEND
```

`--internal` は社内あて。名義の照合を省きます。**お客様には絶対に使いません。**

### 送る前に必ず

```bash
python3 tools/line_client.py coupon-get --id 01M27R6C993BKR6W044VVV7QM4
```

`status` が `RUNNING`、`reward` が `discount fixed 1000 JPY` であることを目で見る。

### 通数

**2通。** 月200通の無料枠には響きません（`quota` で残りを確認できます）。

## 2. 見え方の確認（お二人にお願いすること）

次の5点を見てもらいます。**ひとつでも直したいところが出たら、クーポンは作り直します**
（作成後は修正できないため）。

| | 見るところ |
|---|---|
| 1 | クーポンのカードが**トークに表示されるか**（画像なしでも出るか） |
| 2 | タイトル「**ご紹介ありがとうクーポン**」 |
| 3 | 割引額「**1,000円**」 |
| 4 | 有効期限「**2027年6月1日まで**」 |
| 5 | 説明文を最後まで読んで、**おかしい日本語・事実と違う記載が無いか** |

### 説明文（いま入っているもの）

```
お知り合いをご紹介いただいたお礼のクーポンです。

★次回のご利用料金から1,000円割引

- ご紹介いただいた方がサービスをご利用になり、作業が完了した時点で適用となります。ご予約のみでは適用となりません
- ご予約の際に、ご紹介いただいた方のお名前をお知らせください
- 他のクーポン・割引との併用はできません
- ご利用の際は、この画面をスタッフにご提示ください
- 使用済みのクーポンはご利用になれません。誤って「使用済み」にしてしまった場合は、スタッフにお申し付けください
```

> **作り直すときは `data/line-coupon-referral.json` を直して、`coupon-create` をもう一度。**
> 古いほうは配らずに放置します（終了させると獲得済みの方が使えなくなるため）。

## 5. 原稿

差し込みは SMS と同じ規則です（`{last_when}`＝「昨年11月」、`{last_service}`＝「浴室クリーニング」）。
**名乗りは必ず「ハウスクリーニングの渡辺」。本文のどこかに社名「ワンヒッター株式会社」を残します。**

> LINEは友だち登録してくださった方だけに届くので、SMSのような配信停止の表示義務
> （特定電子メール法4条）はかかりません。ただしブロックで止められることは、
> お客様のほうが分かっています。文面に「停止」の案内は入れていません。

### `docs/原稿/line-test.txt` — 社内テスト用

### `docs/原稿/line-shokai.txt` — 紹介してくださった方へ

どちらも別ファイルにしてあります。**`tools/line_client.py` が本文の中身も検算する**ので、
相手方のもの（おそうじ本舗の店名・本舗の受付番号）が混ざっていれば送信前に止まります。

## 6. うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| `--tel か --name が要ります` | お客様あてなのに照合の材料が無い。氏名か電話番号を渡す |
| `名義が食い違う（台帳=本舗）` | **本舗のお客様です。公式LINEは送りません。** 正しい挙動 |
| `台帳を読めないので名義を照合できません` | `GOOGLE_SHEETS_SA_KEY` が未設定。`. ~/.config/one-hitter/line.env` を先に |
| `HTTP 400 {"message":"Internal Server Error"}` | クーポン作成のときだけ出る。形が違う。OpenAPI定義と1項目ずつ突き合わせる |
| 相手に届かない | ブロックされている可能性。`quota` の消化数は増えるので、そこで気づける |
