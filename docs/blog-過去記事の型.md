## 2. 型（3本とも共通していたもの）

1. **題名が、検索する人の言葉そのまま。**「〜ができる原因」「〜を掃除する方法」「〜対処法　5選」。当社の言いたいことではなく、**困っている人が打つ言葉**が題名になっています
2. **3本セットで1つの困りごとを囲む。**トイレの黄ばみは〈原因〉→〈掃除する方法〉→〈日々の対策〉の3本。洗濯物のホコリも〈4つの原因〉→〈対処法〉→〈つかないようにする方法5選〉の3本
3. **見出しが、やることそのもの。**「糸くずフィルターは洗濯のたびに掃除する」「換気をしよう」。**「はじめに」「まとめ」「いかがでしたか」は1つもありません**
4. **画像は1枚だけ。冒頭。**本文中に写真は入っていません
5. **長さは内容で決まっている。**原因だけの回は800字、方法の回は2,000字、5選の回は2,800字
6. **前の記事を受ける1文から始める。**「前回はトイレの黄ばみ、尿石が付いてしまう原因を解説いたしました。今回は…」
7. **カテゴリがメニュー名。**「水まわり」「洗濯機」。`/blog/` の一覧では全記事が「ブログ」に見えますが、**記事ページのカテゴリはメニュー別**でした（既存記事一覧.md の記述と食い違うので、こちらが正）
8. **タグは地名＋意図。**江戸川区・船堀・ハウスクリーニング・手軽・安い。既にアーカイブページがあります
9. **締めはLINE友だち追加とクーポン。**「まずはLINE友達追加でお得なクーポンをGET！」

## 3. 第1束・第2束（40本）との差

**ここが直すところです。**

| | 過去記事 | 第1束・第2束 | どうするか |
|---|---|---|---|
| 題名 | 「〜の原因」「〜する方法」「〜5選」 | 「〜｜〜」の説明的な題名 | **検索する人の言葉に寄せる** |
| 構成 | 1つの困りごとを3本で囲む | 1本完結 | **3本セットに組み直す** |
| 見出し | やることそのもの | 説明的・随筆的 | **やることを見出しにする** |
| 長さ | 800〜2,800字（内容で決まる） | 800〜1,161字（ほぼ一定） | **「方法」「◯選」の回は2,000字超を通す**（`check-blog.py` の上限1,500字を上げる必要あり） |
| 画像 | 冒頭1枚 | 冒頭1枚＋本文中 | 過去記事に合わせるなら冒頭のみ |
| カテゴリ | 水まわり／洗濯機（メニュー名） | 事例研究／読本／お知らせ | **メニュー名に変える**（`check-blog.py` の `CATEGORIES` を変える） |
| タグ | 江戸川区・船堀・手軽・安い | ハウスクリーニング・江戸川区 | **既存のタグに揃える**（アーカイブに載る） |
| 締め | LINE友だち追加＋クーポン | 予約LPへ（`?src=blog`） | **判断が要る。下の4番** |

## 4. 判断が要るところ（cmo へ）

1. **締めをどちらにするか。**過去記事はLINE、いまの40本は予約LP（`?src=blog`）です。`?src=blog` は「どの記事から予約が来たか」を数えるために入れています。**LINEに変えると数えられなくなります。**両方置くか、LPだけにするか。LINEはcrmの持ち物なので、勝手には決めません
2. **カテゴリを「水まわり」「エアコン」「洗濯機」等のメニュー名に変えてよいか。**変えるなら `check-blog.py` の `CATEGORIES` と、40本の front matter を直します
3. **`check-blog.py` の本文上限 1,500字を上げてよいか。**「◯選」の型は2,000〜2,800字です。いまの上限では通りません
4. **40本を書き直すか、第3束から新しい型にするか。**書き直すなら題名・見出し・構成の全面改稿になります（中身と出典はそのまま使えます）

## 5. 詰まっているところ（cmo が解くもの）

**「どの記事がアクセスを集めたか」を出すには、次のどちらかが要ります。**

- **Search Console**：Google Cloud のプロジェクト（`sa-key.json` の project）で **Search Console API を有効にする**こと、かつ Search Console のプロパティ（`one-hitter.jp`）に**サービスアカウントのメールアドレス**（`~/.config/one-hitter/sa-key.json` の `client_email`。値はここには書きません）を閲覧者として追加すること
- **GA4**：Google Analytics Data API を有効にし、同じアドレスをプロパティの閲覧者に追加すること。GA4プロパティIDも要ります

**どちらも設定はオーナーかCMOの手番です。**通れば、過去3年ぶんの流入キーワードと記事別の表示回数・クリック数を出して、上の「型」を実績で裏づけ直します。

それまでは、この文書の型（実際にサイトが使っていた型）で進めます。
