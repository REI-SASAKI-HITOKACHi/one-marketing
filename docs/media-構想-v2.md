# 新メディア構想 v2 ─ 「自分で掃除した結果」の症例集

作成 2026-09-11 ／ 担当 ネット流入施策担当（`web-inflow`）
前提：`docs/潜在層メディア-市場調査.md`（市場の有無を数字で確認済み）、`docs/media-構想.md`（v1。「洗いどき」は却下、生成器は流用）
**まだ何も作っていません。何も公開していません。**

---

## 0. 結論

**市場はある。ただしオーナーの3層のうち、建てられるのは1層だけ。**

| オーナーの案 | 調査の結果 | v2での扱い |
|---|---|---|
| 自分で掃除しようとする人 | **大きい**（「エアコン 掃除 自分で」推定48,400/月、トレンドで顕在語を上回る、YouTube上位10本で約800万〜1,050万回） | **主対象** |
| 赤ちゃんが生まれてカビ臭が気になった人 | 小さい（顕在語の1/16〜1/33。知恵袋70件。商圏内の器 年約5,000世帯） | **切り口（タグ）。10〜20ページ** |
| ペットの汚れが気になる人 | 小さく、需要が掃除機・空気清浄機に向いている | **切り口（タグ）** |

そして、**「お掃除百科事典」の形では建てません。** 理由は3つ、全部数字にあります。

1. 一般的なハウツーの検索上位は、メーカー（花王・Panasonic・アース）・大手（おそうじ本舗176本・ベアーズ618本）・ポータル・個人YouTuber（数百万回）で固まっている。**後追いの百科事典は、CaSy（2025年2月で更新停止）と同じ末路になる**
2. 「投稿できるサイト」を新設しても、投稿者は来ない。掃除の投稿文化は **Instagram（#お風呂掃除 50万リール）と RoomClip** に既にある
3. 潜在→顕在の転換点は「**自分でやって、ダメだった**」瞬間にある（サジェスト「掃除したのに臭い」「落ちない」「取れない」、知恵袋「頼むべき」2,353件）。**ここは業者にしか書けない。** 百科事典はここを書かない

だから、**症例集**にします。

> **「自分で掃除してみた結果」の症例集。**
> 何をした → どうなった → **ここから先はプロが要った／要らなかった**。
> 実写と結果だけ。1件1ページ。同じ症状の人が、自分の家の次の一手を決められる場所。

**当初の目的（自社の供給を超える依頼を作り、窓口で受けて提携先へ渡す）は変えません。** 症例の末尾が、そのまま窓口です。

## 1. なぜ「症例集」が百科事典に勝てるか

| | 百科事典（CaSy型） | 症例集（v2） |
|---|---|---|
| ページの単位 | トピック（「エアコンのカビの落とし方」） | **1件の結果**（「築12年・ペットあり・送風ファンにカビ・キッチンハイターで拭いた → 2週間で臭い再発 → 分解洗浄」） |
| 誰が書いても同じか | 同じになる | **同じにならない**（環境×症状×やったこと×結果の組み合わせ） |
| 一次情報 | 無い | **実写・数値・結果**。当社の年319件と、投稿者の結果 |
| AI要約に食われるか | 食われる（定義・手順） | **「うちの場合」は要約できない**。ハウツー検索はAI要約が出ても63%のクリックが残る（v1 1-1） |
| Googleのスパム判定 | AI量産と区別がつかない | 実在の結果の記録。1件ずつ違う |
| 転換点 | 書かない | **毎ページの末尾**が転換点（「ここから先はプロ」） |
| 集計できるか | できない | **できる**。「塩素系クリーナーで洗濯槽のカビ：n件中、再発 m件」——**誰も持っていない統計になり、AI検索に引用される** |

**最後の行が、この案の本当の資産です。** 症例が溜まるほど、「やってみた結果の統計」という**日本のどこにも無い一次データ**になります。

## 2. 症例の3つの供給源（投稿者ゼロでも回る設計）

投稿サイトの鶏と卵を避けるため、**投稿者がいなくても症例が増える**順に置きます。

| 順 | 供給源 | 量 | 中身 |
|---|---|---|---|
| 1 | **当社の施工**（渡辺さんの写真5枚） | 月8件〜 | プロが見た「DIYではここまでしか届かない」の証拠。図鑑生成器（v1案B）をそのまま使う |
| 2 | **アンケートの自由記述**（209名）と**顧客台帳の備考**（ペット・喫煙・築年数） | 既存 | 「頼む前に何を試したか」の記録。**掲載許可はアンケートQ8で取る設計が既にある** |
| 3 | **投稿**（写真1枚＋質問5つ） | 0から | 「何を／どこに／何年／何をした／どうなった」だけ。記事は書かせない |

### 投稿の見返り（Instagramにない価値）

**「プロが写真を見て、続けるべきか・やめるべきかを返す」。** v1の判定ルール（`data/araidoki-rules.json`）がここで生きます。
投稿者は無料の判定をもらい、当社は症例1件と、判定が「プロ」なら依頼候補1件を得る。**投稿フォーム＝相談フォーム＝窓口の入口**が同じ1枚になります。

### 投稿の守り

- 自由記述は「ひとこと」1欄だけ。断定語の検査（生成器に実装済み）を通す
- 写真は寄りのみ。顔・表札・私物・郵便物が写っていれば非掲載（当面は目視、後にAI判定）
- 掲載前に必ず1回、当社が見る（週1回のまとめ承認の中で）
- **効果の断定・商品への誹謗・健康被害の断定は掲載しない**（`docs/潜在層メディア-市場調査.md` 3-4）

## 3. ページの型（4種だけ）

| 型 | 例 | 供給源 | 役割 |
|---|---|---|---|
| **A 症例** | 「江戸川区・築12年・ペット2匹｜エアコンの送風ファン｜キッチンハイターで拭いた → 2週間で再発 → 分解洗浄」 | 1・2・3 | 本体。1件1ページ。末尾に「ここから先はプロ」or「自分で足りた」 |
| **B 方法別の結果** | 「洗濯槽：塩素系クリーナー — n件の結果（再発 m件／黒いカス継続 k件）」 | Aの集計 | **唯一の一次統計**。AI検索・報道の引用先。四半期ごとに自動更新 |
| **C 境界線** | 「エアコン：自分でできるのはここまで（フィルター・ルーバー）／ここから分解（熱交換器・送風ファン）」 | 当社 | サジェスト「自分で どこまで」「送風ファン」に正面から答える。**業者にしか書けない** |
| **D 切り口** | 「赤ちゃんが生まれた家のエアコン｜東京都の指針に書いてあること・当社の現場で見えるもの」「ペットのいる家のエアコン内部・n件」 | 公的資料＋A | ②③のタグページ。各10〜20本。地域業者が記事1本で上位に入れている領域 |

**作らないもの：** 「エアコンのカビの原因とは」「掃除の頻度は」のような一般ハウツー（メーカー・大手の土俵）。

## 4. 流入（広告→LPとは別の2本目の漏斗）

| 経路 | 根拠 | 型 |
|---|---|---|
| **検索（転換点の語）** | 「掃除したのに臭い」「落ちない」「取れない」「どこまで」「頼むべき」 | A・C |
| **検索（切り口）** | 「エアコン カビ臭い 赤ちゃん」「犬 エアコン 臭い」は小規模業者が上位に入れている | D |
| **動画（Shorts／Reels／TikTok）** | 潜在層の最大の到達手段。上位は「安く自分で」の個人系。**「やってみた結果、中はこうだった」の型で出す**（業者の宣伝の型は見られていない：ビフォーアフター動画は数百回） | Aを動画生成器（v1）で |
| **AI検索の引用** | 「方法別の結果」は日本にない統計 | B |
| **Instagram・GBP** | 柱1の週2本＋週1本 | A |

**季節：4月に立ち上げ、5〜7月に集中**（エアコン掃除は6月が1〜3月の4.6倍）。
**1〜2月の谷は、このメディアでは埋まらない。** 谷を埋めるのは柱1（既存客のLINE・GBP・次回予約割引15%）の仕事。ここを混ぜない。

## 5. 依頼への橋（当初の目的）

```
症例ページ ──「うちも同じ」──▶ 投稿フォーム（写真1枚＋質問5つ）
                                    │
                        判定（v1のルール＋後に写真AI）
                       ┌────────────┼────────────┐
                    「自分で足りる」  「続けてよい」   「ここから先はプロ」
                       │             │              │
                  道具（アフィリ）   LINEで次の      手配フォーム
                  ＋LINE登録        洗いどきに通知    ├ 自社の空き枠
                                                   └ 提携先（案E）へ
```

- **手配フォーム・提携先網・LINEの戻し・覚書ひな形は v1 のものをそのまま使う**
- 全国から来る依頼は提携先へ。**案E（職人ネットワーク）は、いずれ商圏外にも要る**。まず江戸川区・浦安の5社から

## 6. EC（「大きな絵」の扱い）

- **アフィリエイトは日用品で3%**（Amazon・楽天とも）。1,000円のカビ取り剤で30円。**収益源にはならない。維持費の足し**
- ただし「症例で実際に使った道具」のリンクは、読者の役に立ち、**何が売れるかのデータ**になる
- 自社ECは、そのデータで「症例集の読者が繰り返し買うもの」が見えてから。在庫を持つ判断はその後
- ペット層の需要が掃除機・空気清浄機に向いている事実は、EC側の切り口として記録しておく

## 8. 90日で確かめること（同じ失敗を繰り返さないための「殺す条件」）

**市場があることは確認した。確認していないのは「症例集の読者が、依頼に転じるか」（v1の批判2）。** これを90日で測ります。

| 期間 | やること | 見る数字 |
|---|---|---|
| Day 1〜30 | 型A 30本（当社施工＋アンケート由来）、型C 4本、型B 2本、型D 各5本を非公開で用意。ドメイン取得・配信 | — |
| Day 31〜60 | 公開。動画を週2本。Instagram・GBPと同期 | 症例ページの訪問数／投稿フォームの送信数／判定の内訳 |
| Day 61〜90 | 投稿の受付を開始 | **判定「プロ」→手配フォーム送信の率**／投稿からの症例数／方法別統計の被引用（Search Console） |

**殺す条件（Day 90）：** 投稿フォームの送信がゼロに近く、かつ手配フォームへの転換が測れない → **メディアの役割を「柱1の素材置き場＋提携先への送客」に縮小し、拡張をやめる。** 拡張条件はその逆。数字の閾値は Day 30 の実測を見て置く（今置くと嘘になる）。

## 10. この文書の限界

- 「症例集の読者が依頼に転じる率」は未検証。8章で測る
- 推定検索数は推定ツールの値（Google値＝Yahoo値×4の係数換算）。桁の比較にしか使っていない
- ペットフード協会の飼育データは利用先が限定されており、当社メディアでの引用は要確認
- 日本のGoogleの実際の順位は取れていない（WebSearchは米国拠点）
