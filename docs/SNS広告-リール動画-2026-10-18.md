### BGM について（オーナー指示 2026-10-18「BGM付ければ完成でいいよ」）

**他人の曲は使っていません。`tools/make-reel-bgm.py` で、その場で合成した自前の曲です。**
鳴っているのは全部サイン波の足し合わせで、素材を一切借りていないので、権利の問題が起きません。

- F メジャー・84BPM・8小節（Fmaj7 → Am7 → B♭maj7 → Csus）。
  ベル（鉄琴寄り）のアルペジオ＋パッド＋低音＋ごく小さいシェイカー。打楽器は入れていません
- 各本の長さぴったりに作り、終わりの2.2秒でゆっくり消えます
- 音量は RMS −13.8dBFS／ピーク −1〜−2.9dBFS。Meta の正規化（約 −14 LUFS）に合っています
- **リールは音を切って見られることが多いので、音を消しても成立するように作ってあります**
- 気に入らなければ、入稿のときに Meta の音源ライブラリから当て直せます。
  そのときは `python3 tools/build-ad-reels.py --no-bgm` で無音版を出せます

## 作り直し・手直しのしかた

```bash
git checkout origin/claude/web-inflow -- assets/photos   # 素材（この枝では追跡していない）
python3 tools/fetch-fonts.py                              # 字（OFL。大きいので置いていない）
pip3 install pillow imageio-ffmpeg
pip3 install numpy                                        # BGMの合成に要る
python3 tools/build-ad-reels.py --check                   # 文言の検査だけ（描画しない）
python3 tools/build-ad-reels.py --poster                  # 3本ぜんぶ＋確認用の1枚
python3 tools/build-ad-reels.py hood-fan                  # 1本だけ
python3 tools/build-ad-reels.py --no-bgm                  # BGMなしで出す
python3 tools/make-reel-bgm.py --all                      # BGMのwavだけ出す
python3 tools/build-ad-reels.py --proxy                   # 確認用の軽量版（720x1280）も出す
```

台本は `data/ad-reels.json`。写真・切る範囲・見出し・ひとこと・カメラの動き・長さは全部ここにあります。
**写真を差し替えるときは、`data/photo-catalog.json` の「問題」欄と `判定` を必ず見てください。**

## Drive の置き場

**「広告動画（SNSリール）」フォルダを作りました。**
https://drive.google.com/drive/folders/1yI79KZpphNSMyINzg0WpQrwC4P1LtKZb
（ID `1yI79KZpphNSMyINzg0WpQrwC4P1LtKZb`。親は ONE HITTER の作業フォルダ `1_VkA21-rE4XROBQqBAjrPnyEp3pNt-tX`）

中に「このフォルダについて.txt」を置いて、何を入れるフォルダかと作り直しの手順を書いてあります。

**動画3本はまだ入っていません。** Drive MCP はファイルの中身を base64 の文字列で渡す作りのため、
動画は通りません。**容量を落としても同じです**（720×1280 の2MBでも base64 で約280万文字になり、
ツール呼び出しには載りません）。容量上限ではなく、渡し方の限界です。

入れる道は2つ。ブラウザ担当に 1 を依頼済みです。

1. **Chrome拡張の `file_upload` で drive.google.com に直接上げる。**
   ファイル選択ダイアログに実ファイルを渡す仕組みで base64 を経由しないため、
   **軽量版ではなく 1080×1920 の本体をそのまま入れられます**
2. 手で入れる（本体・軽量版・`-コマ.jpg` すべて Claude Code の画面からダウンロードできます）

**急ぎではありません。** 入稿はファイルから直接できるので、Drive 格納はOKが出たあとで構いません。
