## 2. 🛑 **ダミーを「削除」する手段が、当社側にありません**

**ここが依頼の前提と違うところです。先に結論を書きます。**

### API には、友だちを外す・ブロックする口が1つもありません

LINE公式のOpenAPI定義（`messaging-api.yml`）の**全エンドポイントを機械で列挙して確認**しました。

```
/v2/bot/followers/ids          友だちのIDを取る（読むだけ）
/v2/bot/profile/{userId}       1人のプロフィールを見る（読むだけ）
/v2/bot/message/...            送る
/v2/bot/richmenu/...           リッチメニュー
/v2/bot/coupon/...             クーポン
…
```

**`delete` も `block` も `unfollow` も、友だちに対しては存在しません。**
**「友だちをやめる」はお客様側の操作で、アカウント側からはできない仕様**だからです。

### 管理画面のチャットからも、たぶん届きません

LINE公式アカウントマネージャーのチャット画面には、個別にブロックする操作があります。
**ただしチャット画面に出てくるのは「やり取りのあった相手」だけです。**
**253人のダミーは一度も発言していないはずなので、チャット一覧に出てきません。**

> **ここは画面を見ないと確定できません。ブラウザ担当に見てもらってください。**
> 確かめること：**「友だち一覧」から、発言のない相手を個別にブロックできるか。**
> できたとしても、**253回、手で押す**ことになります。

## 3. ✅ 代わりの答え：**消さずに、届け先を選ぶ**

**無料枠に収める方法は「友だちを減らす」だけではありません。**
**「一斉配信（broadcast）をやめて、選んだ人にだけ送る（narrowcast）」で解けます。**

| 送り方 | 届く人 | 消費する通数 |
|---|---:|---:|
| **broadcast（一斉配信）** | 330人 | **330通 → 無料枠200を超える** |
| **narrowcast（オーディエンス宛）** | **選んだ人だけ** | **その人数ぶんだけ** |

### いますぐ使えるオーディエンスが1つあります

```
リッチメニューインプレッション: 202604261513 ／ 63人 ／ READY
```

**リッチメニューを実際に見た63人**です。**ダミーは見ません。本物の可能性が高い63人です。**

**`/v2/bot/message/validate/narrowcast` に通したところ、形は通りました（HTTP 200・1通も送っていません）。**
**63通なら無料枠200の中に余裕で収まります。**

> ⚠️ **narrowcast はオーディエンスが50人未満だと使えません**（LINEの仕様。人物の特定を防ぐため）。
> **63人はぎりぎり足ります。** これ以上減らすと使えなくなります。

### 本物の友だちを貯めていく手だて（今日からできる）

| やり方 | 何ができるか |
|---|---|
| **クリックリターゲティング**（`audienceGroup/click`） | 配信のリンクを押した人でオーディエンスを作る |
| **インプレッションリターゲティング**（`audienceGroup/imp`） | 配信を見た人でオーディエンスを作る |
| **ユーザーIDでオーディエンスを作る**（`audienceGroup/upload`） | webhook で発言・友だち追加を拾った人を貯める（`LINE_ログ` タブ。2026-09-07 から記録中） |

**1回 narrowcast すれば、そこから「押した人」のオーディエンスが作れます。**
**63人 → 押した人 → …と、本物だけが濃くなっていきます。**

## 4. 年末の一斉配信は、どう組むか

**「330人に1通」は、いまのプランでは送れません。** 代わりにこうします。

```
① リッチメニューを見た63人へ narrowcast          63通（無料枠200の中）
② ①のリンクを押した人でオーディエンスを作る
③ 次の配信は②へ                                さらに少ない通数で、反応する人だけに
```

**無料枠200通に対して、①だけなら余裕が137通残ります。**

> ⚠️ **超えたときにどうなるか（送れないのか、課金されるのか）は未確認です。**
> コミュニケーションプランには従量課金が無いので**送れない**はずですが、**推測で書きません。**
> **プランを変える＝お金の話なので、オーナー判断です。**
