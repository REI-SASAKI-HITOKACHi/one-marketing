## 3. ブラウザ担当へ：第1束との違い

貼る手順は同じです。違うのは4点です。

1. **カテゴリがメニュー名になりました。**エアコン／水まわり／洗濯機／レンジフード／お知らせ。CMSのカテゴリに同じものが無ければ、新しく作ってください

3. **締めが2段になりました。**予約LP（`?src=blog`）が主、その下にLINE友だち追加。**どちらのリンクも消さないでください**
4. **本文が長い回があります**（最長1,272字）。見出しは `##` と `###` の2段を使っています

`source` `notes` `status` の3欄をサイトに出さないのは、第1束と同じです。
