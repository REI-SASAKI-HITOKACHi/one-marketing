## 2. 何が問題なのか（調査結果の読み方）

### 2-1. アカウントはあるが、資産になっていない

Instagramの中身が取れないので「投稿されているか」は言えません。
**しかし、投稿されていたとしても、その投稿からお客様が来る道がありません。**

```
いま
  Instagram ──✕──> 公式サイト     （サイトにリンクが無い。逆向きの導線も無い）
  Facebook  ──✕──> 公式サイト
  GBP       ──✕──> 公式サイト
  公式サイト ──○──> 公式LINE       （唯一つながっている1本）
```

SNSを増やす前に、**この配線が先**です。配線は原稿より早く、確実に効きます。

### 2-2. 「素材が無い」のではなく「素材が置かれていない」

| 素材 | 手元の量 | いまの掲載先 |
|---|---:|---|
| 施工写真（厳選済み） | **28枚**（うち掲載可 **23枚**） | LP。**公式サイトの施工事例は2022年で止まっている** |
| Googleクチコミ 全文 | **5件**（★5のみ） | LP・アンケート |
| アンケート満足度 | **98.6%**（209名中206名） | LP |
| 元の写真 | 162枚（2026/08/10〜09/05） | Drive `施工写真_一次格納 / 02_過去分` |

**掲載できない5枚**（`docs/photo-inventory.md`）:
`IMG_7917` `IMG_7922` `IMG_7932` `IMG_7939`（店舗床。什器に Off-White のロゴ）、
`IMG_7993`（洗面。お客様の私物）。

### 2-3. 効くのはSNSより先にGBP

- 公式サイト経由の新規は **年4件・売上の0.5%**（`docs/流入経路の分析.md`）
- GBPは **★5.0で2位**。差は件数だけ（23件 vs 60〜94件）
- 施工は月およそ30件。**その2割が投稿してくださると月6件、半年で60件前後**（`docs/gbp-audit.md`）
- 手段はすでに用意済み（アンケート公開済み・現場QR作成済み）

**広告費ゼロで順位が動く枠が、目の前にあって、埋まっていません。**
SNSはここに合流させるのが、いちばん短い道です。

## 3. 確認できなかったこと（誰が、何分で確認できるか）

**下の3つは、ログイン済みのブラウザがあれば合計10分で埋まります。**
このスレッドの実行環境ではブラウザが外部に出られないため、
**オーナー、または `bridge`（オーナーのPC上で動く）スレッドでの実施をお願いします。**

### ① Instagram `@onehitter.jp`（所要3分）

スマホのInstagramアプリか、ログイン済みのPCブラウザでプロフィールを開いて、以下をそのまま書き写してください。

```
1. フォロワー数
2. 投稿数
3. いちばん新しい投稿の日付
4. プロフィール文（そのまま）
5. プロフィールのリンク欄に何が入っているか（空なら「空」）
6. アカウントの種別（個人 / クリエイター / ビジネス のどれか）
7. ログインできる人（誰のアカウントとつながっているか）
```

**6番が重要です。** ビジネスアカウントでないと、インサイト（保存数・プロフィールアクセス）が見られず、
指標が取れません。個人アカウントなら切り替えが要ります（無料・1分）。

### ② Facebook「One Hitter」ページ（所要3分）

```
1. フォロワー数
2. いちばん新しい投稿の日付
3. Instagramと連携されているか（Metaビジネススイートに両方出るか）
4. 管理者権限を持っている人
```

### ③ Googleビジネスプロフィール（所要4分）

```
1. 管理画面にログインできる人
2. 「投稿」を過去に使ったことがあるか。あれば最終の投稿日
3. 直近30日の「表示回数」「経路検索」「電話」の数
4. 写真の枚数（現在10枚と外から見えています）
```

### ④ その他（所要はゼロ。①〜③のついでに）

```
5. X・TikTok・YouTube のアカウントを作ったことがあるか（作っていれば、放置でもURLを）
6. 顔出しの可否（オーナー・渡辺さんそれぞれ）
```

**② サイトの更新は二極化していて、中間がない。**
週次で回っている側（はなえ 2026-09-09、おそうじエンジニアリング 2026-08-22、i.so-ji 2026-08-10）と、

**③ この商圏で最も更新頻度が高い会社が、SNSを1つも持っていない。**
はなえハウスクリーニング（2026-09-09更新）は、下層4ページまで走査して0件でした。
**発信意欲の高い事業者ですら自社ブログに閉じていて、SNSへ出ていません。**
→ **SNS側の競合密度は低い。**

**④ 差別化の軸は、ビフォーアフター画像ではなく「施工事例の具体性」に置かれている。**
事例ページを持つ会社は、地名・物件名まで出しています。

- アースホームサービス：「**千葉県浦安市｜シーガーデン新浦安**」＝物件名まで
- おそうじエンジニアリング：「**千葉県市川市大和田：K様**」＝地名＋イニシャル

**画像そのものより、「うちの近所でやっている」という近接性の提示が共通パターンでした。**
→ 投稿のキャプションに **地名（西葛西・葛西・浦安・南砂 など）を必ず入れる**設計にします（7章）。
物件名は、お客様が特定されうるので**当社では出しません。**

### 4-4. 見落としてはいけない読み方

**SNSが空いていることは、機会であると同時に、警告でもあります。**

> 「この商圏の同業がSNSをやっていない」は、
> 「**この商圏のお客様がSNSで業者を探していない**」という意味かもしれません。

だから90日の設計では、**SNS単独に賭けず、GBP（地図検索）を先に置いています**（5-2）。
なお、くらしのマーケット／ユアマイスター／EPARK等のポータルでの露出状況は**今回調べていません。**
ここは「同業がどこで客を取っているか」の裏取りとして、**別途やる価値があります**（9章 #7）。

## 5. 90日運用案 ─ 方針

### 5-1. 何のためにやるか

**フォロワー数は目標に置きません**（`docs/org/roles/web-inflow.md`）。
ローカル商圏なので、全国の10万フォロワーより、**江戸川区・西葛西・浦安の1,000人**です。

背景の数字：

| | |
|---|---:|
| 自社（ONE HITTER）の平均単価 | **¥52,374** |
| おそうじ本舗経由の平均単価 | ¥28,176 |
| 本舗へのロイヤリティ | 27.6% |
| 置き換えられた場合の年間の改善 | **約¥629万** |
| 2026年9〜12月の空き | **約940時間 ≒ 188セット** |

**枠は空いていて、単価の高い経路があり、その経路への入口だけが無い。**

### 5-2. 90日をどう置くか

90日は **2026-09-11 〜 2026-12-09**。この期間の性格を正しく見ておきます。

- 11〜12月は年末の大掃除で**引き合いが増える時期**（次回予約割引は「なし」の設定）
- ただし稼働率は9〜12月でも **20〜50%**。**いま埋める余地は実際にある**
- そして **1〜2月が最閑散期**（割引15%）。**SNSの仕込みが効くのはここ**

したがって、

> **90日の目的は「1〜2月の谷を埋めるための土台を作ること」。**
> **即効性はSNSではなくGBPに置く。SNSは3か月かけて型と素材の流れを作る。**

これを取り違えて「SNSで今月の売上を作る」と置くと、必ず失敗します。
**投稿から予約までは早くて1〜2か月かかる**という前提で組んでいます。

### 5-3. やらないことを先に決める

90日のあいだ、**次には手を出しません。**

| やらないこと | 理由 |
|---|---|
| TikTok・X・YouTube の新規開設 | 1人で回す前提。**チャネルを増やすと全部が薄くなる**。まずInstagram1本を型にする |

## 7. 投稿の型（5種）

**素材と法令の制約から逆算して、この5つに絞りました。**

### 型B｜汚水（1カット・数字を添える）

### 8-1. 誰が撮るか

**渡辺さん（現場責任者）。ただし現場で手が塞がっています。**

```

2. Before ②（寄り。いちばん汚れているところ）

4. After  ②（Before② と同じ位置・同じ角度から）
```
