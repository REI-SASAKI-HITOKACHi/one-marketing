# ブログ本文の予約リンク・LPリンクが押せない件（2026-11-01・依頼 20261101-02-lp）

## 結論

- **公開中のブログ125本を全部取得して数えた**（sitemap.xml・14:45 JST）。本文に予約ページかLPのURLがあるのは 60本（押せるリンクになっているのは 36本）。そのうち **23本・26段落で、URLがただの文字（`<a>` なし）＝押せない**
- 押せないのは予約ページ（yoyaku）だけでなく **LP（lp.onehitter.jp/aircon・mizumawari・nenmatsu）へのURLも同じ**。2026-10-09 以降に入れた記事（1721〜1761・1803・1810・1812）が全部これ
- 押せるのは 2022〜2023 の旧記事17本・9/23〜24 の18本・入口ページ1805（lp の道具 make-hp-iriguchi.py で作った物）
- **予約投稿（11/2〜11/21）も同じ書き方**：web-inflow の原稿（docs/blog/2026-11-*.md）21本が全部、URLを文字のまま書いている。CMS に入れた予約投稿も同じ状態のはず（公開前なので外からは見えない。browser が CMS で確認）

## 原因

- 原稿（Markdown）が `ご予約はこちらから。https://yoyaku.onehitter.jp/?src=blog` のように **URL を地の文に書いている**。9/23〜24 の記事は `[文言](URL)` の書き方だったので押せた
- CMS に入れるときの変換（Markdown→HTML）も、CMS（Jodit）も、**地の文の URL を自動でリンクにしない**。だから `<p>…こちらから。https://…</p>` のまま公開された
- 投稿前の点検（web-inflow の check-blog.py・cmo の check-blog-public.py）が「URLが `<a>` になっているか」を見ていなかった

## 直し方

1. **公開中の23本**：下の表の「いま」の段落を「直した後」に差し替える（CMS の本文を HTML 表示にして置き換え。題名・公開日時・他の段落は触らない）。押したときの文言はURLの代わりに「空いている日を見て予約する」「エアコンクリーニングのページを見る」などにした（`?src=blog` はそのまま）
2. **予約投稿（11/2〜11/21）**：公開前に同じ置き換え。CMS の各記事で、文字のURLを同じ形の `<a>` に（一覧は下）
3. **再発防止**：原稿は `[空いている日を見て予約する](https://yoyaku.onehitter.jp/?src=blog)` の書き方にする（web-inflow）／変換は地の文のURLも `<a>` にする／check-blog-public.py に「本文の予約・LPのURLがすべて `<a>` か」を足す（cmo）

機械で使える形：`docs/ブログ-予約リンク直し-2026-11-01.json`（published＝記事URL・いま・直した後、drafts＝原稿の該当行）
