# C対E：10/24 の MTG までに判定する案（2026-10-16 計測担当）

> **10/18 オーナー決定**：E 100% への切り替えは、E の優位が数字ではっきり出て、かつオーナーに相談してから。10/17 の「悪くなければ E に寄せる」案は取り下げ。下の (c) の線（はっきり差が付いたら）は判定に使うが、満たしても切り替えはオーナー相談のあと。

依頼：CMO 20261016-06 ②（第7回MTG 7-7 オーナー原文「判定タイミングが遅いと思う。必要サンプル数が足りないなら広告予算を増加させる折衝を嶺へＣＭＯがして」）

## 今のペースだと、いつ判定できるか
- エアコンの広告クリックは約7.5回／日（両版の合計）。起点 10/15 08:2x から **10/24 朝までで各版 約32クリック**
- 今の判定表の基準：各版100で中間（壊れていないか）、200で判定 → **中間が 11/10 前後、判定は 11/30（各版 約170）**
- 主指標（予約ページへ進んだ人の割合）の差を見分けるのに要る数（片側 p<0.10・検出力80%）：

| C の率 → E の率 | 各版に要る人数 |
|---|--:|
| 10% → 15%（1.5倍＝今の設計の基準） | 約390 |
| 10% → 20%（2倍） | 約113 |
| 30% → 45%（1.5倍。率が高い指標なら） | 約92 |

**1.5倍の差を見分けるには各版390人が要り、11/30 でも足りません。** 今の設計（各版200で1.5倍）は、もともと大きめの差しか拾えません。

## 案ごとの見込み

### (a) 日予算を上げる → **クリックは増えない見込み**
- 10/13 の実測で「予算による制限」は無し。入札が「クリック数の最大化」のまま、検索の数で頭打ちになっている
- 予算を上げても、出る検索が増えなければクリックは増えない。**確かめ方**：キャンペーンの列「検索広告のインプレッション シェア損失率（予算）」と「（ランク）」（browser）。予算の損失がほぼ0なら、予算では増えない
- 増やせるのは入札（1クリックの上限）を上げる場合だけ。ただし今の入札戦略では上限を手で決めていないので、効くかは未確認

### (b) 地域・キーワードを広げる → **10/24 には間に合わない**
- 各版113（2倍の差を見分ける数）に 10/24 までに届くには、両版で1日約27クリック＝**今の約3.6倍**が要る
- カビのキーワード（①）は別のLP（カビ特化）に着地させる決定なので、C対E の人数は増えない

### (c) 判定の決め方を変える → **これを推します**
10/24 に「はっきり差が付いた場合だけ、その場で決める」。付かなければ、今のまま 11/10 の中間へ進む。
- 指標は今のまま（予約ページへ進んだ人の割合）。ただし数えるのを広告だけでなく **LP の全ユーザー（C・E 両方へ半々に振っている人すべて）** にして、人数を増やす
- 10/24 に E を採用する線（各版 約34人の場合。片側 p<0.10）：

| C の予約ページへ進んだ人 | E がこれ以上なら採用 |
|--:|--:|
| 2人（6%） | 7人（21%） |
| 3人（9%） | 8人（24%） |
| 4人（12%） | 10人（29%） |
| 5人（15%） | 11人（32%） |

- 逆に、E が C を下回っていれば、10/24 に E を止める
- どちらでもなければ「差なし」として 11/10 まで続ける
- 弱点：小さい差（1.5倍程度）は見逃す。それでも、今のまま 11/30 まで待っても見分けられない大きさなので、失うものは少ない

## CMO への1行
**10/24 には「大きな差が付いたら決める」の形なら判定できる。予算を上げてもクリックは増えない見込みなので（予算による制限なし）、増額の折衝の前に、インプレッション シェアの損失（予算／ランク）を browser に見てもらう。**
