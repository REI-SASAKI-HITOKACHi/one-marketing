## 次の束のために：**施工ネタだけでは100本に届きません**

自社名義で、棚卸しに中身の記録がある現場は **7現場**です。1現場から2〜4本が限界で、
**施工の実況型は、全部で20本前後**が上限だと見ています。

100本にするなら、**施工に紐づかない型**を足す必要があります。こちらは材料が要らないので量産できます。

| 型 | 中身 | 何本くらい |
|---|---|---|
| 手入れの一言 | 自分でできる範囲（フィルター・洗濯槽・排水口・レンジフードのフィルター…） | 30本 |
| 季節 | 冷房前・暖房前・梅雨・年末・引っ越し前後 | 15本 |
| メニューと料金 | 1メニュー1本（マスターの税込をそのまま） | 15本 |
| 対応エリアと段取り | 東京都・千葉県・神奈川県、作業時間の目安、養生、駐車の扱い | 10本 |
| 読み物の案内 | 読本（赤ちゃん版・ペット版）の章立てから1本ずつ | 10本 |
| お客様の声 | Googleクチコミの引用（「」を変えない・特定できる語を伏せる） | 10本 |

**この配分でよければ、次の束から順に作ります。**査読の手間を考えて10本ずつ出します。
