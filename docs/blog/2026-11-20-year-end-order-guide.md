大掃除は、全部を自分でやらなくても進みます。

場所ごとに、自分でできるところと、頼むところを分けると、年末の予定が組みやすくなります。分け方の基準は1つです。**手が届くかどうか。**

![エアコンの吹き出し口と風向板](ph-005.jpg)
*当社が作業したお宅のエアコンの吹き出し口と風向板。養生をして作業中。*

## 先に、掃除のときの決まり

2つあります。

東京都の指針には、ほうきや掃除機を使うとほこりが舞い上がるので、必ず窓を開けるように書かれています。

> ホウキやハタキ、掃除機を使う時は、チリやホコリが舞いあがるので、必ず窓を開けましょう。

電化製品については、取扱説明書を先に読むよう書かれています。

> 水や溶剤での拭き取りは、表面の劣化や漏電、引火の可能性があるので、掃除をする際は取扱説明書をよく読んでから行いましょう。

出典：東京都「健康・快適居住環境の指針」No.23 https://www.hokeniryo.metro.tokyo.lg.jp/documents/d/hokeniryo/web_bunya10

## エアコン

| | 内容 |
|---|---|
| 自分でやる | フィルターを外して水で洗う。乾かしてから戻す。吹き出し口の手が届く範囲を、固く絞った布で拭く |
| 頼む | フィルターより奥（熱交換器と送風ファン） |

奥は、メーカーが洗浄スプレーを使わないよう案内しています。

> 市販の洗浄スプレーは、ご使用しないでください。（ダイキン）

> エアコンの内部洗浄は、お客様自身で実施せずに、高い専門知識を有する業者に依頼をしてください。（三菱電機）

出典：ダイキン https://www.daikincc.com/faq/customer/web/knowledge2700.html ／ 三菱電機 https://faq01.mitsubishielectric.co.jp/faq/show/712?site_domain=default

## レンジフード

| | 内容 |
|---|---|
| 自分でやる | 整流板とフィルターを外し、35〜40℃のお湯で20〜30分つけ置きして洗う。フードの外側を拭く |
| 頼む | 奥のシロッコファン |

つけ置きの目安は、パナソニックの案内にあります。外すのは、整流板とフィルターの2つまでです。ファン本体は外さないでください。

出典：パナソニック「住まいの設備と建材」 https://sumai.panasonic.jp/support/care/kitchen/05/

## 浴室

| | 内容 |
|---|---|
| 自分でやる | 壁、扉、ゴムパッキンの黒い点。床のぬめり。排水口の部品 |
| 頼む | 浴槽のエプロンの内側など、開けないと見えない場所 |

塩素系の洗浄剤は、必ず単独で使ってください。酸性のものと混ぜないでください。窓と扉を開け、換気扇を回したままにします。

> 塩素系洗浄剤は「まぜるな危険」の表示のあるものを、必ず単独で使用してください

出典：国民生活センター https://www.kokusen.go.jp/news/data/n-20260318_1.html

## 洗濯機

| | 内容 |
|---|---|
| 自分でやる | 月1回ほどの槽洗浄。糸くずフィルター。洗濯後はフタを開けて乾かす |
| 頼む | 槽の裏側 |

月1回やっても黒いカスが出るときは、槽の裏の層が市販のクリーナーでは届いていない場合があります。お酢とクエン酸は、金属部品を酸化させるため使わないでください。

## トイレ

| | 内容 |
|---|---|
| 自分でやる | トイレ用の中性洗剤をかけて、しばらく置いてからこする。ふちの裏はペーパーを貼って洗剤を留める |
| 頼む | 中性洗剤を置く時間を延ばしても落ちない黄ばみ |

LIXILの案内にある手順は、外側を水拭き、内側に中性洗剤をかけて放置、ブラシでこすって流す、です。便器の種類によって使えない洗剤があります。お使いの便器の説明書を先に見てください。

出典：LIXIL「便器の日常のお手入れ」 https://www.lixil.co.jp/support/clean/toilet_01_daily.htm

## 排水口

| | 内容 |
|---|---|
| 自分でやる | 髪の毛と糸くずを取る。部品のぬめりを落とす。使っていない排水口にコップ1杯の水を流す |
| 頼む | 水を足しても翌日には臭う場合は、先にご相談ください |

油は、固まる前に拭き取って捨ててください。熱湯を大量に流すのは避けてください。

## 年末の分け方

自分でやる分は、年内のどの日でも構いません。頼む分は、日にちを先に決めます。

12月は繁忙期で、ご希望の日に入れないことがあります。**頼む分だけ、11月のうちに決めておく**と、年末は自分でやる分に集中できます。

## 11月と12月の料金

| | 11月 | 12月 |
|---|---|---|
| 割引 | 10%引き（1箇所のご依頼が対象） | なし |
| 繁忙期の加算 | なし | 各料金に3,300円（税込） |

エアコンクリーニング（お掃除機能なし）は、通常10,780円（税込）です。11月に1箇所だけご依頼の場合は9,702円（税込）になります。

複数台、または複数の場所を同時にご依頼の場合は、同時施工の価格が適用され、早期予約の10%とは併用できません。
