## なぜ動かしたか

**オーナー直接決定 2026-09-23**（`20260923-01-web-inflow` の3番）で、ブログは公式サイトの過去記事の型で書き直すことになりました。CMO 判断（同日）で「**第1束はそのまま出す。第2束から新しい型**」と決まっています。

新しい型は `docs/blog-過去記事の型.md` にまとめています。要点は次の4つです。

1. 題名が、検索する人の言葉そのまま（「〜の原因」「〜する方法」「〜選」）
2. **1つの困りごとを3本で囲む**（原因 → 方法 → 日々の対策）
3. 見出しが、やることそのもの
4. カテゴリはメニュー名（エアコン・水まわり・洗濯機・レンジフード・トイレ・お知らせ）

ここにある原稿は、1本完結の随筆に近い書き方で、カテゴリも旧い区分（事例研究・読本・お知らせ）のままです。
