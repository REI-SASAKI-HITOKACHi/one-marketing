## 初めての単価設定｜相場の調べ方と、作業時間・経費から逆算する料金の決め方
https://aircon-urakata.com/start/tanka-settei/ （料金の確認 2026-10-14）

- 相場は「大手チェーン／マッチングサイトの評価上位10件／近所の個人店5件」の3つを並べて自分の立ち位置を決める。記事の確認値（2026年10月・税込）：おそうじ本舗 壁掛け 14,300円・2台以上は1台 12,100円・お掃除機能付き 24,200円、ダスキン 15,400円（条件あり）
- 出発点は「1日に何台入るか」。壁掛け1台＝作業1.5時間＋移動・駐車30分＋片付け15分 ＝ 2時間強 → 1日3台。お掃除機能付き 2.5〜3時間で1日2台、天井埋込（4方向）2.5時間で2台
- 計算例：月の利益40万円 ÷ 22日 ÷ 3台 ＝ 1台約6,100円の利益が要る。閑散期は年平均で1日2台台に落ちるので繁忙期の単価で計算しない
- 1台あたり経費の例（月66台）：洗剤・消耗品500円／ガソリン・駐車800円／道具の買い替え300円／賠償保険100円／車・通信・ソフト500円＋マッチング経由なら売上の20%前後
- お掃除機能付きは「なしの1.6〜1.8倍」。時間が約2倍で破損リスクも上がる。「＋3,000円」の値付けは時間で見ると赤字
- 室外機 4,000〜5,500円（作業20〜30分・同時なら利益率が高い、必ず案内）／防カビ 2,000〜3,300円（見積書に最初から行を作る。効果は言い切らず「臭いの戻りを遅らせる」程度）／複数台割引は1台1,000〜2,200円引きまで
- 値引きは「台数」でだけ。「初回だから」「近所だから」はしない。複数台割引と駐車場代の実費請求の2つを決めておく
- 料金表は税込3行＋オプション2〜3行＋追加条件（駐車場・古い機種・高所）。「〜円〜」の「〜」は不安を残す、型番で決まるなら言い切る。料金シミュレーターを置くと「料金だけ聞いて終わる電話」が減る
- 安売りしない理由：安さで来た客は次も安い店へ／台数を詰めると養生が雑になり事故が増える／繁忙期は値上げせずとも埋まる／値上げは下げるより難しい（「大手の7〜8割で始め、口コミが増えたら9割へ」）／下請け単価（1台3,000〜5,000円）と比べない

→ ワンヒッター：当社ノーマル 10,780円・お掃除機能付き 17,380円（比 1.61倍）は記事の目安「1.6〜1.8倍」の下端。実所要との突き合わせは `../当てはめ.md` A・B。

## くらしのマーケットで売上が変わった私が、集客を1社に任せない理由
https://aircon-urakata.com/start/shukyaku-site-hikaku/ （確認 2026-10-09）

- 筆者の経歴：25歳でハウスクリーニング会社に就職→28歳で独立。最初はテレビ通販系の在宅クリーニングを孫請けで1台3,000円。入金遅れの末に発注元と連絡が取れなくなった
- くらしのマーケットに出店して注文が急増（記憶として：多い日は1日30件以上、夏は3か月先まで埋まる）。ただし予約の返信・日程調整だけで1日8時間以上かかる日があった
- 「手数料ではなく、払ったあとに何が残るかで考える」。下請け4,000〜5,000円 vs マッチング 10,000−2,000＝8,000円
- 業者が増えて「登録すれば来る」時代は終わった。1社に売上の大半を預けるリスク → **直接受注（HP・Google・紹介）／マッチングサイト（空き枠を出す）／協力会社・同業**の3本立て
- 月末に見るもの：経路ごとの件数／手数料・広告費・現場経費を引いた残額／返信から完了までにかかった時間／1社への偏り・入金予定
- 現在のくらしのマーケット条件（記事の確認日 10/9）：予約金額（税込）の20%＋消費税、最低手数料2,000円（税別）。サイト経由のリピーターの直接依頼も申告が必要と公式FAQにある
- 手数料込みの掲載価格は「残したい額 ÷（1−手数料率）」。2割上乗せでは足りない（10,000円残すなら22%で約12,821円）
- 直接受注は Googleビジネスプロフィール（正確な情報・実作業の写真・率直な口コミ依頼、お礼に割引や特典を付けない）と自分のHP
- 現在の運用：直接の問い合わせは LINE公式アカウント、予定はウレシー（Googleカレンダーへ移行を検討中）

→ ワンヒッター：当社の実測（マッチングPF手数料 約35%・リピート率2%／自社直販リピート26%／業務提携LTV 18.6万円）と同じ構図。`../当てはめ.md` E。

## エアコンクリーニングで開業する全手順｜現役業者が順番どおりに解説
https://aircon-urakata.com/start/kaigyo-zentejun/

- 順番：技術（3か月前）→独立かFC→道具と車（2か月前）→保険（1か月前、開業日より前）→届出と会計→料金と書類→集客（3本立て）→開業後に作業手順を固定しトラブル対応を覚える
- 技術：研修か同行で**10台以上の異なる機種**を触ってから
- 開業前チェックリストに「料金表・見積書・作業報告書・同意書がある」「水漏れ・基板・爪折れの対処を読み、吸引ポンプ・接着剤を積んだ」

→ ワンヒッター：開業済みなので手順そのものは不要。チェックリストの後半2項目（書類3枚・トラブル用品の常備）は現場点検に流用できる。

## 開業資金は10万円で足りる？道具代・車・運転資金の見積もり方
https://aircon-urakata.com/start/kaigyo-shikin-10man/

- 最低限の道具の目安合計 約75,000〜175,000円（洗浄機 30,000〜80,000円で大きく変わる）。**電装養生カバーは「基板事故を防ぐ。必須」**、ドレン吸引ポンプは水漏れ対処用
- 副業で車ありなら15〜25万円、専業なら車・生活費込みで100〜150万円が安全
- 買わなくていい：家庭用の高圧洗浄機（圧が強すぎてフィンを倒す）、100均の噴霧器

→ ワンヒッター：特になし（道具の点検にだけ使える）。

## FC加盟か独立か｜費用と収支の考え方を比較
https://aircon-urakata.com/start/fc-vs-dokuritsu/

- 目安（仮定）：FC初期150〜400万円、ロイヤリティ月3〜10万円、契約3〜5年・中途解約に違約金、料金は本部が決める。独立は道具＋保険15〜25万円
- 月20件・単価12,000円の仮定で、FC残額160,000円／独立188,600円（集客サイト半数経由の場合）
- FC向き：営業が苦手・資金あり・決まったやり方が苦でない・地域で本部の知名度あり

→ ワンヒッター：当社は本舗（FC）と自社の両方を持つ。本舗の実効率（39%＋固定）は savedata 既知。記事の数字は仮定なので比較には使わない。

## 研修はどこで受ける？スクール・FC研修・同行の違い
https://aircon-urakata.com/start/kenshu-dokode/

- 専門スクール（JACA・ハウプロ・愛生など）5〜30万円／FC研修（加盟金に含む）／現役業者への同行（無料〜謝礼。1日1万円前後か助手として無償が相場感）
- スクールで見る点：実機の台数と機種の幅、**受講後に質問できる窓口（いちばん価値がある）**、道具販売とのセット、受講生の継続年数

→ ワンヒッター：人を増やすときの教育設計の参考。今は特になし。

## 副業からエアコンクリーニングを始める｜就業規則・確定申告20万円の線・住民税
https://aircon-urakata.com/start/fukugyo-chui/

- 副業期は「受けない仕事を決める」（天井埋込・業務用・古い機種の完全分解は時間が読めない）。マッチングサイトは土日だけ受付を開ける
- 専業に切り替える目安：閑散月（10〜11月・2〜3月）の土日が埋まるか／直接受注が3割／生活費6か月分

→ ワンヒッター：当てはまらない。ただし「協力スタッフ（副業の応援）を受け入れる時の注意点」として読める。

## 屋号・名刺・簡易ホームページの最小構成
https://aircon-urakata.com/start/yago-meishi-hp/

- 名刺は表＝屋号・名前・電話・作業の種類、裏＝予約先QR、余白＝**清掃日を書く欄**
- 簡易HPに載せる5つ：料金表（税込）／対応エリア（市区町村名・出張費の範囲）／**対応できる機種・できない機種（断る条件も先に）**／連絡方法と返信の目安時間／運営者情報（保険加入の有無も）
- GBP：住所を出さずサービス提供地域（最大20か所）で登録できる。**ビジネス名に地域名やうたい文句を足すのはガイドライン違反**。口コミの依頼先はここ、QRを名刺の裏に

→ ワンヒッター：HP・GBPは整備済み。「できない機種の明記」「保険加入の明記」「次回清掃日の記入欄」は未確認なので lp・crm に確認材料として渡せる。
