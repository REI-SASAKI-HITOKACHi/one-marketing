## 見積書・作業報告書・免責同意書のテンプレ｜エアコン屋が持っておく3枚の項目と文例
https://aircon-urakata.com/biz/mitsumori-hokoku-doui/ （更新 2026-10-13。記事自体が「法的な助言ではない」と明記）

- 考え方：トラブルの大半は「聞いていない」から。**料金は見積書、やったことは作業報告書、やらないこと・起きうることは同意書**で先に文字にする。A4各1枚
- **見積書の項目**：宛名・日付・有効期限（例：30日。繁忙期で料金が変わるなら短め）／種類ごとに行を分けた作業内容と台数／税込で統一した単価・数量（オプションは別行）／**含まれるもの**（養生・分解洗浄・試運転・簡易清掃を1行で）／**追加になる条件**（型番違い・駐車場代の実費・ひどい汚れ・高所。金額か「別途見積」）／支払い方法（振込の期日と手数料負担）／発行者（インボイス番号）
- **作業報告書の項目**：機種（メーカー・型番・製造年、室内機のシールを撮る）／**作業前の状態**（異音・水漏れ・エラー・リモコン動作。「作業前から〇〇だった」をここに残す）／作業内容（分解範囲・洗剤・防カビの有無）／写真 最低4枚（作業前のファン・熱交換器、作業後の同じ場所、型番シール）／試運転（冷暖房・吹き出し温度・水漏れなし・異音なし・立ち会いの有無）／次回の目安と注意・署名
- **免責同意書**：対象＝製造15年以上・お掃除機能付き・修理歴あり・作業前から異音やエラー・部品供給終了。説明する内容＝プラスチック部品（ルーバー軸・ツメ・カバー）の経年劣化による破損、電装部品の不調の表面化、分解して初めて分かる損傷、一時的な臭い戻り。**自分の責任は残す**（養生不足・明らかな過失は対象外。全部免責にすると署名されず、法的にも意味を持ちにくい）。**代わりの選択肢**（分解範囲を減らす／見送る／メーカー修理を先に）を書く
- 電子化：見積・請求は請求書サービス、作業報告書はスマホで写真添付→PDF、**同意書は紙に署名して写真で控え**
- 使う順番：予約時に見積書（型番と台数を聞く）→作業前に同意書（該当機種だけ）→作業後に報告書。**予約確認文に「室内機の底面のシールの写真を送ってください」の一言**を入れておくと、見積書と同意書が現場に着く前に用意できる
- 「3枚はお客様を疑うためではなく、自分の説明を揃えるための台本」

→ ワンヒッター：見積アプリ（quotation）に「含まれるもの」「追加になる条件」の固定文、作業前状態のチェック欄、型番シール写真の取り込みを足す材料。同意書は和真さんの現場運用と法務確認が要る（`../当てはめ.md` D）。

## 事務作業をAIで楽にする｜返信・日程調整・請求書の下書き
https://aircon-urakata.com/biz/ai-office-work/ （確認 2026-10-12）

- 流れ：材料（確定料金・作業メモ・空き時間、個人情報は伏せる）→AIが下書き→自分が確認してLINE・カレンダー・請求ソフトへ。「下書きができた」と「送信・登録できた」は別
- 返信の指示文に「分からない料金・日程・作業時間は推測せず要確認に」「予約を確定する表現は使わない」
- 日程候補は「空き枠」と「行ける時間」を分け、移動・駐車・準備・休憩を含める。前後の現場との移動を無視して埋めない
- 請求の下書きは「AIに金額を考えさせず、決まった単価と数量を整理させる」。宛名・登録番号・振込先は正式な情報から
- お客様情報：練習では「お客様A」に置き換え、予約確定・顧客への送信・請求確定は人の確認を入れる

→ ワンヒッター：当社はすでにスレッド組織で同じ原則を運用中（名乗り照合・送信前確認）。新しい知見は少ない。

## 出張先でカード決済を受ける｜Square・Airペイ・STORES決済の比較
https://aircon-urakata.com/biz/card-payment-onsite/ （確認 2026-10-12）

- 現場の注意：決済はネット接続が要る（マンション奥・地下は玄関や窓際へ）。レシートはメール（SMS明記はSquareのみ）

→ ワンヒッター：当社の現場決済の現状は未確認（この担当では確認していない）。必要なら crm / cmo に事実確認を出す。

### 予約・会計・集客｜エアコン屋の仕事まわりガイド
https://aircon-urakata.com/work-guide/ （確認 2026-09-20〜10-09）

- 流れ：LINEで機種・台数・**写真**・希望日を受け取る→予定（作業時間に移動と片付けを足す）→日時と料金を確定して返信、カレンダーへ
- **最初に聞く：台数・型番・設置状況の写真・希望日・訪問エリア／最後にまとめる：訪問日時・確定料金・追加料金の条件・支払い方法**
- 確認文の例は「この時点では、まだ予約確定ではありません」と明記する形
- LINE公式の無料範囲のチャット履歴保存は6か月 → 長く要る作業記録は別に残す
- 予定共有：Googleカレンダー（共有範囲を設定、顧客住所入りのカレンダーを公開しない）／TimeTree（Connect App＝API は2023年12月終了）
- 売上メモの項目：作業日／案件名・管理番号／作業内容／請求額／支払い方法／入金日／未入金の有無／備考

→ ワンヒッター：受付時の「写真をもらう」が当社の予約ページ・公式LINEで定型化されているかは要確認（crm）。

### ChatGPT・Claudeでホームページを作る｜画面つきガイド
https://aircon-urakata.com/ai-homepage-guide/ （約4.4万字。制作例の節を中心に読んだ）

- 6ステップ（相談→指示文→見本→画面で確認→公開先→下書きから公開）。指示文に「口コミ・件数・資格・保証・料金は勝手に作らない」「未定は未定のまま」
- 制作例「料金シミュレーター」：台数・お掃除機能・オプション・駐車場→税込の概算＋内訳＋作業時間の目安→LINEと電話のボタン。「概算と言い切り、正式料金は型番と設置状況を見てから」と書く。料金は設定1か所にまとめる
- 制作例「同じ指示文で5月と10月」：ChatGPT の画像生成で雑誌風の広告を作ると、5月は情報が多いが架空の料金・電話・店名が混入、10月は文字は正確だが料金・問い合わせ欄が入らない。**入れたい要素を指示文に書けば両立した**（2026-10-28 の試行）。料金・電話は空欄枠で作らせ、自分で打ち直す

→ ワンヒッター：当社LPには料金シミュレーターが既にある（`docs/LP料金シミュレーター-検証結果-2026-09-08.md`）。「作業時間の目安」を出すかは lp に比較材料として渡せる。広告画像の指示文の作り方は web-inflow の素材。
