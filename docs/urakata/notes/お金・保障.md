## エアコンクリーニング業の賠償保険｜超ビジネス保険で確認する補償・見積もり・事故対応
https://aircon-urakata.com/money/cho-business-hoken-taiken/

- 東京海上日動「超ビジネス保険」を例に、賠償責任保険の見積もり時の確認項目を整理（加入体験記ではなく、筆者の保険料・限度額・事故歴は未掲載）。
- 代理店に伝えるべき事故例：洗浄中の本体・基板の損傷／壁紙・床・家具の損害／作業後の漏水による階下被害／預かった・取り外した部品の損傷／自分の道具の破損・盗難。
- 賠償責任と自分の道具の損害は別の補償。施工対象物そのものと周囲の財物で扱いが違う場合がある。
- 見積もり比較5項目：業種・作業内容・売上高の申告が実態どおりか／必要な事故が対象か／1事故・期間中の支払限度額／免責金額／補償開始日時・事故連絡先・必要書類。
- 事故時は作業を止めて被害拡大を防ぎ、日時・型番・作業内容・損傷箇所・お客様への説明内容を記録し写真を保存、速やかに保険会社・代理店へ相談。

→ ワンヒッター：法人でもそのまま当てはまる。現契約で「作業対象物（洗っているエアコン本体）」「受託物」「作業後の漏水」が対象かを、この5事故例で照合する価値が高い。事故時の記録項目は現場マニュアルに転記できる。

## 個人事業主のエアコン屋に必要な保険は3つ｜賠償・ケガ・生命の順で考える
https://aircon-urakata.com/money/kojin-jigyo-hoken-3/

- 備えを「お客様への賠償」「自分が働けない期間」「家族の生活」に分けて考えると重複・不足を整理しやすい。
- 賠償責任保険は、作業対象物・作業後の漏水・預かった部品などを具体的に挙げて対象／対象外を確認。比較は補償範囲・支払限度額・免責金額・保険期間・事故時の窓口。
- 休業への備えは、生活費と事業固定費を見積もってから、労災の特別加入・所得補償保険・就業不能保険・傷害保険を比較。2024年11月から一定のフリーランスも労災の特別加入の対象に。
- 老後の積立（小規模企業共済：掛金 月1,000円〜70,000円）は事故・休業への備えと分ける。
- 相談前に、保険証券・年間売上と業務内容・生活費と固定費・心配な事故例をまとめておく。

→ ワンヒッター：賠償保険の部分は法人にも当てはまる。労災の特別加入・小規模企業共済・家族の保障は個人事業主向けで、法人の当社には直接当てはまらない（従業員の労災は通常の労災保険の扱い）。

## 個人事業主のお金の備え｜NISA・iDeCo・小規模企業共済と税金
https://aircon-urakata.com/money/taishokukin-tsumitate/

- 順番は「すぐ使うお金（生活費・事業の支払い・税金・急な修理）を残す」→「事故・休業に備える」→「長く使わないお金を積み立てる」。
- 清掃業の備え5つ：賠償責任保険（作業対象物・受託物の扱いに注意）、労災の特別加入、休業中の所得（国保には通常、傷病手当金がない）、仕事の車の自動車保険（使用目的を実態どおりに）、医療・生命保険。
- 制度の違い：NISA（運用益非課税・控除なし）、iDeCo（掛金が所得控除・原則60歳まで引き出せない）、小規模企業共済（掛金 月1,000円〜7万円が所得控除、任意解約は20年未満で元本割れ、契約者貸付あり：一般貸付は年1.5%・2026-10-03時点）。
- 架空の税額試算：利益400万円・月3万円の共済掛金で税負担は年5万4,300円減。利益200万円・月1万円では所得税がもともと0円で、減るのは住民税のみ（年1万2,000円）。売上の大小ではなく利益と控除で決まる。
- 投資リスクの例：MSCI ACWI は2007年7月13日〜2009年3月9日に64.82%下落（円建て・配当込み）。2007年10月末の一括投資は回復まで約6年2か月（J.P.モルガン資料）。使う時期が決まっているお金を株式に頼らない。

→ ワンヒッター：ほぼ個人事業主向けで、法人の当社には当てはまらない。使えるのは「仕事の車の自動車保険の使用目的を実態どおりに」と「閑散期・納税資金・機材修理費を先に確保する」という資金繰りの考え方のみ。

## 楽天証券とSBI証券の選び方｜個人事業主の口座開設と積立の準備
https://aircon-urakata.com/money/nisa-shoken-koza/

- 両社とも NISA の投信積立の候補。選ぶ基準は、普段のカード・銀行との相性、入出金、費用、安全設定（ポイントだけで決めない）。
- 楽天証券：楽天カード積立、楽天銀行とのマネーブリッジ・自動入出金、月100円から。SBI証券：三井住友カード・Olive の積立、銀行引落サービス、100円から（一部ファンドは別）。
- 売却代金がすぐ銀行に着金するとは限らない。NISA は同じ年に新規買付できる金融機関は一つ。
- 口座の安全設定：公式アプリかブックマークから入る、パスキー設定、パスワード使い回し禁止、通知を有効化、不審な通知のリンクは開かない。SBI証券は2026年6月30日からパスキー設定が原則必須。

→ ワンヒッター：個人の資産形成の話で、法人の当社には当てはまらない。特になし（フィッシング対策の考え方は社内の口座管理にも共通）。

## 個人事業主のクレジットカード比較｜個人カード・事業用の大手5社8券種
https://aircon-urakata.com/money/kojinjigyo-creditcard/

- まず「仕事と私用が分かれているか」。今の個人カードを仕事用と決める方法でも始められる（筆者も個人カードで仕事の買い物をしている）。
- 比較8券種（年会費・通常還元）：楽天カード（無料・1.0%）、三井住友カード（NL）（無料・0.5%）、JCB カード S（無料・0.5%）、JCB カード W（無料・1.0%、入会18〜39歳）、JCB Biz ONE 一般（無料・1.0%）、三井住友カード ビジネスオーナーズ（無料・0.5%、条件付きで最大1.5%）、セゾンコバルト・ビジネス・アメックス（無料・0.5%、指定サービス4倍）、アメックス・ビジネス・グリーン（13,200円）。
- 還元率の差は、経費年60万円なら0.5%と1.0%で年3,000円相当の差。特典目的で不要な道具を買わない。
- ETCカードの年会費条件が JCB で2026年11月10日引落分から変わる（前年利用なしなどで550円）。
- 運用3点：仕事の支払い先をカードに集める／明細を会計ソフトへ（領収書は確認・保存）／引落日と入金日のずれを把握。

→ ワンヒッター：法人なら法人カードの比較になるため、個人カードの部分は当てはまらない。スタッフ用の追加カード（Biz ONE のパートナーカード、ビジネスオーナーズのパートナーカード18枚まで無料など）と「現場の買い出しで決済制限に備え別の支払い手段も持つ」点は参考になる。

## 個人事業主の税金ガイド｜2年目の予定納税・消費税・事業税に備える
https://aircon-urakata.com/money/kojinjigyo-tax-guide/

- 売上＝使っていいお金ではない。独立2年目は予定納税・消費税の中間納付・事業税が重なり「払っても払っても届く」と筆者自身も驚いた。
- 所得税の予定納税：予定納税基準額15万円以上で、原則3分の1ずつ7月・11月。消費税の中間納付：前年の国税部分48万円超で年1回、400万円超で年3回、4,800万円超で年11回。
- 個人事業税（埼玉県の例）：請負業など5%、事業主控除290万円。青色申告特別控除は事業税には適用されない。例：所得450万円なら（450−290）×5%＝8万円。
- 経費の区別：所得税・住民税は経費にならない、個人事業税は経費、国保・国民年金は社会保険料控除、共済・iDeCoは所得控除、NISAは控除なし。
- 月1回の確認：売上と未入金、経費の記録、年末の利益見込み、納税用のお金を税目別に分ける、直近3か月の支払い予定。

→ ワンヒッター：個人事業主の税制で、法人の当社（法人税・法人住民税・法人事業税）には当てはまらない。「消費税の中間納付で先に現金が出る」「納税資金を別に見積もる」という資金繰りの考え方は共通。

## インボイスと免税の外注先｜個人事業主の消費税・70％控除と仕事の頼み方
https://aircon-urakata.com/money/invoice-outsourcing/

- インボイス登録すると売上1,000万円以下でも消費税の申告・納税が必要になる場合がある。免税判定は原則2年前の課税売上高。
- 計算方法（一般課税／簡易課税／2割特例・3割特例）で外注先の登録有無の影響が変わる。2割特例は2026年分まで対象になり得て、2027・2028年分には3割特例。
- 免税事業者からの仕入れの経過措置：2023年10月〜2026年9月 80% → **2026年10月〜2028年9月 70%** → 2028年10月〜2030年9月 50% → 2030年10月〜2031年9月 30% → 以後なし。「2026年10月から50%」と書く古い解説は改正前。
- 例（一般課税）：税込11万円の外注で、登録ありなら控除1万円、登録なしなら7,000円。差は3,000円。その差と仕上がり・時間厳守・お客様対応の安心感を比べて考える。
- 外注先の登録番号を公表サイトで確認、作業範囲と税込・税抜を事前に共有、会計ソフトの税区分を取引時期に合わせる。免税を理由に一方的に値下げを迫るのは取引上の問題になり得る（公正取引委員会Q&A）。

→ ワンヒッター：法人にも当てはまる部分が大きい。免税の協力業者・応援の職人に外注しているなら、2026年10月以降は控除70%で会計ソフトの税区分が最新か確認する価値がある。

## 税金のカード払いは得？手数料・ポイントで買った道具の経費を整理
https://aircon-urakata.com/money/tax-payment-card-points/

- 国税のカード納付は1万円までごとに99円（税込）の手数料。10万円なら990円で、還元0.5%なら490円の負担増、1.0%で10円のプラス、1.5%で510円のプラス（1ポイント1円で使い切る仮定）。
- 税額が10万1円なら手数料1,089円。1万円単位で切り上がるので「1%なら必ず得」ではない。地方税は別体系。
- カードで払っても経費になるかは変わらない（所得税・住民税は経費外、個人事業税は経費）。
- ポイントで備品を買った場合、国税庁は「値引きとして処理」か「経費計上＋ポイント分を雑収入」の方法を示している（1万円の消耗品に2,000円分のポイントなら、どちらも差し引き8,000円）。
- カード利用時と口座引落時の両方を経費に入れる二重計上に注意。

→ ワンヒッター：カード納付の手数料計算と、ポイントで買った備品の処理は法人でも考え方として使える。個人の税目の扱い（所得税・住民税・個人事業税）は法人には当てはまらない。

## エアコン屋は税理士にどこまで頼む？記帳・申告・相談の分け方
https://aircon-urakata.com/money/zeirishi-erabikata/

- 会計ソフト（日々の入力を減らす）と税理士（判断と申告の相談）は役割が違う。自分で入力して申告だけ頼む、など分担できる。
- 見積もりは年額と範囲で比べる：顧問料以外の申告費用、入力の担当、仕訳数による料金、今の会計ソフトが使えるか、連絡方法・返答の目安、担当者・契約期間・解約とデータ返却。
- 「節税額や還付を契約前に保証する説明」は根拠を確認する。
- 税理士ドットコムは無料の紹介サービス（依頼費用は別契約）。第三者の利用者22人アンケートでは比較しやすさの評価と、電話連絡が煩わしい・地域で候補が限られるという回答（少人数で一般化不可）。
- 作業中に電話に出られないなら、連絡できる時間・方法を先に伝える。

→ ワンヒッター：法人でも税理士の見積もり比較項目（年額・範囲・データ返却条件）はそのまま使える。現在の顧問契約の見直し時のチェック表として有用。

## このカテゴリから当社に効く上位3つ

1. **賠償責任保険の照合（011・012）**：「洗っているエアコン本体（作業対象物）」「預かった部品（受託物）」「作業後の漏水・階下被害」が現契約の対象か、限度額・免責とあわせて代理店に確認する。事故時の記録項目（日時・型番・作業内容・損傷箇所・お客様への説明・写真）は現場マニュアルに入れる。
2. **免税の外注先の経過措置70%（040）**：2026年10月から控除割合が80%→70%。協力業者への外注がある場合、会計ソフトの税区分と外注先の登録状況を確認する。価格の見直しは根拠を共有して協議（一方的な値下げは避ける）。
3. **税理士との契約の見直し項目（053）**：年額の総額、含まれない業務、データ返却条件、連絡方法を書面で確認する。法人でも同じように使える。
