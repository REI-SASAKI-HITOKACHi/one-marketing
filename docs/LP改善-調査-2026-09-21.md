## 2. 競合の実測（分析軸ごと）

### 2-1. 価格の相場 ― **当社は「安い側」ではありません**

これが今回いちばん重要な発見です。

| 事業者 | 壁掛け・お掃除機能なし（税込） | 出典 |
|---|---:|---|
| くらしのマーケット 江戸川区の上位表示 | **¥8,000 前後**（「秋の大特価！1台5500円」の出品もあり） | https://curama.jp/aircon/tokyo/23/ |
| カジタク ライトプラン | **¥9,700**（通常10,780円から「今だけ1,080円OFF」） | https://www.kajitaku.com/house-cleaning/airconditioner/ |
| おそうじ革命（全国一律・北葛西店も同額） | **¥9,980** | https://www.osoujikakumei.jp/edogawa_kitakasai/ |
| アイ・コーポレーション（東京） | **¥5,390**（1台目）／4,290（2台目）／3,190（3台目） | https://ai-corpo.co.jp/tenpo/tokyo/aircon/ |
| **ワンヒッター** | **¥10,780** | `docs/price-master.md` |
| おそうじ本舗 | ¥14,300（2026年8月1日改定。旧12,100円） | https://www.osoujihonpo.com/campaign/aircon-multiple-units/ |

**当社は上から2番目に高い。**
それなのに当LPには「**安いと、かえって不安になると思います**」（aircon L682–683 の見出し「なぜ、この価格でできるのか」）という章があります。
**江戸川区でこの言葉を読む人は、その直前に 8,000円台を見ています。** この章は、いまの相場に対してかみ合っていません。

> 直すべきは価格ではなく、**この章の役割**です。「安さの言い訳」をやめて、**「8,000円台と何が違うのか」を書く場所**に変えます（§5 の「差額の説明」）。

### 2-2. 複数台割引 ― **家庭の2台目に効く割引が、当社にだけ無い**

| 事業者 | 割引 |
|---|---|
| おそうじ本舗 | **2台以上で1台あたり2,200円引き**（通年。4台目以降も同額） |
| おそうじ革命 | 2台目以降 最大2,000円引き |
| くらしのマーケット | ページ上部に**「2台以上頼むと最大30％お得！」**を常設 |
| アイ・コーポレーション | 1台目5,390／2台目4,290／3台目3,190 の**階段表示** |
| カジタク | 「2台以上でおトク！」 |
| **ワンヒッター** | **5台以上から ¥500/台**（`docs/price-master.md` 複数台割引） |

一般家庭のエアコンは2〜3台です。**5台からの割引は、広告で来た人にはほぼ効きません。**
当LPのシミュレーターは台数を選ばせますが、**2台を選んでも単価は1円も下がらない**（aircon L643–646、掛け算しているだけ）。競合の階段表示を見てきた人には、これは「割引が無い」に見えます。

→ **これは料金の変更なので、LPでは決められません。** 経営企画室（planning）とオーナーの判断が要ります。§7 に依頼事項として出します。**v2 は、割引を作らない前提でも成立する構成にしてあります。**

**当LPの見出しは、実は競合の誰よりも良い。** 症状を名指ししていて、読めば刺さります。

- **地域名が無い**（L433 は「東京・千葉・神奈川 対応」）。競合の地域ページは見出しに区名を入れる（おそうじ革命 江戸川北葛西店）。**「江戸川区 エアコンクリーニング」で押した人が、最初の1画面で自分の区名を見つけられない。**
- **第三者評価が無い**。L446–450 の3つの数字は 98.6%／0円／60分で、**全部が自社申告**。

| 事業者 | 保証の文言 |
|---|---|
| おそうじ革命 | 「**3日以内にご連絡いただければ納得いくまで再作業！**」「万一の故障も損害保険で完全保証！」「**追加料金絶対なし宣言！**」 |
| カジタク | 「**仕上がり満足保証**」「作業完了後**7日以内**であれば無料でやり直し」 |
| アイ・コーポレーション | 「作業中の破損・故障は責任をもって修理弁償します。**作業後1週間以内も同様に対処**」 |
| **ワンヒッター** | 「万一に備え、**損害賠償保険にも加入しています**」（aircon L592, L771）のみ。**やり直しについて一言も無い** |

### 2-6. 断る条件・対象外を先に書く

アイ・コーポレーションは「お客様のお約束」「お客様のお願い」という章を立てて、**駐車が徒歩5分以上なら断る／無垢材・漆喰の部屋は断る／製造10年以上は補償対象外／バケツに水をもらう／洗浄はベランダか玄関外で行う**まで書いています。
カジタクは各プランに「■対象／■対象外」を列挙し、**「床からエアコン中心までの高さが3m以上の場合、お掃除を受付けていません」**まで書いています。
おそうじ本舗は「**製造から9年以上経過しているエアコンは…サービスをお断りさせていただく場合**」。

当LPで対応する記述は、駐車場代の注記（aircon L613, L669）と「落としきれない可能性がある場合は、作業前に必ずお伝えします」（L697）だけです。
**書くと申込が減るように思えますが、逆です。** 当日トラブルと、当日キャンセルが減ります。

### 2-7. CTAとフォーム

| 事業者 | CTAの型 | 回数 | フォーム |
|---|---|---|---|
| おそうじ本舗 campaign | カート（数量±・オプション追加）＋**上部固定の合計金額** | 上部固定＋各プラン | カート→注文 |
| カジタク | プランごとに数量セレクト＋カートに入れる | 3プラン分＋オプション | カート→注文（予約時に**製造年**を入力させる） |
| アイ・コーポレーション | **同一文言のボタンを4回**「エアコン分解洗浄を申し込む（お見積機能付き）」 | 4回 | 見積もりカート→確認メール→電話 |
| おそうじ革命 | 「お見積り」「見積もり・注文」 | 10箇所以上 | 別ページ |
| **ワンヒッター aircon** | WEB予約（4回）／LINE（2回）／電話（3回）＋追従バー3分割 | — | **5項目**（名前・電話・郵便番号・メニュー・時期） |

**当LPのフォームは5項目で、競合より軽い。ここは勝っています。**
壊れているのは**接続**です。シミュレーターで「お掃除機能付き×2台＋室外機セット＝繁忙期加算込み」まで確定させたのに、`この内容で予約に進む`（L672）を押すと**選んだ内容がどこにも残らない**。フォームのメニュー欄（L833–838）は3択の `select` に戻ります。

もう一点。**追従バーが3つ並び（電話／LINE／WEB予約、L874–876）**になっています。`docs/lp-design-research.md` は「実データは最大2系統」と書いていて、**自分で決めた基準を自分で破っています**。しかも LINE タップは**コンバージョン計測に入っていない**（`docs/広告-キーワードと着地先の整合.md` の🔴2）。**計測できない導線を、追従バーの真ん中に置いている**状態です。

### 2-8. キャンペーンと期限

| 事業者 | 文言 |
|---|---|
| おそうじ本舗 | 「**キャンペーン期間｜2025/7/1（tue）～8/31（sun）**」／「2026年8月1日から価格改定いたします。**7月31日までにお見積りいただきサービス実施日が8月31日まで**であれば現状価格で提供いたします」 |
| カジタク | 「\ 今だけ1,080円OFF！ /」「\ 割引キャンペーン実施中 /」 |
| ユアマイスターの出品見出し | 「【9月秋割】」「【9月限定】早割受付スタート❣️」「物価高騰対策🔥特別価格お早めに‼️」 |
| **ワンヒッター** | **無し。** 期限のある表示はゼロ |

当社には**期限を出せる材料が既にあります**。

- **繁忙期加算 3,300円**（5〜7月・12月）。いまは9月＝加算なし。**12月から加算が始まる**。
- **早期予約割引 3〜4月・8〜10月は10%**（`docs/price-master.md`）。**9月は10%の対象**。

つまり「**いま頼むと、12月に頼むより1台あたり3,300円安い**」は**事実として言えます**。
これは値引きではなく**料金表の説明**なので、景表法上も安全です。**競合の「今だけOFF」より強い。**

## 7. 判断が要るもの（cmo へ）

### 7-1. 🔴 広告グループと着地先の分離
`B_浴室` と `B_レンジフード` が同じ水まわりLPに着地していて、**1箇所を探している人に2箇所分の金額を見せている**。
v2 の FV 並べ替えで緩和はできますが、**根本的には着地先を分けるべき**です。`?ag=` を拾えるようにすれば**FVだけを出し分ける**ことも可能（`aircon-b` と同じ A/B の仕組みが既にある）。
→ **判断：v2 でFV並べ替えだけにするか、`ag` によるFV出し分けまでやるか。** 後者なら +2h。

### 7-2. 🟡 オーナー確認が要る2件（お金と運用に関わる）
1. **やり直し保証**：「作業日から7日以内にご連絡いただければ無償でやり直します」と書いてよいか。革命・カジタク・アイコーポの3社が明記しており、**無いのは当社だけ**。
2. **製造年数の上限**：本舗は9年、アイコーポは10年で「お断りする場合がある／補償対象外」と明記。**当社の運用はどうなっているか。**

### 7-3. 🟡 人物写真がゼロ
「自社の職人が伺います」という章に、職人が1人も写っていない。**今回見た競合は、いずれも人を出している**。
→ **判断：撮影を手配するか、v2 は写真なしで出して次回に回すか。**

### 7-4. 🟡 複数台割引（planning とオーナー）
家庭の2〜3台に効く割引が当社だけ無い（本舗 2,200円/台、革命 最大2,000円、くらマ「最大30%」）。
LPでは決められません。**v2 は割引が無い前提で成立する構成にしてありますが、広告の費用対効果には効きます。**

### 7-5. 🟢 LINEをコンバージョンに入れる
FVからLINEを外す判断は、**LINEタップが計測されていないこと**が理由の半分です。計測担当が足せば、FVに戻す選択肢も出ます。
