# SMS一斉配信サービス 調査レポート（国内向け・API送信前提）

- 作成日：2026-09-05
- 対象：ワンヒッター株式会社（法人・東京／千葉／神奈川）
- 用途：既存顧客への再販SMS、施工後アンケート案内SMS
- 前提送信量：**初年度 年間およそ1,000〜1,500通**（月平均およそ100通）。年末商戦に**一度に650〜800通の一斉送信**が1回発生
- 必須条件：① REST APIで送信できること ② 1通10円以下 ③ docomo / au / SoftBank / 楽天モバイルに届くこと
- 為替前提：**1 USD = 156.25 円**（2026-09-04, Frankfurter APIのECB参照レート）。USD建て事業者の円換算はこのレートによる

> 本レポートの数字は、原則として**各社の公式サイトの料金ページ・FAQ・公式データファイル**から取得したものだけを記載しています。
> 公式に記載がなかった項目は「**公式記載なし・要問合せ**」と明記し、第7章に一覧化しています。推測を含む記述には「たぶん」と明示しています。

## 1. 結論：**KDDI Message Cast** に決定（KDDI／Supership）

> **この章はCMOが差し替えています。** 調査担当は NTT CPaaS を推奨していましたが、
> 決定に効く事実を公式サイトで再確認した結果、**KDDI Message Cast に覆しました。**
> 理由は下の「なぜ推奨を覆したか」に書いています。調査担当の元の推奨内容は第2章に残しました。

### 決定理由

1. **年末商戦の一斉送信（650〜800通）が、まるごと無料トライアルに収まる。**
   トライアルは **2か月・最大3,000通まで無料**（初期費用・月額0円、アカウント発行日から翌月末まで）。
   今年度の想定送信量（年1,000〜1,500通）の大半がここに入ります。**実質、初年度はほぼ無料で回せます。**
2. **到達課金（届いた分だけ課金）。** 公式のAPI連携ページに
   「初期費用・月額費用が無料。またユーザーにメッセージが届いた分のみの課金（従量課金制）」と明記。
   **今回の名簿は2023〜2026年に蓄積したもので、解約・番号変更で死んでいる番号が確実に混ざっています。**
   送信課金の事業者だと、その分も払うことになります。
3. **1通9.35円（税込）〜**で、条件の10円以下を満たす。初期費用0円・月額費用0円。
   **月額固定費がゼロなので、送らない月に下駄を履かない。**
4. **キャリア直収。** KDDI自身のサービスなので、到達率で不利になる要素がない。
   公式FAQで国内全キャリアへの配信可を確認済み。
5. HTTPS APIで送信・配信結果取得ができ、要件（API送信）を満たす。

### なぜ調査担当の推奨（NTT CPaaS）を覆したか

| 論点 | NTT CPaaS | KDDI Message Cast |
|---|---|---|
| 単価（税込） | 10円（確定値） | **9.35円〜** |
| 課金方式 | 送信課金 | **到達課金（届いた分のみ）** |
| 無料トライアル | 60日・**100通**まで | **2か月・3,000通**まで |
| 送信元番号 | 持ち込みかレンタルが必要。**レンタルだと月220〜550円** | 記載なし（追加費用の記載もなし） |
| 利用開始まで | 即日 | 最短6営業日（API連携は6〜10営業日） |

調査担当が NTT を推した最大の理由は「無料トライアルで即日始められる」ことでしたが、
**KDDIにも無料トライアルがあり、枠は100通対3,000通で30倍です。**
しかも年末商戦の一斉送信がまるごと収まる規模なので、この論点はむしろ KDDI に有利でした。

**「即日 vs 6営業日」の差は、今回は問題になりません。**
今日は2026-09-05で、冬季見込み客へのSMSは10月下旬〜11月に打ちます。6〜10営業日なら9月中に開通します。

### 価格差は判断材料になりません

年1,500通なら**年間の支払いは1万5千円前後**で、候補各社の差は年2,000円未満です。
**この規模では単価の優劣は誤差なので、決め手は「到達課金かどうか」「トライアル枠」「固定費ゼロ」でした。**

### 採用にあたっての注意（正直に）

- **9.35円は「〜」表記で、料金ページに「各種条件によって、単価は変動」とあります。**
  月1,000通規模での実単価は非公開です。**申込時に「月1,000通程度の利用で1通いくらか」を必ず確認してください。**
  → **もし10円（税込）を超える提示なら、NTT CPaaS（10円・確定値）に切り替えます。** これが撤退ラインです。
- **送信者名に会社名（英字）を出すのは、日本国内SMSでは事実上どこも不可**です。KDDIも同様。
  差出人は電話番号表示になります。これは事業者選定では覆せないので、
  **本文の1行目に「ワンヒッター（おそうじ）です」と名乗る**ことで代替します。
- 本舗顧客への送信は送信主体がおそうじ本舗江戸川中央店になるため、**文面を分ける必要があります**（既知の論点）。

## 2. 次点：**NTT CPaaS「SMS API」**（NTTドコモビジネスX／旧NTTコム オンライン）

KDDIの単価提示が10円を超えた場合、または法人審査に通らなかった場合の切り替え先。

- **1通10円（税込）と確定値で公開**されており、「〜」表記でないぶん見積りが読める。
- 接続方式は公式FAQで「REST APIにて接続可能。HTTP、SMPPの2方式」と明記。
- 送達結果をWebhookでリアルタイム取得でき、SMS本文のURLを `shortenUrl: true` で短縮＋クリック計測できる。
  **クリック計測が標準で付くのはNTTの明確な利点**なので、アンケート回収率を細かく見たくなったら再検討の価値あり。
- 60日間の無料トライアルがクレジットカード不要・即日（100通まで）。
- 弱点：単価が条件の上限ちょうどで余裕がない。送信元電話番号の持ち込みかレンタルが必要で、
  レンタルすると月220〜550円（税込）が実質の固定費になる可能性が高い。
  「国内SMSの利用には別途審査が必要」との注記があり、審査基準・期間ともに非公開。

### 補足：実際の利用パターン（年1,000〜1,500通）での年間総額

## 5. 申込に必要なもの・入力項目

### 推奨：NTT CPaaS「SMS API」

**ステップ1：無料トライアル（クレジットカード不要・即日）**
1. https://www.nttcpaas.com/ の「60日間無料トライアル」からユーザーアカウント登録
2. 登録するとメールアドレス認証用のメールが届くので、リンクをクリックしてパスワードを設定
3. マイページでアクセスキーが発行される → そのキーでAPIを実行できる
   - トライアルは**リクエスト日から60日間**
   - **送信数・通話数に制限あり／テスト送信できる相手先も限定される**（＝本番の800通一斉送信はトライアルでは試せない）
   - **双方向SMSはトライアルでは使えない**

**ステップ2：有料プランへのアップグレード**
- マイページの「ご利用申し込み」ボタンから申込
- **必要書類：登記簿（登記事項証明書）**
- **必要情報：国税庁から払い出される法人番号**（ワンヒッター株式会社の13桁の法人番号）
- 支払方法：**請求書払い または クレジットカード払い**を選択
- 請求書は毎月10営業日以内に担当者のメールアドレス宛に送付される
- **国内SMSの利用には別途審査がある**（公式サイトの料金ページ注記）。営業への問い合わせが必要
- 送信元電話番号を決める必要がある。選択肢は次の3つ：
  1. **自社の固定電話番号を持ち込む**（0120や03など。**携帯電話番号は持ち込み不可**）→ 月額0円
  2. **0032-06 / 0032-07 で始まる10桁番号をレンタル** → 月額550円（税込）／SMS送信専用
  3. **050で始まる11桁番号をレンタル** → 月額220円（税込）／SMS＋音声通話
  - ※レンタル番号は自分で選べない（NTT側の払い出し）
  - ※**SoftBank宛は何を選んでも「0032-06-9000」が表示される**
- リードタイム：**最短7営業日**（電話番号の設定が7〜25営業日、サービス設定が概ね7営業日）

**問い合わせ時に聞かれる項目（空電プッシュ側の案内より、CPaaSも同様と思われる）**：利用用途／1回あたり・月間の想定配信通数／配信タイミング（即時・予約）／API連携の有無

### 次点：KDDI Message Cast

1. https://kddimessagecast.jp/ の「お問い合わせ・無料トライアル」フォームから連絡（営業時間：平日10〜19時）
2. 導入検討 → **申込書の提出** → アカウント発行手続き → KDDI側の動作試験 → アカウント通知書の受領 → 利用開始・課金開始
3. API連携の場合、**申込から6〜10営業日**
4. 新規は**2か月間または3,000通まで無料トライアル**（別途申込フォームが送られてくる）
5. 注意：**月途中に利用開始・解約しても、その暦月の月額利用料は全額請求**（今回は月額0円なので実害はないはず）

### 参考：SMSLINK / CPaaS NOW（ネクスウェイ）

1. https://smslink.nexway.co.jp/price_form から見積依頼（30秒）
2. 営業と要件ヒアリング → **申込書＋ヒアリングシートを提出**
3. 提出から**5営業日以内**に開発環境への接続用トークンキーを受領（**開発中は課金されない**）
4. 支払いは**銀行振込 または 口座引き落とし**
5. API仕様書は**問い合わせて開示を受ける方式**。事前にWebで読めない点に注意

## 6. 除外した事業者と、その理由

| 事業者 | 除外理由 |
|---|---|
| **Twilio** | **条件②（1通10円以下）を満たさない。** 日本向けアウトバウンドSMSは $0.0890/通 ＝ **約13.9円**（1USD=156.25円）。加えて電話番号リースが $1.15/月〜。さらに、**既定の国際ゲートウェイ経由ではau宛の送信元番号に「010」が前置される**うえ、日本の英数字Sender IDを使うには国内ゲートウェイ（営業経由の申込）と**約5週間の事前登録**が必要。到達後の見え方でも国内直収勢に劣る |
| **Amazon SNS / AWS End User Messaging** | **条件②を満たさない。** AWS公式の価格データファイルで日本は **$0.07451/通（全キャリア共通）＝ 約11.64円**（税別）。**AWSを既に使っていても割引はなく、円安が進むとさらに上がる。** 短縮URL・クリック計測が標準でなく自前実装が必要。日本はロングコード非対応（ショートコードは初期$1,750＋月$1,150で論外）。ただし**AWS公式表では日本のSender ID対応は「Yes」**なので、価格条件さえ緩めば候補にはなりうる |
| **空電プッシュ**（NTTドコモビジネスX） | サービス自体は優秀だが、**API連携は公式に「NTT CPaaSをご利用ください」と案内されており、実体は推奨した NTT CPaaS SMS API と同じ**。空電プッシュ本体はGUI（管理画面）中心のサービスで、今回の「API送信のみ」という要件には二重契約になる。加えて**料金が完全に非公開（全項目「お問い合わせください」）**で比較できない |
| **メディアSMS（オーロラSMS／メディア4u）** | **単価・月額基本料の両方が公式サイト上で「お問合せください」**となっており、条件②を満たすかどうかを裏取りできなかった。無料デモは最大2か月と長く、APIも一斉送信用・認証用の2種類が追加料金なしと記載されているので、機能面では候補になりうる。**価格が公開されていないことを理由に、今回は推奨から外した**（除外ではなく判断保留） |
| **アクリート（SMS Connect）** | 初期費用0円は公式に記載があるが、**月額費用・SMS送信料が「お問い合わせください」**で単価不明。同上の理由で判断保留 |
| **Cuenote SMS（ユミルリンク）** | 初期0円・1通6円〜と公開されているが、**「別途月間のSMS最低送信数が定められています」**と明記されており、その最低送信数が非公開。年1,000〜1,500通という今回の量では**この最低送信数に届かない可能性が高い**（たぶん）。単価は魅力的なので、他が全滅した場合の問い合わせ先としては有効 |
| **KARTE Message（プレイド）** | SMSはマルチチャネルMAプラットフォームの一機能で、**SMS単体の料金が非公開**。今回の用途（API経由でSMSを送るだけ）に対して製品規模が過大 |
| **CAT-SMS** | **調査できず。** 当環境のプロキシから cat-sms.jp への接続が 502 で遮断され、公式サイトを開けなかった（第7章参照） |
| **SMSCast** | **調査できず。** 同上（smscast.jp への接続が 502 で遮断） |

## 7. 裏が取れなかった項目の一覧（正直に）

### 接続自体ができなかったもの
1. **CAT-SMS**（cat-sms.jp）── 当環境のプロキシが 502 を返し、公式サイトに到達できなかった。**一切調べられていない。**
2. **SMSCast**（smscast.jp）── 同上。**一切調べられていない。**

### 公式サイトに記載がなく、確認できなかった項目
3. **NTT CPaaS の最低利用料金** ── 料金ページ・FAQのどちらにも記載がない。「無い」とは書かれていないので、**本当に無いのかは要確認**。
4. **NTT CPaaS で送信元電話番号のレンタルが必須かどうか** ── 製品ページには「お客様持ち込み電話番号」か「レンタル電話番号」の2択として書かれているが、「どちらも無しでSMSを送れるか」は書かれていない。**たぶん必須**で、その場合 月220〜550円（税込）が実質の月額固定費になる。試算では両方のケースを併記した。
5. **NTT CPaaS の「国内SMS利用に必要な別途審査」の中身と所要日数** ── 料金ページに注記があるだけで、審査基準も期間も非公開。**ハウスクリーニング業のマーケティングSMSが通るかどうかは保証できない。**
6. **NTT CPaaS の送信レート上限** ── 「受信負荷に応じた速度制限設定」ができるとあるが、具体的な上限TPSの記載がない。800通の一斉送信で追加費用や事前申請が要るかは**未確認**（たぶん不要）。
7. **KDDI Message Cast の月1,000通時の実単価** ── 「9.35円（税込）〜／各種条件によって単価は変動」としか書かれておらず、**下限価格が今回の量で適用されるかは不明**。
8. **KDDI Message Cast の最低利用料・最低契約期間** ── 公式サイトに記載なし。
9. **KDDI Message Cast の契約主体（個人事業主可否）** ── 公式サイトに記載なし。
10. **KDDI Message Cast の長文の課金通数ルール** ── 「文字数に応じて課金通数が異なります」とあるだけで、何文字ごとに1通かの記載がない。
11. **KDDI Message Cast の送信元番号指定オプションの料金** ── オプションページに料金の記載がない。
12. **KDDI Message Cast の Webhook（プッシュ型の結果通知）の有無** ── 「配信確認API」（＝ポーリング型）の記載はあるが、Webhookの記載は見つからなかった。
13. **SMSLINK / CPaaS NOW の単価が税込か税別か** ── 料金ページにも FAQ にも税区分の記載が一切ない。**「6円〜」が税別なら実質6.6円（税込）**になる。試算では税区分不明のまま記載した。
14. **SMSLINK / CPaaS NOW の月1,000通時の実単価** ── 「月間の送信通数によって異なります。詳しくはお問い合わせください」で非公開。
15. **SMSLINK / CPaaS NOW の Webhook の有無** ── 公式サイト上で確認できなかった（第三者記事にはWebhook・ポーリング・CSVの3方式とあるが、**公式の裏が取れていないので採用しない**）。
16. **SMSLINK / CPaaS NOW の契約主体（個人事業主可否）** ── 公式サイトに記載なし。
17. **空電プッシュ・メディアSMS・アクリートの料金全般** ── 全項目が「お問い合わせください」で非公開。
18. **Cuenote SMS の「月間の最低SMS送信数」の具体的な数値** ── 非公開。
19. **Amazon SNS / AWS EUM の日本語SMSの分割文字数** ── AWSの公式ページ上に70文字での分割を明示した記述を見つけられなかった。
20. **Amazon SNS / AWS EUM の Sender ID が日本の国内キャリアで実際にどう表示されるか** ── 対応国表では「Yes」だが、docomo/au/SoftBank/楽天の受信端末で会社名が出るかは**未検証**。日本のキャリアは英数字送信者名を原則認めていないため、**表示されない可能性が高い（たぶん）**。
21. **Twilio の日本語SMS分割文字数** ── ガイドラインには「160 characters before concatenation」とあるが、日本語（UCS-2）での70文字分割は**そのページには明記されていない**。
22. **各社の年末スパイク（一度に800通）時の制限** ── NTT CPaaS以外は、送信レート上限・事前申請の要否について公式記載を見つけられなかった。
