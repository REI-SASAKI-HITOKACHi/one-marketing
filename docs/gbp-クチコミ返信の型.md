# GBP クチコミ返信の型

作成日: 2026-09-12 ／ 担当: web-inflow（下書き）・cmo（査読）・ブラウザ担当（投稿）
根拠: オーナー指示 2026-09-12「MEOは口コミへの返信も漏れなく行ってね」（依頼ID 20260912-09-web-inflow）

Googleビジネスプロフィール（GBP）のクチコミに返信するときの決まり。
返信文はお客様本人だけでなく、これから頼むかどうか迷っている人が読む。
**「読んだ人が、この会社は一人ひとりをちゃんと見ている、と思う」** ことが目的。

---

## 1. 流れと期限

| 段階 | 誰が | いつまで |
|---|---|---|
| 新着クチコミの検知 | ブラウザ担当（API承認後は自動取得） | 届いた日 |
| 下書き | web-inflow | 届いた翌日まで |
| 査読 | cmo | 下書きを受けた当日中 |
| 投稿 | ブラウザ担当が管理画面から（API承認後は自動投稿） | **クチコミ投稿から3日以内** |

- 下書きは `docs/gbp-クチコミ返信-下書き.md` に追記して、掲示板で cmo に査読依頼を出す
- 未返信は月曜の週次報告で「新着◯件・返信済み◯件・未返信◯件」として数える。未返信0件が基準
- **ネガティブなクチコミ（★3以下、または不満・苦情の文言があるもの）は下書きを作らない。** 先に cmo へ上げる（後述の第6章）

---

## 2. 文の型（お礼 → 拾った事実 → 次回への一言）

1件 **80〜150字**（宛名・署名を除いた本文で数える。宛名・署名込みでも150字程度に収める）。
3つの部品を、この順に並べる。

| 部品 | 中身 | 目安 |
|---|---|---|
| ① お礼 | 何に対するお礼かを具体的に。「ご利用」だけで終えない | 1文 |
| ② 拾った事実 | そのクチコミに書かれた**メニューか出来事を1つ**取り上げ、当社側から一言添える（理由・背景・こちらが心がけていること） | 1〜2文 |
| ③ 次回への一言 | 締め。特典や割引は書かない。「お待ちしています」の気持ちだけ | 1文 |

### 宛名と署名

- 宛名は **Googleの表示名をそのまま「◯◯様」**。ローマ字も日本語もそのまま（例:「kui様」「ゆきちゃん様」「Mina Mah様」）。読みを推測して漢字にしない。イニシャルにもしない
- 署名は **「ワンヒッター株式会社」** で固定。代表名・担当者名は書かない
- 改行は「宛名／本文／署名」の3ブロック。本文の中は改行しない

### 3つの見本（構造の例。そのまま使い回さない）

**見本A：リピートのお客様**
> ◯◯様
> 今年も[メニュー]をお任せいただき、ありがとうございました。[クチコミに書かれた出来事]について、[こちらが心がけていること]。また[時期]にお待ちしています。
> ワンヒッター株式会社

**見本B：初めてのお客様**
> ◯◯様
> [メニュー]のご依頼、ありがとうございました。[お客様が驚いた・気に入った点]は、[当社側の理由・背景]。何かあれば、いつでもお声がけください。
> ワンヒッター株式会社

**見本C：作業のやり方を褒められたとき**
> ◯◯様
> [褒められた行動]に目を留めていただき、うれしいです。[なぜそうしているか]。[メニュー]は[季節・頻度の目安]にご覧になると違いが分かります。次回もどうぞよろしくお願いいたします。
> ワンヒッター株式会社

## 3. 出だしと締めの言い回し（同じ語で始めない）

**連続する返信で、同じ出だし・同じ締めを使わない。** 一覧を上から順に使うのではなく、クチコミの中身に合うものを選ぶ。
「この度は」「ありがとうございます」から始まる返信が並ぶと、機械的に見える。

### 出だし（① お礼）の例

- 今年も[メニュー]をお任せいただき、ありがとうございました。
- [◯回目]のご利用、うれしく拝見しました。
- [出来事]まで書いていただき、ありがとうございます。
- [メニュー]、ご満足いただけてよかったです。
- [部位]まで一緒にお任せいただき、ありがとうございました。
- 暑い中、お時間をいただきありがとうございました。
- 細かいところまで見ていただいて、ありがとうございます。

### 締め（③ 次回への一言）の例

- また来年、夏が来る前にお待ちしています。
- 次回もどうぞよろしくお願いいたします。
- 来年も暑くなる前にお伺いします。
- 次にお会いするときも、同じ気持ちで伺います。
- またお声がけください。お待ちしております。
- 気になることがあれば、いつでもご連絡ください。
- 次は[別のメニュー]もお役に立てるかもしれません。（※ 売り込みの色が出ないよう、1文だけ）

### ② で「当社から一言添える」ときの切り口

- なぜその作業をしているか（「作業前に状態をお見せするのは、何をどこまで洗うかを共有したいからです」）
- 仕上がりを左右する箇所（「細かいところまで見るのは、そこが仕上がりを左右するからです」）
- 季節・頻度の目安（「ひと夏フル稼働したエアコンは、内部に汚れがたまりやすいものです」）
- 当社の手順が現場ごとに変わらないこと（「仕上がりの確認は、どの現場でも同じ手順でしています」）

## 4. 禁止語・禁止表現

### 書かない言葉

| 区分 | 言葉 | 理由 |
|---|---|---|
| 効能・健康 | 除菌・殺菌・抗菌・病気・危険・守る・健康・アレルギー・カビを吸う | 薬機法・景表法。健康効果の断定になる。SNS・ブログと同じ線 |
| 断定・最上級 | 完全・完璧・必ず・絶対・No.1・最高・最安・一番・業界随一・新品同様 | 根拠のない断定。「新品同様」はお客様の言葉としては引用可だが、当社の文では書かない |
| 他社 | 大手・他社・◯◯社・「よそでは」 | 他社の悪口に見える。お客様が比較を書いていても、こちらは触れない |
| 特典 | 割引・早割・クーポン・次回◯円引き・特典・サービスします | 次回の特典を約束すると、クチコミの対価と受け取られる（ステマ規制）。「早割」も返信では書かない |
| 個人情報 | 住所・最寄駅・建物名・施工日・時間帯・家族構成・部屋数 | 特定につながる。クチコミに書かれていても復唱しない |
| 商品名 | 他社商品・メーカー名（例: ハイター、◯◯社製エアコン） | 登録商標。お客様が書いていても、当社の文では一般名（塩素系漂白剤・洗濯槽クリーナー等）に言い換えるか触れない |
| AIっぽい言い回し | ぜひ・安心・しっかり・大切な・いかがでしょうか・貴重なご意見・励みになります・スタッフ一同 | 定型に見える。どの返信にも入っている言葉は、書いていないのと同じ |

### 書き方で気をつけること

- **依頼範囲の外まで見たことを「無料でやります」と読める書き方にしない。** 「気づいたことはお伝えしています」までにとどめる
- **お客様が健康や身体に触れていても、そこは拾わない。** 別の事実（メニュー・作業・時期）を拾う
- **お客様の誤字・表記ゆれを、返信で指摘したり正したりしない**
- **クチコミの文をそのまま繰り返さない。** 「ピカピカとのこと、うれしいです」のようなオウム返しは1か所まで
- 絵文字・「！」の連打は使わない。「！」は多くて1つ
- 敬語は「です・ます」。「〜させていただきます」の重ね使いはしない

## 5. 投稿前チェックリスト

下書きを cmo に出す前に、web-inflow が自分で確認する。cmo は同じ表で査読する。

- [ ] 本文が 80〜150字（宛名・署名を除く）。Pythonで数えた
- [ ] 宛名がGoogleの表示名そのまま＋「様」
- [ ] そのクチコミに書かれたメニューか出来事を、1つ拾っている
- [ ] 出だしが、直前の返信と同じ語で始まっていない
- [ ] 締めが、直前の返信と同じ言い回しでない
- [ ] 第4章の禁止語が1つも入っていない（Pythonのチェックで確認）
- [ ] 他社・商品名・特典・個人情報に触れていない
- [ ] 健康・効能の断定がない
- [ ] 署名が「ワンヒッター株式会社」だけ
- [ ] ★3以下、または不満の文言があるものは下書きしていない（cmo に上げた）

## 6. ネガティブなクチコミが来たとき

**返信を書かない。** まず事実を確かめる。

1. 該当クチコミの本文・星・投稿日・表示名を、掲示板で **cmo に上げる**（件名「【要確認】ネガティブなクチコミ」）
2. cmo が現場（渡辺さん）に事実確認をする。施工の記録・写真・当日のやり取りを照合する
3. 返信するかどうか、何を書くかは cmo が決める。オーナーに上げるかどうかも cmo の判断
4. 返信する場合も、この型は使わない。cmo が個別に文を作る

返信しないまま放置するのは避けたいが、**確認より先に謝ったり反論したりする方が損が大きい**。
3日の期限はこの場合は適用しない。cmo の判断が出るまで待つ。
