# 読本・点検が暗いままの原因（2026-09-22 調査）

依頼 `20260922-01-lp` ／ 調査 LP・サイト担当

## 結論：**CSSを直す必要はありません。作り直すだけで直ります。**

**両ページとも、古いCSSで生成されたまま更新されていないだけでした。**

## 根拠

### 1. 配色のCSSは、この2ページが持っているものではない

`tools/media_common.py` の `base_css()` が、**`lp/survey/index.html` の `<style>` を
そのまま読み込んで**使っています。

```python
def base_css() -> str:
    html = SURVEY.read_text(encoding="utf-8")
    m = re.search(r"<style>(.*?)</style>", html, re.S)
    ...
```

### 2. いまの `lp/survey/index.html` に、ダークの記述はありません

```
grep -n 'prefers-color-scheme|data-theme|color-scheme' lp/survey/index.html
  26:  color-scheme:light;
```

**`prefers-color-scheme` も `[data-theme="dark"]` も、もうありません。**

`tools/media_common.py` の `COMMON_CSS` にも、web-inflow の他のツールにも
**`prefers-color-scheme` は1件もありません**（`tools/*.py` を全部grepして0件）。

### 3. 生成された時期が、掃除より前だった

| | 日時 |
|---|---|
| 点検（`lp/media/tenken/index.html`）を生成 | **2026-09-11 09:59** |
| 読本（`lp/media/dokuhon/index.html`）を生成 | **2026-09-13 13:24** |
| **アンケートからダーク配色を削除** | **2026-09-15 08:53** |

**どちらも、掃除より前に作られています。**
生成物の中にだけ、当時のダークのCSSが残っています。

## やること（web-inflow 担当へ）

```bash
python3 tools/build-dokuhon.py
python3 tools/build-tenken.py
python3 tools/build-tenken-slots.py   # 空き枠を使っている場合
```

**これだけで、生成物から `@media (prefers-color-scheme: dark)` と
`:root[data-theme="dark"]` が消えます。** CSSを手で書き換える必要はありません。

`unei.html` `genba.html` `moushikomi.html` `shomen.html` など、
**同じ生成元から出る他のページもまとめて直ります**（`unei.html` にも同じ記述があるのを確認済み）。

### 確認のしかた

```bash
node tools/check-darkmode.js
#   dokuhon / tenken が「白地 ✅」になれば完了
```

※ このコマンドは**本番を測ります。**配信するまでは暗いままの表示で正しいです。

## なぜ私が直さないか

**`lp/media/` は web-inflow 担当の持ち物**です（`docs/org/roles/web-inflow.md`）。
私（lp）の持ち物は `lp/aircon/` `lp/mizumawari/` `lp/aircon-b/` `cms/` `docs/price-master.md` です。

**加えて、生成物は web-inflow のブランチにあります。**
私のブランチで同じファイルを作ると**枝分かれして衝突します。**
向こうで作り直して、向こうのブランチで配信するのがいちばん速くて安全です。

**CSSの書き換えではなく再生成なので、作業は数分です。**
