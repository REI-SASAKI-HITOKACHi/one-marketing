# 5. 成果の承認について（先方に伝えておくこと）

**成果地点が「決済完了」のため、承認までに時間がかかります。**

```
クリック → 申込 → 現地で見積確定 → 施工 → 入金確認 ← ここで成果が確定
```

**申込から入金確認まで、通常2〜4週間かかります。**
パートナーから見ると報酬の確定が遅くなるため、あらかじめ案件情報に明記しておきたいと考えています。

**承認しないもの**

- 入金が確認できなかったもの（キャンセル・不成立を含む）
- 対応エリア外からの申込
- 同一のお客様からの重複した申込
- 既存のお客様からの申込（当社に施工履歴のある方）
- 明らかないたずら・テスト送信

# 6. 電話での申込について（先方への相談事項）

**当社のLPは電話番号を大きく出しており、電話でのお申込みが一定数あります。**
アフィリエイトの計測はWebフォームからの申込のみを拾うため、
**パートナーが送客しても、お客様が電話をかけた時点で成果になりません。**

パートナーから見れば「送客したのに成果が出ない案件」になり、掲載が止まる原因になります。

**ご相談：**
電話経由の申込について、**手動での成果登録**は可能でしょうか。
可能であれば、当社側でユニークコール（電話番号の出し分け）を導入し、
アフィリエイト経由の着信を特定したうえで登録したいと考えています。
