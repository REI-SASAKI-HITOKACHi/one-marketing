### 投稿のやり方（次回のため）

**Meta Business Suite のコンポーザーは使えません。** `リール動画を作成` も `投稿を作成` も、
ファイル選択の `input[type=file]` が **DOMに存在せず**、クリックするとOSのファイル選択が開くだけで、
こちらからファイルを渡せません。

**`www.facebook.com` のページ側の投稿画面を使ってください。** こちらは `input[type=file]` が
DOMに実在します（5個。うち**2番目**が画像＋動画を受け付ける）。

```js
// 2番目の file input に id を付けてから file_upload で渡す
const fi=[...document.querySelectorAll('input[type=file]')]; fi[1].id='oh-fb-video';
```

- 本文は**キー入力で入れること**。`computer type` と `key Return` を交互に使う
  （DOM代入では Lexical エディタに入りません）
- 画面は 投稿の作成 → 次へ → リール動画の編集 → 次へ → リール動画の設定 → 投稿
