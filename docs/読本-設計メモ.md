**設計上の帰結**
- 冒頭の1画面で決まる。**数字1つ＋1文**。スクロールしなくても「え？」が成立すること
- 段落は3行以内。1画面に1つの話。途中で呼ばれても戻ってこられるよう、章は短く独立させる
- 「業者です」は途中で言う。言うときは一言で、言い訳しない
- ペット版は赤ちゃん版の7割の長さ
- 押し売りに見える要素（ボタン・料金）は最後の1画面だけ。それまでボタンを出さない
- 名前を呼ばれて閉じた人を逃さない：冒頭にLINEで「続きを送る」…は今回は入れない（追加の同意が要る）。代わりにURLをカードに残す（カードを持ち帰る）

## 構成（新）

1. **数字で始める**（第三者データ。出典は画面下に小さく）
2. **もう1つの数字**で「家の中」に話を移す（東京都のカビ調査 33.7%／浴室79.7%）
3. **身分を明かす**（1文。「私は江戸川区でエアコンや浴室を分解して洗っている職人です」）
4. **自社の事例**（写真3枚と汚水。説明は最小。写真に語らせる）
5. **自分でできること／できないこと**（メーカーの原文）
6. **迎える前に**（時期の話。押さない）
7. **頼むなら**（商品。1画面）

## 文章の決まり（AI臭さを消す）

- 「私」で書く。会社名は3で1回、7で1回だけ
- 「〜です。〜ます。」を3回続けない。体言止め・倒置・短文を混ぜる
- 「ここからは」「お伝えします」「いかがでしょうか」「ぜひ」「安心」「大切な」「しっかり」は禁止
- 「私たちは断定しません」のような自己言及をしない。断定しないなら、ただ書かない
- 数字は1画面に1つ。数字の後に必ず「つまり何か」を1文
- 比喩は現場のものだけ（バケツ、養生テープ、脚立）。抽象的な比喩は使わない
- 引用は原文どおり。地の文で言い換えない
- 「危険」「病気」「守る」「除菌」は使わない（景表法・薬機法・医療法人への配慮）

## デザインの方向

**「雑誌の特集ページ」。** 白い紙に、黒い明朝の大きな数字。写真はフルブリード。色は1色（LPの深い青緑）を、章番号と出典の線にだけ。

- 書体：見出し Shippori Mincho B1（LPと同じ）。本文 Zen Kaku Gothic New 400、17px、行間2.0
- 冒頭画面：数字を画面の6割の高さで。下に1文。それだけ
- 写真：横幅いっぱい、角丸なし、キャプションは小さく1行、「実際の現場写真」の帯は出さない（ダサい）。代わりに撮影日を添える
- ボタン：最終章まで出さない
- ダークモード対応は捨てる（紙の質感が要る。白固定）

## カード（A6）の方向

- 待合のパステルの紙の中で目立つのは、**白地に黒の大きな明朝**。色を使わない
- 表：数字1つ（読本の冒頭と同じ）と1文。QRは下1/4。「読むだけ・無料」は小さく
- 裏：読本の題名、URL（QRが読めない人用）、運営者、施設ID
- 施設で普通紙に印刷しても成立する（ベタ塗りなし）
- 見出し候補は2つ用意し、オーナーが選ぶ：
  - A. 数字型（読本の冒頭と同じ数字）
  - B. 問い型「赤ちゃんが来る前に、エアコンの中を見たことがありますか。」（オーナー案）

## v4 の前半（身分を明かす前）に置くもの
「赤ちゃんを迎える部屋を整える手引き」として、それ単体で成立させる。当社が出てくるのは後半だけ。
1. 冒頭の数字（v3 のまま：40〜60回 → 30cm）
2. **部屋の空気を整える3つ**：温度・湿度の目安／換気の仕方／結露（一次資料の原文）
3. **新しく買うもの・置くもの**：家具・カーテン・防虫剤・芳香剤・寝具（東京都 子供ガイドライン、指針）
4. **カビの住みかを自分で見る順番**：東京都の調査の順（浴室→押入れ→洗面所→寝室）＋エアコン・洗濯機・加湿器。場所ごとに「どこを見る／見えたらどうする」
5. **手入れの回数 早見表**：出典つき（フィルター、槽洗浄、浴室、加湿器、寝具）
6. **やってはいけない3つ**：洗浄スプレー（メーカー）、まぜるな（東京都）、カビに直接掃除機（東京都）
→ ここで身分を明かす → 現場写真 → 分解しないと洗えない場所 → いつやるか → 頼むなら
分量：v3 の約2倍。章は独立させ、途中で名前を呼ばれても戻れるように。
数字・手順は一次資料の原文だけ（docs/読本-出典.md に追記）。無い数字は書かない。

## ミスの傾向（自分で整理）と、次から必ずやること

| 傾向 | 出た箇所 | 次から |
|---|---|---|
| **読者に「作り手の都合」を説明する**（自己言及・前置き・断り書き） | 冒頭の注記、「続きは3分ほど」、「頼むかどうかは読み終わってから」 | 読者が得をしない文は書かない。「この読み物は」「書いている者は」「〜してください（読者の行動の指図）」を出す前に消す |
| **出典の見せ方が過剰**（正確さの誇示） | 項目ごとの出典行 | 本文は ※n だけ。出典は末尾に1回。冒頭の数字の出典だけ例外 |
| **文字だけの長文**（読み物なのに絵が無い） | 前半7章に写真ゼロ | 1章に1枚。素材サイトのアカウントを使う。写真の無い章を作らない |
| **理由の無い様式**（漢数字の章番号） | 一〜十 | 様式は「なぜ」を言えるものだけ。言えなければ普通の形（算用数字） |
| **売り文句を書けない**（説明文をCTAに置く） | 「頼むなら」「分解して、部品ごとに洗います」 | CTA はオーナーの文言をそのまま使う。自分で書くときは「お客様が得るもの」を先に、手順は後 |
| **料金条件の思い込み**（事実確認なしに「ありません」） | 駐車場代 | 料金・条件は price-master と見積アプリの文言だけ。無い条件は書かない。「〜はありません」は特に確認 |
| **自分のポリシーを客より優先**（同一現場の整合性） | 汚水写真の選び方 | 実物の施工写真である限り、いちばん伝わる写真を選ぶ。整合性の脚注は付けない |
