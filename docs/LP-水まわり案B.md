## 置き場所と「本番に出ない」しくみ

| | |
|---|---|
| ソース | `lp/mizumawari-b/index.html`（写真は `lp/mizumawari/img` と同じもの） |

## 何を比べるテストか

見た目の部品（色・書体・ボタン・料金計算機・フォーム・追従バー）は **案Aと同じもの** を使った。
**変えたのは「構成と訴求」だけ** なので、差が出たら「学習した型」の効果と読める。
GA4では `lp_id=mizumawari` をそろえ、`lp_variant` を A／B で分けてある（aircon-b と同じ）。

## 決めてほしいこと（オーナー）

1. **担当者の写真を出すか。** 出すなら写真1枚と一言の経歴。今は枠だけ（下書きの目印つき）
2. **A/Bの始め方。** 広告の配信先を半分ずつ `/mizumawari/` と `/mizumawari-b/` に分けるのが確実（CMO・計測担当と決める）。配信は「外に出す」なのでオーナー許可
3. **比べる数字。** 申込完了（`generate_lead`）÷ セッション を lp_variant 別に。広告費が限られているので、差が小さいうちは結論を急がない
