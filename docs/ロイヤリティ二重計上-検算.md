## 1. どこで二重になっているか

各月の `支出/成績` タブは、こういう作りになっています（5月の例。列と行は月によって位置が違いますが、**12か月すべて同じ形**です）。

| セル | 名前 | 式 |
|---|---|---|
| F53 | 合計 | `=(SUM(F2:F52))-J61` |
| J61 | 本舗個別ロイ | `=SUMIF(E2:E52,"個別ロイ",F2:F52)` |
| L61 | 本舗合計 | `=H61+I61+J61-K61` |
| F61 | ロイヤリティ | `=L61+F9+F10+F11+F12` |
| **B62** | **販売管理費** | `=(F53+F61-F59)+K61` |

B62 に F53・F61・L61・J61 を代入して、打ち消し合う項を消すと、こうなります。

```
販売管理費 ＝ SUM(F2:F52)          ← 支出明細の全額
            ＋ H61 ＋ I61           ← 本舗38%ロイ・本舗10%ロイ
            ＋ F9＋F10＋F11＋F12    ← ここ
            － F59                  ← 人件費
```

`-J61` と `+J61`（L61の中）、`-K61` と `+K61` は、それぞれ打ち消し合って消えます。
**残るのが `F9+F10+F11+F12` で、この4行は `SUM(F2:F52)` の中にも入っています。**

つまり、この4行だけが2回足されています。

| 行 | 品目 | 科目 | 金額 |
|---|---|---|---:|
| 9 | HITOWAサイト保守費用 | 広告費 | ¥4,400 |
| 10 | HITOWAサポート・アカウント管理費 | 耐久品 | ¥1,650 |
| 11 | 固定ロイ | 個別ロイ | ¥22,000 |
| 12 | HITOWAHPC利用料 | 広告費 | ¥22,000 |
| | | **計** | **¥50,050** |

> **「固定ロイ22,000 は科目が『個別ロイ』だから J61 で引かれていて無事」ではありません。**
> J61 は F53 から引かれますが、**同じ J61 が L61 の中で足し戻されている**ので、差し引きゼロです。
> 結果、4行とも二重になります。

- **営業利益・経常利益がその分だけ少ない**

## 4. 直すなら（案）

どちらでも結果は同じです。**1行だけ直せば12か月ぶん片付きます**（月ごとにセル位置は違います）。

**案A（推す）** — 合計のほうから固定分を外す

```
F53: =(SUM(F2:F52))-J61-F9-F10-F11-F12
```

**案B** — ロイヤリティのほうで足すのをやめる

```
F61: =L61
```

**案Aを推します。** F61「ロイヤリティ」は「その月に本舗へ払うロイヤリティの総額」として
他でも読まれる数字なので、固定分を含んだままのほうが意味が通ります。
F53「合計」のほうは、もともと「ロイヤリティを除いた支出」のつもりで `-J61` している
（＝二重を避ける意図がある）ので、**そこに漏れがあった、という直し方が素直です。**

月ごとの対象セル：

| 月 | 合計 | ロイヤリティ | 販売管理費 |
|---|---|---|---|
| 1〜5・8〜12月 | F53 | F61 | B62 |
| 6月 | F72 | F80 | B81 |
| 7月 | F86 | F94 | B95 |
