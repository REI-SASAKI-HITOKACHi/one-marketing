# 料金シミュレーター修正の検証結果

検証 2026-09-08 ／ マーケ部長（責任者として実施）
対象：LPスレッドの修正（`dca01fd 料金シミュレーターの割引ロジックを修正`）

---

## 結論

**実装は正しい。ただし年末LPだけ、修正が本番に配信されていない。**

`https://one-hitter-nenmatsu.netlify.app/` は旧ロジックのままです。
**SMSの誘導先がこのページなので、配信されるまでSMSは出せません。**

## やった検証

**相手のコードは読みましたが、期待値は相手のコードから作っていません。**
`data/prices.json` とパンフレット（印字p10・p11）から、こちらで独立に計算した値と
突き合わせています。

**検証したのは「配信済みのHTMLそのもの」です。** リポジトリのソースではありません。
`lp/*/index.html` は `<meta charset>` を持たない断片で、ビルドで包まれる形のため、
そのままブラウザで開いても本番と同じにならないからです。

| 対象 | 通り数 | 結果 |
|---|---:|---|
| 水まわりLP（本番） | **255**（8箇所の全組み合わせ） | **全一致** |
| 年末LP（本番） | 255 | **★203件が不一致 ＝ 未配信** |
| エアコンLP（本番） | **128**（種別2×台数4×オプション8×繁忙期2） | **全一致** |
| エアコンLP-B（本番） | 128 | **全一致** |
| 予約フォーム（ローカル） | 7 | 全一致（本番は未配信。Netlify操作を止められているため） |

合計 **766通り**。JSエラーはどのページでもゼロ。

## 検証で分かった、こちらの誤り

エアコンLPの検証で、最初 84件の不一致が出ました。
**オプション（室外機セット・防カビコート・防虫キャップ）と繁忙期加算が
「1台ごと」にかかることを、こちらの期待値が見落としていました。**
LPスレッドの実装が正しく、こちらの計算が誤りでした。修正して再実行し、128通り全一致。

## 細かい指摘（実害なし）

`lp/mizumawari/index.html` と `lp/nenmatsu/index.html` に、古い英語コメントが残っています。

```js
// The most expensive item is charged at its standalone price;
// every additional item takes the simultaneous-service price.
```

いまの実装（割引額が最小の箇所を単品に残す）と**逆のことを書いています。**
次に触る人が誤解するので、消してください。

## LPスレッドの報告で良かった点

**「値上がりになる組み合わせが5通りある」を自分で見つけて報告しています。**
コンロのセット価格を条件つきにした結果、これまで誤って安く出していたぶんが
正価に戻るケースです。こちらの依頼書には書いていませんでした。

```
浴室＋コンロ        24,530 → 25,960（+1,430）
レンジフード＋コンロ 24,530 → 25,960（+1,430）
追い焚き＋コンロ     25,960 → 27,390（+1,430）
洗面台＋コンロ       16,830 → 18,260（+1,430）
コンロ＋洗濯機       23,430 → 25,960（+2,530）
```

パンフレットどおりなので直すのが正しく、値上がりであることも明示されています。
