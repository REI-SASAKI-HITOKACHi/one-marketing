### 字数の余りは **37文字ではなく 27文字** です

**「3通案は173文字」という数字が独り歩きしています。** 実測はこうです。

| | 文字数 |
|---|---:|
| ひな形（差し込み前） | **169** |
| 差し込み後・最短 | 163 |
| 差し込み後・中央 | 169 |
| **差し込み後・最長** | **183** |
| 3通の上限 | 210 |
| **余り（最長の方で）** | **27** |

**効くのは「最長の方」です。** 差し込みで長くなる方（法人名＋「天井カセットエアコンのクリーニング」など）が
210文字を超えると、**その方だけ4通目に入ります。**
`173` はこちらが 9/13 に概算で出した数字で、**確定したひな形の実測値ではありませんでした。**

> **`080-1344-3137` は、すでに本文に2回入っています。**
>
> - 「ご入用でしたら080-1344-3137（渡辺）へお電話ください。」
> - 「ご案内が不要な方も同じ番号へお知らせください。」
>
