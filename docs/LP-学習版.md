## 置き場所と「本番に出ない」しくみ

| | |
|---|---|
| ソース | `lp/<名前>/index.html`（写真は今のLPと同じもの） |
| 確認用の書き出し | `python3 tools/build-site.py netlify --draft <名前>` → `preview/netlify/<名前>/` |
| 手元で開ける確認用ページ | `python3 tools/make-kakunin.py <名前>` → `preview/kakunin/<名前>.html`（計測タグを外し、送信しない。写真は埋め込み） |
| 本番に出ない理由 | `build-site.py` の **`DRAFTS`** に置いた。通常のビルド（`PAGES`）では作られないので `deploy/` に入らず、配信しても本番に出ない。`preview/` は git に入れない |
| A/Bを始めるとき | オーナーの許可を取って、`DRAFTS` から `PAGES` へ移すだけ。**今のLPのURL（アフィリエイト登録済みの5本）は変えない** |

**今のLP（4本とも）には一切触っていない。**

## 何を比べるテストになるか（訂正あり）

学習版の見た目（色・書体・ボタン）は **LP v2 で決めたもの**（温かい白・丸いボタン）。
**本番の今のLPはまだ v2 前**（寒色の白・角ばったボタン）。9/29 に「見た目の部品は案Aと同じ」と書いたのは不正確で、
今の本番と比べると見た目の差も混ざる。

CMO の共有（20260928-03）では **LP v2 の本番切替は 10/9 の判定後**。
→ **A/Bは「今のLPを v2 に切り替えたあと」に始めれば、構成と訴求の違いだけを比べられる。**

料金の計算機・申込フォーム・追従バーは、今のLPと同じ部品・同じ計算。

## LPごとの違い

- **エアコン（C・D）**：当てはまるものを押す診断（「つけた瞬間カビ臭い」など6項目。押すと結果が出る）。汚水の写真。
  クチコミは大手から乗り換えたK様（FV直下）と3回目のY様。よくある頼み方は「1台」「2台（特典−2,200円）」「お掃除機能付き1台」で、
  計算機で選んでいる時期（繁忙期か）に合わせて金額が変わる
- **年末（B）**：今の年末LPの核「12月から、料金が上がります」（11月まで33,660円／12月40,260円）をクチコミ直下に置いた。
  よくある頼み方は「12月のご予約だと」の金額も並べる（通常価格＋3,300円×箇所数）
