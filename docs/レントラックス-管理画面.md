# 初回ログインで出る「3つの質問」

**回答しないと、管理画面が見られなくなります。**（先方資料 p4）
先に読むもの：`docs/vendor/rentracks/改正個人情報保護法へのご対応についてのお願い.pdf`

## 何を聞かれているのか（かみくだくと）

レントラックスは当社に「**誰がいつ、どの媒体の広告をクリックして来たか**」を渡します。
これは個人情報そのものではないので「**個人関連情報**」と呼ばれます。

当社がそれを「**この注文はあの田中さんのものだ**」と結びつけて使うなら、
**お客様から事前に同意をもらっておく必要がある**、というのが改正個人情報保護法の決まりです。
（2022年4月施行・第26条の2）

## 当社はどうなのか

**結びつけます。** 成果を承認するか却下するかを、当社が決める仕組みだからです。

管理画面に並ぶ成果を1件ずつ見て、「この注文は入金が済んでいるか」を
当社の台帳と突き合わせる必要があります（`_rt.cinfo` に入れる注文IDがその鍵です）。
**この突き合わせが、まさに「紐づけ」にあたります。**

→ **したがって、質問1の答えは A（実施していない）ではありません。**

## 回答案

### 質問1：個人関連情報と個人データの紐づけについて

**選ぶのは、ログインする時期によって変わります。**

| いつログインするか | 選ぶ答え |
|---|---|
| **プライバシーポリシーの改定を公開する前**（＝今すぐログインする場合） | **C：実施していないが、実施の予定がある** |
| **公開したあと** | **B：実施しており本人の同意取得済み** |

> **いま公開しているプライバシーポリシーには、アフィリエイト広告のことが書かれていません。**
> 書いていないのに「同意取得済み（B）」と答えると、事実と違う申告になります。
> 改定案は用意してあります（`cms/privacy-policy/proposed.html` 第10章）。**公開待ちです。**

### 質問2：（Bと答えた場合）同意取得の方法

そのまま貼れる文です。

```
プライバシーポリシー内に、広告の効果測定のために第三者から広告の情報を取得し
当社のご利用情報と照合する場合がある旨を記載しており、
お申し込みフォームの送信をもってご同意いただく形で取得しています。
```

### 質問3：（Cと答えた場合）実施の予定日と、同意取得の方法

そのまま貼れる文です。**日付は、ポリシーを公開する予定日に直してください。**

```
2026年9月中の予定です。
プライバシーポリシー内に、広告の効果測定のために第三者から広告の情報を取得し
当社のご利用情報と照合する場合がある旨を記載したうえで、
お申し込みフォームの送信をもってご同意いただく形で取得する予定です。
```

> **Cで回答したあと、ポリシーを公開したら、先方に一報を入れてください。**
> 問い合わせ先：`privacy@rentracks.co.jp`（件名「改正個人情報保護法へのご対応について」）

## この決まりを守らないと何が起きるか

先方の資料（p4）に書いてあることです。

- 回答しないと、**管理画面の情報が見られなくなります**
- 回答しないと、成果の通知メールで**媒体様情報と備考情報が `*****` に伏せられます**
  → **どの媒体から来た成果か分からなくなり、承認の判断ができません**
