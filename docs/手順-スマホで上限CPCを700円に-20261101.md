# 嶺さん用：上限クリック単価を ¥500 → ¥700 にする手順（2026-11-01 計測担当・嶺さんの返事待ち）

**嶺さんの OK が出てから渡す。** お金に関わる変更（1クリックに払う上限が上がる）。日予算 ¥7,000 は変えない。元に戻せる（¥500 に戻すだけ）。

## いちばん早い方法
**10/28 13時台に嶺さんが「クリック数の最大化・上限 ¥500」にしたのと同じ画面です。** そのとき「上限」に ¥500 と入れた欄を ¥700 に変えて保存してください。

## 画面の順番（Google 広告ヘルプで確かめた範囲）

### ブラウザ（ads.google.com）の場合
1. ［キャンペーン］メニューの［キャンペーン］を開き、「**検索_江戸川_段0_v2**」を選ぶ
2. キャンペーンのページメニューで **［設定］** を選ぶ
3. **［単価設定］** を開く
4. 入札戦略が「クリック数の最大化」になっていることを確かめ、**「上限クリック単価の上限」** の欄を **700** に変える
5. **［保存］**

出典：入札戦略を変更する https://support.google.com/google-ads/answer/6324950?hl=ja ／「クリック数の最大化」入札戦略について https://support.google.com/google-ads/answer/6268626?hl=ja
- **未確認**：手順4の欄が［単価設定］の中のどこに出るか。ヘルプには「上限クリック単価の上限」という名前はあるが、既にあるキャンペーンでの欄の位置は書いていない。［入札戦略を変更］を押さないと出ない場合は、押して「クリック数の最大化」を選び直し、上限に 700 を入れて保存（入札の方式は同じまま）

### アプリの場合
1. ［キャンペーン］で「検索_江戸川_段0_v2」を選ぶ
2. 右上の **歯車アイコン** を押す
3. ［入札戦略］の下の、今の入札戦略を押す
4. 画面の指示に沿って「クリック数の最大化」の上限を 700 にする
5. **［保存］**

出典：入札戦略を設定する（Google 広告モバイルアプリ） https://support.google.com/google-ads/answer/9924762?hl=ja
