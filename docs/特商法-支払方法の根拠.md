# 特商法ページ「支払方法・支払時期」の根拠（2026-09-17）

**オーナー回答（2026-09-17）**：「その場で精算。現金＋square対応決済方法。square公式を念のため確認して」

---

## 🔴 そのまま書けない部分が1つあります

**「Square対応決済方法」と「当社のSquareアカウントで実際に使える決済方法」は、同じではありません。**

Square公式（ヘルプセンター）で確認した事実：

> **電子マネー決済を受け付けるには「店舗ごとに有効化の手続きが必要」で、
> 申し込み後「通常約4〜9日」の審査期間がある。JCBの利用申し込みも必要。**
> 出典：[電子マネーを申し込む｜Squareヘルプセンター](https://squareup.com/help/jp/ja/article/6711-jp-only-e-money-application)

**＝Squareが対応していても、当社が申し込んでいなければ使えません。**
**特商法の表記は掲示した時点で拘束力を持つので、「使えるはず」では書けません。**

## Square が日本で対応している決済手段（公式）

| 区分 | ブランド |
|---|---|
| クレジット／デビット | Visa・Mastercard・American Express・JCB・Diners Club・Discover・UnionPay（銀聯） |
| 電子マネー | **交通系IC**（Suica・PASMO・Kitaca・TOICA・manaca・ICOCA・SUGOCA・nimoca・はやかけん）・**iD**・**QUICPay** ／ **別途申込と審査（4〜9日）が必要** |
| 非対応の電子マネー | **楽天Edy・WAON・nanaco**（Squareが対応していない） |
| QRコード決済 | PayPay・d払い・楽天ペイ・au PAY・メルペイ・WeChat Pay・Alipay+ ／ **別途申込が必要** |
| モバイルウォレット | Apple Pay |

出典：
[対応している決済ブランドと利用可能な決済端末一覧](https://squareup.com/help/jp/ja/article/6618-jp-only-accepted-e-money-card-brands-with-the-square-reader) ／

## 特商法ページに書く文言（CMO案）

### 支払時期

```
作業完了後、その場でお支払いいただきます。
```

**これはオーナー回答そのままなので、確定です。**

### 支払方法 — **段階を分けます**

**いま確実に書けるもの（＝Squareの基本機能。申込不要）**

```
・現金
・クレジットカード／デビットカード
　（Visa、Mastercard、American Express、JCB、Diners Club、Discover）
```

**オーナーの確認が取れてから足すもの**

```
・電子マネー（交通系IC、iD、QUICPay）   ← Squareで別途申込・審査が要る
・QRコード決済（PayPay ほか）            ← 同上
```

> **確認のしかた**：Squareの管理画面 →「アカウントと設定」→「決済手段」で、
> **電子マネー・QRコード決済が「有効」になっているか**を見る。
> 有効なら足す。申込がまだなら**書かない**（使えないものを掲示すると、それ自体が問題になります）。

**カードブランドも、厳密には当社の契約で JCB が有効かを確認したほうが安全です。**
上の電子マネーの申込ページに「**JCBの利用申し込みが必要**」と明記されているためです。

## 進め方

1. **LP担当は、上の「いま確実に書けるもの」で特商法ページを埋める**（②の箱を閉じる）
2. **オーナーがSquare管理画面で電子マネー・QRの有効／無効を見る**（1分）
3. 有効だったものだけ、あとから足す

**2 を待って1を止めない。**「現金＋カード」だけでも、掲示として嘘にはなりません。
**足りないのは「載せていない手段がある」ことで、これはお客様の不利益になりません。**
