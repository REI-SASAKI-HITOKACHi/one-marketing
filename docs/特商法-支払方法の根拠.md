## 🔴 そのまま書けない部分が1つあります

**「Square対応決済方法」と「当社のSquareアカウントで実際に使える決済方法」は、同じではありません。**

Square公式（ヘルプセンター）で確認した事実：

> **電子マネー決済を受け付けるには「店舗ごとに有効化の手続きが必要」で、
> 申し込み後「通常約4〜9日」の審査期間がある。JCBの利用申し込みも必要。**
> 出典：[電子マネーを申し込む｜Squareヘルプセンター](https://squareup.com/help/jp/ja/article/6711-jp-only-e-money-application)

**＝Squareが対応していても、当社が申し込んでいなければ使えません。**
**特商法の表記は掲示した時点で拘束力を持つので、「使えるはず」では書けません。**

## Square が日本で対応している決済手段（公式）

| 区分 | ブランド |
|---|---|
| クレジット／デビット | Visa・Mastercard・American Express・JCB・Diners Club・Discover・UnionPay（銀聯） |
| 電子マネー | **交通系IC**（Suica・PASMO・Kitaca・TOICA・manaca・ICOCA・SUGOCA・nimoca・はやかけん）・**iD**・**QUICPay** ／ **別途申込と審査（4〜9日）が必要** |

| QRコード決済 | PayPay・d払い・楽天ペイ・au PAY・メルペイ・WeChat Pay・Alipay+ ／ **別途申込が必要** |
| モバイルウォレット | Apple Pay |

## 特商法ページに書く文言（CMO案）

### 支払時期

```
作業完了後、その場でお支払いいただきます。
```

**これはオーナー回答そのままなので、確定です。**

### 支払方法 — **段階を分けます**

**確定版（2026-09-17）**

```
・現金
・クレジットカード／デビットカード
　（Visa、Mastercard、American Express、JCB、Diners Club、Discover）
・電子マネー（交通系IC、iD、QUICPay）
・QRコード決済（PayPay、d払い、楽天ペイ、au PAY、メルペイ）
```

### 書き方の根拠

- **電子マネーは3種を明記してよい。** Squareの電子マネーは
  **交通系IC＋iD＋QUICPay がひとまとまりで有効化される**ので、部分的に欠けることがない。
  **交通系ICの内訳**（Suica・PASMO・Kitaca・TOICA・manaca・ICOCA・SUGOCA・nimoca・はやかけん）は、
  **書かなくてよい。**「交通系IC」で通じるし、書くほど間違いの余地が増える
- **楽天Edy・WAON・nanaco は書かない。** **Square自体が対応していない。**
  現場で「使えません」と言うことになる
- **QRは国内5つだけ書く。** WeChat Pay・Alipay+ は Square の対応一覧にあるが、
  **当社のお客様（1都2県の住居・法人）でこれを出す人はほぼいない。**
  **書かないことはお客様の不利益にならないので、確実なほうに倒す**
- **JCB は書いてよい。** 電子マネーの申込には JCB の利用申し込みが前提で、
  **その電子マネーが有効になっている＝JCBも通っている**

⚠️ **1点だけ：Square管理画面の「決済手段」でQRのブランドが個別に並んでいて、
上の5つに欠けがあったら、欠けているものを外してください。**

1. **LP担当は、上の「いま確実に書けるもの」で特商法ページを埋める**（②の箱を閉じる）

> ## **安心させる文が2つとも、申し込んだ後にしか出てこない。**
> **押すのをためらっている人は、どちらも読めない。**

とくに 386 行目が効きます。
**「お電話で説明してから確定します」は、このページでいちばん強い一文**です。
**「押した瞬間に確定してしまうのでは」という、いちばん大きな恐怖に直接答えている。**
それが**押した人にしか見えない。**

**新しく文を作る話ではありません。すでに書いてある文を、要る場所に移す話です。**

## 決済の事実確認

- **予約フォームは決済を持っていない。** `stripe` `payjp` 等の決済スクリプトは0件
  （`card` の9件はすべてCSSのクラス名）。**Netlify Forms に送るだけ**
- **＝「予約時に費用は発生しません」は、事実として正しい**

## ボタンの直前に置く4行（CMO案）

```
・ご予約の時点で費用は発生しません
・はじめての方には、お電話で作業内容と料金をご説明してから確定します
・前日までのご連絡なら、キャンセル料はかかりません
・お支払いは作業完了後その場で
　（現金・各種カード・交通系IC・iD・QUICPay・PayPay などのQRコード決済）
```

**この順番には理由があります。** 押す直前の人が抱く不安は、この順に来ます。

1. **押したら金を取られるのか** → 1行目
2. **押したら決まってしまうのか** → 2行目
3. **やめられるのか** → 3行目
4. **払えるのか** → 4行目

**4行目（支払方法）だけを入れても、1〜3の不安は残ります。**
**オーナー指摘のとおり、決済タイミングのほうが先です。**
