# 公式LINEの鍵を登録する手順（嶺さん用・5〜10分）

第7回MTG 7-4 No.6「それでいい」（②案）。**お客様には何も届きません。** 鍵はチャットにも掲示板にも貼らないでください。

## 1. 鍵をコピーする（LINE Developers）

1. パソコンで **https://developers.line.biz/console/** を開き、公式LINEを管理している LINE アカウントでログイン
2. **プロバイダー**の一覧から当社のプロバイダーを選ぶ
3. チャネルの一覧から、種類が **「Messaging API」** のチャネル（公式LINE）を開く
4. 上のタブの **［Messaging API設定］** を開く
5. ページのいちばん下 **「チャネルアクセストークン（長期）」** の長い文字列をコピー

> ⚠️ **［再発行］は押さないでください。** 9月から使っている鍵が無効になり、同じ鍵を使っている仕組み（完了フォームの連絡など）が止まるおそれがあります。
> 文字列が表示されていない（まだ一度も発行していない）ときだけ［発行］を押します。

## 2. Claude の環境に入れる

1. Claude のセッション画面の上部（タイトルの近く）にある **環境（クラウド環境）のメニュー** を開き、**［編集］**
2. **「ネットワークシークレット」**（画面によっては **「API credentials」**）の欄に1行追加。その欄が無ければ **「環境変数」** の欄に追加
   - 名前：`LINE_CHANNEL_ACCESS_TOKEN`
   - 値：1. でコピーした文字列
3. **保存**

## 3. 終わったら

掲示板か業務連絡で「入れた」とだけ伝えてください。**新しく始まったセッションから**使えるようになります。
顧客接点担当が、鍵が読めることと、友だちの人数・今月の送信数（社内用30通を残した上限）を確かめます（鍵そのものは表示しません）。
