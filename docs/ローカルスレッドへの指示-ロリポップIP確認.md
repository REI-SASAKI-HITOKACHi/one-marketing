ワンヒッター株式会社の作業です。ブラウザ操作をお願いします。

# 背景

KDDIの法人SMSサービス「KDDI Message Cast」をAPI連携で申し込む。
申込書に「接続元のグローバルIPアドレス」を書く必要があり、KDDIは
レンジ指定を認めていない。単一のIPを申告しなければならない。

自社の顧客管理システム（＝ロリポップのサーバー）からSMS APIを叩く構成に
できるかどうかは、ロリポップの外向きIPが固定されているかで決まる。
それを確かめたい。

# やってほしいこと

## 1. ロリポップにログイン

https://user.lolipop.jp/ にアクセス。
※ログイン情報はオーナー（佐々木さん）が入力します。ログイン画面まで進めて、
　「ログインをお願いします」と声をかけてください。

## 2. 確認用ファイルを設置する

リポジトリの `tools/ip-check.php` をアップロードする。

- ロリポップ管理画面 →「サーバーの管理・設定」→「ロリポップ！FTP」
- 公開フォルダ（web など、独自ドメインの公開ディレクトリ）の直下へ
- ファイル名は `ip-check.php` のまま

ファイルの中身はこのリポジトリにある。取得先:
https://github.com/REI-SASAKI-HITOKACHi/one-marketing/blob/claude/one-hitter-cmo-strategy-5qk4ux/tools/ip-check.php

ロリポップFTPには「新規ファイル作成」機能があるので、
アップロードが難しければ新規作成して中身を貼り付けてもよい。

## 3. 開いて結果を控える

ブラウザで `https://（設置したドメイン）/ip-check.php` を開く。

次のような出力が出る。

    ■ 外向きIP（KDDIの申込書に書くのはこれ）
      ipify       : 203.0.113.45
      AWS         : 203.0.113.45
      ifconfig.me : 203.0.113.45

    ■ 判定
      外向きIPは 1つ に定まりました → 203.0.113.45

**画面全体をスクリーンショットで撮って、結果をテキストでも控えてください。**

## 4. 時間を空けてもう一度

**30分以上あけて、同じURLをもう一度開く。**
1回目と同じIPが出るかどうかが、この作業の本題。

- 毎回同じ → ロリポップからAPIを叩く構成が使える
- 毎回違う → この構成は使えない（KDDIがレンジ指定を認めていないため）

## 5. 後片付け

確認が終わったら、**ip-check.php を必ず削除する。**
サーバー情報が見えるファイルなので、置きっぱなしにしない。

4. 出力の「参考情報」欄（SERVER_ADDR / ホスト名 / curl / allow_url_fopen）

## この確認で分かること

| 結果 | 次にどうするか |
|---|---|
| 毎回同じIP | そのIPを申込書に記入して提出。追加費用ゼロ |
| 毎回違うIP | ロリポップ案は不成立。VPS（月700〜1,000円）を立てるか、KDDIに相談 |
| 外部通信ができない | 同上。ロリポップからAPIを叩けない |

## 補足：同じIPでも残るリスク

共用サーバーなので、**ロリポップ側のサーバー移転・増強でIPが変わる可能性は残る。**
変わった瞬間にSMSの送信が止まり、原因が分からないまま数日を失う。

年末商戦の本番（650〜800通）で使うなら、固定IPが保証されるVPSを1台立てるほうが安全。
月700〜1,000円。デモ期間はロリポップで通し、本番までにVPSへ移す、という進め方もある。
