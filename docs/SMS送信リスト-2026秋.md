## SMS本文（自社系統・案）

```
ハウスクリーニングのワンヒッターです。
その後、お掃除した箇所の調子はいかがでしょうか。
12月から1箇所あたり3,300円の繁忙期加算がかかります。11月末までのご予約なら通常価格です。
ご予約・ご相談はこちら
https://one-hitter-nenmatsu.netlify.app/?src=sms
ご不要でしたらご返信ください。以後お送りしません。
```

181文字。長文SMSの範囲内で、キャリアの分割送信で届きます。

- 誘導先は年末LP（`docs/SMS配信のリンク設計.md` の決定）。**1通に複数のリンクは入れない**
- `?src=sms` でSMS経由の反応を他と分けて数えられます
- 顧客ID（`cid`）は手作業フェーズでは付けません。1人ずつURLが変わると和真の手間が10倍になるためです。
  送った日と番号は分かるので、突合はそれで足ります。KDDI開通後は `cid` を付けます
- 金額は `data/prices.json` が正。繁忙期加算は5・6・7・12月に1箇所あたり3,300円（税込）

## 和真への渡し方（工数の最小化）

**シートは開いてもらいません。** グループLINEに、本文と宛先10件を1通で送ります。

```
━━ ここからコピー ━━
（SMS本文）
━━ ここまで ━━

【本日の宛先 10件】
1. 〇〇 様　090xxxxxxxx
 …
```

LINEでは電話番号が自動でリンクになるので、**タップ→SMSアプリが開く→貼り付け→送信**で終わります。
1件あたり3タップ、10件で15分ほどの想定です。

1. SMS本文（上記）でよいか
2. スケジュールマッチング経由228名を送ってよいか（規約の確認）
3. 1日10件・9/9開始でよいか

## 公式LINE側

公式LINE（友だち330・うち初期追加約200はダミー）への配信は、**この内部用アカウントとは別**です。
CMOが持っているトークンは3人グループ用の内部アカウントのもので、公式LINEには使えません。
配信するには公式LINE側のチャネルアクセストークンが要ります。必要になったらお知らせください。
