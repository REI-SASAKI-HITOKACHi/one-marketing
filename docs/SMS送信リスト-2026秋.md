## どこにあるか

**新しいタブは作っていません。** `冬季見込み客_2026` タブを、
**スマホで送信作業をするための並び**に組み替えました。

| 列 | 内容 |
|---|---|
| A | 優先 |
| B | 顧客名 |
| C | 電話番号（数字だけ。長押しでコピーできる） |
| D | **▶ 送る** … タップするとSMSが宛先と本文入りで開く |
| E | 送信する本文（Dが効かない端末用の控え） |
| F | **送信済み**（プルダウン1タップ） |
| G | 返信メモ |
| H | 送信日の目安 |
| I〜Y | 配信区分・理由・セグメント・売上など、これまでの情報（消していません） |

作り直しは `python3 tools/build-sms-list.py`。
F列とG列に和真が入れた内容は、作り直しても消えません。

### ★ D列「▶ 送る」は実機で1度だけ確かめてください

`=HYPERLINK("sms:09012345678?body=本文","▶ 送る")` という仕組みです。
**スマホのGoogleスプレッドシートでタップできれば、宛先と本文が入った状態でSMSが開きます。**
1件あたり2タップで終わります。

ただし、端末やアプリの版によっては `sms:` のリンクが無効化されることがあります。
**効かなかった場合は、E列の本文をコピーしてC列の番号に送ってください**（従来どおり4〜5タップ）。
和真に1件だけ試してもらって、どちらの運用になるか教えてください。

## 本文は1人ずつ変えています

台帳にある「前回のメニュー」「最終施工日」「今回おすすめ」を差し込んでいます。

```
堀江さま
今年1月に浴室クリーニングでお世話になりました、ハウスクリーニング ワンヒッターの渡辺です。
その後、お掃除した箇所の調子はいかがでしょうか。
12月から1箇所あたり3,300円の繁忙期加算がかかります。11月末までのご予約なら通常価格です。
キッチンと洗濯機もあわせてご検討いただけます。
ご予約・ご相談はこちら
https://one-hitter-nenmatsu.netlify.app/?src=sms
ご不要でしたらご返信ください。以後お送りしません。
```

228〜252文字。長文SMSの範囲で、キャリアの分割送信で届きます。

- **名乗りを系統で出し分けています。** 自社は「ハウスクリーニング ワンヒッターの渡辺です」、
  本舗経由は「おそうじ本舗江戸川中央店の渡辺です」
- 誘導先は年末LP（`docs/SMS配信のリンク設計.md` の決定）。1通に複数リンクは入れない
- 顧客IDは付けていません。1人ずつURLが変わると、D列の「▶送る」が使えても
  E列のコピー運用に落ちたときの手間が増えるためです。送った日と番号で突合できます
- 金額は `data/prices.json` が正

9/9〜9/12の80名は優先1〜3（2回以上ご利用のリピーターが中心）です。

KDDI Message Cast が開通したら（9/22〜25見込み）、残りはAPIで一括送信に切り替えます。

## 本文はひな形にしてあります

`data/sms-template.txt` を書き換えて `python3 tools/build-sms-list.py` を流すと、
488名ぶんの本文が作り直されます。オーナーが文面を直したら、差し替えるだけです。

ダブルクォートで囲んだところが1人ずつ差し替わります。

| 目印 | 入る値 |
|---|---|
| `"顧客名"` | 姓だけ（堀江） |
| `"フルネーム"` | 台帳のままの氏名 |
| `"名乗り"` | 自社＝ハウスクリーニング ワンヒッターの渡辺です／本舗＝**おそうじ本舗の渡辺です** |
| `"施工時期"` | 昨年11月／今年4月 |
| `"前回メニュー"` | 浴室クリーニング など |
| `"おすすめ"` | 換気扇とキッチン など |
| `"予約URL"` | 年末LP（src=sms付き） |
| `"電話番号"` | 受付番号 |

**差し替えるものが空だった行は、その行ごと消えます。**
最終施工日が分からないお客様には「"施工時期"に…」の行が出ません。
そのため、**1行に1つの話題だけ**を書いてください。

## D列「▶ 送る」の実機テスト

シートの**2行目に「【実機テスト】自分あて」の行**を固定で置いてあります。
宛先は受付番号（080-8043-8259）なので、タップして送信しても誤送信になりません。

9/9 13:00に和真へLINEで案内し、「開いた／開かない」を回収します（TODO T036）。
結果によって運用が変わります。

| 結果 | 運用 | 1件あたり |
|---|---|---|
| 開いた | D列をタップするだけ | 2タップ |
| 開かない | E列の本文をコピーしてC列の番号へ | 4〜5タップ |
