## 3. LPに取り込むべき、サイト側の良い素材

- **「LINEで無料クーポン」** — サイト全ページのCTAに存在。LPのLINE導線をこれに接続すれば
  友だち追加の動機が明確になり、CVRが上がる。※クーポンの内容と条件を要確認。
- **「最短即日対応」** — アクセス欄に記載。LPでは「最短翌日」としているので、即日が正なら強い訴求になる。
- **営業時間 8:00〜20:00「※時間外でも対応しております」** — LPのフォーム下に添えると安心材料になる。
- 冒頭コピーが秀逸：**「日本人の嫌いな家事ランキング不動の第1位は掃除。1日30分なら、1年で180時間以上を嫌いなことに費やす」**
  → 案Bの共感パートに、この時間の話をそのまま使いたい。
- 「これまでのハウスクリーニングは料金が高く時間がかかる。家事代行では素人同然の作業員が派遣される。
  One Hitterはプロの技術を必要な分だけスマホ一つで」→ ポジショニングが明快。LPの差別化パートに転用可。
- 施工事例ページ（浴室周辺／エアコン／キッチン周辺）に写真が既にある可能性 → LPのBefore/After枠に流用できるか要確認。
