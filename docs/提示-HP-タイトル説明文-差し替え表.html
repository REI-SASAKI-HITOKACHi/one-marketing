貼る前に browser が確かめること（2点・5分）

  1. 説明文の欄があるか：管理画面（/_sys/）で各ページの設定に「ディスクリプション／説明文」の欄があるか。無ければ説明文は見送り（共通の <head> には入れない。全ページ同じ文になるため）
  2. タイトルの欄は「ページ名」か、別の欄か：公式サイトは「ページ名 | 江戸川区のハウスクリーニングならワンヒッター株式会社」を自動で作っています。
    ・別の「タイトル」欄がある → 右のタイトルをそのまま入れる
    ・ページ名しか無い → ページ名は替えない（見出し・メニューの表示も変わるため）。この場合は説明文だけ入れる
    ・トップ（/）はサイト名を替えない（全ページの後ろに付く文字が変わるため）

貼ったあと・戻し方

  • 貼ったら各ページを開き、ソース表示で <title> と <meta name="description"> を確かめる（lp が読み取りで点検し直せる）
  • 戻すとき：タイトルはこの表の「今」に、説明文は空に戻す。料金などの本文は触らない
