# 第2部：成果承認の運用（T026）

## なぜ要るのか

**成果の発生から45日を過ぎると、入金が確認できていなくても自動で承認されます**（先方 9/12 回答）。

**キャンセルでも、未入金でも、当社が 3,300円（税込）を払います。**
**当社は申込から入金まで2〜4週間かかる**ので、45日はぎりぎりです。
**承認APIはありません（CSVの取り込みのみ）**ので、人がやる運用になります。

## 決めたこと

| | |
|---|---|
| **誰が** | **計測担当**が一覧を出す。**却下の実行はブラウザ担当かオーナー**（管理画面にこちらは入れない） |
| **いつ** | **毎週月曜 08:00 JST**（定期実行 `trig_01M3k5W9pr2HoNduxCD2B2HV`） |
| **どの頻度** | **週1回。それ以上は要りません**（下記の検算） |
| **何日前に警告するか** | **発生から38日**（＝自動承認の**7日前**） |

## なぜ38日なのか（45日ではなく）

**月曜にしか見ないからです。** 45日ちょうどにすると、**その週に見落とした分は、次に見るときには手遅れ**です。

**9/15 に発生した成果で検算しました。**

| 点検日（月） | 経過 | 自動承認まで | 拾うか |
|---|---:|---:|:--:|
| 10-19 | 34日 | あと11日 | — |
| **10-26** | **41日** | **あと4日** | **★拾う** |
| 11-02 | 48日 | **期限切れ** | （手遅れ） |

**38日なら、月曜運用でも4日の余裕を残して拾えます。**
**45日ちょうどだったら、11/2 に初めて気づいて手遅れでした。**

## 毎週やること

```
python3 tools/rentracks-shonin-check.py <管理画面から落とした注文リストのCSV>
```

**CSVはこちらからは落とせません**（管理画面に入れないため）。
**毎週、CMOかブラウザ担当に「注文リストのCSV（保留ぶん）」を依頼します。**

出てきた注文ID（備考欄の `OH-...`）を台帳と突き合わせて決めます。

| 台帳の状態 | どうするか |
|---|---|
| 施工完了・入金済み | **承認** |
| キャンセル／エリア外／日程不成立／2回目以降／未入金 | **却下** |
| **まだ施工前・入金待ち** | **却下**。45日で自動承認されるほうが損が大きい |

> **判断がつかないものは却下してください。**
> **却下したあとに入金が確認できれば、先方に連絡すれば戻せます。**
> **自動承認されたものは戻せません。**

### CSVが手に入らなかった週

**「未点検（CSV未入手）」と正直に書いて、依頼を出し直します。黙って飛ばしません。**
定期実行の指示文にもそう書いてあります。
