# カビ特化LP用の広告グループ設計（2026-10-16 計測担当・下書き）

オーナー決定（第7回MTG・原文）「…独立してカビ特化ＬＰを別途作成して配信する…検索ワードは「エアコン　臭い」とかその周辺にして」
入稿は browser。**配信はオーナー決定済み。予算を増やす場合だけ再度オーナー承認。**

## 1. どこに作るか
- キャンペーン `検索_江戸川_段0_v2` の中に、**新しい広告グループ `A2_エアコン臭い`** を作る（地域・入札・日予算はキャンペーンのまま）
- **日予算は今の ¥5,000 の中で回す**（新しい費用枠は作らない＝オーナーの再承認は要らない）。10/13 の実測で「予算による制限」が無いので、余っている予算をこのグループが使う形になる
  - 予算による制限が出始めたら、A_エアコン（C対E）のクリックを食う。そのときは CMO が「別枠にするか」をオーナーに上げる
- **予算の注意（10/18 実測）**：今は「ランク」で負けていて、予算での取りこぼしはほぼ0%（10/13〜15）。このグループは同じ日予算 ¥5,000 を A_エアコン と分けて使うので、**始めてから3日、A_エアコン の表示が減っていないか、予算の損失率が10%を超えていないか**を browser に見てもらう。超えたら、別枠にするかを CMO がオーナーに上げる
- 着地：lp が作るカビ特化LP（URL が決まったら入れる。仮 `https://lp.onehitter.jp/aircon-f/`）。**C対E の /aircon/ には飛ばさない**（C対E の人数を混ぜないため）

## 2. 最終ページURL（計測のパラメータ）
```
https://lp.onehitter.jp/<カビLP>/?src=gads_kabi&cid={campaignid}&ag={adgroupid}
```
- `gads_kabi` は src 規約への追加が要る（web-inflow の持ち物。依頼する）
- `ag` で A_エアコン と分けられる。カビLP の lp_variant は lp が決める（F の予定）

## 3. キーワード（10/18 作り直し：検索数の実測から）
browser がキーワードプランナーで読んだ月間検索数（東京・千葉・神奈川・10/17）：
エアコン 臭い 8,100／エアコン カビ 臭い 2,400／エアコン 酸っぱい 臭い 1,300／臭い 掃除 110／臭い 業者 70／生乾き 20／暖房 臭い エアコン 10

**軸は4語（すべてフレーズ一致）**
| キーワード | 月間検索数 | ねらい |
|---|--:|---|
| "エアコン 臭い" | 8,100 | 中心。自分で直したい人も多いので、除外で絞る |
| "エアコン カビ 臭い" | 2,400 | カビと分かっている人 |
| "エアコン 酸っぱい 臭い" | 1,300 | 臭いの種類で探す人 |
| "エアコン 臭い 業者" | 70 | 頼む気がある人（少ないが、いちばん申込に近い） |

外した語：臭い 掃除（110・「エアコン 臭い」のフレーズ一致で拾える）、生乾き（20）、暖房 臭い エアコン（10）。検索が少なく、別のキーワードにしても管理が増えるだけなので。

## 4. 除外キーワード（このグループだけ・フレーズ一致）
| 除外 | 理由 |
|---|---|
| 自分で／方法／やり方／直し方／取り方／DIY | 自分で直したい人（「エアコン 臭い」の検索の多くはこれと考えられる・推定） |
| スプレー／消臭剤／洗浄剤／ハイター | 自分で使う道具を探す人 |
| 原因 | 原因を調べている段階の人（10/18 CMO 判断で除外。最初の検索語句レポートで、申込に近い語が混ざっていないか見る） |
| 車／自動車／カー | 車のエアコン（当社は対象外） |
| 冷蔵庫／洗濯機 | 別の家電 |
| 求人／バイト | 仕事探し |

キャンペーン共通の除外（他社名など）はそのまま効く。**入れて3日後に検索語句レポートを browser に読んでもらい、外れの語を足す。**

- **`docs/提示-カビ広告文-学習後.html` の見出し15本・説明文4本**（10/17 版。長雨のフック4本、うち1本を位置1に固定）

## 6. 測り方
- 申込：予約_Web の `src=gads_kabi`（予約ページ経由は `lp=<カビLP>`）
- 段別：`python3 tools/funnel-keiro.py --start <開始> --end <終了> --src gads_kabi`（予約ページ到達・入力開始・送信・申込の日別）
- 判定の線：始めてから **クリック100** で、A_エアコン と申込÷クリックを比べる。申込0件のまま100クリックなら止めて、検索語句とLPを見直す
