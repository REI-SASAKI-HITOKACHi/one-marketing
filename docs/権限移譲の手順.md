# 既存アカウントの権限を、ネット流入施策担当へ移譲する手順

> **【2026-09-11 変更・CMO指示】この手順は、オーナーのPC上の「ブラウザ担当（browser）」が画面で実施します**（`docs/org/browser-スレッド-立ち上げと最初の仕事.md` 2章）。
> **トークン類の渡し方は Google ドキュメント『ワンヒッター_認証情報（ここだけ）』1本だけ**です。下の「0. 渡し方」にある Drive ファイル分割方式は廃止しました（本文は背景資料として残しています）。
> 認証情報ドキュメントに入ったら、当スレッド（web-inflow）が Drive MCP で読み、疎通確認をして結果を CMO に返します。値はチャット・掲示板・md に出しません。

作成 2026-09-10 ／ 対象：オーナー ／ 所要：合計およそ1時間（項目ごとに分けてできます）
関連：`docs/media-構想.md` 6章、`docs/sns-90日運用案.md` 3章

> **先に、いちばん大事なこと**
>
> **パスワードやトークンを、チャットに貼らないでください。**
> 過去にサービスアカウントの鍵がチャットに貼られ、作り直しが必要になっています（`docs/cmo-savedata.md` 6章）。
> 渡し方は、この文書の「0. 渡し方」の1通りだけにします。

## 0. 渡し方（全項目共通）

この担当（`web-inflow`）は**クラウド上で動いていて、ブラウザで画面を操作できません。**
だから「IDとパスワード」をもらっても使えません。**使えるのはAPIのトークン・鍵・権限付与だけ**です。

**トークン類は、Googleドライブのファイルに入れて渡してください。** すでに `Netlify_トークン` をこの形で渡していただいています。

```
1. Googleドライブに「認証情報」フォルダを1つ作る（既にあればそれを使う）
2. 共有設定は「制限付き」のまま（リンクを知っている人全員には絶対にしない）
3. 項目ごとに1ファイル。ファイル名は下の表のとおり
4. こちらが Drive API で読み取ります。読み取ったら、チャットには一切出しません
```

| ファイル名 | 中身 |
|---|---|
| `Meta_Instagramトークン` | 2章で発行する長期アクセストークンと、InstagramアカウントID |
| `Meta_Facebookページトークン` | 3章のページアクセストークンと、ページID |
| `YouTube_OAuth` | 4章のクライアントIDとシークレット、リフレッシュトークン |
| `Netlify_トークン` | **既に渡していただいています**（有効期限 2026/12/31） |
| `Anthropic_APIキー` | 5-2章で発行するClaude APIのキー（案Aの判定用。**2026-09-10 承認済み**） |

## 1. 【完了（2026-09-11、ブラウザ担当）】Instagram `@onehitter.jp`（所要 15分）

### 1-1. プロアカウントに切り替える（個人アカウントのままなら）

スマホのInstagramアプリで：

```
1. プロフィール → 右上 ≡ → 設定とプライバシー
2. アカウントの種類とツール → プロアカウントに切り替える
3. 「ビジネス」を選ぶ（クリエイターではなく）
4. カテゴリは「ハウスクリーニング」または「清掃サービス」
```

**これをしないとインサイト（保存数・プロフィールアクセス）が取れず、APIでの投稿もできません。**

### 1-2. Facebookページとリンクする

```
5. 設定とプライバシー → アカウントセンター → アカウント → 追加 → Facebook
6. 「One Hitter」ページの管理者であるFacebookアカウントでログイン
7. プロフィール → プロフィールを編集 → ページ → 「One Hitter」を選ぶ
```

### 1-3. Meta開発者アプリを作り、長期トークンを発行する

PCのブラウザで https://developers.facebook.com/ を開きます。

```
8.  右上「マイアプリ」→「アプリを作成」
9.  ユースケース：「Instagramでコンテンツを管理する」系を選ぶ（表記はMeta側で変わることがあります）
10. アプリ名：「onehitter-media」など。連絡先メールはオーナーのもの
11. 作成後、左メニューの「Instagram」→「APIセットアップ（Instagramログイン）」
12. 「Instagramアカウントを追加」で @onehitter.jp をログインして追加
13. 同じ画面の「アクセストークンを生成」を押す
    → 出てきた文字列（EAA… で始まる長い文字列）が長期トークン。
    → 同じ画面に出る「InstagramアカウントID」（数字）も控える
14. その2つを、Driveの `Meta_Instagramトークン` に貼る
```

- **アプリは「開発モード」のままで構いません。** 自分のアカウントへ投稿するだけなら、Metaの審査は不要です
- 長期トークンの有効期限は**60日**です。期限前に自動で更新する仕組みをこちらで組みます。**更新に失敗したときだけ**、再発行をお願いします
- APIでの投稿は1日あたりの上限があります（公式ドキュメント上は50件・2025年時点）。運用は週2本なので影響しません

## 2. 【完了（2026-09-11、ブラウザ担当）】Facebook「One Hitter」ページ（所要 5分。1章の続きでできます）

```
1. 1-3のアプリの左メニュー → 「アプリに製品を追加」→ 「Facebookログイン」
2. 「ツール」→「グラフAPIエクスプローラ」
3. 右側「ユーザーまたはページ」→ 「One Hitter」ページを選ぶ
4. 権限に pages_manage_posts / pages_read_engagement を追加 → 「Generate Access Token」
5. 出てきたトークンとページIDを、Driveの `Meta_Facebookページトークン` に貼る
```

Instagramの投稿を、こちらがAPIでFacebookページにも出します（アプリ内の「Facebookにもシェア」は手動なので使いません）。

**確認したいこと：** Facebookページの現在のURLは `facebook.com/people/One-Hitter/100084190801350/` で、
**独自のユーザーネームが未設定**の形です。ページ設定から `@onehitter.jp` のようなユーザーネームを付けると、
URLが短くなり、サイトやInstagramから貼りやすくなります（任意。1分）。

## 3. Googleビジネスプロフィール（所要 10分＋Googleの審査待ち）

**ここはトークンを渡す必要がありません。既存のサービスアカウントを「管理者」に追加するだけです。**

### 3-1. サービスアカウントを管理者に追加

https://business.google.com/ にログインして：

```
1. 「ワンヒッター㈱」のプロフィールを開く
2. 「ビジネスプロフィールの設定」→「ユーザーとアクセス権」→「追加」
3. メールアドレスに次を入れる
     claude-sheets@one-hitter-sheets.iam.gserviceaccount.com
4. 権限は「管理者」
```

### 3-2. Business Profile API の利用申請

GBPのAPIは、Googleに申請してプロジェクト単位で承認されないと使えません。

```
5. https://developers.google.com/my-business/content/prereqs の案内にある申請フォームを開く
6. プロジェクトID：one-hitter-sheets（番号 844550773178）
7. 用途：「自社のビジネスプロフィールへの投稿と写真の追加、パフォーマンス指標の取得」
8. 送信。承認まで数日〜数週間かかることがあります
```

- 承認が下りるまでは、GBPの投稿は**こちらが原稿を作り、オーナーが貼る**運用になります
- サービスアカウントの追加がうまくいかない場合は、OAuth（オーナーのGoogleアカウントで1回同意）に切り替えます。その場合は改めて手順を出します

### 3-3. ついでに直せるもの（`docs/gbp-audit.md`。各1〜2分）

```
9.  ビジネス説明を貼る（文案は docs/gbp-audit.md にあります）
10. 営業時間を 8:00〜20:00 に
11. 屋号を「ワンヒッター株式会社」に
```

## 4. YouTube（所要 15分。Shortsを出す場合のみ）

```
1. https://www.youtube.com/ に、会社用のGoogleアカウントでログイン → チャンネルを作成
2. https://console.cloud.google.com/ → プロジェクト one-hitter-sheets を選ぶ
3. 「APIとサービス」→「ライブラリ」→ YouTube Data API v3 を有効化
   （サービスアカウントに Service Usage 管理者があるので、ここはこちらでもできます）
4. 「認証情報」→「認証情報を作成」→「OAuthクライアントID」→ 種類「デスクトップアプリ」
5. クライアントIDとシークレットを控える
6. こちらが出す「同意URL」を1回開いて許可 → 出てきたコードをDriveの `YouTube_OAuth` に貼る
```

**注意：** Googleの審査を受けていないアプリからアップロードした動画は、**自動的に「非公開」に固定されます**（2020年〜のポリシー）。
公開で出すには、OAuth同意画面の審査申請が要ります。**最初は非公開でアップロードし、公開はオーナーが画面で切り替える**運用にします（週1回のまとめ承認と同じタイミングでできます）。

## 5. 新メディア用のドメインとサイト（所要 10分。`docs/media-構想.md` 5-1）

**ドメインの取得はお金の判断です。** 承認いただいたら：

```
1. ドメインを取得（年1,500〜3,000円程度。お名前.com / ムームードメイン / Cloudflare 等）
2. ドメインのネームサーバーを Netlify DNS に向ける（Netlify側の値はこちらが出します）
3. 以後の配信・更新はすべてこちらが Netlify API で行います（既存トークンで足ります）
```

- `one-hitter.jp` のサブドメインは使いません。**9/30の期限が未更新で、DNSがネームギアにあり、オーナーが未ログイン**という状態なので、そこに依存させると装置ごと止まります

## 6. 公式サイト one-hitter.jp について

**このサイトは LP・サイト担当（`lp`）の持ち物です。** 当担当には移譲しないでください。
CMSのログインとロリポップの権限は、**CMOの判断で `lp` へ**渡してください。
当担当は「サイトにSNSリンクを置く」「施工事例を新メディアと同期する」を、`lp` への依頼として出します。

## 7. 渡していただいた後、こちらがやること

| 受け取ったもの | こちらがすぐやること |
|---|---|
| Instagramトークン | 疎通確認（プロフィール取得）→ フォロワー数・投稿数・最終投稿日を `docs/sns-90日運用案.md` の「未確認」に埋める → トークン自動更新の仕組み |
| Facebookページトークン | 疎通確認 → フォロワー数・最終投稿日を埋める |
| GBP管理者追加 | API承認待ちの間に、投稿原稿と写真10枚を用意 |
| YouTube OAuth | 非公開アップロードのテスト1本 |
| 新ドメイン | Netlifyに新サイトを作成・SSL・`docs/media-構想.md` 7章の試作を配信（非公開URL） |
