> **2026-09-13 追加のオーナー決定**

> **この文書の結論を1行で。**
> 人を1名増やすと損益分岐点は **約1,830万円** に上がる。2026年並みの利益（約481万円）を残すには **約2,460万円** が要る。

### ① 保守 2,000万 ── 回避すべき着地。落ちたら固定費を軽くして守る

**どういう年か**
自社ネット新規が月5件どまり。提携は現2社の深耕のみで3社目が決まらない。
新戦力は、既存の取りこぼしとマッチングPFの件数消化に充てる年になります。

| | |
|---|---|
| 人員の使い方 | 新人は**本舗案件とマッチングPFを中心に配置**（教育コストが低く、稼働が読める）。和真さんは自社の高単価案件と次回予約に専念 |
| 広告 | **年25万。**1〜2月に月5万でテスト → 成果が出なければ月1〜2万の維持に落とす |
| 協力業者 | **完全歩合（案A）のみ。**閑散期に支払いが発生しない形にする。年間約50件 |
| 打ち手 | 早期予約15%割引の徹底、SMS/LINE再販、本舗案件の取りこぼし回収 |

**年間では黒字（経常利益190万）。ただし 2月・8月・9月・12月 の4か月が赤字になります。**
年間の利益は2026年より約291万減るので、ここに落ちたら固定費を削りにいきます。

| 手段 | 効果 | 備考 |
|---|---:|---|
| 新規正社員の入社を3月→5月に2か月遅らせる | **+69万** | 繁忙期(5〜7月)には間に合う。ただしQ1の空き枠は埋まらない |
| HP関連費の見直し（HPローン22,000＋HITOWA HPC 22,000＋保守4,400／月） | **最大 +58万** | HP経由売上は年63,100円。2027年中に回収できなければ契約を見直す |
| 協力業者を案B（メニュー固定単価）に変える | **+13万** | §6参照。50件規模なので効果は小さい |
| 賠償保険・通信・ソフトの棚卸し | +10〜20万 | 月159,708円の経費のうち、重複や使っていないものを外す |

> **赤字月そのものは問題ではありません。**2026年も2月は経常利益 50,401円でした。
> 問題は**資金繰り**で、和真さんの報酬50万と新人の給与が毎月固定で出ていくため、
> 保守に落ちると2月・8月・9月・12月に現金が減ります。**上の2つで年127万を確保すれば、赤字月は2月だけに戻せます。**

### ② 中立 2,600万 ── 計画どおりに施策が効いた年

**どういう年か**
自社ネット新規が月12件に乗る。提携3社目が成約する。
新人が6月に独り立ちし、繁忙期を協力業者で吸収できた場合。

| | |
|---|---|
| 人員の使い方 | 新人は3〜5月にOJT、**6月から独り立ち**。和真さんと2枚看板で自社案件を取る |
| 広告 | **年80万。**1〜2月テスト → 3〜4月に増額 → 5〜7月の繁忙期に月12万 → 年末に月7万 |
| 協力業者 | 年間約100件。繁忙期のピークと遠方（千葉・神奈川）案件を回す |
| 打ち手 | 台帳957名へのクロスセル（換気扇807名・浴室780名）、施設ターゲット291件、空室清掃（2〜3月） |

**経常利益 585万。2026年の 481万 を上回ります（+104万）。**
2026年並みの利益を残すラインが 2,460万なので、**中立2,600万はその上**。
つまり中立は「投資を回収して、ようやく増益の入口に立つ」水準です。ここを下回ると減益になります。
赤字になるのは**2月だけ**（▲4.2万）。

### ③ 攻め 3,200万 ── 自社の入口が機能した年

**どういう年か**
自社ネット新規が月16件。提携が6社に増え、法人・施設が売上の柱になる。
2025年実績の2倍。ここに到達して初めて「スケールが加速した」と言えます。

| | |
|---|---|
| 人員の使い方 | 自社チーム2名は**高単価案件（法人・セット・水回り）に専念**。低単価と遠方は全部外に出す |
| 広告 | **年100万。**5〜7月に月15万、10〜11月に月10万。CPA 9,500円を割っている限り加速 |
| 協力業者 | 年間約180件。3社では足りなくなる可能性があるので、**Q2終了時点で4社目の要否を判定** |

**② 法人・提携（単価が桁違い）**

## 11. 推奨と、運用のしかた

### 推奨

1. **正式な予算は「中立 2,600万円」を必達、「攻め 3,200万円」を目標として置く。**
   保守2,000万円は予算ではなく、四半期ゲートの警戒ラインとして使います。
2. **2027年の成否は、④自社ネット新規が月12件に乗るかどうかでほぼ決まります。**
   ①②③を全部うまくやっても、④が今のまま（月0.6件）なら 2,460万円（2026年並みの利益を残すライン）に届きません。
3. **1〜2月に手を打つ。** 年間で最も薄い時期（2026年2月は売上613,260円・経常利益50,401円）に
   新しい人件費が乗ります。早期予約15%割引と空室清掃の営業を、正社員の入社より先に走らせます。
4. **協力業者3社は「安く回す先」ではなく「ピークを取りこぼさないための保険」として設計する。**
   支払率を下げに行くと品質が落ち、★5.0が崩れて入口が止まります。

### 運用 ── 1月〜2月の実績で、その年がどこに着地するかが読める

| 見るもの | 保守へ | 中立へ | 攻めへ |
|---|---|---|---|
| 広告テスト（月5万）のCPA | 9,500円超 | 9,500円以下 | 9,500円を大きく下回る |
| 自社ネット新規の月間件数 | 5件未満 | 8〜12件 | 13件以上 |
| 提携3社目の商談 | 動いていない | 商談中 | 成約 |
| 早期予約15%割引への反応 | 前年並み | 前年比+30% | 前年比+50% |

**3月末のゲートで、その年の着地見込みを確定させます。** 中立に届いていなければ、
そこから先は保守の組み方（人員配置・広告の段・外注）へ切り替えます。

### 着地の見込みごとに、先に決めておくこと

| | 決めておくこと |
|---|---|
| **保守に落ちたとき** | ①新規正社員の入社を5月に遅らせるか（+70万）②HP関連費を見直すか（最大+58万）。**この2つを3月末までに判断できる状態にしておく** |
| **中立で進むとき** | 協力業者3社の稼働配分。繁忙期に何件まで回せるか |
| **攻めに乗ったとき** | **Q2終了時点で4社目の要否を判定。** キャパが774件でほぼ埋まるため |

なお**広告は年額ではなく段で管理します**（§5）。CPA 9,500円を超えたらその月で止め、
下回っている限り加速する。年額 25万／80万／100万 は、その結果として出てくる数字です。
