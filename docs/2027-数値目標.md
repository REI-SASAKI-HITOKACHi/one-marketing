# 2027年 数値目標（保守・中立・攻め）

作成: 2026-09-13 ／ 作成者: 経営企画室（`planning`）
前提: **2027年3月までに正社員1名を追加、協力業者3社を確保**（オーナー指示 2026-09-13）

> **この文書の結論を1行で。**
> 人を1名増やすと損益分岐点は **約2,150万円** に上がる。2026年並みの利益を残すには **約2,880万円** が要る。
> つまり **「保守」は目標ではなく、回避すべき着地**。実質の必達は中立2,600万、狙うのは攻め3,200万。
> ただし保守に落ちる可能性はあるので、**そのときコスト側で何をするか**まで書いてある（§3-①）。
> 3本とも、それぞれに合った人員の使い方・広告の出し方・外注の組み方をセットで置いた。

ただし現実に保守へ落ちることはあるので、**そのときコスト側で何をするか**を §3-① に書いています。

### ① 保守 2,000万 ── 回避すべき着地。落ちたら固定費を軽くして守る

**どういう年か**
自社ネット新規が月5件どまり。提携は現2社の深耕のみで3社目が決まらない。
新戦力は、既存の取りこぼしとマッチングPFの件数消化に充てる年になります。

| | |
|---|---|
| 人員の使い方 | 新人は**本舗案件とマッチングPFを中心に配置**（教育コストが低く、稼働が読める）。和真さんは自社の高単価案件と次回予約に専念 |
| 広告 | **年25万。**1〜2月に月5万でテスト → 成果が出なければ月1〜2万の維持に落とす |
| 協力業者 | **完全歩合（案A）のみ。**閑散期に支払いが発生しない形にする。年間約50件 |
| 打ち手 | 早期予約15%割引の徹底、SMS/LINE再販、本舗案件の取りこぼし回収 |

**そのままだと赤字（▲90万）。黒字にするには固定費を90万下げる。**

| 手段 | 効果 | 備考 |
|---|---:|---|
| 新規正社員の入社を3月→5月に2か月遅らせる | **+70万** | 繁忙期(5〜7月)には間に合う。ただしQ1の空き枠は埋まらない |
| HP関連費の見直し（HPローン22,000＋HITOWA HPC 22,000＋保守4,400／月） | **最大 +58万** | HP経由売上は年63,100円。2027年中に回収できなければ契約を見直す |
| 協力業者を案B（メニュー固定単価）に変える | **+20万** | §6参照。50件規模なら効果は小さい |
| 賠償保険・通信・ソフトの棚卸し | +10〜20万 | 月159,708円の経費のうち、重複や使っていないものを外す |

> **上の2つ（入社時期＋HP関連費）だけで +128万。保守でも黒字（約+38万）に載せられます。**
> 保守を予算として置くなら、**この2つをセットで決めておくこと**が条件になります。

### 設計の考え方

**① 自社リピート資産（獲得コストほぼゼロ）**
957名の台帳がすべて。12ヶ月以上ご無沙汰583名、換気扇未購入807名、浴室未購入780名。
SMS・公式LINE・アンケート・次回予約割引で回す。リピート率（2回以上）を **25% → 27%／30%／34%** へ。
2025年12月の実績「1年以上前の顧客へ15件架電 → 成約0」があるので、**電話ではなく施工7日後のSMS/LINE**で、季節に合ったメニューを出す形にする。

**② 法人・提携（単価が桁違い）**
業務提携の平均単価は100,128円、LTV 186,272円、リピート率45%。法人の平均LTV 175,527円は個人の3.9倍。
**提携先を2社 → 3社／4社／6社へ。** 施設ターゲットリスト291件（web-inflow が作成済み）と、不動産管理会社の空室清掃（相手の繁忙期2〜3月＝当社の閑散期）が入口。
冷たいテレアポは使わない（40件→0アポ、140件→0アポの実績あり）。

**③ マッチングPF（増やさない）**
手数料35%・リピート率2%。**戦略的に据え置く。** 件数を増やしても資産にならない。
協力業者に回して自社チームの枠を空け、単価の高い①②④に充てる。

**④ 自社ネット新規（ここが勝負）**
2026年は年7件・13万円。ここを **月5件／月12件／月16件** に上げる。
すでに道具は揃っている ── LP3本＋年末LP、予約フォーム（yoyaku.onehitter.jp）、公式LINE（友だち330人）、GBP（★5.0・24件）、アフィリエイト（レントラックス・成果3,000円）、読本サイト、SNS週5本、ブログ週1本。
**広告の獲得単価(CPA)の上限は9,500円**（マッチングPFに払っている実質手数料と同額）。この範囲なら出すほど有利。
なお2026年の年末計画では「ネット経由 月25件」を12月の到達点に置いていた。**攻めシナリオの月16件でも、その目標より控えめ**。

**⑤ その他**
チラシ単独配布は再開しない（週2,000枚で反応0の実績）。

### 名義（自社／おそうじ本舗）の構成を変える

2026年1〜8月の売上種類別：**自社152件・7,960,978円（単価52,374円）／本舗131件・3,691,083円（単価28,176円）。**
自社単価は本舗の **1.86倍**、さらに本舗にはロイヤリティ **27.6%** がかかる。

|---|---:|---:|---:|---:|
| 本舗経由の売上比率 | 31.7% | 28% | 22% | 17% |

**本舗の件数を減らすのではなく、自社の件数を増やして比率を下げる。**
本舗のお客様への営業は、引き続きおそうじ本舗として行う（`docs/org/README.md` 4.5）。

## 5. 広告の出し方（3パターン）

**方針はオーナー確認済み（2026-09-13）：小さく試して、成果が出たら加速する。**
だから年額を先に決めるのではなく、**段（ステップ）と、次の段へ上がる条件**を先に決めます。

### 共通のルール

| | |
|---|---|
| 上限 | **獲得単価（CPA）9,500円。** マッチングPFに払っている実質手数料と同額。ここを下回る限り、出すほど有利 |
| 止める条件 | **月次でCPAが9,500円を超えたら、その月で止める。次の段へ上がらない** |
| 上げる条件 | 2か月連続でCPA 9,500円以下、かつ受注が実際に付いている |

| 出さない | レントラックスとの関係上、**指名検索への出稿はしない**（先方へ申し入れ中） |

| 3（年末） | 7〜10万 | 段2をクリア。10〜11月に当てる |

### 3パターンの年額

| 時期 | ① 保守 | ② 中立 | ③ 攻め |

## 11. 推奨と、運用のしかた

### 推奨

1. **正式な予算は「中立 2,600万円」を必達、「攻め 3,200万円」を目標として置く。**
   保守2,000万円は予算ではなく、四半期ゲートの警戒ラインとして使います。
2. **2027年の成否は、④自社ネット新規が月12件に乗るかどうかでほぼ決まります。**
   ①②③を全部うまくやっても、④が今のまま（月0.6件）なら 2,150万円に届きません。
3. **1〜2月に手を打つ。** 年間で最も薄い時期（2026年2月は売上613,260円・経常利益50,401円）に
   新しい人件費が乗ります。早期予約15%割引と空室清掃の営業を、正社員の入社より先に走らせます。
4. **協力業者3社は「安く回す先」ではなく「ピークを取りこぼさないための保険」として設計する。**
   支払率を下げに行くと品質が落ち、★5.0が崩れて入口が止まります。

### 運用 ── 1月〜2月の実績で、その年がどこに着地するかが読める

| 見るもの | 保守へ | 中立へ | 攻めへ |
|---|---|---|---|
| 広告テスト（月5万）のCPA | 9,500円超 | 9,500円以下 | 9,500円を大きく下回る |
| 自社ネット新規の月間件数 | 5件未満 | 8〜12件 | 13件以上 |
| 提携3社目の商談 | 動いていない | 商談中 | 成約 |
| 早期予約15%割引への反応 | 前年並み | 前年比+30% | 前年比+50% |

**3月末のゲートで、その年の着地見込みを確定させます。** 中立に届いていなければ、
そこから先は保守の組み方（人員配置・広告の段・外注）へ切り替えます。

### 着地の見込みごとに、先に決めておくこと

| | 決めておくこと |
|---|---|
| **保守に落ちたとき** | ①新規正社員の入社を5月に遅らせるか（+70万）②HP関連費を見直すか（最大+58万）。**この2つを3月末までに判断できる状態にしておく** |
| **中立で進むとき** | 協力業者3社の稼働配分。繁忙期に何件まで回せるか |
| **攻めに乗ったとき** | **Q2終了時点で4社目の要否を判定。** キャパが766件でほぼ埋まるため |

なお**広告は年額ではなく段で管理します**（§5）。CPA 9,500円を超えたらその月で止め、
下回っている限り加速する。年額 25万／80万／100万 は、その結果として出てくる数字です。
