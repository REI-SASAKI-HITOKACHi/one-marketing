中立2,600万は、その2,630万にわずかに届きません。**つまり中立は「売上を5割伸ばして、利益は横ばい」。**
増えた分はほぼそのまま人と協力業者に出ていきます。**利益を増やすには 2,630万を超えるか、協力業者の支払条件を詰めるか。**

### ① 保守 2,000万 ── 回避すべき着地。落ちたら固定費を軽くして守る

**どういう年か**
自社ネット新規が月5件どまり。提携は現2社の深耕のみで3社目が決まらない。
新戦力は、既存の取りこぼしとマッチングPFの件数消化に充てる年になります。

| | |
|---|---|
| 人員の使い方 | 新人は**本舗案件とマッチングPFを中心に配置**（教育コストが低く、稼働が読める）。和真さんは自社の高単価案件と次回予約に専念 |
| 広告 | **年25万。**1〜2月に月5万でテスト → 成果が出なければ月1〜2万の維持に落とす |
| 協力業者 | **完全歩合（案A）のみ。**閑散期に支払いが発生しない形にする。年間約50件 |
| 打ち手 | 早期予約15%割引の徹底、SMS/LINE再販、本舗案件の取りこぼし回収 |

**年間では黒字（経常利益153万）。ただし 2月・8月・9月・12月 の4か月が赤字になります。**
年間の利益は2026年より約375万減るので、ここに落ちたら固定費を削りにいきます。

| 手段 | 効果 | 備考 |
|---|---:|---|
| 新規正社員の入社を3月→5月に2か月遅らせる | **+69万** | 繁忙期(5〜7月)には間に合う。ただしQ1の空き枠は埋まらない |
| HP関連費の見直し（HPローン22,000＋HITOWA HPC 22,000＋保守4,400／月） | **最大 +58万** | HP経由売上は年63,100円。2027年中に回収できなければ契約を見直す |
| 協力業者を案B（メニュー固定単価）に変える | **+13万** | §6参照。50件規模なので効果は小さい |
| 賠償保険・通信・ソフトの棚卸し | +10〜20万 | 月159,708円の経費のうち、重複や使っていないものを外す |

> **赤字月そのものは問題ではありません。**2026年も2月は経常利益 50,401円でした。
> 問題は**資金繰り**で、和真さんの報酬50万と新人の給与が毎月固定で出ていくため、
> 保守に落ちると2月・8月・9月・12月に現金が減ります。**上の2つで年127万を確保すれば、赤字月は2月だけに戻せます。**

## 11. 推奨と、運用のしかた

### 推奨

1. **正式な予算は「中立 2,600万円」を必達、「攻め 3,200万円」を目標として置く。**
   保守2,000万円は予算ではなく、四半期ゲートの警戒ラインとして使います。
2. **2027年の成否は、④自社ネット新規が月12件に乗るかどうかでほぼ決まります。**
   ①②③を全部うまくやっても、④が今のまま（月0.6件）なら 2,630万円（2026年並みの利益を残すライン）に届きません。
3. **1〜2月に手を打つ。** 年間で最も薄い時期（2026年2月は売上613,260円・経常利益50,401円）に
   新しい人件費が乗ります。早期予約15%割引と、休眠している提携先8社の掘り起こしを、正社員の入社より先に走らせます。
   **単価の安い仕事で埋めにいくことはしません**（薄利どころか逆鞘になる）。
4. **協力業者3社は「安く回す先」ではなく「ピークを取りこぼさないための保険」として設計する。**
   支払率を下げに行くと品質が落ち、★5.0が崩れて入口が止まります。

## 12. 2028〜2030年のシミュレーション（2027年を達成できた場合）

**オーナー指示 2026-09-14：「この水準を来年達成できることで、その翌年以降は同レベルのリピーターを
確保することで大幅に伸ばせると睨んでる」。それを数字にしたもの。**

ロジックは §1〜§11 から一切変えていません。動かした前提は3つだけです。

| 前提 | 保守的 | 中 | 良 |
|---|---:|---:|---:|
| 自社で獲った新規のリピート率 | 30% | **36%**（実測値） | 40% |
| 自社ネット新規（2030年・月） | 18件 | 28件 | 36件 |
| アクティブな提携先（2030年） | 18社 | 24社 | 27社 |

**本舗案件は3年とも390万で据え置き**（伸ばさない前提は変えていません）。

### 積み上げの式

> **①（翌年の自社リピート資産）＝ 前年の① × 0.90 ＋ 前年の④自社ネット新規 × リピート率 × 1.13**

- **0.90** … 既存リピート層の自然減を10%と置いた（仮置き）
- **リピート率 36%** … 自社直販の実測値（1〜6月施工に絞った再計算。`docs/流入経路の分析.md`）
- **1.13** … 2026年のリピート平均単価 45,374円 ÷ 全体平均 40,062円。一度使った人はセットで頼む

必要人員はキャパから逆算（1人あたり年間380件。2026年に和真さん1人で469件をこなしている実績から）。

### 結果

| 年 | 保守的 売上／経常 | 中 売上／経常 | 良 売上／経常 |
|---|---:|---:|---:|
| 2027年（計画） | 2,600万／**507万** | 2,600万／**507万** | 2,600万／**507万** |
| 2028年 | 2,911万／**586万** | 3,295万／**810万** | 3,576万／**975万** |
| 2029年 | 3,202万／**806万** | 4,068万／**823万** | 4,635万／**1,190万** |
| 2030年 | 3,502万／**1,032万** | 4,852万／**1,414万** | 5,808万／**2,055万** |

| 2030年時点 | 保守的 | 中 | 良 |
|---|---:|---:|---:|
| 施工件数 | 844件 | 1,128件 | 1,305件 |
| 社員（和真さんを含む） | 2人 | 3人 | 3人 |
| 本舗案件が売上に占める割合 | 11% | 8% | 7% |

### 読み方

1. **やがて利益の伸びが売上の伸びを追い越す。** 中・良は2028年から、保守的でも2029年から
   （保守的の2029年は売上+10%に対し利益+38%）。リピートは獲得コストがゼロだから
2. **いちばん控えめに見ても、3年で経常利益は2026年の2.0倍**（1,032万 vs 528万）
3. **利益が踊り場になる年がある。** 中の2029年は売上+23%なのに利益+2%。3人目を入れる年だから。
   翌年に戻る（中の2030年は+72%）
4. **本舗比率は放っておいても下がる。** 2027年15% → 2030年で7〜11%

**計算は `tools/plan2027.py` の `chouki()`。** `--案` ではなく Python から呼ぶ形。

> ⚠️ **これは約束の数値ではありません。** 2027年の計画を達成できた場合の見通しです。
> 和真さん向け資料でも「約束するのは2027年3月末・9月末の2つだけ」と明記しています。
