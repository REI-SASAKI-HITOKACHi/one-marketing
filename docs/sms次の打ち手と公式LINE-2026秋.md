## 🔴 ただし結論は「良いセグメントに送れ」ではありません。**もう残っていません**

**返信率18.8%の層（リピーター×昨年同期）は16名送って、もう未送信0です。完売しました。**
**残っているのは、実測でいちばん弱い組み合わせだけです。**

## だから、決めること3つ

### ① **D_その他の18名には送らない**
**21名に送って返信0。** 見込みが無いと実測で分かっている唯一の層です。¥594 は小さいですが、
**「効かないと分かっているものを送らない」を1回やっておく**ほうが後で効きます。

### ② 残り300名は送る。**ただし期待値を先に言っておきます**
| | |
|---|---:|
| 費用 | 300名 × 3通 × 11円 = **¥9,900** |
| 返信の期待値（本舗の実測1.4%） | **約4件** |
| 受注の期待値（返信8件→受注1件の実績） | **0〜1件** |

**¥9,900 で受注0〜1件。** 止める理由にはなりませんが、**ここに次の期待をかけないでください。**

### ③ **次の玉はSMSの外です**
| | 1件あたり |
|---|---:|
| SMS の受注（実績1件） | **¥9,702** |
| 休眠提携先8社（`20260921-01-crm`） | **1件平均 ¥94,051** |

**桁が1つ違います。** SMSは「安いから回す」もので、**年末の穴を埋める玉ではありません。**

## 「何を言うか」を選ばなかった理由

**自社8.0% vs 本舗1.4%** という大きな差はありますが、**自社と本舗は文面も宛先も両方違う**ので、
**文面の差なのか宛先の差なのか分けられません。** 根拠として使えません。
**セグメント差（同じ自社の文面で 0%〜18.8%）は宛先だけが違うので、こちらは使えます。**
