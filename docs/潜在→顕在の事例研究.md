# 他業界の「潜在ニード → 顕在化（顧客化）」事例研究と、ハウスクリーニングへの転用

作成 2026-09-11 ／ 担当 ネット流入施策担当（`web-inflow`）／ オーナー指示「他業界の事例を徹底的に調査し、転用できる観点を報告」
**数字はすべて、取得した一次資料（有価証券報告書・10-K・官公庁・企業公式・業界団体）に書かれていたものだけ。取れなかったものは「未確認」。**
事例の詳細（出典URL・取得日）は調査3本の原文を末尾に付す。ここでは結論と転用に絞る。

---

## 0. 結論を先に

**潜在ニードを顧客に変えた勝者は、「メディア」で変えていない。** 3つの型のどれかで変えている。

| 型 | 何が起きるか | 代表例（数字） |
|---|---|---|
| **① 自分のことを無料で知る** | 買う気のない人が「自分の家・体・資産」を知りたくて来る。証拠（数字・写真）を本人が見た瞬間に、提案を受け入れる | Zillow：無料査定を1.73億戸に、年96億訪問、成約時に不動産業者が支払う／Credit Karma：無料スコアで1.4億会員、売上$22.6億／ほけんの窓口：**来店客の成約率55%**／アサンテ：シロアリ無料点検 年1.14万件、保証中顧客16万軒／レイコップ：無料貸出→購入転換 **7割** |
| **② 他人の「その瞬間」のレジで売る** | 別の買い物・契約・出産・入居の瞬間に、その瞬間専用の商品を、売り手のレジで同時に売る。紹介元には成功報酬 | アニコム：新規契約の**約7割がペットショップでの購入と同時**、代理店4,986店／Handy×Walmart：家具購入の会計で設置を同時販売／Amazon.co.jp：設置は「商品と同時のみ・後から追加不可」／東京ガス：既存の請求接点に乗せて4年で9万件／カジタク：「店で買えるチケット」で累計540万件 |
| **③ 名前・映像・暦で「気になる」を作り、周期にする** | 見えないものに名前と映像を与え、権威が推奨サイクルを宣言し、暦に紐づける | 加齢臭（1999・資生堂命名）／ミドル脂臭（2013・マンダム）→ルシード売上+60%／レイコップ：ダニの見える化で国内490万台／洗濯槽クリーナー：「黒く濁る液」と「年1回」の宣言／8020運動：達成率7%→61.5%（**35年**）／メーカーの「4/10試運転の日」「5/5エアコンの日」 |

そして、**この業界で最大の、数字で確認できる空白**がこれです。

> **エアコンをプロに頼みたい人 59.8% ／ 実際に頼んだ人 7.5%。**（ダスキン 大掃除調査 2025、n=4,160）
> 「依頼したことがない」44.8%（ミツモア 2024、n=692）。踏み出せない理由は「費用」「他人が家に入る抵抗」「感染症」（マイナビ 2023）。

つまり、この業界の「潜在」は、**掃除に興味のない人ではなく、「頼みたいのに踏み出せない人」**です。
3つの型は、まさにこの「踏み出せない」を崩す仕組みでした。転用先はここにあります。

## 1. 型①「自分のことを無料で知る」— 診断・測定・窓口

| 事例 | 入口（無料で渡すもの） | 顕在化の瞬間 | 誰が払う | 数字（一次） |
|---|---|---|---|---|
| Zillow Zestimate（米） | 自宅の推定価格 | 価格を見て売買を考え始め、業者に接続 | 不動産業者（成約時の成果報酬 or 郵便番号ごとの枠購入） | 1.73億戸・年96億訪問・売上$26億（10-K 2025） |
| Credit Karma（米） | 信用スコア | スコアに合う商品が提示され申込 | 金融機関（cost-per-action） | 会員1.4億・売上$22.6億（Intuit 10-K 2025） |
| ほけんの窓口 | 中立の相談（平均2時間） | 相談の場で契約 | 保険会社（販売手数料。生保27社・損保16社） | 成約率55%・相談81万件・683店（ポーター賞2018／VALUE REPORT 2025） |
| SUUMOカウンター | 無料相談・建築会社紹介・**10分相談** | 数社紹介→展示場案内。**断り代行**まで | 建築会社（公式は403で一次未確認） | 「何となく家が欲しい」層が「そのようなお客様のほうが多い」（公式ブログ） |
| エネチェンジ | 電気代の比較 | サイト上で切替申込 | 電力・ガス会社（一時報酬＋料金連動の継続報酬） | ユーザー65万件・切替手数料相場2%（決算資料） |
| JINS／眼鏡市場／資生堂／アシックス／西川 | 視力・肌・足・眠りの測定（無料・数分〜30分） | その場で「あなた向け」の提案 | 本人（商品購入） | 効果の数字は各社非公開 |
| アサンテ／サニックス／ダスキン ターミニックス | シロアリ無料床下点検＋**写真つき報告書を全員に** | 報告書を見て施工 | 本人（施工のみ有料）。施工後は年1回無料点検で周期化 | アサンテ 申込調査1.14万件/年・保証中16万軒 |
| 予防歯科（8020・リコール） | 定期検診 | 治療→予防へ需要の転換 | 本人・保険 | 達成率7%→61.5%、受診率63.8%（厚労省2024）。**35年かかった** |
| レイコップ | 無料貸出・体験会 | 布団から出るダニ・ホコリを見る | 本人 | 貸出→購入 **7割**（社長談・BCN）、国内490万台 |

**共通する仕組み（一次資料から）**
1. 入口は「買う」ではなく「知る」。SUUMOのアドバイザーは「何となく」の客が多数と明言
2. 顕在化は「本人が証拠を見た瞬間」。誤差1.8%の推定価格、28項目の測定、床下写真、動く細菌（歯科の位相差顕微鏡）
3. 診断そのものに値札を付けない。払うのは提案先の事業者か、施工に進んだ本人
4. **「やらない」を見せることが中立性の代替**。ダスキン「対策の必要がある場合のみ提案」、SUUMO「断り代行」
5. **押し売り型は規制対象**。「点検商法」の相談は年約2万件（国民生活センター2025）、東京都はシロアリ無料点検業者に6か月の業務停止命令（2021）。**入口はプル型（本人が申し込む）に限る**

| 東京ガス／大阪ガス | 毎月の請求接点・会員特典 | ハウスクリーニング（大阪ガスは「提携先スタッフが施工」「会員10%割引」） | 提携先へ手数料（非開示） | 東京ガス 4年で9万件超（2025-04） |

| 引越し会社／管理会社 | 引越し見積（「エアコンを外せる数少ないチャンス」）、入居者特典 | レオパレス「指定企業」型、大東建託ruum「入居者15%OFF」型 | 指定発注・割引掲載 | — |
| 家電量販 | 購入後（ヤマダは推奨タイミングを明記：**赤ちゃんをお迎えする準備・ペット・購入3年・梅雨前**） | エアコンクリーニング | — | エディオン 累計230万台 |

**共通する仕組み**
1. 会計の瞬間に、売り手のレジで作業を売る。**Amazonですら単独のクリーニングは残さず、モノ付随の一回きりに絞った**
2. **その瞬間専用の商品に名前を付ける**（0歳専用／購入後1か月／赤ちゃんをお迎えする準備）
3. 紹介元は成功報酬か会員割引で得をする。広告は後
4. **棚に置ける形**（チケット・チラシ・専門家の手渡し）にして他人の導線に載せる
5. 儀式と累計実績で「今やる理由」と「安心」を作る

## 3. 型③「名前・映像・暦」— カテゴリー創造と周期化

| 事例 | 何を見える化／習慣化したか | 仕掛け | 数字（一次） |
|---|---|---|---|
| 加齢臭（資生堂1999）／ミドル脂臭（マンダム2013） | ニオイに名前と原因物質 | 学会発表→調査リリース→「40才からの」を店頭で統一 | ルシード売上+60%（xTREND）、ニオイケア+70%（2016） |
| レイコップ | ダニ・ハウスダスト | テレビ通販（ジャパネット）＋無料貸出 | 国内490万台（2017）。**単品依存で後に多角化** |
| 洗濯槽クリーナー | 槽の裏の黒カビ（「洗浄液が黒く濁る」） | **推奨頻度の宣言**（パナ 年1回、ジョンソン 1〜2か月） | 市場規模は未確認 |
| らくハピ エアコン洗浄スプレー | 「中は汚れている」の認識 | 「3か月に一度」宣言 | 累計1.2億本。**ダイキン公式「使用しないでください」、三菱電機「推奨していません」、NITE「業者に依頼を」** |
| ダスキン モップ定期交換 | 掃除を定期契約に | 訪問販売員の定期訪問 | 家庭460万件・モップシェア90%以上。**家庭向けは減収続き、役務（サービスマスター）は+6.6%** |
| 車検／試運転の日／スタッドレス | 制度・暦 | 法制度、業界団体（JRAIA「4/10試運転の日」、ダイキン「5/5」） | 継続検査2,164万件/年 |
| 8020運動 | 治療→予防 | 行政＋業界団体の目標設定 | 7%→61.5%、35年 |
| 年末大掃除 | 儀式（衰退中） | — | 実施率 71.7%（2008）→**51.1%（2024）**。プロ依頼10.1%（微増）。**エアコン依頼意向59.8% vs 実行7.5%** |
| ハウスクリーニングのサブスク | 年1回化 | 大手も「定期」は家事代行寄り。クリーニングの定期化は2割弱 | 「定期的に依頼」18.7%（ミツモア） |

**共通する仕組み**
1. 見えないものに**名前と映像**を与えると、検索され、自分ごと化される
2. **推奨サイクルを権威が宣言**する。「いつやるか」を客に考えさせない
3. 暦に紐づける。ただし儀式は衰退しうる（大掃除）。需要を**別の暦（冷房前）に付け替える**余地がある
4. 定期の価値は「保証・交換・忘れないこと」
5. 単品ヒットは競合と飽きで多角化を迫られる

## 4. ハウスクリーニングへの転用：観点と、これまでの案の反省

### 4-1. これまでの3案は、なぜ弱かったか

| 案 | 型 | 事例が示す弱点 |
|---|---|---|
| 洗いどき（相談所） | ①の写真版 | 「知る」のが写真判定＝**本人が証拠を見る体験が弱い**。Zestimateは自分の資産の数字、シロアリは床下の実写真。**オンラインの判定は、床下に潜る体験に負ける** |
| 症例集・よごれカルテ | ③の映像版 | カテゴリー創造は**メーカーの広告費（レイコップはジャパネット、おそうじ本舗は年数億円）**か35年（8020）が要る。データも無い |
| DIYハウツー | ③ | メーカー・大手が埋めている |

**共通の誤り：「メディア」を入口にしようとした。** 勝者の入口は、無料の体験・他人のレジ・儀式であって、メディアは増幅装置。

### 4-2. 転用できる観点（この業界の空白「意向59.8% vs 実行7.5%」を崩す順）

| 観点 | 事例 | ワンヒッターでの形 |
|---|---|---|
| **A. 中を無料で見せる（プル型・写真報告書を全員に）** | シロアリ点検、位相差顕微鏡、レイコップ貸出7割 | 「エアコンの中、10分で写真にして渡します」。**申し込んだ人だけ**（飛び込み禁止）。報告書は依頼しなくても渡す。「今回は不要」も書く。**すでにクチコミで「汚れを見せてくれる」が2件、当社の型そのもの** |
| **B. 施工中に、他の設備を無料で見て報告書にする** | ダスキン ターミニックス「保証中は年1回無料点検」 | 施工に来たついでに、他の部屋のエアコン・換気扇・洗濯槽を見て写真報告。**エアコンのみ客621名・換気扇未購入807名＝約3,100万円の潜在**に、獲得費ゼロで当たる |
| **C. 暦に乗る：「冷房前」を儀式にする** | 試運転の日・エアコンの日・スタッドレス | メーカーが作った4/10〜5/5に「試運転して臭ったら」で受付。年末に集中する需要を**冷房前（5〜6月・当社の繁忙期の直前）**へ付け替える。1〜2月の谷には「暖房前」を当てる |
| **D. その瞬間専用の商品を、他人のレジに置く** | アニコム7割、Handy、産院、管理会社、ヤマダの推奨タイミング | 「入居直後専用」「エアコン購入直後専用」「赤ちゃんを迎える前」「ペットを迎える前」の4商品。管理会社・仲介店・産院・ペットショップ・家電店にQR／チケット。紹介元へ12%。**オーナーの3層（DIY・赤ちゃん・ペット）は、メディアの読者ではなく、この「瞬間」で取る** |
| **E. 次回を決めて帰る** | 歯科リコール、車検、メルスプラン | 施工当日に次回日付を仮予約（既に次回予約割引の制度あり）。契約書なしの実質サブスク |
| **F. 名前を付ける** | 加齢臭、黒カビE菌 | 「冷房前クリーニング」「エアコン内部チェック」等。広告費が無くても、C・Dの導線の中で使えば自分ごと化に効く |
| **G. 中立性は「やらない」で見せる** | ダスキン、SUUMO断り代行 | 報告書に「今回は不要」の判定を入れ、その件数も公開する。点検商法との違いを構造で示す |

## 5. 別案：「エアコン内部チェック」窓口（型①×②×③の合成）

**一行で：** 「エアコンの中を、無料で写真にして渡す」を入口に、暦（冷房前）と他人のレジ（節目）で申込を集め、当社と提携職人が点検・施工し、成約時に紹介料を受ける。

```
入口（プル型のみ）
  暦：4/10 試運転の日〜6月「試運転して臭ったら、中を無料で見ます」   ← 型③
  節目：入居直後／エアコン購入直後／赤ちゃん・ペットを迎える前の専用商品を
        管理会社・仲介・産院・ペットショップ・家電店のレジにQRで          ← 型②
        ↓
無料の内部チェック（10分・写真報告書を全員に・「今回は不要」も書く）      ← 型①
        ↓
  本人が写真を見る ＝ 顕在化の瞬間
  ├ 必要 → その場で見積 → 施工（自社の枠 or 提携職人）→ 次回日付を決めて帰る  ← 型③
  └ 不要 → 報告書だけ渡す → 次の暦にLINEで戻す
        ↓
提携職人：自分の地域の申込を受けて点検・施工。成約時に12%を窓口へ。      ← Zillow型
```

**なぜこれか（数字）**
- 崩す空白が最大：意向59.8% vs 実行7.5%。踏み出せない理由（費用・他人が家に入る抵抗）を、**「無料・10分・写真を渡して帰る」が両方とも下げる**
- 当社の強みと一致：クチコミ5件中2件が「汚れを見せてくれる」。稼働率は通常20〜50%（点検に使える時間がある）
- 供給を超える：申込は全国から受け、点検・施工は提携職人が担う。Zillowが業者から成約時に取る構造と同じ
- 「メディア」の役割は増幅：報告書（実写）がそのまま図鑑・動画・GBP投稿になる。生成器はv1のまま使える

**やってはいけないこと（規制）**
- 飛び込み・電話での「無料点検」は一切しない（点検商法：相談年2万件・業務停止命令の前例）
- 報告書で不安を煽らない。「今回は不要」を書く
- 健康の断定はしない（東京都の指針の引用まで）

**人が要るところ（正直に）**
- 点検は現場の時間を使う（10分＋移動）。**最初は施工のついで（観点B）から始め、単独の点検は冷房前の6週間だけ**に絞る
- 提携職人の最初の5社と、節目チャネルの最初の3件（管理会社1・産院1・ペットショップ1）は、オーナーの電話が要る。**ここだけは自動化できない**。それ以降の運用（申込の振り分け・報告書の生成・通知）はこちらが自動で回す

**90日で測ること**
- 点検→施工の率（アサンテ・ほけんの窓口は非公開／55%。当社の数字を取る）
- 節目チャネル3件からの申込数
- 「今回は不要」と判定した件数（公開して信用にする）
