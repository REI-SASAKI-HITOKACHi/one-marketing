2026年の着地（2027年の土台）

計画 §1「2026年（見込み）17,000,000円」

計画では　2026年は 1,700万円で終える見込み。2027年の 2,600万円（+53%）はここを土台にしている。

1〜10月の実績1,342万円337件
10月：計画との差−12万円計画116万 → 実績104万（35件）
11月の予約・施工済み76万円32件。計画は163万
12月の予約14万円3件。計画は184万

読み　12月は例年、11月後半から予約が入る月で、今の薄さはまだ異常ではない。ただ1,700万に届くには、11〜12月で例年以上を積む必要がある。件数の上限（12月は約50件）が先に来るので、1現場あたりの金額で積む計画にしてある（§7）。

出どころ：1〜8月 283件・11,652,061円（2026年シートの実績）／9〜12月は売上表の集計 11/5 12:27／計画は「2026年 通期1,700万への上方修正計画」（10/10・第7回MTG）

自社ネット新規 ── 2027年の勝負どころ

計画 §5 ④「13万 → 500万」・§6「3つのパターン」

計画では　9〜12月の4か月で入口を回して、12月の件数で3つのパターンを見る。A 外れる（月2〜3件）／B 想定どおり（月5〜8件）／C 当たる（月10件以上）。2,600万は B を前提にしている。2027年の目標は月12件・年143件。

A 外れる月2〜3件

広告で買いにいく。SNSは本数を減らして質に振る

B 想定どおり月5〜8件

効いた入口だけに広告を足す。効かないものは止める

C 当たる月10件以上

1月から広告を一気に上げ、協力業者も前倒し

10月のネット経由8件11.9万円。2026年1〜8月は合計4件
11月（5日時点）5件線は2件。+3件
12月の目標25件いま0件。11/15 に4件が線

読み　「来ていない」状態から「来始めた」状態に変わった。10月はパターンBの上限、11月はそれを超える勢い。ただし1件の金額が小さい（10月は平均 約1.5万円）。来たお客様に、現場で次の1箇所と次回予約を出せるかが、2027年の500万に効く（§7 のお願い1）。

出どころ：売上表の集計（月次タブの流入経路）。ネット経由＝予約ページ・LP・公式サイトのフォームから申し込んだもの（10/18 の数え方）。11月は受注前の予約1件を含む。線は経営企画室の追跡表（net11-tsuiseki）

広告のテスト（段0）

計画 §4 広告費「テストは2026年12月末までに済ませる」

計画では　2026年内に月5万円でテストし、結果を持って2027年に入る。1件取るのにかける上限は 9,500円（マッチングサイトに払っている手数料と同じ額）。

10月の広告費15.7万円10/1〜30。月5万の約3倍まで上げて試した
10月の広告の申込6件うちキャンセル2・受注4
申込1件あたり3.9万円計画の上限 0.95万円の約4倍
11月の広告からの受注2件5日時点
時期入札の方式1日のクリック1クリック結果
9/20〜10/15クリックを最大化15.3¥282申込6件（クリックの1.5%）
10/16〜10/27申込を最大化（自動）6.6¥773表示が3分の1に減った
10/28〜クリックを最大化に戻した16〜22¥324〜334量は戻った。11/1以降に申込2件

読み　広告は「量」は出せるようになったが、1件あたりがまだ高い。広告の客は1件が小さい（エアコン1台が中心）ので、初回だけでは赤字。2回目の予約まで取れれば元が取れる計算にしてある。だから広告で来たお客様ほど、次回予約とクチコミが大事になる。日予算を上げるかは 11/9 に数字で決める。

出どころ：計測担当の広告の日次（Google広告）と予約の記録。申込1件あたり＝10月の広告費 ÷ キャンセルを除いた申込4件

① リピート資産 と ② 法人・提携

計画 §5 ①「617万 → 850万」・②「法人・提携 → 750万（提携）」

計画では　① は台帳の957人。獲得コストほぼゼロで、いちばん確実な伸びしろ。② は提携先をアクティブ10社 → 15社、年100万円以上の先を1社 → 4社。

読み　① の早期予約が強い（10月16件・11月17件）。11月の自社の受注金額の半分以上がここ。現場で取ってもらっている次回予約が、そのまま数字になっている。② の提携は9月6件・10月3件と来ていたが、11月はまだ0件。休眠先への声かけは送付物を作り直して進めている。

出どころ：売上表の集計 11/5 12:27（One Hitter 名義の行。11月は予約を含む。9月の「その他」1件 7.7万円は除いた）。①＝早期予約・リピート・紹介・定期便、②＝業務提携・営業

これからの2か月と、和真さんにお願いしたいこと

計画 §8 各四半期「10〜12月 年末商戦」

計画では　12月の繁忙期加算（+3,300円）を「11月までに予約する理由」に使う。既存のお客様への案内を3回。

  1. 現場で「次の1箇所」を出す12月は件数の上限（約50件）が先に来る。件数ではなく1現場の金額で積む。エアコンで来たお客様に、防カビ・室外機・水まわりの話を1つ。1件 +5,000円で、11〜12月だけで約50万円になる。
  2. ネットと広告で来たお客様ほど、次回予約とクチコミを広告の客は初回だけだと赤字。2回目の予約が取れて、はじめて元が取れる。クチコミは今 ★5.0・25件。
  3. 12月の時間を守る12月にネットで25件を受けるには、200時間のうち残りが少ない。大きいご依頼は、できれば11月中に入れたい（9箇所のご依頼は 11/30 が12月の枠を削らない）。
  4. 協力業者のレビュー（1〜2月に決めるため）付き合いのある先ごとに、腕・段取り・得意なメニュー・任せられる範囲。支払条件3案（歩合・固定単価・日当）のどれが合うか、和真さんの感覚がいちばん正確。
