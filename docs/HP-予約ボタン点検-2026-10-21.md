# 公式サイト（one-hitter.jp）の予約ボタンの点検（2026-10-21 LP・サイト担当）

依頼 20261021-02-lp（cmo・オーナー指示「無料経路(hp.sns)を強化する必要があるね」）の 1。
**読み取りだけで点検した**（サイトマップの159ページを1回ずつ取得。CMS には触っていない）。道具：`preview/hp/crawl.py`（使い捨て）。

## 結論

**予約ページへのリンクは全ページにある。ただし `src` が `hp` で始まっていないので、HP から来た予約が「直接・その他」に数えられている。**

measurement の集計（`tools/funnel-keiro.py` の `keiro_of_src`）は、`hp*` を HP、`blog*` をブログとして数える。
公式サイトのリンクは `top`・`site_footer`・`site_cta`・`menu` で、どれにも当たらない。
**いま「無料経路の受注0件」と見えている数字の中に、HP 経由の申込が「直接・その他」として混ざっている可能性がある。**

## 直し方（おすすめ順）

### A. measurement の判定に1行足す（CMS に触らない・過去の分もさかのぼって直る）**← おすすめ**

`tools/funnel-keiro.py` の `keiro_of_src` で、`top`・`site_footer`・`site_cta`・`menu` を HP に入れる。

```python
    if s.startswith("hp") or s in ("top", "site_footer", "site_cta", "menu"):
        return "HP"
```

- GA4 には今も `traffic_src` がそのまま入っているので、**9/20 以降の分も数え直せる**
- measurement の持ち物なので、掲示板で依頼済み（20261021-03-measurement）

### B. CMS のリンクを `hp-…` に書き換える（A をしたうえで、揃えたいときだけ）

- 共通テンプレート（ヘッダー・フッター・本文下の CTA）は**ブラウザ担当の持ち物**。1か所直せば全ページに効く
- 書き換えると、A の判定に足した4つは使われなくなる（過去の分のために残しておく）
- 手順（browser）：
  1. `https://one-hitter.jp/_sys/` → 共通パーツ（ヘッダー／フッター）を開く。**書き換える前に今のHTMLを全部コピーして保存**
  2. `?src=top` → `?src=hp-nav`、`?src=site_footer` → `?src=hp-footer`、`?src=site_cta` → `?src=hp-cta` に置き換える（`https://yoyaku.onehitter.jp/` の部分は変えない）
  3. `/menu/` の本文の `?src=menu` → `?src=hp-menu`
  4. 保存後、トップと記事1本を開いて、リンク先の URL を確かめる（LP 担当が読み取りで点検し直せる）
- 戻し方：手順1で保存した HTML を貼り戻す
