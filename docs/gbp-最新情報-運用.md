# GBP「最新情報」の運用の型

作成日: 2026-09-13 ／ 担当: web-inflow（原稿）・cmo（査読）・ブラウザ担当→API（投稿）
根拠: オーナー決定 2026-09-13「アクティブに見えるように最新情報とか更新しておいて」「施工するたびに写真＋アンケート結果を更新するようにしてね。本舗の案件を混ぜないように注意してね」（cmo 依頼 20260913-02-web-inflow）

## 1. 何を出すか

**自社の施工1件＝投稿1本。** 写真（作業前→作業後の組写真、または洗浄後の水）＋アンケートの一言（お客様名は出さない）。
月1本の「読本の要約」や季節の案内は、施工の投稿が続いた上で足す（最初の3か月は施工1本のみ）。

## 2. 頻度と期限

| | 目安 |
|---|---|
| 頻度 | **週1本**（施工が週2件以上あっても、投稿は週1本。ネタは翌週に回す） |
| 素材が届いてから原稿まで | 2営業日 |
| 原稿 → cmo 査読 | 当日中（SNS と同じ） |
| 投稿 | API 承認まで：原稿を `docs/gbp-最新情報-原稿.md` に溜め、承認後にまとめて出す（古いものから週1本のペース）。承認後：cmo OK の翌営業日に自動投稿 |
| 最初の1本 | 9/16 までに原稿（秋の文脈。早割は春のもの。9月に書かない） |

## 3. 本文の型（全角 150〜300字。GBPの上限 1,500字は使い切らない）

1. **どこで、何を**（1文。「江戸川区のお宅で、エアコン1台。」地名は区まで）
2. **写真で見えていること**（2〜3文。事実だけ。原因は「〜と見ています」まで）
3. **アンケートの一言**（1文。「」で引用。お客様が特定できる語を含むものは使わない。無い週は省く。**作らない**）
4. **手入れの一言 か 料金**（1文。料金は `docs/price-master.md` の税込のみ。「〜円から」は総額表示の税込で）
5. **導線**（ボタン「詳細」→ 公式サイト。本文には URL を書かない）

例（型の確認用。実物は原稿ファイルに）
```
江戸川区のお宅で、壁掛けエアコン1台。
吹き出し口の奥に黒い筋、熱交換器のフィンは灰色でした。分解して部品ごとに洗った水が3枚目です。
フィルターを洗っても、この奥には届きません。エアコンクリーニング（ノーマル）は 10,780円（税込）です。
```

## 4. 写真の条件

- 当社が施工した現場で撮った実物。**合成・生成・加工なし**（トリミングと明るさ調整のみ）
- 作業前→作業後の組写真は、`docs/photo-inventory*.md` で**同一箇所を確認済みのペアだけ**。確認できないものは「ビフォーアフター」と書かず、1枚ずつ載せる
- お宅・お客様が特定できる要素（表札、窓の外、家具の全景、銘板、人物）を入れない
- **本舗のロゴ・制服・車両・資材が写り込んでいないか目視**（写り込んでいたら使わない。トリミングで消せる場合も使わない）
- 1投稿 1〜3枚。1枚目は作業前（汚れが伝わるほう）
- 保存場所：`assets/photos/`（1600px・EXIF 除去済み）。元データは `assets/photos-raw/`（git の外）

## 5. 本舗の案件を混ぜない（必須3ステップ。cmo 指示 2026-09-13）

1. **台帳と機械で突き合わせる。** その施工のお客様の電話番号か氏名で `tools/derive-soushin-keitou.py` の `meigi_hyou()` → `meigi_shiraberu()` を引き、**最新の施工の名義が「自社」のものだけ**投稿する。「本舗」「決められない（台帳に無い・下請・空欄）」は投稿しない。照合の結果（名義・最新施工日）を原稿ファイルの各原稿に1行で残す
   - 現場の写真だけで氏名・電話番号が分からない案件は、台帳の同日の行で照合する。同日に本舗名義の施工があれば、その日の写真は使わない
2. **写真の目視**（4章のとおり。ロゴ・制服・車両・資材）
3. **文言**：「おそうじ本舗」の語、本舗の電話番号（080-1344-3137）を書かない。名乗りは「ワンヒッター」のみ

## 6. 書かないこと

- 断定表現：「完全除去」「必ず」「100%」「二度と」
- 効果・健康：「除菌」「殺菌」「抗菌」「病気」「守る」「安心」「危険」（東京消防庁などの原文引用の中だけ可）
- 実績の数字：**98.6%**（209名中206名・2023年1月〜2025年12月）以外は使わない。**98.8% は使わない**
- 他社の評価、価格の比較、割引率（キャンペーンはその期間中だけ。早割は春）
- お客様の氏名・住所・特定できる情報。アンケートの引用は「」内を変えずに、特定につながる語だけ「…」で省く
- AI っぽい語：ここからは／お伝えします／いかがでしょうか／ぜひ／しっかり／大切な

## 7. ボタンと計測

- ボタン：「詳細」→ `https://one-hitter.jp/?utm_source=gbp&utm_medium=post&utm_campaign=<YYYYMM>`（**すべて小文字**。measurement と表記を揃える。例 `utm_campaign=202609`）
- 予約に直接飛ばしたい投稿だけ「予約」→ `https://yoyaku.onehitter.jp/?src=gbp`（netlify.app は書かない）
- 効果は週次の数字（月曜 08:30）の GBP 欄で見る：投稿数・表示回数・ボタンのクリック（管理画面のインサイト）

## 8. 手順（1本ごと）

1. 素材が届く（Drive「01_これから撮る分」の写真＋アンケート回答）。`data/zukan/<日付-対象>.json` に現場記録を1件作る（`tools/build-zukan.py` の形式）
2. 5章の3ステップ（台帳照合 → 写真の目視 → 文言）
3. `docs/gbp-最新情報-原稿.md` に追記（日付・写真・本文・ボタン・照合結果）
4. 掲示板で cmo に査読依頼（原稿の見出しを1行）
5. cmo OK → API 承認前はブラウザ担当へ、承認後は自動投稿 → 投稿URLを原稿ファイルに追記
6. 同じ素材を SNS（`docs/sns-投稿原稿/`）とブログ（`docs/blog/`）に使ってよい。文章は書き分ける
