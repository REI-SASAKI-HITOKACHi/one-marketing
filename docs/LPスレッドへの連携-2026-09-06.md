## 1. ダークモード配色をやめ、ライト固定にしました

**今後ダーク対応を戻す場合は、オーナーの合意を取ってからにしてください。**

## 2. フォームに流入元（src / cid）の記録を追加しました

**3本とも、どこから来た予約かを記録する仕組みがありませんでした。**
このままでは広告を出しても、どの広告から予約が入ったのか判別できません。

```html
<input type="hidden" name="src" id="h-src" value="direct">
<input type="hidden" name="cid" id="h-cid" value="">
```

URLの `?src=` と `?cid=` を読んで hidden に写します。
値は英数字・ハイフン・アンダースコアだけに制限し、20文字で切っています。
パラメータが無ければ `src=direct` になります。

Netlify Forms の受信データに列が増えるので、**経路別の受注数が数えられます。**
広告のCPA上限は9,500円です（根拠は `docs/流入経路の分析.md`）。

## なぜ大事か — URLを動かせる範囲が変わります

「5本とも変えられない」と「1本だけ変えられない」では、打てる手がまったく違います。

- **`/mizumawari/` だけ**は、パスを変えるとアフィリエイトの遷移先が死にます。
  変えるときは**必ず先にオーナーへ広告側の設定変更を依頼**してください。ここは従来どおりです。
- **残り4本**を指しているのは、**こちらが管理しているリンクだけ**です。
  具体的には SMS本文（`data/sms-template*.txt` → `tools/build-sms-list.py` で再生成）、
  現場のQRカード、公式LINE、予約フォームからの導線。
  **どれも、こちらで一括で貼り替えられます。**
  つまりこの4本は「契約で凍結されている」のではなく、
  「動かすならCMO側に一声かけてください」という程度のものです。

いま実害はありませんが、**この誤解を放置すると、直すべきURL構成を
「アフィリエイトがあるから触れない」と誤って諦める**ことになります。
現に年末LPの2URL問題（下記A）は、そこが論点になりかけました。
