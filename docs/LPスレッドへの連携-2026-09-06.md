# LP概要案プレゼンスレッドへの連携（2026-09-06）

> **CMOスレッドが `lp/aircon/` `lp/mizumawari/` `lp/aircon-b/` に手を入れ、本番へ反映しました。**
> 通常この3本はそちらの管轄ですが、オーナーの明示的な指示により今回はこちらで実施しています。
> **以後の対応はそちらでお願いします。**

## 1. ダークモード配色をやめ、ライト固定にしました

オーナーがダーク設定のスマホでLPを開いたところ、濃紺の背景になり
**「デザイン的にイマイチ」**との判断がありました。

- 各LPの `@media (prefers-color-scheme: dark){...}` ブロックを削除
- `:root` に `color-scheme: light;` を宣言（OS側のダーク設定に追随しない）
- `thanks.html` にも同じダーク配色が入っていたので揃えました

**理由**：施工写真のビフォー／アフターが訴求の中心で、暗い地の上では
「汚れ→綺麗」の明度差が弱く見えます。ハウスクリーニングのLPはライト基調が一般的です。

**今後ダーク対応を戻す場合は、オーナーの合意を取ってからにしてください。**

## 2. フォームに流入元（src / cid）の記録を追加しました

**3本とも、どこから来た予約かを記録する仕組みがありませんでした。**
このままでは広告を出しても、どの広告から予約が入ったのか判別できません。

```html
<input type="hidden" name="src" id="h-src" value="direct">
<input type="hidden" name="cid" id="h-cid" value="">
```

URLの `?src=` と `?cid=` を読んで hidden に写します。
値は英数字・ハイフン・アンダースコアだけに制限し、20文字で切っています。
パラメータが無ければ `src=direct` になります。

Netlify Forms の受信データに列が増えるので、**経路別の受注数が数えられます。**
広告のCPA上限は9,500円です（根拠は `docs/流入経路の分析.md`）。

## 3. 🔴 aircon-b の `thanks.html` が存在せず、404になっていました

**パターンBのフォームを送信すると、完了画面が404だった**ということです。

- `lp/aircon-b/` のフォームの送信先は `/aircon-b/thanks.html`
- しかし `deploy/netlify/aircon-b/thanks.html` が無く、本番でも404を返していました
- `thanks.html` は**ビルドで生成されず、リポジトリに置いてあるファイル**です。
  aircon-b を追加したときに作り忘れたものと思われます
- aircon のものを複製して配置し、本番も200を返すようになりました

**A/Bテストの結果に影響します。** パターンBだけ送信後の体験が壊れていたため、
**この修正より前に取ったBの数字は、そのまま比較に使えません。**

## 4. 本番へ反映済みです

`one-hitter-lp.netlify.app` に、上記を含む3本を再デプロイしました。
ルート直下の `_headers` `_redirects` `robots.txt` `favicon.ico` `apple-touch-icon.png` も
そのまま含めています（ZIPデプロイはサイト全体を置き換えるため）。

反映後の確認：3本ともダーク指定なし・ライト固定・src記録あり・`thanks.html` が200。

**`lp/nenmatsu/` はCMOスレッドの管轄で、別サイト（`one-hitter-nenmatsu.netlify.app`）にあります。**
独自ドメインが通った時点で1サイトに統合する方針です（オーナー判断）。

## 5. そちらで判断が必要なもの（引き継ぎメモから未回答のもの）

1. `lp.one-hitter.jp` のDNSを切るか → **ドメインの有効期限が2026/09/30で未更新。先にそちら**
