## 何が変わったか

**税込表示に統一するため、旧価格に消費税を乗せました。実質10%の値上げです。**
（経緯は `docs/価格の税込税抜-調査結果.md`。調査結果は「旧価格は既に税込」でしたが、
オーナー判断で値上げとして実施しています。）

**ただし11項目は据え置きです。** 元から税込の形（きりのいい額の1.1倍）だったため、
再度1.1倍すると二重課税になります。

## 確認方法

置換後、次で残りがないか確認できます。

```bash
grep -nE "9,800|15,800|16,800|18,100|13,800|15,100|6,800|7,800|33,600|30,600|37,200|3,000円" lp/*/index.html
```
