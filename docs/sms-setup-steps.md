# SMS配信の申込からAPIキー共有まで

対象：KDDI Message Cast（決定理由は `docs/sms-provider-research.md`）
オーナーの所要：**10〜15分**。以降の送信作業はすべてCMO側でやります。

---

## 全体の流れ

```
① 申込フォームを送信          … オーナー（5分）
        ↓  最短6営業日
② アカウント通知書がメールで届く … 待つだけ
③ APIキー（認証情報）を発行     … オーナー（5分）
        ↓
④ APIキーをCMOへ渡す           … オーナー（1分）
        ↓
⑤ 宛先リスト・文面・送信・集計   … ★CMO側で全部やります
```

**③まで進めば、あとは渡辺さんの工数ゼロで一斉送信が回ります。**

---

## ① 申込フォームの入力内容

https://kddimessagecast.jp/ から「お問い合わせ・お申し込み」へ。

| 項目 | 入れる値 |
|---|---|
| 会社名 | ワンヒッター株式会社 |
| 業種 | サービス業（ハウスクリーニング） |
| 利用目的 | 既存のお客様への再来案内、および施工後アンケートのご案内 |
| 想定送信数 | **月100〜200通。年末に一度だけ800通程度の一斉送信あり** |
| 利用開始希望 | 2026年9月中 |
| プラン | **APIプラン**（管理画面プランではなく、必ずAPIと伝えること） |
| 連携方法 | HTTPS API |

**「トライアルを希望」と明記してください。** 2か月・最大3,000通まで無料です。
年末の一斉送信がこの枠に収まります。

### 必ず聞いてほしいこと（1つだけ）

> **「月1,000通程度の利用の場合、1通あたりいくらになりますか？」**

公開単価は「9.35円（税込）〜」で、"〜" が付いています。
**10円（税込）を超える提示だった場合は、その旨だけ教えてください。**
NTT CPaaS（1通10円の確定値）に切り替えます。これが撤退ラインです。

CMO側で次を進めておきます。

## ③ APIキーの発行

アカウント通知書が届いたら、管理画面にログインしてAPI用の認証情報を発行します。
画面の項目名が分からなければ、**そのままスクショを送ってください。** どれを押すか指示します。

発行時に控えるもの（事業者によって名称が違います）：

- APIキー／アクセストークン／クライアントID・シークレット のいずれか
- 送信元番号（発番されたもの）
- APIのエンドポイントURL

---

## ④ APIキーの渡し方（ここだけ注意）

**チャットに直接貼らないでください。** サービスアカウントの鍵と同じ扱いにします。

おすすめの順に3つ。

### 方法A：Driveの非公開ファイルに置く（いちばん簡単）

1. Googleドライブで新規テキストファイルかドキュメントを作る
2. ファイル名は `SMS_API認証情報`（中身にキーを貼る）
3. **共有はしない**（オーナー本人のみ）
4. チャットには **ファイル名だけ** 教えてください

こちらはDrive連携でそのファイルを読めます。読んだら「受け取りました」と返します。

### 方法B：環境変数として設定する

Claude Code の設定ファイルに書く方法です。手順は別途お伝えします。
リポジトリにはコミットされません。

### 方法C：一時的にチャットで渡し、直後に再発行する

サービスアカウント鍵のときと同じやり方です。
急ぐ場合のみ。**渡した直後に必ずキーを作り直してください。**

## ⑤ 以降（CMO側）

- 送信は全てAPI経由。管理画面は使いません
- 送信結果（到達／不達）を取得して、`顧客管理台帳` の電話番号の生死を更新します
  → 不達だった番号は「要確認」に落として、次回から除外します
- 反応（クリック・入電・受注）を追跡して、セグメント別の効果を出します

## 補足：送信者名について

**日本国内のSMSでは、差出人に会社名（英字）を出すのは事実上どの事業者でも不可**です。
受信側には電話番号が表示されます。これは事業者選定では覆せません。

代わりに **本文の1行目で名乗ります**：

```
ワンヒッター（おそうじ）です。
先日はご利用ありがとうございました。
...
```

おそうじ本舗のお客様には、送信主体が「おそうじ本舗江戸川中央店」になるため
**文面を分けて送ります**（既知の論点。CMO側で対応済み）。
