# こちらで判断した理由（変えたければ言ってください）

## お金に関わるもの

| 項目 | どうしたか | なぜ |
|---|---|---|
| **アフィリエイト予算目安** | **11万〜50万円**（オーナー決定 2026-09-12） | 月37〜167件ぶん。パートナーから「やる気のある案件」に見え、掲載されやすくなります |
| **特別単価の提供** | 条件付OK（実績に応じて個別相談） | NGにすると強いパートナーが離れます。「相談」なら、いま何も約束しません |
| **サンプル提供・体験取材** | **空欄のまま** | どちらも無料で施工を1件出すことになります。**お金の判断なので、こちらでは決めません。** やるなら効果は大きい（体験レビュー記事が書ける）ので、検討する価値はあります |

## 断ったもの

| 項目 | どうしたか | なぜ |
|---|---|---|
| **ポイントサイト集客** | NG | ポイント目当ての申込は成約せず、却下が増えます |
| **本人申込・購入** | NG | パートナー本人の申込を成果にすると、報酬目当ての空申込が出ます |
| **タグ埋め込み** | 要検討 | パートナーの追跡タグを当社LPに載せる話です。**他社が書いたスクリプトを自社サイトで動かす**ことになり、プライバシーポリシーにも書く必要が出ます。即答しません |
| **リスティング** | 条件付OK（商標NG） | 社名で検索した人は放っておいても来ます。そこに広告費を払うのは無駄です（議題#20の決定） |

## そのほか

| 項目 | どうしたか | なぜ |
|---|---|---|
| **承認作業＝週1回・月曜** | 週1回／その他→毎週月曜日 | 成果地点が「決済完了」で入金確認が要るため、毎日は回りません。放置すると自動承認でキャンセル分にも払うので、週1回は固定します |
| **拒否理由の登録＝OK** | OK | 却下の理由をパートナーに見せる作業です。手間は増えますが、**理由が分からない却下はパートナーが最も嫌います** |
| **API連携・コールトラッキング＝詳細説明希望** | 詳細説明希望 | どちらも導入を検討中で、仕様を聞いてから決めます。メールでも同じことを聞いています |
| **商品リンク作成＝OK（リンク提供不可）** | OK（提供不可） | 掲載先が `/mizumawari/` の1本だけで、配るリンクがありません |
| **承認率保証＝なし** | なし | キャンセル・未入金を却下する以上、承認率は約束できません |
| **タグ設置スピード＝即日** | 即日 | すでに実装済みで、配信を待つだけだからです |
| **CVR・承認率＝空欄** | 空欄 | **実測がありません。推測で書くと、根拠のない数字を先方に渡すことになります** |
| **男女比・年齢層** | 男3：女7／30〜50代 | **社内に性別・年齢のデータがありません。** オーナーの体感で決めました（2026-09-12）。GA4のデータが溜まれば実測に置き換えられます |
| **売上指数** | 5〜7月をピークに | オーナーの体感（2026-09-12）と、料金表で繁忙期加算3,300円を付けている月（5・6・7・12月／`docs/price-master.md`）の両方に合わせました |
