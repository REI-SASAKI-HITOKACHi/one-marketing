# 画面の操作でつまずいた点（次に同じ画面を触るとき用）

- **日付の期間指定**：入力欄に直接タイプすると「適用」で値が消えることがある。
  **カレンダーのセルを2回クリックする**のが確実（1回目＝開始、2回目＝終了。
  開始より前の日を押すと新しい開始になる）。設定後は innerText の「カスタム 2026年◯月◯日〜」で検証する
- **ページを移ると期間が「過去7日間」に戻る**ことがある。ページごとに設定し直す
- **アセット（サイトリンク）の一覧**は `/aw/assets` ではなく **`/aw/assetreport/associations?assetType=sitelink`**。
  `/aw/assets` と `/aw/assets/sitelinks` はどちらも404
- **広告バリエーションは広告一覧に出ない。** 左ナビ「テスト」→ 右上の **「表」ビュー**に切り替えて初めて見える
  （カードビューは空に見える）。詳細は `/aw/experiments/details?experimentId=...`
- **広告一覧の費用と広告グループの費用が合わない**のは、差額がバリエーション側だから（削除済みではない）
- Google広告の表は `tr` ではなく `role=row`。`document.querySelectorAll('tr')` は空を返す。**innerText を読むのが速い**
- 内蔵ブラウザの**スクショの座標フレームとCSS座標は倍率が違う**。
  `const s=800/innerWidth` を掛けて変換する。`resize_window` で広げるとむしろ縮小表示されて扱いにくい
- GBPの祝日の営業時間は **Google検索の「ビジネス情報」モーダル**（business.google.com から自動で飛ぶ）。
  「確認」を押すと通常営業時間が入った状態になり、**チェックを入れずに保存すれば「通常どおり」**になる
