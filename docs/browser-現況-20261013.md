### ⚠ 本文は必ず base64 で渡す（次に同じ作業をするとき）

**手でJSに本文を書くと壊れる。**11/06（記事1772）で実際に2か所変わった。

| 原稿 | 入ってしまった字 | 原因 |
|---|---|---|
| 羽根**1枚**1枚 | 羽根**10枚**1枚 | `根` の直後の `1` が続いて `10` になった |
| はっきり書かれて | はっきり**と**書かれて | 書き写しで足してしまった |

保存前に字数の食い違い（1676→1678）で気づいて直した。**公開側に誤った版は出ていない。**

**正しいやり方**：

```js
const B64 = "…";   // <scratchpad>/b64-NN.txt の中身をそのまま
const d = JSON.parse(new TextDecoder().decode(Uint8Array.from(atob(B64), c=>c.charCodeAt(0))));
const setV=(el,v)=>{const s=Object.getOwnPropertyDescriptor(el.constructor.prototype,'value').set;
  s.call(el,v); el.dispatchEvent(new Event('input',{bubbles:true})); el.dispatchEvent(new Event('change',{bubbles:true}));};
setV(document.querySelector('input[name="pbd[date]"]'), d.date);
setV(document.querySelector('input[name="pbd[hi]"]'), '10:00');
setV(document.querySelector('input[name="page[name]"]'), d.title);
[...document.querySelectorAll('input[name="input[tag_1925][]"]')].forEach(c=>{const w=(c.value===d.cat); if(c.checked!==w)c.click();});
[...document.querySelectorAll('input[name="input[tag_2133][]"]')].forEach(c=>{const w=d.tags.includes(c.value); if(c.checked!==w)c.click();});
const ed=window.Jodit.instances[Object.keys(window.Jodit.instances)[0]];
ed.value=d.html; if(ed.synchronizeValues) ed.synchronizeValues();
const ta=document.querySelector('textarea[name$="[text]"]');
JSON.stringify({same: ta.value===d.html})   // ← true を見てから保存する
```

**`same: true` が出てから［投稿］を押す。**
