## 2. 診断（重要度順）

即 = 今月中 / 次 = 90日以内 / 土台 = 継続

1. **[即] 完成したLPが公開されていない。** `deploy/DEPLOY.md` 手順①（Aレコード1行）で停止。
   ネームサーバーが `ns1.namegear.co` / `ns2.namegear.co` のため、その管理元への依頼が必要。
   アフィリエイトは成果報酬3,000円・作業完了ベースで合意済み → 公開翌日から売上が立ちうる。
2. **[即] 予約の受け皿が外部Googleフォーム。** GA4でCVが取れず、離脱箇所も不明、改善も打てない。
3. **[即] 電話の流入元が分からない。** 掲載番号が 080-1755-7275 の1本のみ。手順は `docs/tracking-setup.md`。
4. **[即] サイト料金表がパンフレットと不一致。** 洗濯機1,000円差／繁忙期加算がメニュー別／所要時間4件相違。
   景表法リスク＋アフィリエイターの信頼毀損。詳細は `docs/site-audit.md`。CMS権限は受領済み。
5. **[次] 対応エリアがサイトに存在しない。** 「千葉」「神奈川」「23区」「対応エリア」いずれも不出現。
   title・keywordsとも江戸川区のみ。→「本社：江戸川区／対応エリア：東京・千葉・神奈川」の併記へ。
6. **[次] meta description 不在、OG画像が小さなロゴ。** 施工ビフォーアフターに差し替える。
7. **[次] 根拠のある数字が載っていない。** 「98.8%」「満足度4.9」「リピート率70%超」は根拠不明。
   一方、根拠のある **98.6%（209名中206名／2023年1月〜2025年12月）** は未掲載。
8. **[土台] ブログ3年4ヶ月・施工事例4年の停止。** 地域タグ（浦安市・市川市・葛飾区・江東区・足立区）は
   既に作られており方向性は正しかった。止まっただけ。
9. **[土台] 計測タグの新旧同居。** 旧UAを撤去し、GA4のCVを再設計。
10. **[土台] 既存客への再販導線がない。** LINE公式はあるが季節リマインド運用なし。
    エアコンは年1回必ず再発する。獲得コストが最もゼロに近い売上。

## 3. 最大限の目標

ネット売上の上限は需要ではなく**施工枠**。よって目標はこう置く。

> 1年後、**施工枠が埋まっていることがボトルネックになる**状態をつくる。
> そのうえで、単価の高い仕事から順に枠を埋められるようにする。

| 時期 | 到達点 | 合格ライン |
|---|---|---|
| 90日 | 「ネット経由で今月何件受注したか」に即答できる | 流入元×受注件数×売上が毎週見える／アフィリエイト稼働／地図検索に正しい情報 |
| 6ヶ月 | 地元の地図検索で指名なしでも見つかる | 主要ローカルKWで地図3枠入り／口コミ継続獲得／再依頼の発生を確認 |
| 12ヶ月 | ネット経由が施工枠の主たる供給源になる | 枠の充足率／再依頼比率／獲得コストが平均単価の10%以下 |

**数値目標（月◯件・年商◯円）は敢えて未確定。** 施工キャパと平均受注単価の実数が未取得のため。
この2つが埋まり次第、上表に実数を入れて確定させる。

## 7. 意思決定待ち（4件）

1. 施工キャパ（スタッフ何名 × 1日何件）— 最大目標の上限そのもの
2. 平均受注単価と実際のリピート率 — 獲得コスト3,000円の是非を決める
3. Googleビジネスプロフィールのオーナー確認状況 — 未取得ならハガキ認証に2週間
4. 成果報酬以外の広告予算の有無 — ゼロでも計画は成立するが、繁忙期の取れ高が変わる
