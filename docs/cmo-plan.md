## 結論

2023年 +16.4%、2024年 +20.9% と伸びていた売上が、2026年は同期比 +5.4% に鈍化。
8月の業務提携1件（¥1,683,000）を除くと**実質は前年同期比 −9.8%**。
成長が止まった時期は、自社サイト経由の受注が前年の3分の1に落ちた時期と一致する。

## 4. 広告費ゼロで動く、止まっている3つのレバー

1. **フォローコールが2年間ほぼ未実施。** 全件に施工7日後のフォロー日が自動セットされているのに、
   実施フラグは 2024年 10.8%（9月以降4ヶ月連続ゼロ）／2025年 444件すべてFALSE／2026年もほぼ全件FALSE。
2. **「ＯＨ打診」（本舗→自社転換の打診）が2年間ゼロ件。** 2024年 0/408、2025年 0/444。
   本舗経由は年200〜255件、ロイヤリティ27.6%。**※FC契約上可能かは要確認（下記7-1）。**
3. **サブスクが成立しているのに契約者1名。** 「おそうじ定期便」は月¥9,800×12ヶ月＝年¥117,600。
   2025年にこの形で12回利用した顧客が1名いる。2026年も8件（¥78,400）どまり。

## 5. やらないこと（過去の実測で否定済み）

| 施策 | 実績 |

| ポスティング単独 | 週300〜2,000枚で「反応0」「反応3件」。2024年チラシ関連費¥124,300に対し受注1件 |
| 冷たいテレアポ | 業務提携狙い 40件→0アポ、140件→0アポ。法人向け120件→資料送付10・アポ0 |
| 1年以上前の顧客への架電 | 2025年12月に15件へ架電 → つながらず13件・**成約0** |

最後の1件が重要。「既存顧客に連絡すれば売れる」はそのままでは成立しなかった。
だから 4-1 のフォローコール再開は、**関係が新しいうち（施工7日後）に、電話ではなくLINE／SMSで、
季節に合った具体的なメニューを提示する**形にする。

## 6. 最大限の目標

> **本舗経由の枠を、自社ネット経由の受注で置き換える。1件も増やさずに年間およそ ¥630万の改善。**

| 内訳 | 計算 | 年間効果 |
|---|---|---|
| 単価が上がる（¥28,176→¥52,374） | 197件 × ¥24,198 | +¥4,767,006 |
| ロイヤリティが消える（27.6%） | ¥5,537,000 × 27.6% | +¥1,528,212 |
| **合計** | | **約 +¥6,290,000** |

2026年1〜8月の本舗経由131件・¥3,691,083を年換算（197件・¥5,537,000）し、実績平均単価を適用。
全件置き換えは非現実的なので、達成度は下記で段階化。

| 時期 | 到達点 | 合格ライン |
|---|---|---|
| 60日（〜11月上旬） | ネット経由 月10件／9〜12月の谷を埋めはじめる | 受注件数が毎週見える／9〜12月の予約が前年同期(¥4,604,253)超のペース |
| 120日（〜年末） | ネット経由 月25件／年末繁忙期を取り切る | 2026年通年 ¥17,000,000（前年比+8.5%）／非エアコン比率上昇 |
| 12ヶ月（〜2027年8月） | 本舗経由の半分を自社ネットに置き換える | 置き換え効果の半分（約¥315万）／リピート率 16%→25% |

**前回計画からの変更点：90日を計測整備に使う設計をやめた。** 台帳から何が効いて何が効かないかが
既に分かっているため、計測を待たずに打てる。最初の3手（フォローコール再開・既存顧客への秋冬案内・
サイト復旧）は広告費ゼロ・準備1週間以内。計測は並行して整える。

## 8. 台帳側で見つけた不具合（読み取りのみ。修正はコピー上で行う）

- **A. 2026年「売上分析」タブが実データと不一致。** 9月の行が丸ごと集計から欠落、
  流入経路「早期予約」が「リピート」に合算、2・3・10・12月の数字にズレ、`#REF!` 残存。
  → このタブで判断すると早期予約の効果が見えず、9月が落ちる。
- **B. 2025年も同型の問題。** 施工日付未入力の「おそうじ定期便」4件が月別クロス表から欠落、
  紹介案件1件（¥178,000）の日付変更がピボット未反映、経路未記入1件が漏れ。経路別サマリは実データと一致。
- **C. 月次サマリ行の集計式が複数月で破損。** 2024年は7・10月「本舗単価」が`#DIV/0!`、8月ラベル誤り、
  12月「下請件数」が本舗と同値、11月P/Lが1月と同値。2025年は5・6月の「自社件数」が不整合。
  売上金額と合計件数そのものは正しい。
- **D. 「リピートお客様一覧」タブが未更新。** 2023年は46名しか載っていないが実データは259名・2回以上42名。

**提案：A〜Dを直した集計タブと、リピート施策用の顧客リストを、原本に触れずコピー上で作成する。**
確認後に原本へ反映するかを判断いただく。指示待ち。

## 9. 確認したいこと

1. **FC契約上、本舗経由の顧客を自社リピートに転換できるか。** 6章の目標規模がこれで変わる。
   不可なら「本舗を維持したまま自社を積み増す」へ組み替える。契約書を確認できるのはオーナーのみ。
2. **業務提携2社の来年の発注見込み。** 2026年の成長は8月の1件が作っている。
3. **Google口コミの件数・平均点。** Googleが自動取得を拒否するため未取得。管理画面の画面写真1枚で足りる。
4. **一斉連絡の手段（LINE公式 / SMS）。** LINE友だち数とSMS一斉送信の可否で第2週の設計が変わる。

## 10. 数字の検証方法

各年とも、月次タブの明細を1件ずつ再集計し、シート自身のサマリ行またはP/Lタブと突合して一致を確認した。
一致しなかった箇所は本文8に記載（2024年6月の非表示1行・¥54,120、2026年の売上分析タブ）。
Webの状態（DNS、meta、sitemap全129URL、計測タグ）は2026-09-04に `one-hitter.jp` から直接取得して確認。
確認できなかった数字は「読み取れず」「未確認」と明記し、推定値は目標に使っていない。
