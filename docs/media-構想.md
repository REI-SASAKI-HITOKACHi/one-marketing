# 新メディア構想 ─ 0ベースの複数案

作成 2026-09-10 ／ 担当 ネット流入施策担当（`web-inflow`）／ 柱2の着手文書
オーナーからの解説（2026-09-10）を受けて作成。**まだ何も作っていません。何も公開していません。**

---

## 0. オーナーの構想を、こう受け取りました

| 指示 | 受け取り方 |
|---|---|
| 受注を1件でも多く。**自社の供給キャパを無視した規模**で | 目標は「自社の売上」ではなく「**集めた依頼の数**」 |
| 受注は弊社でなくてもよい。**弊社が窓口になり、キャパ超過分は同業者へ発注**するのが1つ目の到達点 | ワンヒッターが、いま**買う側**にいる見込み客を、**売る側**に回る |
| **僕の手間がかからないこと。** 全権限を委任するので自動で、質と量を最大化 | 人間が要る工程を「現場の写真」だけに絞り込む |
| CaSyの「お掃除辞典」のようなサイト＋専用SNS。ただし浅はかだと思うので0ベースで | 辞典型は**否定せず、部品として組み込む**。核には置かない（理由は2章） |

### この構想が数字の上でどれだけ正しいか

ワンヒッターは、いま**見込み客を買う側**にいます。

| 買い方 | 払っている額 | 出典 |
|---|---:|---|
| マッチングPF（楽ラクーン等） | **売上の約35%** ≒ 1件 約9,500円。年間およそ95万円 | `docs/流入経路の分析.md` |
| アフィリエイト（レントラックス） | **1件 3,000円**（決済完了ベース） | `docs/アフィリエイト-レントラックス.md` |

つまり、**「ハウスクリーニングを頼みたい人」1人は、この商圏で 3,000〜9,500円で売買されています。**
自分でその人を集められれば、自社で受ければ LTV 42,823円（自社直販・リピート率26〜36%）、
受けきれなければ**同業者に 3,000〜9,500円相当で渡せる**。どちらに転んでも損をしない。

そして、集めた人を渡す先は**すでにこの商圏にいます。**
柱1の調査（`docs/sns-90日運用案.md` 4章）で、江戸川区・浦安に実住所を持つ地場4社は
**SNSリンクが1本も無く、サイトも2014〜2021年で止まっていました。**
ネットで客を集められない同業者が、集めた客を最も欲しがります。**供給側は飢えています。**

## 1. 前提として押さえておく、2026年のネットの現実（一次情報つき）

構想を練る前に、**「記事をたくさん書けば集まる」が2026年に成り立たない**ことを、数字で置いておきます。

### 1-1. 検索からのクリックは、AIの要約に食われている

- Ahrefs の調査（2026年）：**AI Overviews が出る検索では、クリック率が平均58%低下。日本でも約38%減**
  （[Ahrefs プレスリリース](https://prtimes.jp/main/html/rd/p/000000037.000157671.html)）
- 情報収集型キーワードの1位のCTRは **1.76% → 0.61%**（[Web担当者Forum](https://webtan.impress.co.jp/n/2026/07/29/53036)）
- ただし **ハウツー・手順の検索は、まだ平均63%のクリック率を保っている**
  （[emma.tools](https://emma.tools/magazine/ai-overview/)）

→ 「エアコンクリーニングとは」のような**定義・解説記事は、書いてもAIに要約されて終わる。**
　 「自分でやる手順」「うちの場合どうか」の**個別性が高いものだけ、人がクリックしに来る。**

### 1-2. AIで記事を量産すると、サイトごと消される

- Googleは2024年3月に「**大量生成されたコンテンツの悪用**」をスパムポリシーに追加。
  2025年8月・**2026年8月**のスパムアップデートでも、AI記事の量産サイトが繰り返し落とされている
  （[balubo magazine](https://corp.balubo.jp/magazine/google-august-2026-spam-update-ai-content)、[hsworking](https://www.hsworking.com/post/google-spam-update-2026-06)）
- Googleが問題にしているのは「AIで書いたこと」ではなく、「**順位操作を目的とした、有用性の低い大量生成**」
  （[ネオインデックス](https://www.neoindex.co.jp/blog/ai-seo-contents-guide/)）
- 評価されるのは「**実体験・業務で得た知見・実際に試して得たデータ**」＝一次情報

→ **「AIが自動で質量ともに圧倒する」を、記事の本数でやると、確実に負けます。**
　 圧倒すべきは本数ではなく、**一次情報の量**と**応答の速さ**です。ここが2章の設計の根っこです。

### 1-3. だからCaSyの辞典型を核にしない

`casy.co.jp/dictionary` を取得して確認しました。キッチン・トイレ・お風呂・洗面所・リビング・お部屋・玄関の
**7カテゴリの一般的な掃除解説**です（記事一覧はJavaScript描画のため、本数と日付は取得できませんでした）。

これは、**誰が書いても同じ内容になる**種類の情報です。
つまり (1) AI Overviewsに要約されてクリックされず、(2) AIで量産すれば1-2で落とされ、
(3) 仮に上位を取っても、大手（CaSy・ベアーズ・おそうじ本舗・くらしのマーケット）が同じものを持っている。
**オーナーの「浅はかでは」という直感は正しいです。** ただし部品としては使います（3章・案A）。

## 2. AIが運営するメディアが、人間の運営するメディアに本当に勝てる場所

「圧倒する」を本数で解釈しないなら、どこで勝つか。**AIにだけできて、人間の編集部にはできないこと**は4つです。

| # | AIにだけできること | 人間の編集部にできない理由 |
|---|---|---|
| ① | **一人ひとりに、その場で答える**（写真を見て「あなたのエアコンは洗うべきか」を判定する） | 1日に何百件も個別対応できない |
| ② | **業務データを、そのまま公開できる形に変換し続ける**（施工1件ごとに事例・相場・所要時間を自動生成） | 施工のたびに記事を書く人件費が出ない |
| ③ | **1つの素材を、全チャネルへ同時に配る**（写真5枚 → サイト事例・Instagram・GBP投稿・LINE・YouTube Shorts） | 媒体ごとに担当を置く必要がある |
| ④ | **やり取りそのものが、次のコンテンツになる**（相談1件 → 匿名化した公開Q&Aページ1本） | 問い合わせ対応と記事制作が別部署 |

**そして、ワンヒッターには「AIに食わせる一次情報」がすでにあります。**

| 一次情報 | 量 | どこにあるか |
|---|---|---|
| 施工の実データ（メニュー・金額・日付・エリア） | **957名・年319件** | スプレッドシート `顧客管理台帳` |
| 施工写真（ビフォー・アフター・汚水） | 162枚（今後 1案件5枚で増える） | Drive `施工写真_一次格納` |
| 所要時間マスター | 全メニュー | 見積ルール |
| 追い焚き配管のATP測定値（汚れの数値） | 施工ごと | 現場 |
| Googleクチコミ全文 | 23件（5件は全文取得済み） | `docs/クチコミ素材.md` |
| アンケート（満足度・自由記述） | 209名 | 集計済み |

**CaSyにも、くらしのマーケットにも、「1台のエアコンから何リットルの汚水が出て、
何分かかって、いくらだったか」の実データは公開できません。** ここで勝ちます。

## 3. メディア案（7案）

**評価の軸**は、オーナーの指示どおり「依頼の数」「自動化できるか（オーナーの手間）」「同業者へ渡せる形か」の3つです。
各案に「AI側の勝ち筋（2章のどれか）」「最初の依頼が来るまでの目安」「法令上の注意」を添えました。
目安の期間は一般論・経験則であって、当社で検証した数字ではありません。

---

### 案A｜「掃除の相談所」─ 写真を送ると、洗うべきかを判定して、そのまま手配できる

**何か：** エアコン・レンジフード・浴室・洗濯機の写真を送ると、AIが
「**ご自分でできる** ／ **プロが要る** ／ **今は不要**」を判定し、
プロが要る場合は実データに基づく**概算料金**と、**1タップの手配ボタン**を出す。
相談内容は匿名化して**公開Q&Aページ**になり、同じ悩みの人が検索で辿り着く。

**なぜ勝てるか（①④）：**
- 「必要な分だけプロの技術を」という会社のコンセプトそのもの。**「今は不要」と言える媒体は、業者にはできない。**
  それが信頼になり、「窓口」の座を取る
- 相談1件が公開ページ1本になる。**本数はユーザーが増やす。** AI量産ではなく、実在の質問への回答なので1-2に触れない
- 検索の「うちの場合どうか」（1-1で残っている63%側）を正面から取る
- 手配ボタンの先が**自社でも同業者でもよい**。最初から「窓口」の形をしている

**依頼の流れ：** 写真 → 判定 → 概算 → 「手配する」→ 氏名・エリア・希望日 → 自社の空き枠なら自社、無ければ同業者へ

**自動化：** 判定はClaude APIの画像入力で実装できる（**API利用料が要る＝お金の判断**。1判定あたり数円〜十数円の見込み。
正確な単価は `claude-api` の資料で確認してから見積もる）。サイトはNetlifyで当スレッドが今すぐ組める。

**最初の依頼まで：** 流入が要るので**単体では動かない**。柱1のSNS・GBP、および案Bと組み合わせて初めて回る。目安2〜4か月。

**法令：** 判定は「目安」と明示し、診断・保証と受け取られる表現を避ける。料金は `data/prices.json` から生成し「概算・税込」を明記。
手配情報を同業者へ渡すため、**フォームで第三者提供の同意を取る**（個人情報保護法）。

### 案B｜「汚れの図鑑」─ 実際の現場の汚れを、機種・年数・環境ごとに全部見せる

**何か：** 施工のたびに撮る「Before2・After2・汚水1」を、**築年数／使用年数／ペット・喫煙の有無／エリア／メニュー**で
タグ付けして図鑑化する。「築12年・西葛西・ペットあり のエアコンの中身」がそのまま1ページ。
1ページ＝Instagram1投稿＝GBP投稿1本＝Shorts1本に自動展開。

**なぜ勝てるか（②③）：**
- **誰にも真似できない一次情報の塊。** 大手は現場写真を体系的に公開していない
- ハウスクリーニングで最も強い素材（ビフォーアフター・汚水）を、**SNSの「怖いもの見たさ」の拡散力**に乗せる
- 施工が続く限り、**人が原稿を書かなくても毎日1ページ増える**
- 各ページの末尾が「似た状態なら → 案Aで相談」につながる

**依頼の流れ：** SNSで見る → 図鑑ページ → 相談所（案A）→ 手配

**自動化：** 写真がDriveに入る → EXIFの日時で台帳と突き合わせ（`docs/photo-inventory.md` で機械的にできることを確認済み）
→ ページ生成 → 各SNSへAPI投稿。**人間が要るのは撮影だけ。**
写真の投稿許可は、新アンケートのQ8で取る設計が既にある（`docs/survey-redesign.md`）。

**最初の依頼まで：** SNS経由なので 1〜3か月。柱1の90日案と完全に重なる（＝**柱1がそのまま案Bの土台**）。

**法令：** 組写真は**必ず同一箇所**（過去に別現場を組んだ失敗あり）。お客様・住戸が特定できる要素は出さない。
「〇〇菌を除去」等の効果の断定は書かない。

### 案C｜「ハウスクリーニング価格インデックス」─ 本当の相場を、実データで四半期ごとに公開する

**何か：** 自社の年319件の実施工データ＋公開されている同業の価格表から、
「東京東部のエアコンクリーニング 実勢価格（2026年Q3）」のような**相場レポート**を四半期ごとに自動生成し、
PR TIMESなどで配信する。メニュー別・エリア別・季節別。

**なぜ勝てるか（②）：**
- **AI Overviews・ChatGPTが「相場」を答えるとき、引用する先になる。** 1-1のゼロクリック時代に、
  クリックされなくても「出典：〇〇」と名前が出続ける唯一の方法
- 報道・比較サイト・ブロガーが引用し、被リンクが自然に集まる（SEOの土台）
- 「窓口」に必要な**中立性・権威性**をつくる。相場を公開している会社が、同業者を紹介しても不自然でない

**依頼の流れ：** 直接の依頼は少ない。**案Aの概算料金の裏付け**と、**媒体全体の信用**を作る役

**自動化：** 完全に自動化できる（データは手元。生成・配信はスクリプト）。PR TIMESの配信料は**お金の判断**（1配信 3万円程度が相場。要確認）。
無料の配信先（自社サイト・GBP投稿・SNS）だけでも成立する。

**最初の依頼まで：** 単体では依頼を生まない。権威づけの装置。

**法令：** 「相場」は算出方法と母数を明記。他社の価格を載せる場合は出典と取得日を添え、比較で自社を有利に見せない（景表法の比較広告の要件）。

### 案D｜「原状回復クリーニングの窓口」─ 管理会社・大家向けの、まとめて頼めるメディア

**何か：** 賃貸の退去後クリーニング・空室クリーニングを、**管理会社・オーナー・仲介会社向け**に
「相場・ガイドライン解説・事例・まとめて手配」で提供するB2Bメディア。江戸川区・浦安・市川に絞る。

**なぜ勝てるか（②）：**
- **業務提携経路は、当社で最も価値が高い**：平均LTV **186,272円**・リピート率 **45%**・単価 **100,128円**
  （`docs/流入経路の分析.md`）。マッチングPFの6.6倍のLTV
- 1件の契約が**継続的に複数戸**を生む。**「自社で受けきれない量」を最も作りやすい経路**で、
  同業者への発注が最も自然に成立する（管理会社は誰が作業するかより、まとめて頼めることを重視する）
- 個人向けは大手とマッチングPFがひしめくが、**地域の管理会社向けのネット窓口は空いている**（今回の同業10社の中に、この形の発信は無かった）

**依頼の流れ：** 「原状回復 クリーニング 相場 江戸川区」検索 → ガイド → 見積フォーム → 手配

**自動化：** コンテンツ・見積は自動化できる。**ただし管理会社との初回の契約だけは人が要る可能性が高い**（電話・訪問）。
ここはオーナーの手間の例外になる。フォームからの自動見積で、どこまで人を外せるかは試してみないと分からない。

**最初の依頼まで：** 検索経由なので 3〜6か月。ただし1件の重さが違う。

**法令：** 個人向けと同じ。加えて、管理会社との継続取引は書面（基本契約）を作る。

### 案E｜「職人のネットワーク」─ 供給側を先に集める

**何か：** 窓口が集めた依頼を**渡す先**を、先に作る。江戸川区・浦安・市川の**個人事業のクリーニング職人**向けに、
「集客ノウハウ・相場情報・**当窓口からの案件を受ける登録**」を提供するLINE＋サイト。

**なぜ勝てるか：**
- **これが無いと、案A〜Dで集めた依頼の行き先が無い。** 窓口の裏側そのもの
- 柱1の調査で、**地場の同業4社がSNS・サイトの更新ゼロ**だった。ネットで客を集められない職人は、
  集めた客を渡してくれる窓口を歓迎する。**供給側の勧誘は、需要側より簡単**
- 職人向けの情報発信は、AIが得意（相場・集客ノウハウ・繁忙期予測）

**依頼の流れ：** 依頼ではなく**受け皿**。手数料は既存の紹介制度（事業者紹介 5〜15%・原則12%）を逆向きに使う

**自動化：** 登録・案件通知・完了報告はLINE Messaging API（承認済み）で自動化できる。
ただし**最初の数社の勧誘と品質の見極めは人が要る**（電話1本ずつ）。ここもオーナーの手間の例外。

**最初の依頼まで：** —（受け皿）。案A〜Dの依頼がキャパを超えた時点で必要になる。**それまでに5社あれば足りる。**

**法令：** 紹介型（お客様が職人と直接契約し、当社は紹介料を受ける）なら許認可は不要。
**当社が受注して再委託する型**にすると、当社が施工責任を負い、資本金の要件次第で下請法の対象になりうる。
**まず紹介型で始める**のが安全。どちらの型でも、**お客様に「誰が作業するか」を事前に明示する。**

### 案F｜「洗いどきアラート」─ 家電を登録すると、洗う時期にLINEで知らせる

**何か：** エアコンの設置年・機種、レンジフード、洗濯機を公式LINEに登録すると、
**その家の「洗いどき」に合わせて**通知が来る無料サービス。通知に「相場」「空き状況」「手配」を添える。

**なぜ勝てるか（①③）：**
- ハウスクリーニングは**タイミング商売**。5〜7月と11〜12月に集中し、1〜2月が谷（`docs/cmo-savedata.md`）。
  **「今、洗うべき人」に、その瞬間だけ声をかける**のはAIが最も得意
- 検索・SNSのアルゴリズムに依存しない**自前の到達手段**。1-1のゼロクリックと無関係
- 既存の公式LINE（`@366ysqyc`・Messaging API承認済み）の上に載せられる。**新規のインフラが要らない**

**依頼の流れ：** 登録 → 洗いどきに通知 → 手配（自社 or 同業者）

**自動化：** 完全に自動化できる。既存の `tools/line_client.py` と `line-webhook.gs` の延長。

**最初の依頼まで：** 登録者が要るので、単体では動かない。**案A・Bの出口に「登録」を置く**ことで育つ。

**法令：** 通知はユーザーの同意に基づく（登録時に明示）。特定電子メール法はLINEには直接かからないが、配信停止をいつでもできるようにする。

### 案G｜「江戸川区のクリーニング業者、全社のクチコミを全部読んだ」─ 同業者の比較サイトを、自分で運営する

**何か：** 商圏の同業者について、**公開されているクチコミ・料金・対応メニューを全部集めて整理した比較サイト**。
利用者は「比較して選ぶ」ことができ、どの業者に頼んでも、**フォームは当窓口が受ける**。

**なぜ勝てるか（②④）：**
- くらしのマーケット等が握っている「**業者を選ぶ瞬間**」を、地域限定で取りに行く。
  大手PFは全国版なので、「江戸川区の全社を読み比べた」深さでは負けない
- 「受注は弊社でなくてもよい」というオーナーの構想と、いちばん素直に一致する。**比較サイト＝窓口**
- 案Cの相場データと組むと、「相場と全社比較」で地域の決定版になる

**依頼の流れ：** 「江戸川区 エアコンクリーニング おすすめ」→ 比較 → 業者を選ぶ → フォーム（当窓口）→ その業者へ渡す

**自動化：** 収集・更新は自動化できる（公開情報のみ。ログインが要るPF内の情報は使わない）。

**最初の依頼まで：** 検索経由で 3〜6か月。ただし比較系キーワードは競争が激しい。

**法令：これが一番重い。**
- **ステマ規制（景表法・2023年10月〜）**：運営者がワンヒッターであることを**明示**しないと違反。自社を有利に見せる編集も不可
- 他社の商標・クチコミの引用は出典明記・改変なし。**他社の評価を下げる記述は不正競争防止法のリスク**
- 掲載される同業者に事前に知らせるのが筋（知らせないと、供給側との関係を壊す）
- **奇抜だが、中立性を本当に守れるなら最も強い。守れないなら最も危ない。**

## 5. 推奨：1つを選ぶのではなく、1つの装置として組む

**単体で成立する案が無い**のが正直な結論です。だから、役割の違う案を**1つの装置**として組みます。

```
        ┌──────────────── 集める ────────────────┐
        │  B 汚れの図鑑（SNS・GBP・Shortsへ自動展開）  │ ← 柱1の90日案がそのまま土台
        │  C 価格インデックス（AI検索・報道に引用される）│
        └───────────────────┬────────────────────┘
                            ▼
        ┌──────────────── 受ける ────────────────┐
        │  A 掃除の相談所（写真→判定→概算→手配）      │ ← 装置の心臓
        └───────────────────┬────────────────────┘
                            ▼
        ┌──────────────── 渡す ──────────────────┐
        │  自社の空き枠  ──なければ──▶  E 職人ネットワーク │
        └───────────────────┬────────────────────┘
                            ▼
        ┌──────────────── 戻す ──────────────────┐
        │  F 洗いどきアラート（次の洗いどきに、また窓口へ） │
        └────────────────────────────────────────┘

        別枠：D 原状回復の窓口（B2B。額が大きい。人の手が一部要る）
        保留：G 比較サイト（法令の整理が先。装置が回ってから判断）
```

**核は A です。** 「今は不要」と言える媒体だけが、業者ではなく窓口として信頼されます。
B と C は A に人を連れてくる装置、E は A の出口、F は A に戻す装置。

### 5-1. ブランドを分ける（重要な設計判断）

**この装置は、「ワンヒッター」の名前で運営しないことを推奨します。**

- 同業者に依頼を渡す窓口が、施工業者の名前だと、**利用者にも同業者にも中立に見えません**
- おそうじ本舗が「本舗」の名前で集客し、加盟店が施工する構造と同じ。**窓口ブランドと施工ブランドは分ける**
- ワンヒッターは「窓口の運営会社」として**特商法表記・運営者情報に明記**する（ステマ規制の要件も満たす）
- 別ドメインが要る（**取得費用はお金の判断**。年1,500〜3,000円程度）。
  `one-hitter.jp` は 9/30 に期限を控え、DNSがネームギアにあってオーナーが未ログインという状態なので、
  **サブドメインで始めるのは危険**です

### 5-2. 名前の候補（決めるのはオーナー。ここでは方向だけ）

「相談所」「窓口」「図鑑」の性格が伝わり、地域名を含まない（後で商圏を広げられる）もの。
候補出しは装置の形が決まってからにします。
