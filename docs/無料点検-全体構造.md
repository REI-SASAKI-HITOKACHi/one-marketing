## 0. 設計の前提（オーナーの指摘を反映）

## 1. 点検メニュー（3つ。全部「請求されて行く」プル型）

| メニュー | 見せるもの | 道具 | 現場の所要 | つながる施工（税込） | 成約時の粗利の目安 |
|---|---|---|---|---|---|
| **A. 洗濯槽の裏**（主力） | 槽と外槽の隙間から見える裏側のカビ。内視鏡の静止画3〜5枚 | スマホ接続の内視鏡カメラ（**要購入・数千円。お金の判断**） | 5〜8分 | 洗濯機クリーニング 17,380円 | 単価そのまま（オプション：防水パン3,630円・排水溝3,630円） |
| **B. 追い焚き配管** | ATPの数値（清浄度）と、循環口の写真 | ルミテスター（保有）＋試薬（**消耗品費。お金**） | 8〜12分（採水〜測定） | 追い焚き配管クリーニング 19,910円 | 同上（浴室と同時なら16,610円） |
| **C. エアコン（施工中のみ）** | **いま洗っている1台の汚水**を見せ、同じ家の他の台を提案 | 施工中のバケツ | 0分（施工中） | 2台目以降 10,780円（お掃除機能付き17,380円） | 移動ゼロ・最も効率が良い |

- **AとBは「点検だけ」でも受ける（単独点検）。ただし閑散期の空き枠だけ**（4章）
- **Cは点検メニューではなく、施工の型。** 全施工で必ずやる。ダスキン ターミニックスの「保証中は年1回無料点検」と同じ位置づけ
- 浴室・レンジフードは「見せる」より「汚れが見えている」ので点検メニューにしない。ついでに見えれば報告書に1行足すだけ

### 「ついで点検」（全施工で必ず）

施工に行った家で、**追加の移動ゼロ**でAかBを1つやる。これが最も費用対効果が高い（エアコンのみ客621名・換気扇未購入807名）。
- 洗濯機が縦型なら A（3分）、浴室に追い焚きがあれば B（8分）。両方あれば A
- 結果は同じ報告書に載り、同じ導線（3章）で次回予約に落ちる

## 3. その場で受注する（2026-09-11 オーナー指示。法令遵守の形で、極力その場で）

**方針：** 点検の最大の役務は「こんなに汚れてたのか」の驚きにある。報告書を送って終わりでは受注につながらず、他社に持っていかれる。**法令を守ったうえで、その場で申込を取る。施工は後日、キャンセル可。**

### 特定商取引法との関係（要専門家確認。ここは「該当する前提」で設計する）

消費者が「点検」を依頼して訪問した先で、点検と別の役務（クリーニング）を契約する場合、**訪問販売に該当しうる**。該当する前提で、義務を最初から満たす形にする。

| 義務 | この設計での満たし方（全部自動） |
|---|---|
| 氏名等の明示（事業者名・勧誘目的・役務の種類）を勧誘前に | 申込ページの冒頭と、渡辺さんが最初に見せる画面に固定表示。**申込時の予約確認メールにも「訪問時に清掃サービスのご案内をすることがあります」を明記**（＝点検の依頼時点で勧誘目的を告げている） |
| 申込書面・契約書面の交付 | **電磁的方法（メール・LINE等）による交付**。2023年6月施行の改正で、**消費者の承諾があれば電子交付可**。申込フォームに承諾のチェックを置き、送信と同時に書面（PDF）を自動送付 |
| クーリングオフ（書面受領から8日） | 書面に赤枠で明記。施工日は原則9日目以降に置くか、8日以内に施工する場合は「施工後でも8日以内なら解除でき、役務の対価は請求しない」旨を書面に入れる（特商法の役務提供の規定に沿う） |
| 再勧誘の禁止 | 「今回は結構です」の一言で、その場の案内を終える。渡辺さんの画面に「断られたら報告書だけ」のボタン |
| 不実告知の禁止 | 写真と数値だけを見せる。「このままだと壊れる」「危険」は言わない・書かない |

**渡辺さんが覚えることは2つだけ：** 「見せる」と「QRを読んでもらう」。文言・書面・告知は全部システムが出す。

### その場で申し込まない人への導線

その場で決めない人には「今晩、報告書をお送りします」で帰る。報告書に同じ申込リンク（本人の請求＝通信販売）。3日後・14日後の自動追跡。

### 専門家確認

着手前に、行政書士か弁護士に**申込画面・契約書面・クーリングオフ告知の3点**を1回見せる（費用はお金の判断）。確認までは「ついで点検」だけ運用し、その場の申込は既存客の追加注文（既存の見積・受注の型）として扱う。

## 4. 枠の制御（人が判断しない仕組み）

**点検は「閑散期の、空いている、近い」枠にしか入らない。** これをカレンダーから自動で作る（既存の `tools/build-slots.py` の拡張）。

| 条件 | 値（初期値。オーナーが変えられる） |
|---|---|
| 期間 | 1〜2月・3〜4月・8〜10月（次回予約割引がある月＝閑散期の定義に合わせる） |
| 出す枠 | その日に施工があり、**施工先から半径2km以内**に組める前後の空き（移動15分以内） |
| 1日の上限 | 2件 |
| 1週の上限 | 6件 |
| 出さない日 | 施工が3件以上ある日、休日 |

- 施工の住所は台帳にある。申込者の住所は区・市＋町名まで取れば距離は出せる
- 上限に達したら申込フォームは「次の空き」を出す。**渡辺さんに「行けますか」と聞く工程を作らない**

## 5. 成約率30%の線と、続ける／やめるの判断（自動で出す）

| 指標 | 定義 | 線 |
|---|---|---|
| **点検→予約率** | 報告書送付から30日以内に予約フォーム送信 ÷ 点検件数 | **30%を切ったらそのメニューの単独点検を止める**（ついで点検は続ける） |
| 「要洗浄」率 | 判定が要洗浄 ÷ 点検件数 | 参考。低いなら入口の文言が広すぎる |
| 「今回は不要」率 | | **公開する数字**（中立の証明） |
| 点検1件の稼働 | 移動＋点検＋入力の分 | 週次報告に載せる |

**採算の目安（分かっている数字だけ）：** 洗濯機クリーニング17,380円。点検→予約30%なら、施工1件あたり点検3.3件≒稼働100分（移動15分＋点検10分＋入力5分×3.3）。閑散期の空き枠（稼働率20〜50%）なら成立。繁忙期は枠が出ないので自然に止まる。

判断はオーナー。ただし**数字は週次報告に自動で出る**ので、見て「止める」と言うだけで済む。

## 8. 守ること

- 入口は**本人の申込のみ**。飛び込み・電話勧誘・「近くで作業中なので」は一切しない
- 報告書は**依頼の有無に関係なく全員に**渡す。「今回は不要」を書き、その件数を公開する
- 不安を煽る表現（「このままだと…」「危険」）は使わない。事実（写真・数値）と、公的資料の一般論（東京都の指針）まで
- 写真はお宅が特定できないもの（洗濯槽の中・循環口・バケツ）だけ。報告書の掲載許可はアンケートQ8で

## 8-1. 内視鏡カメラの相場と投資対効果（2026-09-11 取得）

**相場：** モノタロウ「スマホ用内視鏡」人気ランキング上位の表示価格は **3,500円（複数）〜7,000円**（取得日 2026-09-11、https://www.monotaro.com/k/store/スマホ用内視鏡/ ）。サンワサプライ等の防水（IP67）・USB Type-C・先端5.5mm前後のものが同価格帯。
→ **予備を含めて2台で 7,000〜14,000円**。

**投資対効果（当社の数字だけ。仮定は明記）**

| 項目 | 値 | 根拠 |
|---|---|---|
| 洗濯機クリーニング 単価 | 17,380円（税込） | `data/prices.json` |
| 内視鏡の費用 | 7,000〜14,000円（2台） | 上の相場 |
| **回収に要る成約** | **1件**（1件で費用を上回る） | 17,380円 ＞ 14,000円 |
| 点検1件の稼働 | 洗濯槽 5〜8分（ついで点検なら移動ゼロ） | 1章 |
| 月の施工件数 | 約30件 | savedata |
| 縦型洗濯機がある家の割合 | **未確認（仮定：半分）** | 現場で数える |
| ついで点検の対象 | 月約15件（仮定） | 上の仮定 |
| 点検→予約率 | **未確認**。30%を線に置く（5章） | ほけんの窓口55%・レイコップ貸出7割は業種が違う。当社で測る |
| 30%なら | 月4〜5件 × 17,380円 ＝ **月約7〜8万円の売上増**、稼働は月約100分 | 仮定の積 |
