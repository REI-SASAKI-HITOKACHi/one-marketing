# 無料点検（型①「中を見せる」）の全体構造 ─ 人の稼働は「点検そのもの」だけ

作成 2026-09-11 ／ 担当 ネット流入施策担当（`web-inflow`）／ オーナー指示「全体構造まで超具体的に。人間の稼働0（点検稼働は除く）」
根拠：`docs/潜在→顕在の事例研究.md`（意向59.8% vs 実行7.5%、シロアリ点検、ほけんの窓口55%、レイコップ貸出→購入7割）
**まだ何も作っていません。何も公開していません。金額の判断はすべてオーナー。**

## 0. 設計の前提（オーナーの指摘を反映）

| 指摘 | 反映 |
|---|---|
| エアコンのアルミフィンの汚れは、洗って初めて汚水で見える | **エアコンは「単独の無料点検」から外す。** エアコンは施工中の汚水で**その場の2台目・他の部屋**を売る（クロスセル型） |
| 洗濯槽の裏側は視覚的に強い | **洗濯槽＝主力の点検メニュー。** 内視鏡カメラ（スマホ接続・数千円）で槽の裏を撮る。**分解しない** |
| ルミテスターで追い焚き配管 | **追い焚き＝第2の点検メニュー。** ATPの数値と写真。当社が既に持っている測定器と型（クチコミ・GBP文案に「数値化」がある） |
| 成約率30%を切るとかなり厳しい | **30%を「続ける／やめる」の線にし、閑散期だけ回す。** 稼働の空いている枠にしか点検を入れない（後述の枠制御） |
| 人の稼働0 | 申込・日程・リマインド・報告書の生成と送付・見積・予約・追跡・週次報告を全部自動。**渡辺さんがやるのは、点検して、スマホのフォームに写真と数値を入れるだけ** |

## 1. 点検メニュー（3つ。全部「請求されて行く」プル型）

| メニュー | 見せるもの | 道具 | 現場の所要 | つながる施工（税込） | 成約時の粗利の目安 |
|---|---|---|---|---|---|
| **A. 洗濯槽の裏**（主力） | 槽と外槽の隙間から見える裏側のカビ。内視鏡の静止画3〜5枚 | スマホ接続の内視鏡カメラ（**要購入・数千円。お金の判断**） | 5〜8分 | 洗濯機クリーニング 17,380円 | 単価そのまま（オプション：防水パン3,630円・排水溝3,630円） |
| **B. 追い焚き配管** | ATPの数値（清浄度）と、循環口の写真 | ルミテスター（保有）＋試薬（**消耗品費。お金**） | 8〜12分（採水〜測定） | 追い焚き配管クリーニング 19,910円 | 同上（浴室と同時なら16,610円） |
| **C. エアコン（施工中のみ）** | **いま洗っている1台の汚水**を見せ、同じ家の他の台を提案 | 施工中のバケツ | 0分（施工中） | 2台目以降 10,780円（お掃除機能付き17,380円） | 移動ゼロ・最も効率が良い |

- **AとBは「点検だけ」でも受ける（単独点検）。ただし閑散期の空き枠だけ**（4章）
- **Cは点検メニューではなく、施工の型。** 全施工で必ずやる。ダスキン ターミニックスの「保証中は年1回無料点検」と同じ位置づけ
- 浴室・レンジフードは「見せる」より「汚れが見えている」ので点検メニューにしない。ついでに見えれば報告書に1行足すだけ

### 「ついで点検」（全施工で必ず）

施工に行った家で、**追加の移動ゼロ**でAかBを1つやる。これが最も費用対効果が高い（エアコンのみ客621名・換気扇未購入807名）。
- 洗濯機が縦型なら A（3分）、浴室に追い焚きがあれば B（8分）。両方あれば A
- 結果は同じ報告書に載り、同じ導線（3章）で次回予約に落ちる

## 2. 申込から次回予約までの流れ（人の作業は★だけ）

```
 [入口]  暦LP／節目QR／既存客LINE／GBP投稿 ── すべて ?src= 付き
   │
   ▼
 [申込]  Web申込フォーム（無料点検専用）
         項目：点検したいもの（A/B）／住所（区・市まで）／電話／希望日（空き枠から選ぶ）／同意
         → 空き枠は「閑散期の、既存の施工の近所の、空き2時間」だけを出す（4章の枠制御）
   │  自動：受付メール＋LINE／SMS。カレンダーに【点検・仮】
   ▼
 [前日]  自動：リマインド（SMS）。当日朝：渡辺さんのLINEに「今日の点検 1件・所要8分・地図」
   │
   ▼
★[点検]  渡辺さんが訪問（10分）。スマホの「点検フォーム」に入力するだけ：
         写真3〜5枚／ATP数値／機種・年数／所見の選択肢（3択：きれい・汚れあり・要洗浄）／自由記述1行
         ★ その場で見積も契約もしない（3章の理由）。「今晩、報告書をお送りします」で帰る
   │
   ▼
 [報告書] 自動生成（当日18時までに）：写真・数値・判定・「今回は不要」の場合はそう書く
         判定が「要洗浄」なら、料金（税込・追加なし）と次回予約割引を明記し、予約フォームのリンク
         → LINE／SMS／メールで送付。同じ内容を「マイ報告書」URL（noindex）にも置く
   │
   ▼
 [追跡]  自動：3日後「ご質問はありますか」／14日後「空き枠の案内」／閑散期の割引の締切前
         「今回は不要」の人：次の点検時期（洗濯槽は1年後・追い焚きは半年後）にLINEで戻す
   │
   ▼
 [予約]  予約フォーム（既存 one-hitter-booking）。src=点検 で記録。施工当日に次回日付を仮予約（歯科リコール）
   │
   ▼
 [週次]  自動：オーナーへ月曜9時に1通「点検◯件／要洗浄◯件／予約◯件／成約率◯%／今回不要◯件／エリア別」
```

**渡辺さんの作業は★の2つだけ**（点検と、スマホフォーム入力）。フォームは写真を撮って送るだけで、報告書の文章は自動で組みます。

## 3. その場で契約しない理由（法令と成約率の両方）

- **特定商取引法：** 消費者が「点検」を依頼して訪問した先で、点検とは別の役務（クリーニング）を勧誘して契約すると、**訪問販売に該当しうる**（消費者庁の解釈。「点検商法」はまさにこの型で、相談年約2万件・業務停止命令の前例）。書面交付・クーリングオフ告知が要り、印象も悪い
- **設計で回避：** その場では見積・契約をしない。**報告書を送り、お客様が自分で予約フォームから申し込む**（＝通信販売・本人の請求）。押し売りの構造を最初から持たない
- **成約率にも効く：** 事例（ほけんの窓口55%）は「証拠を本人が見た」あとの選択。報告書を家族と見て決める時間を与えるほうが、玄関先で決めさせるより落ちにくい（ここは当社で測る）
- **要専門家確認**と明記しておく。着手前に1回、行政書士か弁護士に文面を見せる（費用はお金の判断）

## 4. 枠の制御（人が判断しない仕組み）

**点検は「閑散期の、空いている、近い」枠にしか入らない。** これをカレンダーから自動で作る（既存の `tools/build-slots.py` の拡張）。

| 条件 | 値（初期値。オーナーが変えられる） |
|---|---|
| 期間 | 1〜2月・3〜4月・8〜10月（次回予約割引がある月＝閑散期の定義に合わせる） |
| 出す枠 | その日に施工があり、**施工先から半径2km以内**に組める前後の空き（移動15分以内） |
| 1日の上限 | 2件 |
| 1週の上限 | 6件 |
| 出さない日 | 施工が3件以上ある日、休日 |

- 施工の住所は台帳にある。申込者の住所は区・市＋町名まで取れば距離は出せる
- 上限に達したら申込フォームは「次の空き」を出す。**渡辺さんに「行けますか」と聞く工程を作らない**

## 5. 成約率30%の線と、続ける／やめるの判断（自動で出す）

| 指標 | 定義 | 線 |
|---|---|---|
| **点検→予約率** | 報告書送付から30日以内に予約フォーム送信 ÷ 点検件数 | **30%を切ったらそのメニューの単独点検を止める**（ついで点検は続ける） |
| 「要洗浄」率 | 判定が要洗浄 ÷ 点検件数 | 参考。低いなら入口の文言が広すぎる |
| 「今回は不要」率 | | **公開する数字**（中立の証明） |
| 点検1件の稼働 | 移動＋点検＋入力の分 | 週次報告に載せる |

**採算の目安（分かっている数字だけ）：** 洗濯機クリーニング17,380円。点検→予約30%なら、施工1件あたり点検3.3件≒稼働100分（移動15分＋点検10分＋入力5分×3.3）。閑散期の空き枠（稼働率20〜50%）なら成立。繁忙期は枠が出ないので自然に止まる。

判断はオーナー。ただし**数字は週次報告に自動で出る**ので、見て「止める」と言うだけで済む。

## 8. 守ること

- 入口は**本人の申込のみ**。飛び込み・電話勧誘・「近くで作業中なので」は一切しない
- 報告書は**依頼の有無に関係なく全員に**渡す。「今回は不要」を書き、その件数を公開する
- 不安を煽る表現（「このままだと…」「危険」）は使わない。事実（写真・数値）と、公的資料の一般論（東京都の指針）まで
- 写真はお宅が特定できないもの（洗濯槽の中・循環口・バケツ）だけ。報告書の掲載許可はアンケートQ8で

## 9. まだ分からないこと

- 点検→予約率（30%を超えるか）。10月のついで点検で最初の数字を取る
- 内視鏡で洗濯槽の裏がどこまで写るか（機種による）。**購入して1台で試す**のが最短
- 追い焚きのATP採水に何分かかるか（渡辺さんの実測）
