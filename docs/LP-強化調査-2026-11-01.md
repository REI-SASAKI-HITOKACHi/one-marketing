# LP 強化の調査と、いまのLPの弱点（2026-11-01・LP・サイト担当）

オーナー指示（11/1）：「LPがまだまだ弱いから強化する。ネット上のLPの強化方法を徹底的に調べ、新しい情報を中心に。結果を踏まえて弱点と改善の方向性を報告」。

- 調べたもの：国内外のLP改善・CRO・ホームサービス集客・心理・フォーム・表示速度・広告着地・法規の記事と調査（約25本の検索、2024〜2026年のものを中心。心理と古典的な実験は古いものも採用）
- 見たもの：本番と同じ配信物（/aircon-c/・/aircon-e/・/kabi/・/mizumawari/・/nenmatsu/）をスマホ幅 390px で開き、1画面目の文字・全長・写真・導線を数えた。数字は CMO セーブデータ（〜10/31）から
- **読み方の注意**：ネット上の「◯%改善」の多くは業者のブログで、元の調査が確かめられない。下の表では、確かさを「◎ 一次資料・大規模」「○ 実験はあるが1件・小規模」「△ 業者の主張・出典不明」に分けた。数字そのものより「向き」を使うこと

## 1. 結論（先に）

いまのLPは「料金を先に全部書く」「施工前後の写真」「空き枠からそのまま予約」ができていて、土台は悪くない。弱いのは次の5つ。

| | 弱点 | 改善の方向 | 急ぎ |
|---|---|---|---|
| 1 | **誰が家に来るのかが見えない**（職人の顔写真が0枚） | 1画面目のすぐ下に、渡辺さんの顔・名前・一言・作業中の写真。損害賠償保険も上へ | ★★★ |
| 2 | **相場より高い理由が、価格の隣に無い**（ノーマル 10,780円 vs 成約相場 約7,900円） | 価格の横に「60分かけて分解して洗う／自社の職人／お見積り以上の追加請求なし」を1行で | ★★★ |
| 3 | **検索した言葉・季節と、1画面目がずれている** | 見出しを季節で切り替える。/kabi/ は「9月の長雨」のまま。浴室の広告が「水まわりまとめて」に着地 | ★★★ |
| 4 | **お客様の声が遅く、薄い**（17画面中14画面目・文字だけ3件） | 声を1画面目の直下と予約ボタンの直前へ。施工写真と組にして、状況（何年ぶり・何台）が分かる声を | ★★ |
| 5 | **申込の道が多すぎて、主役がはっきりしない**（予約ページ・LP内フォーム・電話・LINE の4本、予約ボタン7〜9か所） | 主役は「空き日を見て予約」1本。LP内フォームは「相談したい方」へ格下げ。電話は残す | ★★ |

あわせて、**検証のやり方を変える**必要がある（広告は週40〜100クリック・申込は週2件前後。50:50 のA/Bでは何か月も決着しない）。小さな言い回しの比較より、上の1〜3のような大きな変更を入れ、判定は「予約ページへ進んだ率」で見る。

**LP の外の問題も大きい**ことは正直に書いておく（調査でも「キーワード・価格・問い合わせ後の対応はLPを直しても動かない」と繰り返し出てくる）。11月のネット予約 0件（10/29 時点・目標10件）の主因は、10/16〜27 の入札変更で表示が 144→40/日に落ちたこと（measurement の切り分け）。LP の強化は、流入が戻ったときに取りこぼさないための仕事。

### 2-6. 守ること（法規）

- 二重価格：「通常価格」で実際に売った実績が無いのに比べるのは不当表示になりうる（2025年にジャパネットたかたへ措置命令）。当社の「11月の作業なら 9,702円」は、決まった割引の規則で実際にその金額で受けているので問題ない。**「今だけ」「先着」など根拠の無い言い方は使わない**（[commercepick](https://www.commercepick.com/archives/37362)）
- No.1 表示は、調査の対象・期間・人数を書けないなら使わない（98.6% はいまの書き方どおり出典つきで）
- 2024/10 の改正景品表示法で、ステマ規制・直罰が入った。お客様の声は原文・掲載許可を取ったものだけ（いまの運用どおり）（[国民生活センター](https://www.kokusen.go.jp/pdf_dl/wko/bn-hhkouza_sato.pdf)）

## 4. 弱点と改善の方向（くわしく）

### 弱点1：誰が家に来るのかが見えない ★★★

- **事実**：LP の写真 8枚はすべて施工前後と汚水。「伺うのは、ご予約を受けた私たちです」（id="hito"）の欄に写真が無い。伺うのは基本的に渡辺さん1人
- **なぜ効くか**：頼まない理由の2位が「信頼できる業者が分からない」。家に人を入れるサービスでは「実際のスタッフの写真」が業者ブログで一貫して上位。写真つきの声は記憶に残る（CXL）
- **方向**：
  - 1画面目のすぐ下に、渡辺さんの顔写真（作業着・笑顔でなくてよい）＋名前＋一言（例：「ご予約を受けた私が伺い、終わるまで担当します」）＋作業中の写真1枚
  - 「損害賠償保険に加入」を、価格の近くに上げる
  - 予約ページの確認の画面にも同じ顔写真（「当日伺う担当です」）
- **要るもの**：渡辺さんの写真と掲載の同意（**外に出す＝オーナー確認**）。写真は現場で撮ったスマホ写真で十分

### 弱点2：相場より高い理由が、価格の隣に無い ★★★

- **事実**：ノーマル 10,780円（成約相場 約7,900円の約1.4倍）、お掃除機能付き 17,380円（相場平均 約12,800円）。理由（分解・60分・自社職人・追加請求なし）は書いてあるが、価格から離れた場所（3〜8画面目）
- **なぜ効くか**：頼まない理由の1位が料金。比べる人は「安い業者の当日追加」を恐れている。総額を先に言うことは信頼になる（ドリップ価格の調査）。作業時間の長さは手抜きでない目安として知られている
- **方向**：
  - 価格のすぐ下に1行：「60分かけて、熱交換器の奥まで分解して洗います。お見積り以上の追加請求はありません。」（書き方の決まりの範囲で）
  - 「よくある頼み方と金額」を、1画面目の金額の直後に寄せる（いまは5画面目あたり）
  - 1画面目の金額を6つ → 2つ（通常と11月）に減らす。繁忙期の行・お掃除機能付きは下へ

### 弱点3：検索した言葉・季節と、1画面目がずれている ★★★

- **事実**：
  - /aircon-c/・-e/ の見出しは「フィルターを掃除してもカビ臭い」＝夏の冷房の悩み。11月は暖房の時期
  - **/kabi/ の見出しが「9月の長雨で」のまま**（11月）。帯も「12月は割引なし」の否定のまま（下書きあり・承認待ち）
  - B_浴室の広告（「風呂 釜 掃除 業者」など）が /mizumawari/「水まわりは、まとめて頼むほど安い」に着地している。浴室で検索した人に、1画面目で浴室の話が出ない
  - 広告は江戸川区のキャンペーンがあるのに、1画面目は「東京・千葉・神奈川」だけ（事務所は江戸川区北葛西）
- **なぜ効くか**：広告とLPのずれは離脱の第一の原因（各社一致）。AI Max は**ページの中身から見出しと着地先を選ぶ**ので、古い季節の文言は広告の文にまで混ざる
- **方向**：
  - 見出しを月で切り替える（いまの11月の帯と同じ仕組みを見出しにも）。11〜12月は「暖房をつけたら臭う」「年内に済ませる」、5〜7月はいまの見出し
  - /kabi/ の「9月の長雨」を今すぐ季節に合わせる（小さい直し）
  - 浴室の広告の着地：/mizumawari/ に `?ag=bath` で1画面目の見出しと写真を浴室に替える仕組み（URL は変えない）。新しいページを作るより安く、固定URLにも触れない
  - 地域名：広告の地域（江戸川区など）が分かるときは、1画面目に「江戸川区北葛西の事務所から伺います」を出す

### 弱点4：お客様の声が遅く、薄い ★★

- **事実**：3件、文字だけ、全員女性、14画面目（予約欄のすぐ上）。1画面目近くの証拠は「★5.0 Googleクチコミ」「98.6%」の小さい表示
- **なぜ効くか**：写真つきの声は記憶に残る。声をボタンの近くに動かすだけで上がった実験がある。口コミは点数より中身で読まれる
- **方向**：
  - 1画面目の直下に1件、予約ボタンの直前に1件（同じ声を2回でも可）
  - 声と、その家の施工前後の写真を組にする（顔は不要。「この方のお宅のエアコン」）。完了フォームの写真とアンケートの掲載可の声から選ぶ（crm・measurement と）
  - 状況が分かる声を選ぶ（「◯年ぶり」「2台」「暖房の臭いが消えた」）。原文のまま・件数は書かない（いまの決まりどおり）

### 弱点5：申込の道が多く、主役がはっきりしない ★★

- **事実**：予約ページ（空き枠からその場で予約）／LP 内フォーム（5項目・「担当より日程のご連絡」＝連絡待ち）／電話／LINE。予約ボタンは7〜9か所
- **なぜ効くか**：CTA の数そのものより「次の一歩がはっきりしているか」が効く。空き枠から選べるほうが、連絡待ちのフォームより有利（向きは一致）。電話はスマホで強い
- **方向**：
  - 主役は「空いている日を見て予約する」1本に統一（色・文言・位置）。電話は副（年配の方・急ぎの方）、LINE は「相談」
  - LP 内フォームは「日にちが決まっていない・相談したい方」に格下げし、折りたたむ（申込の数字を見て、予約ページに一本化するか判断）

### その他（急がない）

- **長さ**：17〜20画面。比べて決める買い物なので長いこと自体は悪くないが、同じ11月の話が帯と本文で2回、金額が何度も出る。重複を減らす
- **速さ**：HTML 約100KB、1画面目の写真 約320KB（hero-bg 192KB・hero 132KB）。悪くないが、hero-bg を軽くすれば LCP が縮む。流入が少なく Google の実測データが出ないので、PageSpeed Insights の検査値で見る
- **確かめること**：/mizumawari/ の1画面目「**最短即日**」。予約ページの最短は翌日（SAITAN_NICHI=1）。電話なら即日が本当にあるか渡辺さんに確認し、無ければ消す（優良誤認を避ける）

## 5. 検証の進め方（流入が少ない前提）

- 広告は週 40〜100クリック・申込週2件前後。50:50 のA/Bで差を言うには数百件の申込が要る（調査でも「1案あたり1,000件」などの目安）。**いまの C 対 E（11/10 まで）は、申込の数では決着しない見込み**
- そこで：
  1. **大きく効きそうな変更（弱点1〜3）を先に入れる**。言い回しの小さな比較は後
  2. 判定は「予約ページへ進んだ率」「料金計算を触った率」（毎週数百人ぶんある）で見る
  3. **画面の録画・ヒートマップ（Microsoft Clarity、無料）**で、どこで止まり、どこで戻るかを見る。計測タグの追加なので measurement と CMO の判断（費用0・個人情報の伏せ字設定が要る）
  4. 変える前後を週ごとに並べる（同じ週に複数を変えない）
