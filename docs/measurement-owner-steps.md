# 第1章　GA4（アクセス解析）を用意する

## 1-0. まず、いまの状況をお伝えします

**公式サイト `one-hitter.jp` には、すでにGA4が入っています。** 測定IDは `G-8MV0E0GZHS` です。

なので最初にやることは、**「その中身を、佐々木さんが見られるかどうか」の確認**です。

### ▶ あった場合

   **[データ ストリーム]** を押す
6. 一覧に出てきた行をクリックすると、右上に **[測定ID]** が出ます
7. **それが `G-8MV0E0GZHS` なら、当たりです。** → **1-3へ進んでください**

### ▶ 無かった / そもそもログインできない場合

**それで構いません。LP専用に新しく作ります。** → **1-2へ進んでください**

あわせて、**制作会社（リアライズ）に次の1文をメールで聞いてみてください。**

# 第2章　「申込」を成果として登録する

**第1章が終わってから**、こちらでLPに計測を入れて配信します。
**配信のあと**、この章の作業をしてください。順番が逆だと、リストにイベントが出てきません。

## 2-1. まず、動いているか確かめる

1. スマホで **https://one-hitter-lp.netlify.app/aircon/** を開き、下まで読んで、
   電話ボタンを一度押す（かけずに切って構いません）
2. パソコンでGA4を開き、左メニューの **[レポート]** → **[リアルタイム]** を押す
3. **「過去30分間のユーザー数」が 1 以上**になっていて、下のほうの
   **「イベント数（イベント名）」**に `phone_click` や `scroll_depth` が出ていれば成功です

> 数分待っても出ないときは、**ブラウザの広告ブロック機能**が原因のことがあります。
> 別の端末（スマホの4G回線など）で試してみてください。それでも出なければ教えてください。

## 2-2. 成果（キーイベント）に指定する

**指定しないと、Google広告に「何件申し込まれたか」を渡せません。**

1. GA4の左下 **[管理]** → **[データの表示]** → **[イベント]** を押す
2. 表の中から **`generate_lead`** という行を探す
3. その行の右にある **[キーイベントとしてマークを付ける]** のスイッチを**オン**にする
4. 同じように **`phone_click`** と **`line_click`** もオンにする

| イベント名 | 意味 | オンにする？ |
|---|---|---|
| `generate_lead` | **WEBフォームからの申込（本命）** | **オン** |
| `phone_click` | 電話ボタンが押された | **オン** |
| `line_click` | LINEボタンが押された | **オン** |
| `form_submit` | 送信ボタンが押された | **オフのまま**（申込と二重に数えます） |
| その他 | 途中経過を見るためのもの | オフのまま |

> **`generate_lead` が一覧に出てこないときは、まだ誰も申し込んでいないだけです。**
> テストで1件送っていただくのが確実です（お名前は「テスト」で構いません。
> 渡辺さんに「テスト送信をします」と一声かけてから送ってください）。

## 2-3. A/Bテストを比べられるようにする（重要・忘れやすい）

GA4は、**こちらが独自に付けた印を、そのままではレポートに出してくれません。**
「登録」が要ります。**これをやらないと、案Aと案Bを並べて比べられません。**

1. **[管理]** → **[データの表示]** → **[カスタム定義]** を押す
2. **[カスタム ディメンション]** のタブが選ばれていることを確認
3. **[カスタム ディメンションを作成]** を押す
4. 次のとおり入力する（**「イベント パラメータ」は1文字も間違えないでください**）

| 欄 | 入力する内容 |
|---|---|
| ディメンション名 | `LP` |
| 範囲 | `イベント` |
| イベント パラメータ | `lp_id` |

5. **[保存]** を押す
6. **同じ手順を、あと4回**繰り返します

| ディメンション名 | 範囲 | イベント パラメータ |
|---|---|---|
| `LPパターン` | イベント | `lp_variant` |
| `ボタンの場所` | イベント | `link_position` |
| `エリア判定` | イベント | `area_check` ではなく **`area_result`** |
| `見積り額` | イベント | `estimate_total` |

> ⏳ **登録しても、レポートに出てくるまで24〜48時間かかります。** 翌々日に見てください。
> それまで空欄でも、失敗ではありません。

# 第3章　Google広告とつなぐ

**広告を出す直前でよい作業です。** 第1・2章が終わっていれば、あとからでも間に合います。

## 3-1. Google広告アカウントを用意する

1. **https://ads.google.com/** を開き、第1章と**同じGoogleアカウント**でログインする
2. すでにアカウントがあれば、そのままで構いません
3. 無ければ新規に作ります。**アカウントを作るだけなら費用はかかりません**
   （途中でクレジットカードを聞かれますが、**広告を配信開始しない限り課金されません**）
4. できたら、画面の**右上に出ている10桁の番号（例：`123-456-7890`）**を控えてください
   → これが「Google広告のアカウントID」です

## 3-2. GA4とつなぐ

**この作業をすると、GA4で数えた申込がそのままGoogle広告の成果になります。**
広告側で別々に設定するより間違いが少ないので、こちらを推奨します。

1. Google広告の画面で、**上部の工具アイコン（ツール）**を押す
2. **[データ マネージャー]** を押す
3. **[+ サービスを接続]** を押す
4. **[Google Analytics (GA4) & Firebase]** を選ぶ
5. 一覧から、第1章で用意したプロパティ（`ONE HITTER LP` など）を選び、**[次へ]**
6. 内容を確認して **[リンク]** を押す

## 3-3. 申込を「コンバージョン」として取り込む

1. Google広告の左メニュー **[目標]** → **[概要]** を押す
2. **[+ コンバージョン アクションを作成]** を押す
3. **[インポート]** の系統から、**Google アナリティクス（GA4）** を選ぶ
4. 一覧に `generate_lead` `phone_click` `line_click` が出るので、**チェックを入れて取り込む**
5. `generate_lead` を **「メインの目標」**（入札の最適化に使う成果）に設定する
   `phone_click` `line_click` は「サブの目標」で構いません

> **画面の言葉が少し違うことがあります。** Googleは表示名をよく変えます。
> 「コンバージョン」「インポート」「アナリティクス」の3語を手がかりに探してください。
> 見つからなければ、画面をそのまま教えていただければ一緒に探します。

### ✅ ここまで終わったら

**Google広告のアカウントID（10桁）を教えてください。**

# 第4章　電話を0円で測れるようにする ← いちばん効きます

## なぜこれが大事か

ハウスクリーニングは**電話での申込が多い商売**です。
いまLPに載っている番号は担当者の携帯（080-8043-8259）そのままなので、
**何件かかってきたのか、どのLPから来たのか、記録がどこにも残りません。**

**このまま広告を回すと、成果の半分が見えないまま費用だけ出ていきます。**

## 何をするのか

Google広告には、**広告経由で来た人にだけ、LP上の電話番号を専用の番号に自動で
差し替える機能**があります。かかってきた電話は**そのまま 080-8043-8259 に転送**されるので、
**受け方はいまと何も変わりません。**

```
広告を見て来た人 →  LPに「050-XXXX-XXXX」と表示される（自動で差し替わる）
                            ↓ かける
                    Googleが記録  →  そのまま 080-8043-8259 に転送 → 渡辺さんが出る
```

- **追加費用はかかりません。** 通話料もGoogle持ちです
  （課金されるのは、いつもどおり広告がクリックされたときだけ）
- **広告以外から来た人には、いつもの番号がそのまま表示されます**

## 4-1. 通話のコンバージョンを作る

1. Google広告の左メニュー **[目標]** → **[概要]** を押す
2. **[+ コンバージョン アクションを作成]** を押す
3. 種類の一覧から **[電話件数]** を選ぶ
4. さらに **「ウェブサイトに掲載された電話番号への問い合わせ」** を選ぶ
   （「通話専用広告」や「広告の電話番号」ではありません。**ウェブサイトのほう**です）
5. **電話番号**：`080-8043-8259` と入力する
   > ⚠️ **LPに表示されている番号と、1文字でも違うと差し替わりません。**
   > ハイフンの有無まで、上のとおりに入れてください
6. **コンバージョンとしてカウントする通話の長さ**：**`60`秒** と入力する
   （これで、間違い電話や無言電話を成果から外せます。あとから変えられます）
7. **[作成して続行]** を押す

## 4-2. タグの情報を控える

作成が終わると、**タグ（スニペット）を設置する画面**が出ます。

1. **[タグを自分で追加する]** を選ぶ
2. 表示されたコードの中に、次のような行があります

```
gtag('config', 'AW-1234567890/AbC-D_efGhIjKlMnOp', {
  'phone_conversion_number': '080-8043-8259'
});
```

3. **この `AW-` から始まる行を、まるごとコピーしてチャットに貼ってください。**
   （設置作業はこちらでやります。HTMLは触らなくて大丈夫です）

> このコードに、パスワードや個人情報は含まれていません。貼っていただいて問題ありません。

## 4-3. あとで確認すること（広告を出したあと）

広告が動き始めたら、**ご自身のスマホで広告をクリックしてLPを開いてみてください。**
電話番号が **080-8043-8259 ではない番号**に変わっていれば、正しく動いています。

## 4-4. 有料のコールトラッキングは、いま契約しなくて構いません

月額2,200円〜のサービスもありますが（`docs/calltracking-vendors.md` に比較があります）、
**まずは0円のこれで十分です。**

必要になるのは、次のようになったときです。

- Yahoo!広告やInstagram広告にも出すようになった（Google以外は測れないため）
- 通話の録音を残したくなった
- チラシやGoogleビジネスプロフィールからの電話も分けて測りたくなった

# 第5章　プライバシーポリシーに1段落足す

## なぜ必要か

**GA4を使うと、閲覧者の情報がGoogleに送られます。**
Googleアナリティクスの利用規約は、**それをプライバシーポリシーで知らせるよう求めています。**

現在の `https://one-hitter.jp/privacy_policy/` には「8．Cookieについて」がありますが、
**Googleアナリティクスを使っていることは書かれていません。**

> **公式サイトには既にGA4が入っているので、これは今日この時点で必要な状態です。**
> LPに入れる前の話です。

## 5-1. 追記する文案

**「8．Cookieについて」の直後**に、次を **「9．アクセス解析ツールについて」** として
挿入し、**以降の番号を1つずつ繰り下げてください**（現在の9→10、10→11）。

```
9．アクセス解析ツールについて

当社のウェブサイトでは、サービスの改善および広告効果の測定を目的として、
Google LLC が提供するアクセス解析ツール「Google アナリティクス」および
「Google 広告」を利用しています。

これらのツールは、Cookie を利用して、当社ウェブサイトの閲覧状況に関する情報
（閲覧したページ、滞在時間、参照元、おおよその地域、端末の種類など）を収集します。
収集される情報に、氏名・住所・電話番号など個人を特定できる情報は含まれません。

収集された情報は、Google 社のプライバシーポリシーに基づいて管理されます。
・Google プライバシーポリシー https://policies.google.com/privacy?hl=ja
・Google アナリティクス利用規約 https://marketingplatform.google.com/about/analytics/terms/jp/

Google アナリティクスによる情報収集を望まれない場合は、
Google 社が提供するオプトアウト アドオンにより、収集を停止することができます。
・https://tools.google.com/dlpage/gaoptout?hl=ja

また、ブラウザの設定により Cookie を無効にすることでも、収集を停止できます。
その場合、当社ウェブサイトの一部機能がご利用いただけないことがあります。
```

## 5-2. どこを直すか

- **公式サイト**：CMSの「プライバシーポリシー」ページ。制作会社にお願いするか、
  CMSの管理画面から編集
- **LP側**：LPからは公式サイトのプライバシーポリシーへリンクしているので、
  **公式サイトを直せばLPも同時に片づきます**

> ⚠️ **これは公開文書の変更なので、佐々木さんの判断で進めてください。**
> 文案の修正が必要でしたら、言っていただければ直します。

> **補足：** 2023年6月施行の電気通信事業法「外部送信規律」は、検索・SNS・
> オンラインショッピング等の事業者が対象で、**ハウスクリーニング業の自社サイトが
> 対象になるとは考えにくい**というのが調べた範囲での理解です。断定はできません。
> ただし上のGoogle側の規約は業種を問わないので、**いずれにせよ追記は必要**です。

# 第6章　（あとで）独自ドメインを当てたとき

いまLPは `one-hitter-lp.netlify.app` で公開しています。
将来 `lp.one-hitter.jp` に変えるときは、**GA4側で1つ設定が要ります。**

やらないと、**公式サイトからLPへ移動した人が「新しい訪問者」として二重に数えられます。**

1. GA4の **[管理]** → **[データの収集と修正]** → **[データ ストリーム]** → 対象の行をクリック
2. **[タグ設定を行う]**（または [Google タグ] の [設定]）を押す
3. **[設定を編集]** の中の **[参照元リストの除外]** を押す
4. **`one-hitter.jp`** を追加する（「参照元が次を含む」で `one-hitter.jp`）
5. 同じ画面の **[ドメインの設定]** で、`one-hitter.jp` と `lp.one-hitter.jp` の両方を
   同じ計測対象として登録する

> 🚨 **その前に、ドメインの更新が先です。**
> `one-hitter.jp` の有効期限は **2026/09/30** で、2026-09-06 時点でまだ更新されていません。
> 失効するとサイトもメールも止まります。

# おまけ：うまくいかないときの確認

| 症状 | よくある原因 |
|---|---|
| GA4のリアルタイムに何も出ない | ブラウザの広告ブロック機能。別の端末や回線で試す |
| `generate_lead` が一覧に無い | まだ誰も申し込んでいない。テストで1件送る |
| A/Bの内訳が空欄 | 第2章 2-3 の登録から24〜48時間待つ |
| 電話番号が差し替わらない | 第4章 4-1 の⑤で入れた番号が、LPの表示と違う |
| 申込がGoogle広告に出てこない | 第3章 3-3 のインポートが未実施。GA4のキーイベント指定も確認 |

**分からなくなったら、画面のスクリーンショットを送ってください。** 一緒に見ます。
