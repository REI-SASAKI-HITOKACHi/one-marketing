## 結論

年末大掃除は12月に売るものではなく、**10月と11月に売るもの**。
しかも当社は**12月から1箇所あたり3,300円が加算される**。
この加算は値上げの告知ではなく、**「11月までに予約する理由」**として使える。
今年いちばん強い訴求が、すでに料金表の中にあった。

**問題は、埋める手段が去年と同じままであること。** 去年と同じことをすれば去年と同じ数字になる。

年末商戦のカレンダーは動かせない。検索の立ち上がりが10月中旬、予約のピークが11月、12月上旬が駆け込み。
**10月1日に公開されていないLPは、この商戦にほぼ参加できない。** 逆算すると制作は9月中。

## 3. 年末大掃除LP

**新規制作ではなく、既存の水まわりLP（54KB・実写掲載済み）を年末版に組み替える。**

### 先に見つけたこと

`one-hitter.jp/nenmatsu` が sitemap に登録されているが、アクセスすると **401（Basic認証）**。
去年つくって閉じたままの可能性が高い。中身を確認して流用できるか判断する。
使えない場合も、**sitemapに載ったまま401を返すのは検索エンジンに対してマイナス**なので、
公開するか sitemap から外すかの決着が要る。

### 訴求の柱（この順）

1. **12月は1箇所3,300円上がる。11月までなら通常価格** — 値上げ告知ではなく締切の提示。
   実在する繁忙期加算の事前告知なので景表法上も問題ない。
2. **1箇所ではなくセットで見せる** — キッチン/浴室/換気扇セット各¥13,800。
   HP経由の平均単価¥15,775は全体平均¥41,173の38%。サイトが単品しか売れていないのが原因。
3. **★5.0・23件のGoogle口コミ** — 現在サイトにもLPにも1件も載っていない。
   「大手1台分の値段で2台きれいになった」という趣旨の声は比較検討層に直接刺さる。
4. **ルミテスターのATP値 42,194 → 409** — 他社が持っていない証拠。
   年末大掃除は「やった感」が争点なので数値で示せるのは決定打。
5. **枠が埋まることを隠さず書く** — 1チームで回している以上これは事実。嘘をつかずに締切効果が出せる。

### やらないこと

- エアコンを主役にしない（需要期は5〜7月。年末は換気扇・浴室・キッチン）
- 「業界最安」「No.1」は使わない（根拠の立証が不可能）
- Facebook広告は再開しない（CPC¥95.39・CTA¥6,000で撃沈済み）
- チラシ単独配布はしない（週2,000枚で反応0）

## 4. 既存客への再販 ── リーチと動線

### 誰に送るか（優先順）

| 優先 | 対象 | 概数 | 切り口 |
|---|---|---|---|
| 1 | 2025年9〜12月に施工した方 | 約160名 | ちょうど1年。「昨年もこの時期にご利用いただきました」 |
| 2 | 2025年に2回以上利用した方 | 57名 | すでにリピーター。年末セットを提案 |
| 3 | 2026年1〜8月に施工した方 | 286名 | エアコンを使った方へ、年末は水まわりを |
| 4 | 2024年以前で反応のあった方 | — | 最後に回す。1年以上前への架電は成約0の実績 |

**優先1の160名は2025年シートにいる。** 現在読めるのは2026年シートだけのため、
再販リストを作っても「いま案内すべき人」が2名しか出なかった。
2025年シートを `claude-sheets@one-hitter-sheets.iam.gserviceaccount.com` に共有すれば、
300名規模のリストが即日できる。**共有クリック1回で今年の年末の打ち手が10倍になる。**

### どう届けるか

- SMS 7割 / LINE 3割。**電話はしない**（2025年12月に15件かけて成約0）
- 本舗経由の顧客は送信主体が**おそうじ本舗江戸川中央店**になるため、最初から2系統で作る
- 文面と送信リストは当方で作り切る。現場の手数は増やさない

### SMS文面（第1波・自社顧客向け）

```
【ワンヒッター】〇〇様
昨年11月は換気扇のクリーニングをご利用いただき、ありがとうございました。

年末のご予約を受付中です。
12月は繁忙期のため1箇所3,300円が加算されます。11月までのご予約なら通常価格です。

空き状況とご予約 → [URL]
お電話 080-1755-7275（8:00-20:00）
```

前回の施工月とメニューを差し込む。リンクは1本に絞り、電話は高齢層向けに併記
（お客様の声に60代が複数いる）。

### SMS文面（第3波・11月下旬・締切訴求）

```
【ワンヒッター】〇〇様
年末の通常価格でのご予約は、11月30日までです。12月は1箇所3,300円の加算となります。

12月の空き枠は残り〇枠です。
ご予約 → [URL]
お電話 080-1755-7275
```

残枠は実数を入れる。1チームで回している以上これは事実なので、嘘をつかずに締切がつくれる。

### 受注までの動線

1. **SMS/LINE → 既存客専用ページ**（新規向けLPには送らない）
   既存客には価格説明も信頼構築も不要。「前回のご利用ありがとうございました」から始まり、
   年末メニューと空き枠、フォームだけの短いページにする。
2. **URLに識別子を付ける** — `?c=顧客番号`。誰が開いて誰が予約したかが分かるので、
   次の波で反応した人としていない人を分けられる。
3. **フォームは自社ドメイン内に置く** — 現在はGoogleフォームへ離脱していて離脱箇所が不明。項目は5つ以内。
4. **台帳に「LINE/SMS再販」で記録** — 流入経路の選択肢に追加済み。再販が何件・いくら生んだかが月次で出る。

## 5. 提携先 ── 活性化と開拓

手間がかかるのは「探す」「材料をつくる」「関係を維持する」の3つ。**このうち2つは当方が引き取れる。**
オーナーに残るのは**最初の一声と、条件の決裁だけ**。

### 既存2社の活性化 ── 月1回の実績共有が効く

提携先が紹介を続ける理由は手数料より「ちゃんと成果になっている」という手応え。

- **月次の紹介実績レポート**（紹介件数・施工完了数・お客様の声）を台帳から自動生成 → オーナーは送るだけ【当方】
- **紹介カードの整備** — シートに「紹介カード」タブが既にある。中身を確認して実用版に【当方】
- **手数料ルールの明文化** — 2024年の経費に紹介料が¥8,376の1件だけ。制度が曖昧だと相手も紹介しづらい【オーナー】
- **台帳に「紹介元」欄を新設** — 現在どこ経由の紹介か記録されていない。これがないと効果が測れない【当方】

### 新規開拓 ── 冷たいアプローチはしない

テレアポ実績は 40件→0アポ、140件→0アポ、41件→3アポ。**数を打つ方法は当社では機能しない。**
代わりに単価データから相性の良い業種に絞る。

| ターゲット | 根拠 | 入口 |
|---|---|---|
| 不動産管理会社 | 空室清掃22件・平均¥74,503 | 繁忙期が2〜3月で当社の閑散期と噛み合う。空室清掃の単独ページ |
| 店舗・施設 | 天カセ12件で売上の27% | 1件の単価が桁違い。ルミテスターの数値測定は法人ほど刺さる |
| エアコン設置業者 | 提携実績あり | 設置現場で「クリーニングもできます」。相手の手間ゼロ |
| リフォーム業者 | 提携実績あり | 引き渡し前の清掃。継続発注になりやすい |

当方がやるのは**候補リスト作成**・**提携提案の1枚資料**・**費用対効果シミュレーション**。
オーナーは既に面識のあるところから順に声をかけるだけ。

## 6. オーナーにお願いすること（合計15分）

1. **ネームギアで `lp` のAレコードを1行追加** — 5分
   `ns1.namegear.co` / `ns2.namegear.co`。ネームギアは**ドメイン登録サービス**
   （BRドメイン株式会社／京都）でムームードメインと同種。管理画面にログインできれば自分で設定できる。
   追加するのは `lp` → A → `118.27.125.166` の1行のみ。本体サイトには一切影響しない。
2. **2025年シートをサービスアカウントに共有** — 1分（編集者権限）
3. **SMS配信ツールを教える** — 1分（一斉送信の可否・単価・差し込みの可否）
4. **`one-hitter.jp/nenmatsu` のBasic認証を外すか中身を見せる** — 3分
5. **提携先の手数料ルールを決める** — 5分（1件定額か売上の何%か）

### 公開前に必ず確認が要ること

- **繁忙期加算が「1箇所あたり」か「1案件あたり」か。** `docs/price-master.md` に `[要確認]` として残っている論点。
  LPは**パンフレット記載の「各料金に¥3,300追加」に沿って「1箇所につき3,300円」**と書いている。
  ここが違うと表示価格が誤りになるため、**公開前に必ず確定させる**こと。
- Google口コミの原文。★5.0・23件という数字は使えるが、個別の口コミ本文はまだLPに載せていない
  （管理画面から全文を取得してから掲載する）。
- 「例年、12月後半はお断りせざるを得ない日が出ています」の記載。実態と合っているか要確認。

### ついでに直したビルドの不具合

`lp/` 配下の断片が持つ `<title>` が、公開用HTMLの `<body>` 内にもそのまま出力されていた
（`<head>` の正しい title と二重）。**既存の aircon / mizumawari も同じ状態**だった。
ビルド時に断片側の title を取り除くよう修正し、全ページを再ビルド済み。
