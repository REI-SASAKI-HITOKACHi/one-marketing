# 公式サイトのブログ全点検（旧価格・旧電話番号）

実施 2026-09-12 ／ LP・サイト担当 ／ 依頼 `20260912-05-lp` の5番

## やったこと

`https://one-hitter.jp/sitemap.xml` に載っている**ブログのURL 81本すべて**を取得し、
本文（`<main>` の中。共通ヘッダー・フッターは除外）から次を探しました。

- 旧電話番号 … `080-1755-7275` / `08017557275`
- 旧価格（税抜額） … `9,800` `15,800` `16,800` `18,100` `19,800` `13,800` `6,800`

> 共通テンプレート由来の電話番号を数えないよう、**`<main>` の中だけ**を見ています。
> 日本語を含むURL 18本は、そのままだと取得に失敗するのでパーセントエンコードして再取得しました
> （最初の走査では18本が抜けていました）。

## 結果

### ✅ 旧電話番号は、ブログ本文には1件もありません

全81本で0件です。公開ページに出ている電話番号は共通テンプレート由来で、
**リソース5の修正で既に新番号に変わっています。**

### ⚠️ 旧価格が載っている記事が1本あります

**https://one-hitter.jp/blog/20221030-1405/ 「早割還元祭開始!!ー年末大掃除ー」**

| 載っている金額 | 現在の正しい税込額 |
|---|---|
| トイレ丸洗い ￥9,800 | ￥10,780 |
| 洗面台丸洗い ￥9,800 | ￥10,780 |
| 追焚配管丸洗い ￥18,100 | ￥19,910 |
| お掃除時短コーティング ￥19,800 | ￥21,780 |

**2022年の期間限定キャンペーン記事**です。金額が古いだけでなく、
**キャンペーン自体がとっくに終わっています。**

> **オーナー判断（2026-09-06）：「2022年の記事の件は、おそらく問題にならないから放置でいい」**
> この判断は出ているので、**こちらでは触っていません。**
>
> ただし**判断の前提が1つ変わっています。** 当時は年末LPがありませんでしたが、
> いまは `/nenmatsu/` が動いていて、これから年末大掃除の検索が増える時期です。
> **「年末大掃除」で検索した人がこの2022年の記事に当たり、終わった価格を見る**
> 可能性が上がっています。再判断の材料としてCMOへ渡します。
>
> 直すなら選択肢は3つ：①冒頭に「これは2022年の内容です」と1行入れる
> ②非公開にする ③年末LPへのリンクを足す。**②が簡単ですが、被リンクを捨てることになります。**

### ⚠️ sitemap に、404を返すURLが1本あります

**https://one-hitter.jp/blog/20221023-1375/ → 404**

`sitemap.xml` に載っているのに存在しません。検索エンジンに「ここにページがある」と
言い続けている状態です。記事を消したときに sitemap から外れていないと思われます。
**sitemap はCMSが自動生成しているはずなので、生成の取りこぼしか、
消し方（display=0 にしただけ）の問題**かもしれません。CMOへ回します。

## 再実行のしかた

```bash
python3 - <<'PY'
import re, urllib.request, urllib.parse
sm = urllib.request.urlopen('https://one-hitter.jp/sitemap.xml', timeout=30).read().decode('utf-8')
urls = sorted(set(re.findall(r'<loc>(https://one-hitter\.jp/blog/[^<]*)</loc>', sm)))
def enc(u):
    p = urllib.parse.urlsplit(u)
    return urllib.parse.urlunsplit((p.scheme, p.netloc, urllib.parse.quote(p.path), p.query, p.fragment))
TEL = ['080-1755-7275', '08017557275']
KIN = ['9,800', '15,800', '16,800', '18,100', '19,800', '13,800', '6,800']
for u in urls:
    try:
        h = urllib.request.urlopen(enc(u), timeout=30).read().decode('utf-8', 'replace')
    except Exception as e:
        print('取得失敗', u, e); continue
    m = re.search(r'<main[^>]*>(.*?)</main>', h, re.S)
    naka = m.group(1) if m else h
    text = re.sub(r'<[^>]+>', ' ', naka)
    atari = [x for x in TEL if x in naka] + [x for x in KIN if x in text]
    if atari: print(u, atari)
PY
```

**価格を変えたときは、これを流して取り残しを確認すること。**
