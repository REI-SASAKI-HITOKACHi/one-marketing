## 1. 見立て（正直に）

1. **SNSだけでは、12月に月1〜2件は届かない。** 7週間でセッション12では、毎週投稿を続けても申込に届く量ではない。SNSは「見つけてもらう場所」というより、予約ページへの導線と信頼の置き場として続ける位置づけにする。
2. **届く可能性があるのは、検索から入る2つ。**
   - **ブログ（公式サイト）**：すでに28日で表示5,705。古い1本が半分を占めている。第3束20本（11/2〜11/21、年末大掃除・エアコン・換気扇）が入ると、入口が20本増える。全記事に予約ページ（?src=blog）のボタンがあることは点検済み（`check-blog.py` 21本OK、10/21）。
   - **GBP（Googleマップ）**：最新情報を週2本にし、ボタンを全て予約ページ（?src=gbp）へ。表示回数・通話・サイトクリックの実数が未確認なので、まず数字を見る。
3. **12月に月1〜2件へ届く理由（算数。仮定を含む）**：ブログと検索のクリックが11月に2〜3倍（月250〜400）になり、そのうち予約に至る割合が1%前後なら月2〜4件。**この「1%前後」は実測がない仮定。** 実測は HP→予約ページ→申込を src で数えて、11月中に出す（measurement の HP お問い合わせ完了イベントが前提）。
4. **届かなかったときの見分け方**：11/30 時点で、ブログ+GBP のセッションが月200未満なら入口の量の問題、200以上で申込が0なら予約ページ・訴求の問題。原因が分かれていれば、12月の打ち手を変えられる。

## 3. 持ち場ごとの具体

### GBP
- 10/20（浴室）・10/22（カビ・エアコン暖房）・10/24（エアコン11月10%）・10/27（キッチン）は原稿あり。11月分は11/3以降を毎週月曜に2本ずつ。
- 写真は現場ごとに追加。名義・写り込みの規則どおり、私が1枚ずつ目で確認してから渡す。**作業完了フォームの写真（kanryo-shashin）は私の作業環境に無い**ので、置き場所か取り出し方を決めてほしい（それまでは 10/19 の動画のコマと既存の assets/photos から）。
- GBPの統計（表示回数・ルート・通話・ウェブサイトのクリック）を browser に毎週読んでもらい、「機械のアクセスしか来ていない」の見立てを数字で確認する（依頼4）。

### Instagram/Facebook
- リールは10/26・28・30（BGMを作り直した版に差し替え中）、11/2 は和真さんの10/19の現場動画のリール（r02-1）。11月以降は週1本、素材は和真さんの新しい動画。
- プロフィールのリンクは ?src=ig（browser が確認中。リンク欄の変更はオーナー）。

### ブログ

## 4. 他の担当・オーナーへのお願い

1. **measurement**：HP お問い合わせ完了を GA4 のイベントに（依頼済み 20261015-05）。これが無いと「1%前後」を測れない。
2. **browser**：GBP の統計を毎週。GBP 認証（refresh_token）。IG プロフィールのリンク確認。
3. **オーナー**：Instagram プロフィールのリンク欄（アプリのみ）。
4. **和真さん**：現場動画は縦で、10〜15秒、作業前の汚れと洗っている最中も（10/24 MTG の資料のとおり）。
