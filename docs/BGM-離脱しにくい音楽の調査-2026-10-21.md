# 「気になる・離脱しにくい」BGMの調査と、設計への落とし込み

オーナー指示（2026-10-21）：「心理学を学習して人間が気になる、離脱し辛くなるBGMを調査して作成してみて」

作成 2026-10-21 ／ 動画担当スレッド。
**先に正直に書きます。** 調べた範囲では、「短尺動画のBGMをこうすると離脱が減る」という
**直接の研究は見つかりませんでした。** 出てくるのはマーケティング業者のブログばかりで、
検証可能な数字がありません。ここに書くのは、**音楽心理学の査読論文で分かっていること**を、
BGMの設計に自分で落とし込んだものです。推測の部分は推測と明記します。

## 1. 根拠のある知見と、設計に落とした形

### ① テンポは120BPM前後

人が何も聞かずに自然に刻む速さ（spontaneous motor tempo）は、タッピングの研究で概ね
**100〜120BPM**。古典的な Fraisse の実験では、いちばん心地よいとされた間隔が **500〜700ms
＝86〜120BPM** でした。注意はこの周期に同期しやすい（dynamic attending theory）とされます。

- → **120BPM にしました。**（前の版は84BPMと104BPM）
- 注意：これは集団の傾向で、個人差が大きいことも同じ資料に書かれています

### ② 拍をはっきりさせたうえで、適度にズラす

Witek ら（2014, PLOS ONE）は、ファンクのドラムで**中くらいのシンコペーション**のとき
「動きたさ」と「快」が最大になる逆U字の関係を報告しました。
ただし **Senn・Witek ら（2024, PLOS ONE）は、179人の実験でこの逆U字を再現できませんでした。**
その論文は「単純な型は拍が明快だから、複雑な型は面白いから、それぞれ踊りたくさせる」と整理しています。

- → **どちらの説明でも、「ズレも無く、明快さも無い平坦な型」がいちばん悪い**と言えます。
  前の版がまさにそれでした（キックが1拍目と3拍目のオモテだけ、8分の刻みだけ）
- → **2拍目と4拍目に手拍子**を入れて拍を明快にし、
  **低音と2発目のキックをウラ**に置いて適度にズラしました

### ③ 低音を入れる

Cameron ら（2022, Current Biology）は、ライブ会場で**聞こえないほど低い音**を出し入れしたところ、
客の動きが**平均11.8%増えた**と報告しています。本人たちは切り替わりに気づいていません。

- → キックに重ねて**超低音を足しました**
- **注意：スマホの内蔵スピーカーは超低音を鳴らせません。** 効くのはイヤホン・ヘッドホンの人だけです。
  リールの視聴は内蔵スピーカーか無音が多いので、**この項目の効き目は限定的**と見ています

### ④ 耳に残る旋律の作りかた

Jakubowski ら（2017）は3,000人に「頭から離れない曲」を挙げてもらい、
そうでない曲と比べました。耳に残る曲の特徴は
**「速め」「よくある山なりの輪郭（上がって下がる）」「ただし途中に普通でない跳躍がある」**。

- → 8音の動機を作りました：**B♭ → C → F → D(2オクターブ上) → B♭ → G → E♭ → C**
  上がって下がる山なりの形にして、**4音目で大きく跳ばせて**います
- 同じ研究は「ヒットして露出が多いこと」も要因に挙げていますが、こちらは真似できません

### ⑤ 同じことを20秒続けると慣れる

- → **4小節ごとに作りを変える**（パッドの音量、刻みの強さ、動機のオクターブ）
- → **ループの変わり目で1拍だけ全部止める。** 止まると次が気になります

### ⑥ 終わりを解決させない

和音の進行を **B♭ → F → E♭ → F**（I - V - IV - V）にして、**ドミナント（F）で終えています。**
閉じないので、先へ引っぱられます。

- これは推測を含みます。音楽理論の定石（半終止＝未解決）に基づく判断で、
  「離脱が減る」という直接の研究は見ていません

### ⑦ 頭の1秒から鳴らす

- → **フェードインをやめました**（10ms だけ。前の版は0.9秒かけて入っていた）

## 2. 調べたが使えなかったもの

- **「短尺動画の最初の3秒が勝負」**：業者のブログに大量にありますが、**検証可能な根拠が無い**。
  「Reelsは1.0秒で見切る」「2秒以上で判定」など、記事ごとに数字が食い違い、
  いずれもプラットフォームの公式資料を引いていません。**この種の数字は採用していません**
- 音楽のテンポと視聴維持を比べた対照実験は、**見つかりませんでした**

## 3. 前の版が外した理由（オーナー指摘「ゲームボーイ時代のドラクエの葬式みたい」）

| | 原因 | 今回の対応 |
|---|---|---|
| 1 | 音が全部サイン波の足し算 → ゲーム機の音 | 撥弦の物理モデル（Karplus-Strong）に変更 |
| 2 | 84BPMで2小節伸びるパッド＋長い残響 → 教会・葬式の響き | 120BPM、パッドは1小節、残響0.55秒 |
| 3 | 打楽器が無く拍が無い → 浮いて沈む | キック・手拍子・刻み |
| 4 | 低いところでマイナー7th（Am7）→ 暗い | マイナーコードを使わない（I-V-IV-V） |
| 5 | ①〜⑦の設計が何も入っていなかった | 今回はこの7項目から設計した |

## 4. できたもの

`python3 tools/make-reel-bgm.py --candidates` で `dist/bgm-候補/` に出ます。

| 案 | 作り |
|---|---|
| **調査版D・はっきり** | 上の①〜⑦をそのまま。打楽器がはっきり鳴る |
| **調査版E・やわらかめ** | 同じ設計で、手拍子と刻みを55%に落とし、高域を7kHzで切った |

実測（15〜16秒・モノラル換算）

| | 重心 | 70Hz未満 | 拍の山（自己相関） |
|---|---|---|---|
| 前の案A | 1770Hz | 5.1% | 104BPM（0.85） |
| 調査版D | 3222Hz | 8.0% | **120BPM（0.78）** |

拍の山が120BPMに立っているので、**設計どおりの拍で鳴っていること**は確認しました。

## 5. 正直に申し上げること

**私は音を聴けません。** 数値で確かめられるのは、拍が立っているか、明るさ、低音の量、
フェードインの有無までで、**「いい曲か」は測れません。** すでに2回外しています。

合成でここから先を詰めるのは、**当て推量の繰り返しになる見込みが高い**と考えています。
これがまだダメなら、**Instagram アプリ内の音源ライブラリから曲を当てるのが確実**です。

- ライセンス済みなので権利の問題が出ません
- **オーナーが耳で選べます**（私の弱点がそのまま消えます）
- プラットフォームの音源を使うと露出に効くとも言われます（※これは業者情報で、根拠は未確認）
- 無音版は `python3 tools/build-ad-reels.py --no-bgm` ですぐ出せます

**合成BGMにこだわる理由は、権利以外にありません。** アプリ内音源ならその権利の問題も無いので、
そちらのほうが素直だと思います。
