# 1. 広告の月5万 ── **付け替えではありません。純増です**

## 1.1 2026年に「広告の枠」は存在しない

`◯月_支出/成績` の科目「広告費」を1〜12月まで読み直しました（**読み取りのみ**）。

| | 金額 | 中身 |
|---|--:|---|
| 科目合計（12月まで） | **¥893,498** | |
| うち **固定費** | **¥602,400** | HPローン22,000＋HITOWA HPC 22,000＋保守4,400＋CANVA 1,800 の**月¥50,200 × 12か月** |
| うち HITOWAチラシ | ¥166,320 | ¥55,440 × 3回（5・7・9月）。**本舗の販促で当社の裁量外** |
| うち **純粋なネット広告** | **¥46,423** | 5月のGoogle広告1本（母の日ギフトのP-MAX）。**受注0** |
| 残り | ¥78,355 | 紹介料キックバック等（**成果連動**。先に使える枠ではない） |

> ## **裁量で動かせる広告の枠は、実質ゼロです。**
> 固定費は止められず、チラシは本舗、キックバックは成果が出てから払うもの。
> **段0の月5万は、既存の枠の付け替えではなく、純増です。**

## 1.2 純増の大きさ

| 10〜12月の出し方 | 3か月の純増 | 2026年の会社手残り |
|---|--:|--:|
| 現状のまま（¥0） | — | 561万 |
| **月5万（段0）** | **15万** | **546万**（▲2.7%） |
| 月10万（段1の上限） | 30万 | 531万（▲5.3%） |

**現金の面では、月10万まで上げても2026年は黒字のままです。増額の制約は利益ではありません。**

## 1.3 🔴 **10/1にCPAで増額を判断するのは無理です**

9/18開始・日¥1,667なら、**10/1までに貯まるのは13日ぶん・約¥21,671**。
CPA上限9,500円で期待できるコンバージョンは **2.3件**。**ここから増額の判断はできません。**

**10/1は「止めるか続けるか」だけにして、増額は11/1に回すことを勧めます。**
10月中旬が年末検索の立ち上がり（`docs/nenmatsu-plan.md`）なので、**その手前で誤判定すると、いちばん効く時期に枠が無い**という形になります。

### 10/1に見るもの（コンバージョンではなく先行指標）

| 見るもの | 続ける | 止めて設計に戻る |
|---|---|---|
| 表示回数 | 出ている | **ほぼ0**（＝キーワードか入札で詰まっている） |
| クリック | 来ている | 0〜数件（＝広告文かキーワードがずれている） |
| 平均CPC | 1,000円以下 | **1,500円超**が続く（1件9,500円の上限に対し、CVRが6%必要になる） |
| 検索語句 | 1都2県・該当メニューの語 | **エリア外・無関係な語が過半**（＝地域指定か除外語の設定漏れ。母の日と同じ失敗） |

**コンバージョン0は、10/1時点では「止める理由」になりません。** 母数が足りません。

## 1.4 11/1の増額判断（即答できる形）

| 10月の実績（月5万） | CPA | 判断 |
|---|--:|---|

| 3件以下 | ≥ ¥16,667 | **止めて設計に戻す** |

| 月額 | CPA 9,500円を切るのに要る件数 |
|---|--:|
| 5万 | **月6件** |
| 10万 | 月11件 |
| 15万 | 月16件 |

**CPA上限¥9,500の根拠は `分析_流入経路とLTV`**（マッチング手数料35%・年間¥953,723・1件あたり実質¥9,500）。
**④の1件の限界利益は32,362円**（単価34,965円）なので、CPA 9,500円でも**22,862円残ります。** 上限としては安全側です。

# 2. 年末ギフト（11月販売／1〜2月施工）── **月次と噛み合います**

## 2.1 なぜ噛み合うか

**私の月次は施工日付ベースです**（`◯月_売上/顧客` が施工日付で集計される）。
**券の売上は施工月に立ちます。** だから11月に売れた券は **2027年1〜2月の売上**になります。

| | |
|---|---|
| 11月 | **入金**（前受金）。2026年の売上には立てない |
| 2027年1〜2月 | **施工 ＝ 売上計上**。2027年の計画に乗る |
| 広告費 | **2026年11月の費用**（売上は翌年、費用は今年） |

## 2.2 施工期限「申込から5か月以内」は、**設計として正しい**

繁忙期加算（+¥3,300）の対象月は **5〜7月・12月**（`docs/price-master.md` L33）。

| 申込 | 期限 | 加算月にかかるか |
|---|---|---|
| 11月1日 | **3月末** | かからない |
| 11月30日 | **4月末** | かからない |

**11月販売なら、期限いっぱいまで使っても1〜4月の非加算月に収まります。**
**限界利益は満額 ¥9,434（エアコン1台）で残ります。** 12月施工を許した場合の6,134円にはなりません。

## 2.3 2027年の計画に効くところ（変わらず有効）

| | |
|---|--:|
| 2027年2月の経常利益（中立） | **▲35,545円**（唯一の赤字月） |
| エアコン1台の限界利益（非加算月施工） | 9,434円 |
| **赤字を消すのに必要な枚数** | **4枚** |

**施工が1〜3月ではなく1〜2月に寄るぶん、赤字月の2月に当たりやすくなります。** 前より良い設計です。
1月37件・2月32件は年間でいちばん薄い2か月なので、券10〜20枚は計画を崩さずに入ります。

## 2.4 決めておくことが3つあります

### (a) 2027年1〜2月の計画件数に、ギフト施工は**上乗せ**です

オーナー決定（9/13）で**ギフトは2,600万に織り込んでいません**。
→ 1月37件＋α、2月32件＋α。**内数にすると、赤字解消の効果が消えます。**

### (b) 🔴 `ギフト券_発行管理` タブの期日が決まりました ── **10月末**

**11月に売るなら、売る前に発行を記録する場所が要ります。**
これまで「gift が決めた日に足す」としていましたが、**11月販売が決まったので10月末を期日にします。**

| 列 | |
|---|---|
| 発行日／券番号／金額／メニュー／有効期限（申込＋5か月）／施工日／未消化 | 前受金と売上を取り違えないための最低限 |

**11月に入金、1〜2月に売上。この間、台帳のどこにも載らない状態が2か月あります。** そこを埋める器です。
※ 流入経路「ギフト」が `選択肢マスター` に無いので、**それも同時に足します**（いま無いので、売れても測れません）。

### (c) 🔴 **ギフトの広告と段0の広告を、同じ集計に混ぜないでください**

**11月はギフトの出稿月であり、段0の判定月でもあります。**
同じアカウントで回すのは構いませんが、**キャンペーンを分けて、費用とコンバージョンを別々に見られる形にしてください。**
混ぜると、**段0のCPA判定がギフトの出稿で汚れます。** 母の日の¥46,423が「2026年の広告費」として1本にまとまっていたのと同じ形になります。

## 2.5 1つだけ、気をつけたいこと

**11月は年末大掃除の予約ピークです**（`docs/nenmatsu-plan.md`：検索の立ち上がり10月中旬、予約ピーク11月）。
**販売のチャネルは競合しませんが、問い合わせ対応の手は競合しえます。**
ギフトの問い合わせが、年末の予約対応と同じ窓口に来る形なら、**11月のいちばん忙しい週に重なります。**
**数字の話ではないので判断は gift と cmo に預けますが、見落とされやすいところなので置いておきます。**
