## 1. 原稿（これをそのまま入れてください）

```
自分の家は、これで片づきます。ご実家は。

「もう脚立にのぼるのは危ないから」
そう言って、親が掃除をあきらめた場所が、実家にありませんか。

年末、帰る前に。親の家のエアコンを、プロに洗っておく。
あなたが立ち会える日に伺います。

お届け先が東京都・千葉県・神奈川県のご実家に限ります。

　［ ご実家のおそうじを贈る → ］
```

### なぜこの形にしたか

**gift の方向A（情景）と方向B（親の状態）を、1つに畳みました。**
別々に使うと、Aは説明的で、Bは唐突になります。

**いちばん効かせたのは1行目です。**

> **自分の家は、これで片づきます。ご実家は。**

**このブロックを読む人は、年末LPを読んでいる人＝自分の家の大掃除を考えている人です。**
**そこへいきなり「ご実家のおそうじを、贈れます」と出すと、話題が飛びます。**
**「自分の家は片づく。ところで実家は」と繋ぐと、同じ思考の続きになります。**

**これは年末LPの中に置くからこそ使える繋ぎで、独立したギフトLPでは使えません。**
**10月のブロック限定の書き方です。**（11月のLPは別に書きます）

### 指示書の4要件、全部入っています

| | 要件 | どこ |
|---|---|---|
| 1 | 情景（年末・実家・親） | 「年末、帰る前に。親の家の」 |
| 2 | **自分が立ち会えること** | **「あなたが立ち会える日に伺います。」** |
| 3 | **エリアが1都2県だけ** | **「お届け先が東京都・千葉県・神奈川県のご実家に限ります。」** |
| 4 | 次に何をすればいいか | ボタン |

**3 を「お届け先が」と書いているのが肝です。**
**贈り主の住所ではなく、実家の住所で決まる**ことが、この1行だけで伝わります。
**指示書 §4 の「お届け先（ご実家）の郵便番号」と同じ考え方を、先に文で言っておく形です。**

### 使わなかったもの

- **「大切な人にお掃除のギフトを」** … おそうじ本舗の見出し。指示書の禁止どおり
- **「ギフト」という単語を見出しに置かない** … 指示書 §0 の軸（贈り物の棚に並びに行かない）
- **価格を書かない** … 10月は測定用。価格を出すと「高い／安い」の判断が先に立つ
- **「お得」「今だけ」「最安」** … 景表法と、贈り物で安さは武器にならないという §2.1

## 2. 🖼 写真は**入れない**（CMO判断）

**年末LPには既に施工写真があります。** そこへギフトの写真を足すと、
**年末LP本来の訴求（自分の家の大掃除）と視線を奪い合います。**
指示書 §5.4 の「**年末LP本来の訴求を邪魔しない**」に従い、**このブロックは文字とボタンだけ。**

**写真は11月のギフトLPで使います。** そちらは実写のみ・和真さんの作業写真あり、で作ります。

**どちらの場合も郵便番号は記録します。**（理由は §4）

## 4. 【CMO判断】**エリア外の人に、他社は案内しません**

gift からの問い：「エリア外に おそうじ本舗などの全国サービスを案内するか」

### 結論：**案内しない。代わりに郵便番号を記録する。**

**理由は3つです。**

**(1) 誠実さは「はっきり断ること」で既に果たしている。**
他社紹介は誠実さの要件ではなく、その上の善意です。
**「現在は1都2県のみです」と明確に言えば、お客様は次に進めます。**

**(2) LPに他社名を載せると、恒久的に渡すことになる。**
ページはスクショされ、検索され、リンクされます。
**当社のドメインに「おそうじ本舗のギフトカードはこちら」が載っている状態を、あとから消すのは難しい。**

**(3) いちばん重い：本舗のギフトカードは、当社が「真似しない」と決めた商品そのもの。**
当社は本舗の加盟店ですが、**ギフトは唯一、本部と正面から並ぶ領域です。**
**そこへ当社が集めた人を送るのは、やらないと決めた商品を、当社の費用で育てることになります。**

### 代わりにやること：**エリア外の郵便番号を、黙って記録する**

**個人情報は取りません。郵便番号だけ。**

**これが効く理由：**

> **「1都2県に住んでいる人のうち、親も1都2県にいる人は何割か」**
> **── この事業の大きさを決めるのは、この1つの数字です。**

**いま誰も知りません。推測もできません。**
**10月のブロックは、この数字を無料で測れる唯一の機会です。**

エリア外が多ければ **「この事業は小さい」と早く分かる**（＝11月に金を使わずに済む）。
少なければ **「思ったより大きい」と分かる**。**どちらに転んでも、判断材料になります。**

**将来エリアを広げるか、その県の業者と組むかを考えるときにも、そのまま使えます。**

## 5. 計測（計測担当へ渡す仕様）

| イベント | いつ | 注意 |
|---|---|---|
| `gift_block_view` | ブロックが画面に入ったとき | 分母 |
| **`gift_block_click`** | **ボタンを押したとき** | **いちばん大事。「実家」に反応する人がいるか** |
| `gift_zip_submit` | 郵便番号を送ったとき | パラメータに **エリア内／外** と **都道府県** |

> 🚨 **`generate_lead` にしないこと。** これは申込ではありません。
> **広告のコンバージョンに混ぜると、10/1 の CPA 判定が壊れます。**
> **アンケートの `refer_share` と LPの `line_click` を混ぜてはいけないのと同じ理由です。**
