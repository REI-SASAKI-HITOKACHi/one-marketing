# 【市場調査】ハウスクリーニングのギフトは、いくらで売られているか

調査日: 2026-09-16 ／ 調査者: ギフト事業担当（`gift`）
きっかけ: オーナー指示（2026-09-16）「業界トップレベルに改善して再試行」／CMO 指示「手持ちの知識で書かないこと」

> ## 🔴 この調査で、自分の分析の誤りが1つ判明した
>
> 企画書 v2 で **「エアコン1台 10,780円は個人が贈るギフトの相場（3,000〜10,000円）を超えている。
> それが受注0の最有力の説明」** と書いた。**これは誤り。**
>
> **私が使った「3,000〜10,000円」は、出産祝い一般（モノのギフト）の相場であって、
> 「ハウスクリーニングギフト」という商品カテゴリの相場ではなかった。カテゴリを取り違えていた。**
>
> **実際のハウスクリーニングギフトの実売価格は 5,000〜19,000円。**
> 2026年の母の日LPの **16,800円 は、相場の中にしっかり収まっていた。**
> → **「価格が相場から遠すぎた」という仮説は、市場と照らすと支持されない。**
> → **オーナーの見立て（「広告の出し方もLPの中身も導線もすべてが稚拙だった」）のほうが、
> 　 いまある材料とよく合う。**

### 1.2 🔄 2026-09-22：カジタクの価格を再確認（宿題4）── **14,850円は下方修正**

**公式ギフトページ（`kajitaku.com/gift/`）は 9/22 も 403 で読めない。** そこで**小売の掲載実額**（一次に近い）で確かめた。

**分かったこと：**

1. **私が「選べるお掃除ギフト 14,850円」と記録していた商品は、小売では「らくらくお掃除セレクトパック（家事玄人・チケット型）」として 17,000〜19,600円で売られている。** 商品名が変わったか、別SKUを二次情報でつかんでいたかのどちらか。**14,850円は再現できないので取り下げる。**

> ### 結論はむしろ強くなった

## 2. ワンヒッターの価格は、市場の中でどこにあるか

| | 価格 |
|---|---:|
| ダスキン（金額券・下） | 5,000円 |
| ダスキン（金額券・上） | 10,000円 |
| **ワンヒッター エアコン1台** | **10,780円** |
| ダスキン 家事おてつだい1回 | 13,200円 |
| **カジタク セレクトパック**（9/22修正） | **17,000〜19,600円** |
| **2026年 母の日LP 最安（換気扇）** | **16,800円** |
| **おそうじ本舗 ギフトカード** | **19,000円** |
| ダスキン 箇所別おかたづけ1回 | 19,800円 |

**分かったこと3つ。**

1. **ワンヒッターの 10,780円 は、市場では最安クラス。**「高すぎる」どころか安い。
2. **2026年の母の日LPの 16,800円 は、カジタク（17,000〜19,600円・9/22修正）とおそうじ本舗（19,000円）の少し下。上位帯のすぐ下だった。**
3. **したがって「価格が相場から外れていたから売れなかった」は成り立たない。**

> ### 🆕 逆に、新しい問いが出た
> **体験型の上位帯が 17,000〜19,600円 のところに 10,780円 を置くと、4〜5割安い。**
> 贈り物で「安い」は、**必ずしも有利ではない**（贈った側が安物と思われたくない）。
> **ワンヒッターの価格の安さは、ギフトでは武器にならない可能性がある。**
> ※ ただしこれは**仮説**。2026年のLPは16,800円だったので、**この説明は2026年の失敗には当てはまらない。**

## 3. 🚨 重い論点：**おそうじ本舗が、19,000円でギフトカードを売っている**

**ワンヒッターは、おそうじ本舗のフランチャイズ加盟店でもある。**

- ワンヒッター名義でハウスクリーニングのギフトを出すと、**本部が売っている商品と正面から競合する。**
- しかも**価格は 10,780円 と 19,000円**。**本部の商品より4割以上安い。**
- 本舗経由の売上にはロイヤリティ（2026年1〜8月の実効 **39%**＋固定 50,050円/月）がかかっている。

> ### **これは企画の成立可否そのものに関わる。**
> **フランチャイズ契約に競業避止や商品の制限があるかどうかを、こちらでは確認できない。**
> リポジトリ内にFC契約の条項の記録は無い（検索語：フランチャイズ／FC契約／加盟／競業／本部）。
>
> **オーナーに確認が要る。** 契約書を見るか、本部に聞くかしないと分からない。
> **ここが引っかかると、ブランドの見え方（独立型／連結型）以前の問題になる。**

### 3.1 逆に、機会でもある

**本部が19,000円で売っているものを、同じ品質で10,780円で出せる**なら、価格競争力はある。
ただし上の契約論点をクリアしてからの話。

## 4. 業界がどう見せているか（v3 の材料）

| 要素 | おそうじ本舗 | カジタク | ダスキン |
|---|---|---|---|
| キャッチ | **「大切な人にお掃除のギフトを贈りませんか？」** | 記載未取得（403） | **「受け取られた方が、好きな時にお使いいただける便利なギフトカード」** |
| 型 | **選べる体験型**（6メニューから1つ） | **選べる**（4か所から1つ） | **金額券型**と**サービス指定型**の併売 |
| 流れ | ①贈り主が注文 → ②カードが受取主へ届く → ③好きなメニューを選んで利用（電話予約でカード番号を伝える） | 見積なしですぐ予約 | 記載未取得 |
| 想定シーン | **母の日・敬老の日・出産祝い・快気祝い・誕生日・クリスマス・ホワイトデー** | 記載未取得 | **夫→妻／子→親／友人の出産祝い／企業の景品** |
| 追加料金 | **あり**（お掃除機能付きエアコン、浴室1坪以上、フローリング10帖超） | 記載未取得 | 記載未取得 |
| 有効期限 | 記載なし（利用時にカード番号と**有効期限**を伝える、とあるので期限はある） | 記載未取得 | 記載未取得 |

**業界の共通形：「選べる」体験型。**
金額券ではなく、**メニューを選ばせる**のが主流。
→ **企画書 §3.5 の「案B 数量券型」が、業界の標準形に近い。**
→ **案A（予約代行型）は業界に前例が見当たらない。** 贈る人が受取人の家の施工を申し込む形は、確認した3社にはなかった。

> **ただし「選べる」には、当社の弱点がある。**
> おそうじ本舗は6メニュー、カジタクは4か所から選ばせている。
> **ワンヒッターも同じことはできるが、価格帯がメニューでばらつく**（10,780〜21,780円）。
> 本舗・カジタクは**1つの価格で複数メニューから選ばせている**（＝高いメニューに合わせた価格設定）。
> **当社が同じ形を取るなら、最も高いメニューに価格を寄せることになる。**
> これは §3 で積んだ限界利益の議論に直結する。**v3 で詰める。**

## 6. この調査が企画書に与える影響

| 企画書 v2.2 の記述 | この調査を踏まえると |
|---|---|
| §4.3「個人が贈るギフトの相場は3,000〜10,000円」 | **カテゴリが違った。**ハウスクリーニングギフトは5,000〜19,000円 |
| §8.2「受注0の最有力の説明は、価格が相場の1.7〜5倍だったこと」 | **支持されない。**16,800円は相場のど真ん中だった |
| §3「3,000〜10,000円のギフト専用メニューは出せない＝やらない」 | **前提が崩れた。**そもそも3,000〜10,000円に収める必要が無かった |
| §3.4「連名で1人3,593円にして相場帯に入れる」 | **不要ではないが、必然ではなくなった。**単独で10,780円でも市場の中にいる |
| §3.5「案B 数量券型は前払式支払手段に当たるので不利」 | **法務上の不利は変わらないが、業界の標準形はこちら。**案A（予約代行型）に前例が無いことが分かった |
