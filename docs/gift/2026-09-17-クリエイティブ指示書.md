## 0. いちばん大事なこと ── **これを外すと、また0になる**

> ## **この商品は「贈り物」ではなく「親孝行の段取り」を売っている。**
>
> 2026年は「母の日のギフト」として売った。**贈り物の棚に並べに行って、負けた。**
> 贈り物の棚には**おそうじ本舗（19,000円）・カジタク（14,850円）・ダスキン**がいて、
> **全員が全国網**を持っている。**同じ棚では勝てない。**
>
> **v3 が売るのはこれ：**
> **「年末に実家へ帰る。その前に、親の家をきれいにしておく。自分も立ち会える。」**
>
> 買う人が解いている問題は「何を贈ろう」ではなく、
> **「実家が古びてきた。親はもう自分で掃除しきれない。でも自分が帰ってやる時間もない。」**

**この1行が全クリエイティブの軸。ここからズレたものは作らない。**

| | |

## 3. どう見せるか ── ファーストビューの要件

**スクロールせずに見える範囲で、次の4つが伝わること。**

1. **情景**（年末・実家・親）
2. **自分が立ち会えること** ← **他社が絶対に書けない一行**
3. **エリアが1都2県だけであること** ← **隠さない。先に言う**
4. **次に何をすればいいか**

### 3.1 見出しの方向（一言一句はCMOに委ねる）

**方向A（情景から入る／推奨）**
> 年末、実家に帰る前に。
> **親の家のエアコンを、プロに洗ってもらう。**
> 東京・千葉・神奈川。**あなたが立ち会える日に伺います。**

**方向B（親の状態から入る）**
> 「もう脚立にのぼるのは危ないから」
> **そう言って、掃除をあきらめた親の家に。**

**✕ 使わない**：「大切な人にお掃除のギフトを」（＝おそうじ本舗の見出し。同じ棚に並びに行くことになる）

## 4. 🔑 導線 ── **郵便番号を、価格より先に聞く**

```
広告（1都2県・検索） → LP → 郵便番号を入力 → エリア内：価格とメニュー → 申込 → Square
                                          → エリア外：丁寧に断る
```

| 段階 | 設計 |
|---|---|
| **郵便番号** | **「お届け先（ご実家）の郵便番号」と聞く。** 贈り主の住所ではない |
| エリア内 | そのまま価格へ。**「エリア内です」と明示して安心させる** |
| **エリア外** | **決済まで運ばない。**「申し訳ありませんが、現在は東京・千葉・神奈川のみです」＋**おそうじ本舗などの全国サービスを案内してもよい**（誠実さが残る） |
| 申込フォーム | **贈り主と受け取る人の2人ぶん**＋**連名の贈り主欄** |
| 決済 | **Square 請求書（3.25%）を第一候補**（リンク決済3.6%より安い。§5.3） |

> **✕ 「遠方の場合のみ別途相談」は使わない。** 2026年のLPのこの一行が、エリア外の人を入口で受け入れていた。
