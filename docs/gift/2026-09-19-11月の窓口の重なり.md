# 11月、ギフトの電話を誰がかけるか

- 経営企画室の指摘（2026-09-18）を受けた CMO の宿題。数字ではないので判断を預かった
- 結論：**販売数に上限を置いて、電話の本数を先に決める。** 誰がかけるかはオーナー判断

## 指摘の原文

> **11月は年末大掃除の予約ピークです。**販売チャネルは競合しませんが、**問い合わせ対応の手は競合しえます。**
> ギフトの問い合わせが年末の予約対応と同じ窓口に来る形なら、**11月のいちばん忙しい週に重なります。**

## 何本の電話になるか

ギフトの流れは **申込 → 電話 → 日程確定 → お支払い**（`docs/gift/2026-09-18-申込フォーム仕様.md`）。
**課金の前に必ず1本、贈り主へかけます。**これは安全装置なので外せません。

| | |
|---|---|
| 11月の想定販売数 | **5〜20枚**（planning：10〜20枚は計画を崩さずに入る／赤字解消は4〜5枚／広告費5万の回収は6枚） |
| 1件あたりの電話 | **1本**（日程相談）。10〜15分 |
| **11月に増える電話** | **5〜20本 ／ 合計 1〜5時間** |

**総量としては大きくありません。問題は総量ではなく、いつ・誰が、です。**

## 本当の詰まりは「時間帯」です

**サンクスの文言で「お電話は 8:00〜20:00 のあいだにいたします」と約束しています。**

**和真さんは 07:00〜19:00 の現場が続きます**（9/16・9/17 の空室清掃は12時間現場）。
**つまり、約束した時間帯のほとんどで、和真さんは電話に出られません。**

**申込から1〜2日以内にかける**設計なので、**「手が空いたときに」では回りません。**

## 決めたこと（CMO・2026-09-19）

### 1. 11月の販売数に上限を置く ── **20枚**

**電話の本数を、売れてから数えるのではなく、先に決めます。**
20枚なら**最大20本・合計5時間**。**planning の「10〜20枚は計画を崩さずに入る」とも一致します。**

上限に達したら**LPの申込を閉じる**（「今季の受付は終了しました」）。
**売り切れは、贈り物では悪い印象になりません。**むしろ間に合わなかった人が来季の見込み客になります。

### 2. かける時間帯を、先に絞って書く

**「8:00〜20:00」と広く約束せず、実際にかけられる帯に寄せます。**
サンクスの文言は**確定後に直します**（誰がかけるかで帯が変わるため）。

### 3. 🔴 誰がかけるかは、オーナー判断

**これだけは決められません。**候補は3つ。

| | 誰 | 帯 | 向き・不向き |
|---|---|---|---|
| A | **オーナー** | 日中も可 | **いちばん素直。**贈り物の電話は、代表がかけると強い |
| B | 和真さん | **19:30〜20:00 のみ** | 現場の後。**1日1〜2本が限度**。20枚だと月の半分は電話の日になる |
| C | 折り返しにする | お客様の都合 | **課金前の確認が抜ける。**エリア外・お掃除機能付きの取り違えを拾えなくなる。**採らない** |

**Cは採りません。**電話は安全装置で、**2026年の母の日で「対応できない人に金を使った」失敗の再発を止めているのが、この1本**です。

## やらないこと

**電話をやめてフォームだけで完結させる**、は採りません。
**課金の前に人が1回挟まる**ことが、この商品の設計の芯です。
- 郵便番号の上3桁では、**東京の島嶼部（大島 100-0101／八丈 100-1511／小笠原 100-2101）が千代田区と同じ**で弾けません
- **お掃除機能付きの「わからない」**は、当日まで確定しません
- **受け取る方が話を聞いていない**場合がある

**どれも、金を受け取る前に人が拾う前提で設計してあります。**
