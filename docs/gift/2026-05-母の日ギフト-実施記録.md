## 1. 何をやったか（事実）

| メニュー | 掲載価格（税込） |

| 換気扇クリーニング | **¥16,800** |
| 換気扇＋キッチンセット | **¥30,600** |

- ドメインは `gift-mothersday.vercel.app`（**独自ドメインではない。Vercel のサブドメイン**）。

### 1.3 広告

- **Google広告。開始日 2026年4月24日。**
- **キャンペーンタイプは P-MAX**（オーナーは**検索広告を出しているつもりだった**。会話の途中で判明）。

- コンバージョン計測は `/thanks`（決済完了ページ）到達で設定しようとしていた。

  広告文を「まだ間に合う」系に差し替え、予算増額を検討していた。

## 3. ここから読み取れること（gift の読み。事実と分けて書く）

### 3.0 🔴 【2026-09-16 訂正】この節の読みは間違っていた

**下の §3.1 で「集客は成功していた」と書いたが、誤り。**
**§1.3 に「地域：日本（国）」と自分で記録しておきながら、§3 でそれを使わなかった。**

CMO が同じ材料から指摘した（`docs/gift/2026-09-16-受注0の構造的な原因.md`）：

> **売れなかったのではない。そもそも売れない人に、広告費の4分の3を使っていた。**
> 広告の地域指定が「日本（国）」で、対応エリアは**東京都・千葉県・神奈川県**だけ。
> 1,207クリックのうち施工できる場所にいた人は**約290人**。**残り約917人は、買う気になっても買えなかった。**

**さらに、条件はもっと狭い。** ハウスクリーニングは**受け取る人の家**でしか成立しない。
母の日は「子が、母に贈る」ので、**成立条件は「お母様の家が1都2県にあること」。**
贈り主が1都2県にいるだけでは足りない。

**CPC ¥26 の読みも逆だった。**「安く買えた」のではなく「**安い場所に流れていた**」。
1都2県はハウスクリーニングの単価が最も高い帯で、**そこで本気で競ったら ¥26 では買えない。**

**以下の §3.1〜3.5 は、この訂正を踏まえて読むこと。**

### 3.1 ~~いちばん重要：集客は成功していた。売れなかったのは商品と見せ方。~~ ← **訂正済み（§3.0）**

**1,207クリック集めて、受注0。**

- 表示 40,423回・CTR 2.99% は、**需要が存在しないことを意味しない。** むしろ人は反応している。
- 平均CPC **¥26** は極めて安い。**獲得コストは問題ではなかった。**
- **問題は、来た人が買わなかったこと。** 1,207人が見て、1人も買っていない。

> **企画書で「CPA上限 9,500円 との差が −66円」と議論していたが、
> 実際の CPC は ¥26 だった。獲得コストの議論は、この事業の急所ではなかった。**
> **急所は CVR。** 1,207クリックで0件という数字は、単価の話ではなく**受け皿の話**。

### 3.2 ~~価格が相場の2〜5倍だった~~ ← **2026-09-16 に自ら撤回**

**市場調査（`docs/gift/2026-09-16-市場調査-ハウスクリーニングギフト.md`）で撤回した。**
おそうじ本舗19,000円／カジタク14,850円（**※9/22再確認で 17,000〜19,600円に修正。市場調査 §1.2**）／ダスキン5,000〜26,400円で、**実勢は5,000〜19,600円。**
**LPの16,800円は相場のど真ん中だった。価格は主因ではない。**
以下は撤回前の記述（経緯として残す）。


企画書 §4.3 で調べた相場（[リンベル調査](https://www.ringbell.co.jp/giftconcierge/1492)）と突き合わせる。

| | 金額 |
|---|---|
| 個人が贈るギフトの相場（友人・知人／職場） | **3,000〜10,000円が8割以上** |
| 母の日LPの最安メニュー | **¥16,800** |
| 同・真ん中 | **¥30,600** |
| 同・最上位 | **¥50,700** |

**最安でも相場帯の上限の 1.7倍。真ん中は 3倍。最上位は 5倍。**

> **これが受注0の最有力の説明。**
> 企画書 §4.3 では「エアコン1台 10,780円でも個人の相場を超えている」と書いたが、
> **実際に売っていたのは 16,800円〜50,700円 だった。** 相場からもっと遠い。
> ※ 母の日は「親へ贈る」文脈なので相場は上がる（親からの出産祝いは2万円以上が63.7%）。
> 　 ただし**贈る側が子ども世代**である母の日で、5万円のクリーニングは重い。**要検証。**

### 3.3 「別ブランド・独立型」は、一度やって0件だった

- `gift-mothersday.vercel.app` は、**ワンヒッター本体のサイトから切り離された単独のLP**。
- 運営者としてワンヒッター株式会社の表記はあるが、**クチコミ・実績・読本などの信用材料は無い。**
- **独自ドメインですらない**（Vercel のサブドメイン）。

> **企画書 §9 の問い2（独立型 vs 連結型）に、実データが1件ついた。**
> 「独立型に近い形を一度試して、1,207クリックで0件」。
> ただし**価格（3.2）という別の致命傷があった**ので、
> **これだけで「独立型がダメ」とは言えない。** 交絡している。

### 3.4 Square のオンライン決済は、実際に使われていた

**一度、オンラインで前払いを受ける構成を本番で動かしている。**

### 3.5 P-MAX を「検索広告」と思って回していた
