# Netlifyトークンの取得手順（オーナー作業）

作成 2026-09-08
所要 **3分**。パソコンでもスマホでもできます。

---

## なぜ必要か

いまアンケートが壊れています。

```
https://one-hitter-survey.netlify.app/
→ content-type: text/plain で配信されている
→ スマホのブラウザに HTMLのソースがそのまま表示される
```

現場でQRを読み取ったお客様には、あの画面が出ていました。

**原因はCMOの配信ミス**です。ファイルを `/index.html` ではなく `/` として
登録したため、拡張子が無く、NetlifyがHTMLと判定しませんでした。
**中身自体は正しく**、ローカルのビルド成果物とバイト単位で一致しています。
壊れているのはパスだけなので、**正しく配信し直せば直ります。**

配信し直すにはNetlifyのトークンが要ります。以前いただいたものは、
CMO側のコンテナが作り直されたときに消えました。

> このトークンは**今後も使います。**
> 既存客向けの予約フォームも、SMSから飛ばすページも、すべてNetlifyで配信します。
> 一度いただければ、以後は都度お願いすることがなくなります。

---

## 手順

### 1. Netlifyにログイン

https://app.netlify.com/

### 2. トークンの画面を開く

**このURLを直接開くのが早いです。**

https://app.netlify.com/user/applications#personal-access-tokens

（メニューから行く場合：右上のアイコン → `User settings` → 左メニュー `Applications` → `Personal access tokens`）

### 3. 新しいトークンを作る

1. `New access token` をクリック
2. 説明欄に `one-hitter CMO` と入力
3. 有効期限を選ぶ
   - **`No expiration`（無期限）を選べるならそれが一番楽です**
   - 選べない場合は、選べる中でいちばん先の日付にしてください
     （前回は2026/12/31にしていただきました。期限が来ると同じ作業が発生します）
4. `Generate token` をクリック

### 4. 表示されたトークンを控える

**この画面を閉じると二度と表示されません。** 必ずその場でコピーしてください。

`nfp_` で始まる長い文字列です。

### 5. CMOに渡す

**チャットに直接貼らないでください。**

1. Googleドライブで新しいドキュメントを作る（名前は `netlify-token-2026-09` など）
2. 共有設定は「**制限付き**」のまま。誰にも共有しない
3. トークンを貼り付けて閉じる
4. **そのドキュメントのURLだけ**をチャットに貼る

CMOはDriveを読めるので、そのまま受け取れます。

---

## 渡したあと、CMO側でやること

1. アンケートを正しいパスで配信し直す
2. **配信後の検証を自動で走らせる**（今回のバグを二度と見逃さないため）

```
・ステータスが 200 か
・Content-Type に text/html が入っているか   ← 今回ここだけが違っていた
・本文の先頭が <!doctype / <html で始まっているか
```

3. スマホの実機で表示を確認したうえで、渡辺さんへQRを渡す

**今回の反省。** これまで配信後の確認を「HTTP 200 が返るか」だけで済ませていました。
200は返る、中身も返る、それでもブラウザには読めない形で出ていました。
今後は必ず、**お客様に見えるもの**まで確認します。

## 補足：ご自分で今すぐ直したい場合

トークンを渡さずに、Netlifyの画面から直す方法もあります。

1. https://app.netlify.com/ で `one-hitter-survey` のサイトを開く
2. `Deploys` タブを開く
3. GitHubから `deploy/netlify/survey` フォルダを丸ごとダウンロードしておく
   （中に `index.html` が入っていること）
4. Deploysの画面下部にある **ドラッグ&ドロップの枠にフォルダごと投げ込む**

ただし**この方法だとCMO側から今後の配信ができないまま**なので、
予約フォームなど次の作業でまた止まります。トークンをいただくほうが早いです。
