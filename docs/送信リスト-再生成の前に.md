## 1. なぜ再生成の話になるのか

**和真さんが入れた番号は `電話番号_未登録` タブのD列にあります。**
一方 `build-sms-list.py`（CMO のツール）は、**電話番号を `顧客管理台帳` から読みます**
（`'TEL': ('TEL', '元の電話番号表記', '電話番号')`）。台帳は月次タブから作る派生データです。

```
電話番号_未登録 D列   ←  和真さんが入れた場所
      ↓ （ここが繋がっていない）
月次タブ TEL列 → 顧客管理台帳 → build-sms-list.py → 冬季見込み客_2026
```

**つまり、いまのままでは番号は送信リストに届きません。**
