## 1. 結論

**業者経由（国内キャリア直収・共通番号型・050型・海外ゲートウェイ型）で「自社の080を送信元に表示する」正規の手段は、一次情報では見つからなかった。**
KDDIは個別回答で不可、NTT CPaaSは公式FAQで「携帯電話番号は持ち込み不可」（前回調査）。そのほかの各社は「固定・050・0120なら指定可」とだけ書いていて、携帯番号が使えるとは書いていない。
**080から届く形を保てるのは、その080のSIMが入った端末から送る方式（端末型）だけ。**

### 推奨：Android端末＋「SMS Gateway for Android（SMSGate）」をローカルモードで使い、080のSIMから送る

1. **送信元は SIM の番号（080）そのまま。返信と折り返しは同じ端末に戻る。** 送ったメッセージも受けたメッセージも端末の標準SMSアプリに残る（SMSGate FAQ）。
2. **費用はキャリアのSMS送信料だけ**（アプリは無料、Apache-2.0）。**文字数の上限が無く**（長文は自動で分割）、いまの181字の文面と宛先ごとの `cid` 付きURLをそのまま使える。送達（`sms:delivered`/`sms:failed`）と受信は Webhook と API で取れるので、PCやリポジトリのツールから送り、名乗り照合（`meigi_hyou()`）を送る直前に機械でかけられる。
3. **キャリアの「1日200通」上限は、アプリ側の送信間隔・期間ごとの上限・稼働時間の設定で守れる。** ただし作者自身が「一括送信には勧めない（キャリアの制限があるため）」とREADMEに書いている。**数日に分けて少しずつ送る前提で使う。**

### 次点：SMS送信.com（株式会社マイレージテクノ）の「アプリ送信」

1. 仕組みは推奨と同じ（Androidアプリから、端末のSIM番号で送る）。返信は端末に届くと公式FAQに明記がある。
2. 日本の会社の完成品で、PCの管理画面にCSV（宛先ごとに文面）を入れ、端末で「送信開始」を押すだけ。予約送信があり、インボイス対応の領収書が出る。**1通1円＋キャリア料金。**
3. **ただし本文は70字まで**（公式FAQ「1通あたりの文字数を70文字に制限」）。いまの181字の文面と、宛先ごとのURLは入らない。**文面を70字に作り直せるなら、こちらのほうが導入は速い。**

### 両案に共通する前提（未確認。導入前に確かめること）

- **080-1344-3137 と 080-8043-8259 がどの端末に入っているか。** 施工写真のEXIFでは渡辺さんの撮影端末は **iPhone 13** だった（`docs/photo-inventory.md`）。**両案ともAndroid専用で、iPhoneでは動かない。** その iPhone に080のSIMが入っているなら、SIM（またはeSIM）をAndroid端末へ移すことになる。端末を買うなら「お金を使う」に当たるので、オーナーの判断になる。
- **回線の名義と料金プラン**（法人契約か個人契約か、SMS送信料が無料になるプランか）。未確認（リポジトリに記載が無い）。
- **キャリアの約款が、業務での一斉送信をどう扱っているか。** 未確認（約款の本文を読めていない）。

- **長文（分割）が上限の1通に何通として数えられるか：** キャリアの一次情報では**未確認**。ドコモのページは「分割した通数分の送信料が発生」までしか書いていない。SMS送信.com の解説は「70文字を1通として数えるから200通未満でも制限がかかる」と書いている（業者の解説で、一次情報ではない）。
  - 分割分も数えられる場合、**181字（3通分）なら1枚のSIMで1日およそ66名まで**。70字以内なら1日199名まで。
  - 例：本舗名義の送信対象 268名（`docs/チャネル運用方針-2026-09-21.md`）なら、1枚のSIMで**5日**（181字）、**2日**（70字）。**自社名義と本舗名義は別々の番号なので、2枚のSIMで同時に進められる。**
- **法人契約なら上限を緩められるか：** 未確認。どのキャリアでも公式の記載を見つけられなかった。
- **SIMを増やせば上限も増える。** SMS送信.com のFAQに「200件の制限は1契約、1電話番号毎。SIMカード5枚なら理論上1日1,000件」とある。**ただし番号が変わるので、「いつもの080から届く」形は崩れる。**
- **ドコモの「意図せぬ迷惑メッセージ送信に関するお知らせ」**（2024-07-01開始、既定で有効）は、フィッシングサイトや不正アプリへ誘うSMSの送信を検知したときに、送った本人へ注意を出す仕組み。**送信が止められるかはページに書かれていない**（未確認）。当社の本文にはURLが入るので、**URLは独自ドメイン（onehitter.jp 側）に寄せる**という既存の決まり（`CLAUDE.md` 禁止事項）を守ること。https://www.docomo.ne.jp/info/anti-phishing/prevention/itosenu_meiwakusms/
- **特定電子メール法：** 総務省のページでは、広告・宣伝のメールは原則オプトイン、**送信者の氏名または名称と、受信拒否の連絡先の表示が必要**、取引関係にある人は事前同意の例外。https://www.soumu.go.jp/main_sosiki/cybersecurity/kokumin/basic/legal/08/
  **SMSがこの法律の対象に入ることを書いた一次の条文は、今回は確かめられなかった**（総務省のパンフレットPDFを本環境で読めなかった）。業者の解説は、どれも「SMSも対象」としている。

### 判断の論点（CMO・オーナー向け）

1. **解約しなくても固定費はかからない見込み。** 上の「最低利用期間・違約金」と「トライアル終了後の扱い」が申込書で「無し」と確かめられれば、**急いで解約する理由は無い。** 端末型では1日200通という上限があり、KDDIは到達結果とAPIが強い。**大量に送るときや至急のときの予備として残す**選択肢がある（その場合も 03-5674-8758 の着信転送は要る）。
2. **解約・取り下げは「元に戻せない」に当たるので、オーナーの判断。** 取り下げたあと再び申し込むと、また約10営業日かかる。
3. **無料トライアル（3,000通）が当社に適用されるかは未確認のまま**（確認メール案 `docs/mail/kddi-trial-confirm.md` は未送信）。適用されるなら、**費用だけで比べれば KDDI（0円）のほうが端末型（約9,000円）より安い。** 080から届くことを取るか、費用と到達結果を取るか、という比較になる。
