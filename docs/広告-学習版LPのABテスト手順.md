## 2. 設定手順（Google広告の「広告バリエーション」）

元の広告を壊さずに、**同じオークションを半々に分けて**、片方だけ最終ページURLを学習版に替えます。
キャンペーンを複製しないので、入札の学習がリセットされません。

### 2-1. 今の最終ページURLを控える
1. Google広告 → 左のメニュー「キャンペーン」→「広告」
2. 期間を問わず、**配信中のレスポンシブ検索広告**の「最終ページURL」列を見る
3. URL をそのままメモ帳にコピーする（例：`https://lp.onehitter.jp/aircon/?src=gads_aircon&cid={campaignid}&ag={adgroupid}`）
   - **`?` から後ろの部分（`src` `cid` `ag`）が URL に入っているか、入っていないか**も控える。
     入っていなければ、キャンペーンの「最終ページ URL のサフィックス」に入っている。どちらでもよいが、2-3 の書き方が変わる
4. `/aircon-b/` や `/nenmatsu/` に飛ぶ広告があるかも見る（1. の表の判断に使う）

### 2-2. エアコンのバリエーションを作る
1. 左のメニュー「キャンペーン」→「テスト」→「広告バリエーション」タブ → 青い「＋」
2. 対象：**キャンペーン `検索_江戸川_段0_v2` だけ**を選ぶ（「すべてのキャンペーン」にしない）
3. 広告タイプ：「レスポンシブ検索広告」
4. 絞り込み：「**最終ページURL**」が「**次を含む**」`lp.onehitter.jp/aircon/`
   - 末尾の `/` まで入れる。`/aircon-b/` を巻き込まないため
5. 変更の種類：「**URL の更新**」→「最終ページURL」に、2-1 で控えたURLの **`/aircon/` だけを `/aircon-c/` に替えたもの**を入れる
   - 例：`https://lp.onehitter.jp/aircon-c/?src=gads_aircon&cid={campaignid}&ag={adgroupid}`
   - **`?src=…` から後ろは一文字も変えない。** `{campaignid}` `{adgroupid}` の波かっこもそのまま
   - 2-1 で `?` 以降が URL に無かった（サフィックス側にある）場合は、`https://lp.onehitter.jp/aircon-c/` だけでよい
6. 名前：`学習版LP_エアコン_C`
7. 開始日：今日／終了日：**2026-10-31**（10/9 は中間の判定。終了日は後で延ばせる）
8. 「テストへの分配比率」：**50%**
9. 「バリエーションを作成」

### 2-3. 水まわりのバリエーションを作る
2-2 と同じ手順で、4 と 5 と 6 だけ替える。
- 4. 絞り込み：最終ページURL が「次を含む」`lp.onehitter.jp/mizumawari/`
- 5. `/mizumawari/` を `/mizumawari-b/` に替えたURL（`?src=gads_mizumawari&…` はそのまま）
- 6. 名前：`学習版LP_水まわり_B`

**同じキャンペーンに2本目のバリエーションが作れない**と出たら、無理に続けず、そこで止めて CMO に画面の文言を送る
（その場合は、エアコンと水まわりを1本にまとめる方法か、広告グループ内に学習版の広告を足す方法に切り替える。
どちらにするかは計測担当が決める）。

### 2-4. 作った後に確かめる（当日と翌日）
1. 「テスト」→「広告バリエーション」で、2本とも「実行中」（または開始日待ち）になっている
2. 翌日：「広告」画面で、**バリエーション側の広告が「承認済み」**になっている（新しいURLの審査が入るため）
   - 「不承認」なら理由の文言をそのまま CMO に送る
3. 翌日：GA4 のリアルタイムではなく、**翌日の GA4 で `/aircon-c/` と `/mizumawari-b/` に `src=gads_…` の閲覧が付いている**ことを計測担当が見る

## 3. 判定のしかた
- 数字は **`tools/ad-group-hyou.py`**（計測担当）で、広告グループ × **今の版／学習版** の2行に分けて出す。
  版は予約_Web の `lp` 欄またはフォーム名（`reserve-aircon-c` など）で分ける。**`src` は両方同じなので分けに使えない**
- 費用は、広告バリエーションの画面に「元の広告」と「バリエーション」で分かれて出る。それを版ごとに渡す：
  `--hiyou A_エアコン:今の版=円 --hiyou A_エアコン:学習版=円`
- **件数が少ないうちは、差が出ても偶然と区別できません。** 10/9 は「学習版で明らかに悪くなっていないか」を見る中間判定にとどめ、
  勝ち負けの判定は件数がたまってから

## 4. 終わらせ方
- 学習版が良い → 広告バリエーションの画面で「適用」（元の広告のURLが学習版に替わる）
- 今の版が良い → バリエーションを「終了」（元の広告はそのまま残る）
- **どちらも、URLを学習版に一本化するならその前に計測担当が本番の計測をもう一度確かめる**
