## 🔴 いちばん重い問題：使ってはいけない番号が、いま公開されている

**`080-1755-7275` は `CLAUDE.md` で「使わないこと」と決まっている番号**だが、
**下記6ページの「会社情報」の電話番号欄に出ており、タップできる状態にある。**

```
https://one-hitter.jp/access/
https://one-hitter.jp/feature/お風呂/
https://one-hitter.jp/feature/エアコンクリーニング/
https://one-hitter.jp/feature/キッチンクリーニング/
https://one-hitter.jp/feature/水まわり/

```

出方（`/feature/エアコンクリーニング/` の例）：

```html
電話番号  080-1755-7275
<a href="tel:080-1755-7275" onclick="ga('send','event','teltap','cl…
```

**同じページのヘッダー／フッターには `080-8043-8259` が5回出ている。**
**＝ 1枚のページに2つの番号が載っていて、会社情報の欄のほうが使ってはいけない番号。**

**お客様が会社情報を見て掛けると、使っていない番号に掛かる。**
電話が主要な導線である以上、**これは取りこぼしそのもの。**

# 原稿：会社情報の電話番号を差し替える

**★ 差し替える番号が未確定なので、原稿は番号を伏せた形にしてある。**

MTG（2026-09-19・3-2 No.24／T029）でのオーナー訂正は
**「公式サイトに載せる電話番号は和真さんの業務用TEL」。**
その番号そのものは、こちらには伝わっていない。

## 直す対象（6ページ・会社情報の欄のみ）

| ページ | いまの値 | 直したあと |
|---|---|---|
| `/access/` | 080-1755-7275 | **和真さんの業務用TEL** |
| `/feature/お風呂/` | 同上 | 同上 |
| `/feature/エアコンクリーニング/` | 同上 | 同上 |
| `/feature/キッチンクリーニング/` | 同上 | 同上 |
| `/feature/水まわり/` | 同上 | 同上 |
| `/feature/洗濯機/` | 同上 | 同上 |

**表示のテキストと `tel:` リンクの両方を直すこと。**片方だけ直すと、
見えている番号と掛かる先が食い違う（いちばん質の悪い壊れ方）。

```html
<!-- 直す前 -->
電話番号  080-1755-7275
<a href="tel:080-1755-7275" onclick="ga('send','event','teltap', …

<!-- 直したあと（NNN は和真さんの業務用TEL） -->
電話番号  NNN-NNNN-NNNN
<a href="tel:NNN-NNNN-NNNN" onclick="ga('send','event','teltap', …
```

**`onclick` の `teltap` は触らないこと。**ここを消すと電話タップの計測が落ちる。

## 決めてほしいこと

1. **和真さんの業務用TEL の番号**（これが無いと原稿を確定できない）
2. **ヘッダー／フッターの `080-8043-8259`（127ページ）はそのままでよいか。**
   会社情報だけ別番号にすると、**1ページに2つの番号が並ぶ状態は解消されない。**
   - 案A：会社情報も含めて**全部を和真さんの業務用TELに揃える**
   - 案B：**CTAは 080-8043-8259、会社情報は和真さんの業務用TEL** と役割で分ける
   - **案Aを推す。**お客様から見て番号が2つある理由が無く、
     どちらに掛かったかで計測も分かれる
3. 2022年のブログの `080-6817-4796`（61ページ）をどうするか。
   **古い番号が検索に出ている状態。**直すなら投稿ツールができてからの一括作業になる
4. 2023年のブログの 03系・090系は**他社の番号の可能性があるので、触らない**方針でよいか

## 反映について

**CMSへの反映はオーナーの操作。**ここまでが原稿。
**`/access/` と `/feature/` の5ページはページビルダー側の可能性がある**ので、
`/_sys/` のフォームで直せるかは、番号が決まってから調べる。
