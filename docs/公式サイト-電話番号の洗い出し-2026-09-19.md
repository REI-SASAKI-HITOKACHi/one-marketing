# 原稿：会社情報の電話番号を差し替える

**番号が確定した（CMO回答 2026-09-19）。和真さんの業務用TEL ＝ `080-8043-8259`。**
これは共通ヘッダー／フッターのCTAに127ページで出ている番号と同じ。

**＝ やることは「6ページの会社情報欄を、同じページのCTAと同じ番号に揃える」だけ。**

> ⚠️ **CMOからは「公開ページも実測して旧番号0件を確認ずみ、原稿は不要」と
> 連絡があったが、2026-09-19 13:5x に測り直したところ旧番号はまだ出ている。**
> 静的キャッシュでもない（クエリ有り・無しの両方で同じ）。下記「実測」を参照。

**静的キャッシュの見え方の違いではない。** クエリ無し（`x-static-cache: 1`）でも
クエリ付き（キャッシュ回避）でも、**どちらも2回出る。**

**表示のテキストと `tel:` リンクの両方を直すこと。**片方だけ直すと、
見えている番号と掛かる先が食い違う（いちばん質の悪い壊れ方）。

```html
<!-- 直す前 -->
電話番号  080-1755-7275
<a href="tel:080-1755-7275" onclick="ga('send','event','teltap', …

<!-- 直したあと -->
電話番号  080-8043-8259
<a href="tel:080-8043-8259" onclick="ga('send','event','teltap', …
```

**`onclick` の `teltap` は触らないこと。**ここを消すと電話タップの計測が落ちる。

## 反映について

**CMSへの反映はオーナーの操作。**ここまでが原稿。

`/_sys/` のフォームで直せるかは、番号が決まってから調べる。
