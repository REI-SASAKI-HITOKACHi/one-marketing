## 段取り3：配信を開始する前に、必ず確認する4つ

- [ ] **コンバージョン計測が動いているか**（`docs/広告-コンバージョン計測.md`／measurement 担当）
      予約フォーム送信 `generate_lead` と 電話タップ `phone_click` の2つ。**ここが死んでいると、広告費は全部ただの支出になる**
- [ ] **着地ページが開くか**（`https://lp.onehitter.jp/aircon/?src=gads&cid=test` を実際に踏む）
- [ ] **着地ホストがセーフブラウジングで安全か** → `python3 tools/check-safebrowsing.py`
      **`lp.onehitter.jp` が「安全」であること。**ここが判定を受けると、**広告費を払いながら誰も着地できない。**
      2026-09-12 の事故は独自ドメイン側で起きた。判定はいつでも変わるので、配信のたびに見る。
      **429（レート制限）で取れなかったホストを「次回送り」にしたまま配信しないこと。**
      ツールは間隔を広げて自動で追いかけるが、それでも取れないときは単独で叩けば確実に取れる：
      `https://transparencyreport.google.com/transparencyreport/api/v3/safebrowsing/status?site=<ホスト>`
      （返りの `"sb.ssr",N` の `N` が **1＝安全／3＝安全でない／6＝データなし**）。
      **`onehitter.jp`（apex）は、このホスト固有に弾かれやすい。**取れなかったら単独で叩くのが早い
- [ ] **広告文と着地ページの記載が食い違っていないか** → `python3 tools/check-ad-consistency.py`
      価格や実績値の食い違いは**審査落ちの定番**。`98.8` や旧価格 `9,800` の残存、
      広告に出した `10,780` `98.6` がページに載っているか、`98.6` の根拠（期間・母数）がページにあるかを実地で見る
- [ ] **地域が6つだけになっているか**（既定で「日本」が残っていることがある。残っていたら消す）

## 表を作り直すとき

```
python3 tools/build-ads-upload.py
```

見出し（全角2・半角1で30まで）と説明文（90まで）を**機械で検査してから**書き出す。
1本でも超えると CSV を書かずに止まる。`98.8%` や「No.1」等の使えない表現も弾く。

**広告文に使ってよい事実**：満足度98.6%（209名中206名／2023年1月〜2025年12月）／Googleクチコミ★5.0（24件）／東京・千葉・神奈川／60分10,780円（税込）から。
**使わない**：98.8%（根拠と一致しない）、裏づけの無い最上級表現（景表法）、**追加料金のオプションを標準に含まれるかのように書くこと**（例：エプロン内部高圧洗浄は ¥8,470 の別料金）。
