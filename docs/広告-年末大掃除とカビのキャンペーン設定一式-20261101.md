## 測り方（入れたあと）
- 日 ¥1,000・上限 ¥500 なら **1日2〜3クリック前後**（段0 の CPC ¥324〜505 から。推定）。**7日で15〜20クリックしか集まらない**ので、7日で申込の差は判定できない。7日で見るのは「表示が出ているか・検索語句が外れていないか」まで
- 申込：予約_Web の `src=gads_nenmatsu`・`src=gads_kabi`（`cid` で段0 と分ける）
- 段別：`python3 tools/funnel-keiro.py --start <開始> --end <終了> --src gads_nenmatsu`
- 時期別の表：`tools/nyusatsu-hikaku.py` は段0 と合わせて数えるので、新キャンペーンだけを見るときは 広告_日次 のキャンペーン名で分ける（道具の対応は計測担当が追加する）
