**繁忙期の加算**
5月から7月と、12月は、**全メニュー一律で1台・1箇所あたり 3,300円（税込）** が加算されます。この時期はご依頼が集中しますので、日程に余裕を持ってご連絡ください。

**出張費・駐車について**
出張費はいただいていません。お車を停める場所がない場合のみ、コインパーキング代が実費になります。お見積りのときに金額の目安をお出しします。

**複数のメニューをまとめる場合**
同じ日に2箇所以上をご依頼いただく場合は、お見積りでお出しします。養生や道具の出し入れが一度で済むぶん、作業時間も合計より短くなることがあります。

**追加の請求について**
お見積りでお出しした金額から、作業後に増やすことはしません。当日に現場を見て、うかがっていた内容と違っていた場合（お掃除機能なしと聞いていたが付いていた、など）は、作業を始める前に金額をご相談します。始めてからの変更はしません。

**お支払い**
作業が終わってからの現金、またはお振り込みです。

**対応エリア**
東京都・千葉県・神奈川県（江戸川区を中心に）。事務所は東京都江戸川区北葛西にあります。

※料金は季節/年次により改定を行っています。
