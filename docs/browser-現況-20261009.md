### 新規記事の作り方（確立済み・1本あたり4〜5手）

1. `https://one-hitter.jp/_sys/contents/article/561/0/` を開く（**12秒＋8秒待つ**）
2. `find("add_circle")` → **1つ目（ref_407 相当）をクリック**。これで本文と画像の欄（`fieldset,1561,1[...]`）が生える
   ⚠ **新規作成の画面には、最初は本文も画像も無い。**ブロックを足して初めて出る
3. `javascript_tool` で項目を入れる
   ```js
   const setV=(el,v)=>{const s=Object.getOwnPropertyDescriptor(el.constructor.prototype,'value').set;
     s.call(el,v); el.dispatchEvent(new Event('input',{bubbles:true})); el.dispatchEvent(new Event('change',{bubbles:true}));};
   setV(document.querySelector('input[name="pbd[date]"]'), '2026-10-31');   // 公開開始日
   setV(document.querySelector('input[name="pbd[hi]"]'),   '10:00');        // 時刻（全記事10:00）
   setV(document.querySelector('input[name="page[name]"]'), '題名');         // ⚠ page[name] を名指し
   [...document.querySelectorAll('input[name="input[tag_1925][]"]')].forEach(c=>{const w=(c.value==='新着情報'); if(c.checked!==w)c.click();});
   [...document.querySelectorAll('input[name="input[tag_2133][]"]')].forEach(c=>{const w=['江戸川区','ハウスクリーニング','船堀'].includes(c.value); if(c.checked!==w)c.click();});
   ```
4. 本文は Jodit のインスタンスに入れる（`window.Jodit.instances[Object.keys(...)[0]].value = H`）。
   送信される textarea は **`fieldset,1561,1[text]`**（既存記事の編集は `…,0[text]` なので番号が違う）
5. `find("done")` → **ref_604 相当（2つ目のdone）**を `scroll_to` してからクリック →
   URL が `…/<新しい記事ID>/registed/1/` になれば成功
