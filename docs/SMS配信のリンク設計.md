# 既存顧客へのSMS：どこへ誘導し、どう成果を数えるか

作成 2026-09-06 ／ **顧客接点スレッド（`claude/crm-sms-line`）向けの補足**

> ## この文書を作った理由
>
> 顧客接点スレッドに渡した最初の指示に、**SMSの誘導先の指定が抜けていました。**
> 指示を書いた時点で年末LPがまだ公開されておらず、アンケートと公式LINEの話しか渡せていませんでした。
> **文面を作る前に、ここを読んでください。**

## 結論：SMSには「年末LPの申し込みフォーム」のリンクを付けます

電話番号だけを載せた案内にはしません。**自社サイトで受注を完結させることが、この施策の目的そのものです。**

`docs/cmo-plan.md` の目標は「本舗経由の枠を、自社ネット経由の受注で置き換える（年間およそ630万円の改善）」。
電話だけの導線では、この「ネット経由」が積み上がりません。

## 配るURL

```
https://one-hitter-nenmatsu.netlify.app/?src=sms&cid=（顧客ID）
```

| パラメータ | 何のため |
|---|---|
| `src=sms` | SMS経由の予約を、他の経路と分けて数えるため |
| `cid=C0123` | **どのお客様が反応したかを台帳と突き合わせるため。** 顧客管理台帳のA列の顧客ID |

**このパラメータは、フォームの hidden 項目に自動で記録されます**（2026-09-06 実装・動作確認済み）。
Netlify Forms の受信データに `src` と `cid` の列が入るので、送った相手と受注が結びつきます。

- パラメータが無い場合は `src=direct` になります
- 値は英数字・ハイフン・アンダースコアだけに制限し、20文字で切っています

## 宛先ごとにURLを作る

顧客IDは1人ずつ違うので、送信リストを作るときに宛先ごとのURLを生成してください。
`冬季見込み客_2026` タブに顧客IDの列があります。

**短縮URLについて**：SMSは70文字を超えると課金が増えます（`docs/sms-provider-research.md`）。
KDDI Message Cast 側に短縮＋クリック計測の機能があるか確認し、あれば使ってください。
無ければ、上のURLをそのまま入れて文字数を計算に入れてください。

## 誘導先の使い分け

| 送る相手・目的 | 誘導先 |
|---|---|
| **既存顧客への秋冬・年末の案内**（今回の主戦場） | **年末LP** `https://one-hitter-nenmatsu.netlify.app/?src=sms&cid=…` |
| 施工後のフォロー（感想をうかがう） | アンケート `https://one-hitter-survey.netlify.app/?src=sms&id=…` |
| 友だち追加を促したいとき | 公式LINE `https://lin.ee/7kD9WGN` |

**1通に複数のリンクを入れないこと。** 迷わせると、どちらも押されません。

## 年末LPの中身（文面を書くときの前提）

- **訴求の軸は「11月30日までのご予約なら通常価格」。** 12月以降は1箇所につき+3,300円（税込）
- 例として出している金額：レンジフード＋浴室の2箇所で **33,660円（税込）**
  （12月なら40,260円。差は6,600円）
- ページ内に箇所を選ぶと金額が出る見積りツールがあります
- **noindex です。** 検索には出ないので、URLを知っている人だけが見られます

**金額をSMS本文に書く場合は `data/prices.json` を正としてください。** 記憶で書かないこと。

## やってはいけないこと

- **オーナーの承認なしに送信しないこと。** 一斉送信は「外に出す」に該当します。文面と宛先の準備までが担当範囲です
- 本舗（フランチャイズ）経由のお客様は、送信主体がおそうじ本舗江戸川中央店になります。**自社顧客と混ぜないこと**
- 「98.8%」は使用禁止。正しくは98.6%（209名中206名／2023年1月〜2025年12月）
- 深夜・早朝の送信
