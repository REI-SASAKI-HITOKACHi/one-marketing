# 公式LINEの友だちを台帳と照合する方法 — 2案（第7回MTG 10/16 用）

依頼 `20261016-01-crm`。第6回 No.16「台帳と照合できる人のみ送る／施工日と初回メッセージ送信日での照合も」が、鍵が無くて止まっているため。
作成 2026-10-16（顧客接点担当）。**どちらも「外に出す」ものではない**（お客様には何も届かない）。

## いまわかっている事実

- 友だち **333〜335人**（9/21・10/4 に Messaging API で実測。ブロックを除く届く人数）
- 表示名が台帳の氏名と一致したのは **17人（約5%）**。表示名はお客様が自由に付けるので、これ以上は名前では伸びない
- 2023年1月に購入した友だち **253人** が大半を占める可能性が高い（`docs/line-dummy-seiri.md`）
- 当社の記録（スプシ `LINE_ログ`）に残っている公式LINEの個別の記録は **9/7 の友だち追加1件だけ**。業務連絡グループのやり取りは残っているが、お客様の追加・メッセージはほぼ記録されていない

## ① 管理画面（LINE Official Account Manager）から一覧を書き出す

**結論：友だち全員の一覧を書き出す機能は、公式ヘルプでは確認できませんでした。** 見られるのは「チャット」の一覧だけです。

| | |
|---|---|
| 嶺さんの操作 | 管理画面 →［チャット］→ チャットの一覧を上から開き、相手の**表示名**と、トークの**いちばん古いメッセージの日付**を見て、表に書き写す（またはスクリーンショット） |
| 出てくる項目 | 表示名・アイコン（**電話番号は出ない**）。チャットのある相手だけ（認証済みアカウントは連絡先から相手を選べる、と公式ヘルプにある） |
| 所要時間 | チャットのある人数しだい。1人30秒として 100人で約1時間。**何人分あるかは、こちらからは見えない** |
| 照合できる見込み | 表示名で17人前後。日付が取れた人は「その日・前日に自社の施工が1人だけ」なら追加で決まる（人数は書き出してみないと分からない） |
| 弱いところ | 手で書き写すので取り違えが起きうる／表示名とアイコンのスクリーンショットは個人情報になる（置き場所を決める要あり） |

## ② 公式LINEの Messaging API の鍵を環境に入れる

| | |
|---|---|
| 嶺さんの操作 | ① LINE Developers コンソールで、公式アカウントのチャネルの［Messaging API設定］から**チャネルアクセストークン（長期）**を確認（9月に使っていたもの）<br>② Claude の画面上部の**環境のメニュー →［編集］**で、**ネットワークシークレット**（無ければ環境変数）に **`LINE_CHANNEL_ACCESS_TOKEN`** の名前で登録。**チャットには貼らない**。新しいセッションから効く |
| 所要時間 | 5〜10分 |
| こちらで取れるもの | 友だちの **userId の一覧**（333〜335人）／**表示名**（プロフィール）／**今月の送信数**（社内用30通を残した上限の計算）／一斉配信の前の**照合のやり直し** |
| 取れないもの | **過去の友だち追加日・初回メッセージ日**。API にこれを返す仕組みが無い |
| 第6回の「施工日×初回メッセージ日」 | **過去の333人には使えない。** ただし**これから友だちになる方**は、webhook が友だち追加を記録すれば日時がわかるので、「その日・前日の自社の施工が1人だけ」で自動で突き合わせられる。**いま webhook がお客様の追加を記録していない**（上の事実）ので、webhook の向き先の確認が要る（計測担当／CMO） |

---

**crm の推奨：② を先に（5〜10分・送信数の上限と照合のやり直しが毎回機械でできる）。そのうえで webhook を直して、これから増える友だちを施工日で自動照合する。過去の333人の日付照合は①の手作業でしかできず、効果は数十人以下と見込むので急がない。**
