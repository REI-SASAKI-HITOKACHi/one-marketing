# 台本B — お詫び行23 の方 【2026-09-17 冒頭を差し替え】

## 🔴 前提が変わりました：**断られたのではなく、値段で止まっています**

和真さんの回答（2026-09-17）：

> **値段を提示したところで返信がなくなりました**

**これは「断り」ではありません。** 高いと思った方は、普通は何も言わずに消えます。
**返事がないのは、金額に納得できていないという合図です。**

### そして、止まった原因はこちらの見立てどおりでした

**「換気扇」は、どれを指すかで金額が5倍ちがいます。**

| どこの換気扇か | 金額（税込） |
|---|---:|
| 台所のレンジフード | **¥18,480** |
| 台所（プロペラ式） | ¥10,780 |
| **お風呂場の換気扇** | **¥3,630**（浴室クリーニングのオプション） |

**お客様が「お風呂場のつもり」で聞いたのに 18,480円 と言われたなら、黙って消えます。**
**逆も同じです。** どちらのつもりだったかを確かめずに金額を出したのが、止まった原因の可能性が高いです。

> **だから、この電話は「どちらの換気扇か」の確認から始めます。**
> **金額の話をやり直せる、唯一の自然な入口です。** 日程の話は、そのあとです。
