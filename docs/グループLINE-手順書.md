# 3人グループLINE をつくる手順書

対象: 佐々木代表（オーナー本人の操作が必要です）
作成日: 2026-09-07
所要: 40分〜1時間

**佐々木さん・渡辺さん・CMO（内部用の公式アカウント）** の3人グループを作り、
そこで日々のやり取りをする。カレンダーとスプレッドシートは「置き場」として残し、
**届ける経路はLINEに一本化する。**

---

# ★ 早見表：普通に作るだけでは足りない操作

アカウント作成そのものは迷わないはず。**下の6つだけが「知らないと詰まる」ところ。**
先にアカウントを作っておくなら、作成後にこの6つをやれば終わる。詳細は該当章へ。

| # | やること | 場所 | 詰まりどころ |
|---|---|---|---|
| 1 | **グループ・複数人トークへの参加を許可** を **オン** | manager.line.biz → 設定 → アカウント設定 | 既定は**オフ**。オフのままだとグループに招待できない。ここが最初の関門（→ §2） |
| 2 | **あいさつメッセージ** を **オフ** | 同上 | オンのままだとグループ入室時に定型文が流れる（→ §2） |
| 3 | **Messaging API を利用する** → プロバイダー名 `ワンヒッター株式会社` を**新規作成** | manager.line.biz → 設定 → Messaging API | ⚠️ **紐づけは二度と解除できない。** 代理店やツール会社のプロバイダー配下に作らないこと。**WEB版管理画面からのみ設定可**（スマホアプリ不可）（→ §3） |
| 4 | **チャネルアクセストークン（長期）** を発行 | developers.line.biz/console → Messaging API設定タブの一番下 | 発行し直すと前のトークンは無効になる。控えたら非公開のGoogleドキュメントへ（→ §4・§7） |
| 5 | **Webhook URL** を登録して **Webhookの利用をオン** → ［検証］が成功すること | 同上 | URLはApps Scriptのウェブアプリ。**「アクセスできるユーザー＝全員」**でないと検証が通らない（→ §5・§6） |
| 6 | グループを作って**社内連絡アカウントを招待** → 何か発言 → Apps Scriptの `kakunin` でグループIDを取る | LINEアプリ ＋ Apps Script | グループIDが分からないとCMOから送信できない。ここまでやって完了（→ §8・§9） |

**CMOに渡すもの**

```
1. チャネルアクセストークン … 非公開のGoogleドキュメントに貼り、URLだけ共有
2. グループID（Cで始まる文字列） … チャットに直接貼ってOK（秘密情報ではない）
```

**やらないこと**

```
・認証の申請（未認証のままでよい）
・お客様向けアカウント（lin.ee/7kD9WGN）は今回いっさい触らない
・この経路にお客様の個人情報を流さない（署名検証ができないため）
```

---

## 0. なぜ「内部用に新しいアカウント」を作るのか

既存の公式アカウント（`https://lin.ee/7kD9WGN`）は**お客様向け**。そこに社内のやり取りを混ぜない。

| | 理由 |
|---|---|
| 事故 | 年末に808名へ一斉配信する計画がある。配信先を間違えたとき、社内メモがお客様に飛ぶ |
| 費用 | 無料枠は月200通。3人グループへの毎日の連絡だけで月90通前後。お客様配信が乗ると即超過し、ライトプラン月5,000円（税別）が必要になる |
| 不可逆 | Messaging APIの有効化には「**プロバイダーの紐づけは二度と解除できない**」操作が含まれる。お客様アカウントで初めてやるより、内部用で一度通しておくほうが安全 |

内部用は**費用ゼロで、年末配信の下ごしらえも兼ねる。**

---

## 1. 内部用のLINE公式アカウントを作る

1. パソコンで https://manager.line.biz/ を開く。
2. 右上の［**アカウント作成**］をクリックする。
3. 次のとおり入力する。

   | 項目 | 入れるもの |
   |---|---|
   | アカウント名 | `ワンヒッター 社内連絡` ← お客様向けと必ず区別がつく名前に |
   | 業種 | 該当するもの（後から変えられます） |

4. 作成する。**認証は申請しない**（未認証のままでよい。社内用なので）。

---

## 2. グループに入れるようにする

作ったばかりのアカウントは、グループに招待できない設定になっている。

1. 作ったアカウントの管理画面で、右上［**設定**］をクリック。
2. 左メニューの［**アカウント設定**］をクリック。
3. ［**グループ・複数人トークへの参加を許可する**］を **オン** にする。
4. 同じ画面で［**あいさつメッセージ**］を **オフ** にする。
   （オンのままだと、グループに入った瞬間に定型文が流れます）

---

## 3. Messaging API を有効にする

1. 同じ管理画面で ［**設定**］＞［**Messaging API**］を開く。
2. ［**Messaging APIを利用する**］をクリック。
3. **プロバイダーを新規作成**する。名前は次のとおり。

   > ### プロバイダー名: `ワンヒッター株式会社`

   ⚠️ **後から変更できません。** 代理店やツール会社のプロバイダーの下には作らないこと。
   （お客様向けアカウントも将来ここにぶら下げます）

4. ［同意する］→［OK］。
5. 開発者情報の登録画面が出たら、名前とメールアドレスを入れる。

---

## 4. トークンを発行する

1. https://developers.line.biz/console/ に、**同じアカウント**でログイン。
2. さきほどのプロバイダー → 作られた Messaging API チャネル を開く。
3. ［**Messaging API設定**］タブを開く。
4. 一番下の［**チャネルアクセストークン（長期）**］の［**発行**］をクリック。
5. 表示された長い文字列を控える。→ **渡し方は手順7**

---

## 5. 受け口（Webhook）を用意する

渡辺さんの発言をCMOが読めるようにするための受け口。
**スプレッドシートのApps Scriptで作る**ので、サーバーもドメインも要らない。

1. 売上/顧客管理シートを開く → ［**拡張機能**］→［**Apps Script**］。
2. リポジトリの `tools/line-webhook.gs` の中身を全部貼り付けて保存。
3. 右上［**デプロイ**］→［**新しいデプロイ**］。
4. 左の歯車［種類の選択］→［**ウェブアプリ**］。
5. 次のとおり設定する。

   | 項目 | 選ぶもの |
   |---|---|
   | 説明 | `LINE webhook` |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** ← ★ここが「全員」でないとLINEから届きません |

6. ［デプロイ］→ 承認画面が出るので許可する。
7. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）を控える。

### 表示名も出したい場合（任意）

Apps Script の ［**プロジェクトの設定**］→［**スクリプト プロパティ**］で
`LINE_TOKEN` という名前で、手順4のトークンを追加する。
入れなくてもログは動く。入れると発言者の名前が記録される。

---

## 6. LINE側にWebhookのURLを登録する

1. LINE Developers の［**Messaging API設定**］タブに戻る。
2. ［**Webhook URL**］の［**編集**］をクリック。
3. 手順5-7で控えたURLを貼って［**更新**］。
4. ［**Webhookの利用**］を **オン** にする。
5. ［**検証**］を押す。→ **成功** と出れば受け口は生きている。

> 失敗する場合、ほぼ手順5-5の「アクセスできるユーザー」が「全員」になっていない。
> そこを直して、**必ず［新しいデプロイ］をやり直す**（既存デプロイの編集だとURLが変わらず反映されないことがある）。

---

## 7. トークンをCMOに渡す

**チャットに貼らないでください。**

1. Googleドライブで新しいドキュメントを作る（名前は `line-token-2026-09` など）。
2. 共有設定は「**制限付き**」のまま。誰にも共有しない。
3. 手順4で控えたトークンを貼り付けて閉じる。
4. そのドキュメントの**URLだけ**をチャットに貼る。

CMOはDriveを読めるので、そのまま受け取れる。

---

## 8. グループを作る

1. 佐々木さんのスマホのLINEで、**新しいグループ**を作る。
   - 名前: `ワンヒッター 業務連絡`
2. **渡辺さん**を招待する。
3. 手順1で作った**社内連絡アカウント**を招待する。
   - 友だちに入っていない場合は、管理画面の［友だち追加ガイド］からQRを出して読み取る。
4. グループで何か一言書く（`テスト` でよい）。

---

## 9. 動いているか確認する

1. Apps Script に戻り、関数 **`kakunin`** を選んで実行。
2. 実行ログに **グループID**（`C` で始まる長い文字列）と直近の発言が出れば成功。
3. そのグループIDをCMOに伝える（チャットに貼って問題ありません。これは秘密情報ではない）。
4. 併せて `tools/line-webhook.gs` の `SETTEI.kyokaGroupId` にそのIDを貼り、保存 →
   ［デプロイ］→［**デプロイを管理**］→ 鉛筆マーク →［バージョン］を「新バージョン」にして更新。
   これで、そのグループ以外からのイベントを弾くようになる。

## できるようになること / できないこと

| | |
|---|---|
| ✅ CMO → グループ | その日のやること、架電リスト、確認事項を送れる。渡辺さんのLINEに通知が出る |
| ✅ グループ → CMO | 渡辺さんの返信がシートの `LINE_ログ` タブに溜まり、CMOが読める |
| ⚠️ 即時の往復 | **できません。** CMOは常駐していないので、返信を読むのは次に作業するとき。稼働中は1時間に1回 `LINE_ログ` を見る |
| ⚠️ 署名検証 | Apps Scriptはリクエストヘッダーを受け取れないため、LINEの署名検証ができない。URLが推測不能であることと、グループIDでの絞り込みで守っている。**お客様の個人情報をこの経路に流さないこと** |
| ❌ お客様への配信 | この内部用アカウントでは行わない。お客様向けは既存アカウントで別途 |

## 費用

| | |
|---|---|
| LINE公式アカウント（内部用） | **0円**（コミュニケーションプラン・月200通まで） |
| Messaging API | **0円**（API自体の利用料はなし） |
| Apps Script | **0円** |

3人グループへの連絡が月200通を超えることは、通常の運用ではまず起きない。
超えそうになったらCMOから知らせる（`python3 tools/line_client.py quota` で確認できる）。
