# SNS広告（Instagram・Facebook）の再検討案（20261016-04-web-inflow ①）

作成 2026-10-16 ／ web-inflow ／ **案まで。お金を使うのでオーナー承認が要る。出稿・設定はしていない。**
数字は Instagram Graph API の実測（2026-10-16 取得・直近30件の投稿）。広告の過去実績は無い（SNS広告は未実施）ので、**広告の成果の見込みは出せない。**

## 1. 反応の実測（Instagram・投稿ごとのリーチ）

- 通常の画像投稿：リーチ 4〜38（多くは 8〜28）、いいね 1〜4、コメント0、保存0、シェア0
- **リール（動画）だけ突出：** 9/16 エアコン吹き出し口 **135**／9/24 エアコン洗浄後の汚れ **121**／9/18 レンジフード **67**（いずれも自然リーチ）
- フォロワー 362（10/11 時点）。Facebook は反応が取れていない（フォロワー3・コメントは権限不足で読めない）
- 申込への影響：SNS（?src=ig/fb）から予約ページへ届いたのは 9/20〜10/14 で 8 セッション・申込0（GA4）

→ **「反応の良いもの」は、実測では動画（リール）3本**。画像投稿は差が小さく、選べる根拠が弱い。

## 3. 効果の確かめ方と止める条件（案。measurement と合わせる）

見る数字（GA4 の traffic_src = ig_ad／fb_ad）：予約ページ到達 → form_start → booking_submit。広告管理画面では、表示・リーチ・クリック数・費用。

| 時点 | 条件 | 判断 |
|---|---|---|
| 開始後 7日 | 予約ページ到達が 0〜数件にとどまる／クリックの単価が検索広告より高い | 止めて、写真・文面を替えて1回だけやり直す |
| 開始後 14日（上限14,000円に到達） | booking_submit が 0 | **停止**。続けるなら新しい承認 |
| いつでも | 1日の費用が日予算を超える、または不審な動き | その場で停止 |

※ 上の数字（7日・14日・14,000円）は**案**で、過去実績から導いたものではない。オーナーの許容額に合わせて変えてよい。
