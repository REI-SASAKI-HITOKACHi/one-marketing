# 2. 私の計画を2か所直す必要があります

## 2.1 🔴 本舗の539万は高すぎました

`tools/plan2027.py` の `HONPO_URIAGE_NEN_EN = 5,390,000` は、
**2026年1〜8月の本舗 ¥3,691,083 を ×1.459（全社の季節性）した推計値**です。

**オーナー決定（2026-09-14）は「本舗は伸ばさない。自然流入のみ＝今年度と同じ数字」。**
**私はその「今年度」を推計値539万と読んでいました。実績が見えてきたので、読み直します。**

| | |
|---|--:|
| 2026年 本舗 1〜9月（実績） | **¥3,729,583** |
| 2026年 Q4 本舗（cmo の見立て：スケマ・楽ラクーンは戻らない） | 約¥16万 |
| **2026年 本舗 通年の見込み** | **約389万** |

**→ オーナー決定に忠実に従うなら、2027年の本舗は 539万ではなく 389万です。** ▲150万。
**ロイヤリティも58.5万減るので、利益への影響は▲80万ではなく、自社で埋めれば+59万です**（案B）。

## 2.2 🔴 ③「マッチングサイト」は、実体が本舗でした

計画の ③ は「マッチングサイト（楽ラクーン・スケジュールマッチング）」で**年390万を3案とも据え置き**。
**cmo の割り直しで、楽ラクーン67件は全部本舗側と分かりました。** スケマも本舗の番号から架ける経路です。

**つまり ③ は「当社が使っているマッチングサイト」ではなく「本部から回ってくる仕事」でした。**
名前が実体と合っていません。

| | 2026年1〜9月 | 通年の見込み | 計画（2027） |
|---|--:|--:|--:|
| 楽ラクーン | ¥1,845,833（9月0件） | — | |
| スケジュールマッチング | ¥845,350（9月0件） | — | |
| **合計** | **¥2,691,183** | **約269万**（Q4はほぼゼロ） | **390万** |

> **③の390万は「据え置き」ではなく「+45%」でした。**
> 私が ×1.459 で年換算したときにQ4の上積みを見込んでいて、**その上積みが来ていません。**
> **そして本部からの配分は、広告・GBP・LPでは動きません。** 据え置きの根拠がありません。
>
> **→ ③は390万ではなく269万で置き直すべきです。** ▲121万。
> ブロック名も「マッチングサイト」から **「本部からの配分」** に変えます。実体がそれです。

## 2.3 ブロックの切り方そのものについて

**①〜⑤は流入経路で切っていて、自社／本舗が混ざっています**（①のリピートには本舗リピート24件¥655,600が入る）。
**cmo の指摘のとおり、これは計画の読み違いを生みます。**

**2027年のスプレッドシートには `売上種類` 列があるので、両方で集計できます。**
**ダッシュボードに「自社／本舗」の行を足します。** これは私の持ち物なので、そのまま入れます。

# 3. 年末（10〜12月）の穴 ── **cmo の¥88万は妥当。ただし前提が1つ付きます**

## 3.1 本舗側の穴は ¥88万〜¥105万

| | |
|---|--:|
| 2025年Q4 本舗 | ¥1,048,542 |
| うち スケマ¥622,600 ＋ 楽ラクーン¥262,042 | **¥884,642**（cmo の¥88万） |
| 残り（本舗リピート等） | ¥163,900 ← **これも止まりうる** |

**本舗は9月が¥38,500で、楽ラクーンもスケマも9月は0件。** 残りの¥163,900も安全ではありません。
**→ 本舗側の穴は ¥88万が下限、¥105万が上限。cmo の数字は妥当です。**

## 3.2 会社全体で見ると、自社の伸び方しだいで ▲20万まで縮みます

| 自社Q4 | 自社の増減 | **全体の穴** |
|---|--:|--:|
| 去年割れ（−10%） | ▲26万 | **▲115万** |
| 去年並み | ±0 | **▲88万** |
| **+26%（1〜9月と同じペース）** | **+69万** | **▲20万** |

**「穴は¥88万」は、自社が去年並みで止まった場合の数字です。**
**自社が1〜9月と同じ+26%を保てば、▲20万まで縮みます。** そこが本当の分岐点です。

## 3.3 🔴 ただし、いま埋まっているのは **17%** です

# 4. 私からの提案

| # | 提案 | 誰が決めるか |
|---|---|---|
| 1 | **本舗の前提を 539万 → 389万 に直す** | オーナー決定「今年度と同じ数字」の**解釈を実績に合わせるだけ**なので、私が直します |
| 2 | **③を 390万 → 269万 に直し、名前を「本部からの配分」に変える** | 同上。**据え置きの根拠が無くなったため** |
| 3 | 1と2で総売上は2,600万から**▲271万**。**自社で埋めるか、目標を下げるか** | **オーナー判断**（正式目標の変更にあたる） |
| 4 | 2027年スプシのダッシュボードに**「自社／本舗」の行**を足す | 私の持ち物。入れます |
| 5 | **本部からの配分がなぜ減ったか**を嶺さんに確かめる | cmo → オーナー。**マーケの手では動かない唯一の項目** |

> ## 3について、私の意見
>
> **目標2,600万は動かさず、本舗の減りぶんを自社で埋める（案B：自社2,211万）を推します。**
> 理由は2つ。
> **自社に置き換えるほうが利益が出る**（同じ売上で経常利益 507万→566万。ロイヤリティ39%ぶん）。
> そして**自社は現に+26%で伸びていて、本舗は−27%で縮んでいる。** 伸びている側に寄せるのが素直です。
>
> **ただし自社2,211万は2026年（1,127万）の+96%です。** 楽な数字ではありません。
> **+96%の内訳をどこで作るかは、②（提携）と④（ネット新規）の話に戻ります。**
