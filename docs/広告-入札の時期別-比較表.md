# 広告の入札の時期別 比較表（2026-10-28 計測担当・随時更新）

CMO 依頼 20261028-01-measurement。入札を「クリック数の最大化」に戻した後に、良くなったかを1行で言えるようにしておく表。
オーナー承認済みで戻す予定（browser 20261027-03）。**戻した日が決まったら、下のコマンドの `2099-01-01` をその日に替えて流し直す。**

```
python3 tools/nyusatsu-hikaku.py --start 2026-10-01 --end <昨日> \
  --jiki "2026-10-01=クリック数の最大化" --jiki "2026-10-16=コンバージョン数の最大化" \
  --jiki "<戻した日の翌日>=戻した後" --tsuika 2026-10-03
```

- 費用・表示・クリックは 広告_日次。申込は 予約_Web の src=gads_*（キャンセルも数える）＋ 10/3 の LINE 経由1件（--tsuika）
- **時期の区切りは 10/16 から**（CMO の依頼は 10/15〜 だったが、切り替えは 10/15 20:06 で、10/15 の費用はほぼ切り替え前の入札で使われたため）。戻した後も同じく、**戻した日の翌日から**数える
- 行の無い日（スクリプトがまだ書いていない日）は「（行なし）」と出し、日数に数えない

## 戻した後に言う1行（型）
「戻した後 N日：表示 ○/日（CV最大化 41/日）、クリック ○/日（6.4/日）、申込 ○件＝7日あたり ○件（1.9件）、申込1件あたり ¥○（¥17,407）」
- **良くなった**と言うのは、7日あたりの申込が CV最大化の時期（1.9件）を上回り、かつ申込1件あたりが ¥16,200（planning の許容CPA）以下のとき
- 申込は1週間に数件なので、**戻して7日では偶然と区別できない**。14日（申込の合計が CV最大化の時期の件数を超えるか）で言う
