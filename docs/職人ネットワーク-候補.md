# 職人ネットワーク（案E）─ 最初に声をかける候補と、声のかけ方

作成 2026-09-10 ／ 担当 ネット流入施策担当 ／ 関連 `docs/media-構想.md` 案E
**すべて公開情報から。まだ誰にも連絡していません。**

## 0. 何のために要るか

「洗いどき」の窓口が集めた依頼のうち、自社の空き枠で受けられない分を渡す先。
**最初は5社あれば足ります**（構想書 案E）。装置が回り始める前に、受け皿だけ先に作っておきます。

## 1. 候補の選び方

| 優先 | 条件 | 理由 |
|---|---|---|
| ◎ | 商圏内に実住所があり、**ネット集客をしていない**（SNS 0件・サイトが数年止まっている） | ネットで客を取れない事業者が、渡される客を最も歓迎する |
| ○ | 商圏内で、サイトは更新しているがSNSは無い | 集客意欲はあるが手段が限られている |
| △ | フランチャイズ店 | 本部の規約で外部からの案件受けが制限されることが多い。後回し |
| × | 広域チェーン・マッチングPF専業 | 当社が客を渡す理由が無い |

## 3. 渡し方の型（契約の形）

**紹介型で始めます**（構想書 案E「法令」）。

```
お客様 ──契約・支払い──▶ 提携事業者
   ▲                          │
   │ 窓口が紹介               │ 紹介料（原則 施工額の12%。5〜15%）
「洗いどき」（運営：ワンヒッター） ◀────┘
```

- お客様には**確定前に事業者名と料金を伝える**（相談所の手配フォームと運営者情報に明記済み）
- 紹介料は既存の「事業者→顧客 5〜15%・原則12%」（`data/prices.json` の `紹介`）を**逆向きに使う**。新しい料率を作らない
- 当社が受注して再委託する型（当社が施工責任を負う）は、**装置が回って品質を見極めてから**
- 提携事業者との取り決めは、A4・1枚の覚書で足りる（紹介料・お客様情報の取扱い・トラブル時の窓口・写真の提供）。**ひな形は次の作業**

## 4. 最初の電話で聞くこと（オーナー用・5社×5分）

**ここだけは人が要ります**（構想書 6-3）。渡辺さんではなくオーナーから。同業者への提案は経営者同士のほうが早い。

```
1. 今、新規のお客様はどこから来ていますか（紹介／ポータル／チラシ／その他）
2. 月にあと何件くらい受けられますか（空きの規模）
3. 得意なメニューと、受けたくないメニュー
4. 当方の窓口から、お住まいの近くの案件を紹介した場合、施工額の12%を紹介料としてお支払いいただく形で、話を聞いていただけますか
5. 施工前後の写真を1案件5枚、提供いただくことは可能ですか（図鑑・SNSの素材。お客様の許可は当方で取る）
```

**4番で「聞く」と言われた5社が、最初のネットワークです。** 断られても理由（1番の答え）が次の判断材料になります。

## 5. 順番

1. 相談所の試作（案A）が動く状態になってから声をかける（「こういう窓口です」と見せられるほうが早い）
2. 覚書のひな形を用意する（当スレッド）
3. オーナーが◎1〜3に電話。反応を見て○4〜6へ
4. 5社そろったら、相談所の手配フォームの「地域」と事業者の対応エリアを対応づける（当スレッド）
