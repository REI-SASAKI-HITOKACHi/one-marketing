## 1. 取扱店の条件【要項 Ⅱ-1】

| 条件 | 当社 |
|---|---|
| **PayPay 取扱店であること** | **Square 経由で PayPay を受けている**（QRコード決済が有効）。**これで「PayPay取扱店」に当たるかが最大の確認点**（§3） |
| 江戸川区内に店舗（事業所）を有すること | **満たす**：本店 東京都江戸川区北葛西5-14-11 5F（LP の会社概要） |
| 風俗営業・暴力団・宗教政治団体・公序良俗違反に当たらない | 満たす |

- 申請フォームにも「PayPayの取扱店舗では無い場合には、申請頂くことができません」とある【フォーム】
- 業種：フォームの参加料カテゴリーに「07 生活関連サービス業（娯楽業・クリーニング・マッサージ・理美容業等）」がある【フォーム】。出張サービスを除く記載は無い
- **使えないもの**に「店頭ではなく EC サイト等のオンライン上で注文・決済を行うもの」【要項 Ⅱ-5(12)】。当社は**作業完了後にその場で精算**なので、決済は対面＝対象。**予約ページ・Square 請求書での前払いには使えない**（ギフト・前払いには使わない）
- 券種：A券（全店共通）・B券（大型店・チェーン店を除く）。**当社は個店なので A・B どちらも使える**【要項 Ⅱ-2】

## 3. 当社がいま PayPay を受けられるか

- 受けられる：**Square の QRコード決済（PayPay を含む）が有効**（オーナー 2026-09-17）。台帳の入金経路に「(OH)QR決済」の実績がある（例：10/18 の作業完了）
- **わからないこと（えどPay の可否を決める）**：公式の文書には「Square 経由は不可」も「Square 経由で可」も書かれていない。

| 書いてあること | 出典 |
|---|---|
| 参加条件は「PayPay取扱店であること」「区内に店舗（事業所）」の2つだけ。直接加盟が必要とは書いていない | 【要項】 |
| PayPay 商品券は「PayPay加盟店のうち、各PayPay商品券ごとに対象店舗として選定された店舗」で使える。対象店舗になるには、加盟店情報を自治体等（商店街組合を含む）へ提供することへの同意が要る | PayPay 加盟店ヘルプ b0714・b0833、https://paypay.ne.jp/store/introduction/jichitai-gift-vouchers/ |
| 商品券の取引履歴・返金について「決済代行事業者を介してPayPayを利用している加盟店は、契約している決済代行事業者にお問い合わせください」 | b0714（＝代行経由の店も商品券の対象に入りうる書き方） |
| 情報提供の同意フォームは「複数の決済サービスに対応した端末…を利用している加盟店は、本フォームからは申請できません。契約代理店にお問い合わせください」 | b0895 |
| Square 経由でも PayPay の加盟店IDが発行される | Square ヘルプ 8371 |
| Square の日本語ヘルプに「PayPay商品券」の記載は無い | ― |

→ **区商連が「PayPay株式会社に対象店舗の登録手続きを行う」ときに、Square 経由の加盟店IDで登録できるか**が分かれ目。§0 の順1・2 で確かめる。

## 5. 見込み

**件数は読めない。損益の分かれ目で判断する。**

| 項目 | 値 | 出どころ |
|---|---|---|
| えどPay2026 の発行額 | 4億8千万円（プレミアム20%込み）・8万セット | 【要項】 |
| 1次販売 | 区内在住者の抽選。当選者の購入は 11/2〜8。2次は 11/17〜 先着 | 【要項】 |
| 当社で使える券 | A券（全店共通）・B券（大型店・チェーン店を除く）の両方 | 【要項】 |
| 参加料 | ¥15,000（非加盟の個店） | 【要項】 |
| 1件の粗利 | 約¥14,000（ネット経由の平均。増額プレゼンと同じ置き方） | `docs/2026-ネット流入の検証と見込み-1021.md` |
| **参加料の回収** | **新しいお客様 約1.1件 → 2件で回収** | 計算 |
| 決済手数料の増え方 | 現金で払う予定だった人が えどPay に変えると、その分に Square の 3.25%（¥15,000 の作業なら 約¥490） | 計算 |

- 効き方は2つ：①**取扱店一覧に載る**（えどPay を持つ区民が使い先を探す。B券は個店だけなので、個店のハウスクリーニングは選ばれやすい可能性）②**江戸川区の既存のお客様が年末の掃除に えどPay を使える**（来るはずの人の支払い方法が変わるだけで、件数は増えないこともある）
- 12月の件数は ネット25件＋ネット以外33件＝約58件の見込み（`docs/2026-12月ネット25件を受けるために要るもの-1024.md`）。**このうち江戸川区のお客様の割合は手元に無い**（台帳の住所。cmo に区別の件数を出してもらえれば、上限の目安が出せる）。広告の申込（9/20〜10/29、住所の分かる6件）では江戸川区が2件（measurement）
- **何件増えるかは言えない。** 言えるのは「2件で元が取れ、損をしても ¥15,000」ということ
