# スプレッドシートを直接編集できるようにする手順

**所要時間 約10分。オーナーの作業です。**
完了すると、当方が 2026年の売上台帳を直接読み書きできるようになります。

## なぜこの作業が必要か

現在つながっている Google Drive コネクタは **検索・読み取り・アップロードのみ**で、
既存スプレッドシートのセルを編集する機能を持っていない（`update_file` はファイル名と保存先だけ）。
権限の問題ではない（2025年シートの権限を確認：`case.foot.kid@gmail.com` が owner）。
Claude公式コネクタに「Google Sheets」は存在せず、レジストリを検索しても該当なし。

一方で **Sheets API 自体にはこの実行環境から到達できる**（`sheets.googleapis.com` に接続可・認証がないため403）。
つまり足りないのは認証情報だけ。サービスアカウントを1つ作れば解決する。

## この方式の安全性

- サービスアカウントは **明示的に共有したスプレッドシートしか触れない**。Driveの他のファイルは見えない
- 止めたいときは **シートの共有からそのアドレスを外すだけ**で即座に遮断される
- 完全に無効化したいときは Google Cloud で鍵を削除する
- 鍵は環境変数に入れるので、**チャットの記録に残らない**

## Part 1 ── サービスアカウントを作る（約7分）

1. https://console.cloud.google.com/ を開く（`case.foot.kid@gmail.com` でログイン）
2. 画面上部のプロジェクト選択 → **新しいプロジェクト** → 名前 `one-hitter-sheets` → **作成**
3. 左上メニュー → **APIとサービス → ライブラリ** → 「Google Sheets API」を検索 → **有効にする**
4. **APIとサービス → 認証情報** → **認証情報を作成 → サービス アカウント**
   - サービス アカウント名：`claude-sheets`
   - **作成して続行** → ロールの選択は **スキップでOK**
     （ここのロールはGoogle Cloud内の権限で、スプレッドシートへの権限とは無関係）
   - **完了**
5. 一覧に出た `claude-sheets` をクリック → **キー** タブ → **鍵を追加 → 新しい鍵を作成** → **JSON** → **作成**
   - JSONファイルがPCにダウンロードされる
   - この画面に出ている **メールアドレス**（`claude-sheets@one-hitter-sheets.iam.gserviceaccount.com` のような形）をコピーしておく

## Part 2 ── 2026年シートを共有する（約1分）

6. **2026_売上/顧客情報管理** を開く → 右上の **共有**
7. Part 1 でコピーしたメールアドレスを貼り付け → 権限を **編集者** に → 「通知」のチェックを外して **送信**

> ⚠️ このシートの所有者は `wk09015963@gmail.com` です（他3本は `case.foot.kid@gmail.com`）。
> case アカウントに共有権限がない場合は、所有者の方に操作を依頼してください。
> あわせて、今年の売上台帳がオーナー名義でない点は、事業継続の観点で所有権の移管を検討したほうがよいです。

## Part 3 ── 鍵を環境変数に登録する（約3分）

8. ダウンロードしたJSONを1行のbase64に変換する。**Windows PowerShell** で以下を実行：

   ```powershell
   [Convert]::ToBase64String([IO.File]::ReadAllBytes("$HOME\Downloads\ここにファイル名.json")) | Set-Clipboard
   ```

   実行するとクリップボードにコピーされる（画面には何も出ない）。
   Macの場合は `base64 -i ~/Downloads/ファイル名.json | pbcopy`

9. Claude Code の **環境設定** を開き、環境変数を追加する
   （環境・環境変数の設定場所は https://code.claude.com/docs/en/claude-code-on-the-web を参照）
   - 名前：`GOOGLE_SHEETS_SA_KEY`
   - 値：8でコピーしたbase64文字列を貼り付け
10. 保存 → **新しいセッションを開始する**（実行中のセッションには反映されないため）

## Part 4 ── 確認

11. 新しいセッションで「シート接続を確認して」と伝えてください。当方が以下を実行して確認します。

    ```bash
    python3 tools/sheets_client.py whoami
    python3 tools/sheets_client.py tabs 1TK70pwQ8lYmjxUVCfFp1E2T5qDjHOnD4XSviZzUpB64
    ```

    サービスアカウント名とタブ一覧が表示されれば成功です。

## 終わったあとに

- ダウンロードしたJSONファイルは、PC上から削除するか安全な場所に保管してください。**他人に渡さないこと**
- 鍵はリポジトリにコミットしません（`.gitignore` で `*.json` の鍵ファイルを除外済み）

## 当方の運用ルール（変更しません）

- **過去の記録は書き換えない。** 直すのは集計式・欠落した集計対象・壊れた参照のみ
- **変更前に必ず内容を伝え、承諾を得てから実行する**
- **変更前にバックアップコピーを作る**
- 対象は **2026年のシートのみ**。過去3年分は読み取りのままにする
