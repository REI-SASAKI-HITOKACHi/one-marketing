## 1. 一行で

> **掃除の情報は「やり方」が飽和し、「結果」が空白。その空白を、現場と読者のカルテで埋める。**

「よごれカルテ」＝ 1件の汚れについて、**環境・症状・やったこと・結果・プロの所見**を1枚に記録した症例。
読者は自分に近いカルテを読み、自分のカルテを作る。現場（当社と提携職人）は施工1件ごとにカルテを1枚残す。
カルテが溜まると、**日本のどこにも無い「やってみた結果の統計」**になる。

## 2. なぜ「結果」が空白なのか（数字）

| 事実 | 数字 | 出典 |
|---|---|---|
| 「やり方」の需要は大きい | 「エアコン 掃除 自分で」推定 48,400件/月。Googleトレンド5年平均で「エアコン掃除」24 ＞「エアコンクリーニング」18 | 市場調査 1-1・1-2 |
| 「やり方」の供給は飽和 | おそうじ本舗 176本・ベアーズ 618本・くらしのマーケットマガジン・花王/Panasonic/アース。YouTube上位は「100均」「ハイター75円」で数百万回 | 同 1-4・2-1・2-4 |
| 「結果」を聞く人が、答えのない場所にいる | 知恵袋「エアコン 掃除 自分で」約8,293件：「カビだらけで自分では無理？」「22年物で断られた」「頼むべき？」（約2,353件） | 同 2-2 |
| 転換点は「やって、ダメだった」 | サジェスト「掃除したのに臭い」「落ちない」「取れない」「どこまで」「業者」「値段」 | 同 1-3 |
| 「結果」を持っているのは業者だけ | 年319件の施工で、お客様が何を試した後かを現場が見ている | 当社 |

**「やり方」は誰でも書ける。「結果」は現場にいる者にしか書けない。** ここが唯一、大手にもメーカーにもYouTuberにも無い場所。

## 4. 装置の形（3つの輪）

```
 読者の輪                      現場の輪                       データの輪
 ─────────                    ─────────                     ─────────
 近いカルテを読む ──▶ 自分のカルテを作る    施工1件＝カルテ1枚        カルテが溜まる
 （写真1枚＋5問）        │                 （写真5枚＋現場の1問）        │
        ▼               │                        │                    ▼
   判定を受け取る ◀──────┘                        │            方法別の結果統計
   ├ 自分で足りる → 道具・LINE                      │            「塩素系クリーナー
   ├ 続けてよい  → 次の洗いどきにLINE               │             n件中 再発m件」
   └ ここから先はプロ → 手配 ─▶ 自社の枠 ／ 提携職人 ◀┘                    │
                                                              AI検索・報道の引用
                                                                     │
                                                              読者が増える ──▶ 最初へ
```

- **窓口は変えない。** 手配フォーム・提携先網・覚書・LINEの戻しはv1のまま
- **職人の見返りが、E（職人ネットワーク）の勧誘の武器になる。** 柱1の調査で、江戸川区の地場4社はウェブに何も無かった。「あなたの現場がそのまま公開ページになり、近所の依頼が回る」は、彼らにとって初めてのウェブ資産
- **全国から来た依頼を渡す先が、全国の職人になる。** カルテを出す職人が増えるほど、渡せる地域が広がる

## 5. ページの型（4種）と、作らないもの

| 型 | 例 | 供給源 |
|---|---|---|
| **カルテ**（1件1ページ） | 江戸川区・築12年・ペット2匹｜エアコン送風ファン｜市販スプレー2回 → 2週間で臭い再発 → 分解洗浄｜汚水1台分｜所見：スプレーはフィンの表面まで。ファンには届かない | 現場・投稿 |
| **方法別の結果** | 洗濯槽×塩素系クリーナー：n件（黒いカス継続 k・再発 m・解決 j） | カルテの集計。**唯一の一次統計** |
| **境界線** | エアコン：自分で届く（フィルター・ルーバー）／届かない（熱交換器・送風ファン・ドレン） | 当社。「自分で どこまで」に正面から答える |
| **切り口** | 赤ちゃんが生まれた家のエアコン（東京都の指針の原文＋当社のカルテn件）／ペットのいる家（同） | 公的資料＋カルテ。各10〜20本。地域業者が記事1本で上位に入れている領域 |

**作らない：** 「カビの原因とは」「掃除の頻度は」の一般ハウツー（大手・メーカーの土俵。CaSyは2025年2月で更新停止）。

## 11. 守る線（市場調査 3-4）

- 健康：東京都「健康・快適居住環境の指針 No.9」と日本アレルギー学会の**原文引用のみ**。「当社が洗えば喘息が防げる」「赤ちゃんを守る」は書かない。子どもの画像を使ったPRは措置命令の前例
- 効果：「除去」「必ず」「新品同様」は自社の言葉では使わない。生成器が検査して止める
- 組写真：同一箇所の確認済みペアだけ
- 運営者：全ページに「運営：ワンヒッター株式会社（ハウスクリーニング業）／提携職人から紹介料を受け取ることがある」を明瞭に
- 投稿：自由記述は1欄。顔・表札・私物・郵便物が写れば非掲載。掲載前に人が1回見る
- ペットフード協会のデータは利用先が限定されており、引用前に要確認
