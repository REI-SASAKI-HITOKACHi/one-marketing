## 0. 先に：**タカラサービスさま固有の「リピート率」は出せません**

依頼の1番に「件数・累計・**リピート率**」とありましたが、**件数と累計は出せて、リピート率は出せません。**

- **件数・累計**：『【毎月更新】リピート/業務提携』の9行目（タカラサービス）に**取引17件が1件ずつ**入っています。合計も一致しました
- **リピート率**：あの表に入っているのは**「タカラサービスさまから当社への発注」**で、**その先のお客様が再来したかどうかは記録がありません。**台帳にも「紹介元」の列がないので、**どのお客様がタカラサービスさま経由かを機械で特定できません**

**「業務提携経由のお客様は、平均2.52回・リピート率45%」という数字は、提携18社ぶんの合計**です（『分析_流入経路とLTV』）。
**これをタカラサービスさまの数字として書くと、事実と違います。**下のレポートでは「当社の提携先経由のお客様全体」と分かる書き方にしました。

**タカラサービスさま固有のリピート率が要るなら、台帳に「紹介元」の列を足すところからです。**やるなら crm への依頼になります。

## 3. 紹介カード（下書き）

**タカラサービスさまが、エアコン設置のお客様に渡すカード**を想定しています。名刺サイズか A6。

```
   エアコンを設置したお部屋の、
   前からあるエアコンは、いつ洗いましたか。


   ワンヒッター株式会社
   江戸川区北葛西・ハウスクリーニング

   エアコン（お掃除機能なし）   10,780円（税込）
   エアコン（お掃除機能つき）   17,380円（税込）
   レンジフード              18,480円（税込）
   浴室                     18,480円（税込）

   出張費はかかりません。
   駐車スペースが無い場合は、コインパーキング代が実費になります。


   お電話                080-8043-8259
   ご予約                yoyaku.onehitter.jp

   ［QR］


   タカラサービスさまのご紹介
```

**料金は `docs/price-master.md` の税込価格をそのまま使いました**（10,780／17,380／18,480）。
**「お掃除機能つき」を別に書いた**のは、書かないと「10,780円で全部できる」と読まれるためです（9/15 に同じ書き方で直した経緯あり）。

### QRの行き先と、紹介元の見分け方

```
https://yoyaku.onehitter.jp/?src=teikei_takara
```

- `?src=` の規約（`docs/流入の見分け方-src規約.md`）に沿った新しい値です。**英数と `_` だけ・13文字**で、LPの制限（20文字）に収まります
- **予約フォームの受信データに `teikei_takara` が残る**ので、**このカード経由の申し込みを1件ずつ数えられます**
- 他の提携先に広げるときは `teikei_<社名>` で揃えます
- **登録簿への追加は、この案が通ってからにします**（値を増やすときは受け側を先に確かめる、を決めごとにしたため）

**電話の場合は `?src=` では拾えません。**「タカラサービスさまのご紹介」とカードに刷ってあるので、**電話を受けた人が聞き取って台帳に入れる**しかありません。ここは人の運用です。

## 4. 決めてほしいこと

1. **レポートの宛名**。「◯◯ さま」の担当者名が分かりません。台帳には会社名しかありません
2. **紹介カードの枚数と、刷るか PDF か**（A6カードと同じ作りなら `tools/build-a6-card.py` に寄せられます）
3. **`?src=teikei_takara` を使ってよいか**（使うなら規約に足して、計測担当に通します）
4. **タカラサービスさま固有のリピート率が要るか**。要るなら台帳に「紹介元」の列を足すところから（crm への依頼）

**形にする前に、文面だけ先に見てください。**通ったら、A4 1枚の PDF とカードを作ります。
