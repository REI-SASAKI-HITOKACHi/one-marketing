# 承認シート｜無料点検の文面一式（承認は1回。以後は自動送信）

作成 2026-09-11 ／ 担当 web-inflow ／ 状態：**未承認**
対象：`docs/無料点検-全体構造.md` 6章の部品7「文面」。ページ本体は `lp/media/tenken/`（`tools/build-tenken.py`）。
送る仕組み：`tools/tenken-inbox.py` が申込ごとに下書き（`dist/tenken/outbox/`）を作り、承認後は当スレッドの定期実行がメール／SMS／LINEで送る。

**承認の仕方：** 「OK」で全部。直すところは番号で。着手前に、行政書士か弁護士へ ③④ の2点（申込画面と契約書面）を1回見せることを推奨（費用＝お金の判断）。確認までは「ついで点検」だけ運用。

## 守っていること
- 勧誘目的は申込ページ・受付メール・現場の冒頭の3か所で明示（特商法 3条の考え方）
- 書面は電磁的交付の承諾を取ってから送る（承諾が無い場合は紙を郵送＝⑨の封書）
- 追跡は2通まで。「不要」の方には売り込みを送らない（次回案内のみ）
- 「危険」「壊れる」「このままだと」は全文面で不使用
- 電話番号は 080-8043-8259 のみ

## ⑨ 紙の書面（電磁的交付を承諾しなかった方）
`dist/tenken/shomen/{申込番号}.pdf` を印刷して封書で翌日発送（切手代＝お金。件数は少ない見込み）。
