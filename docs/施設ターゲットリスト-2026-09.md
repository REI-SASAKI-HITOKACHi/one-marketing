## 9/18 2段構えに決定。「置いてくれた先」を数えられるようにした

**CMO決定（2026-09-17）**：291件に対して、**①読本の設置のお願いだけを先に出す → ②置いてくれた先にだけ、後から清掃の打診**。
1通で両方狙わない。反応が無かった先に清掃を重ねることもしない。
**＝いま送っている文面はそのままで正しい。変えない。**

要件は1つ：**「読本を置いてくれた先」が後から数えられること。**そこが②の分母になる。

### 見つかった穴：承諾フォームの結果を、誰も進捗タブに書いていなかった

承諾フォーム（`dokuhon.onehitter.jp/setti/` ＝ Netlify の `dokuhon-setti`）は、**施設IDの発行まで自分でやって送信してくる**
よくできた作りだったが、**その結果を進捗タブに下ろす仕組みが無かった。**置いてくれた先が来ても、誰も気づかない状態だった。

→ **`tools/setti-inbox.py`** を作った。

```
python3 tools/setti-inbox.py --dry-run   # 届いているものを見るだけ
python3 tools/setti-inbox.py             # 進捗タブに下ろす
```

ステージ→設置OK、設置日・設置場所・施設ID・カード・先方担当者・反応を書く。
**施設名が一致しないものは、勝手に当てはめない**（カードが人づてに回って、リストに無い施設から届くことがあり得るため）。
表記ゆれ（全角スペース・括弧・「株式会社」の有無）は吸収する。似ている度 0.82 以上で同じ施設とみなす。

**偽の届きぶん3件で確認した**：表記そのまま→一致／`Dog Salon　ルポプリッカ（西葛西）`→一致／リストに無い施設→「要手動照合」。
