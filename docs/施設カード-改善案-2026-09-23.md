## 2. 頼み方の問題（ここがいちばん効くと考えています）

いまの文面（`docs/節目チャネル-文面-承認シート.md` ①）が相手に求めている行動を数えると、**5つ**あります。

1. 10分の読み物を読む
2. 置くかどうか決める
3. 承諾フォームに入力する（1分）
4. 送られてきたPDFを**自分で印刷する**
5. 待合に置く

受付の方から見ると、**報酬の前に、全部こちらの持ち出しの作業**です。しかも1つめの「10分読む」が最初に来ます。

さらに、**12%の紹介料は、医療機関や小さな店にとっては「うれしい話」ではなく「経理が増える話」**です。文面にも「雑収入として計上いただけます」と書いています。これは断る理由を先に渡しています。

### 直す方向（3つ）

**① 頼みごとを1つにする。**「読んでください」も「印刷してください」も外して、**「カードを郵送してもよろしいですか。はい／いいえ」だけ**にします。

**② こちらで印刷して、郵送する。**PDFを送って先方に刷らせるのをやめます。置くだけにします。
→ **印刷代と送料が出ます。オーナー判断が要ります。**A6・両面・普通紙で10枚1施設なら、100施設で数千円の見当です（正確な額は印刷所の見積りを取ってから出します）。

**③ 紹介料を初回の文面から外す。**置いていただけると決まってから案内します。初回は「読み物を置かせてください」だけにします。

### 書き換え案（フォーム本文欄・短い版）

いまの版は10行あります。**4行にします。**

```
江戸川区のハウスクリーニング店です。赤ちゃんを迎えるご家庭向けに、
東京都の指針をもとにした読み物（無料・広告なし）を作りました。
そのご案内カード（A6・10枚）を、こちらの負担で郵送させてください。
置く置かないは、届いてから決めていただいて構いません。
不要でしたらご放念ください。ワンヒッター株式会社 佐々木 嶺 080-8043-8259
```

**違い**：読ませない／印刷させない／フォームを踏ませない／報酬を出さない／断りやすい。
返事は**このメールに「送って」の一言**でも、フォームでも受けられるようにします。

### 件名の案

いまは「赤ちゃんを迎えるご家庭向けの読み物を、待合に置いていただけませんか（江戸川区のハウスクリーニング店）」。

## 3. クリエイティブ（A6カード）

### 見つかった不具合を先に

**`dist/a6/` に残っているカードは古い版です。**9/12〜9/13 に作ったもので、いまの生成器が作るものと中身が違います。

| | `dist/a6/`（古い） | いまの生成器 |
|---|---|---|
| URL | `one-hitter-dokuhon.netlify.app/akachan/` | **`dokuhon.onehitter.jp/akachan/`** |
| 読む時間 | 3分 | **10分**（メール文面と一致） |
| 目次 | 漢数字 一〜四（4項目） | **算用数字 1〜8** |
| 「頼むかどうかは読み終わってから」 | **残っている** | 無い（オーナー指摘 9/13 で削除済み） |

**設置OKが0件なので、この古い版は外に出ていません。**ただ、置いたままだと事故のもとなので、**作り直した版（`dist/dokuhon/`）に差し替え、`dist/a6/` は消すか名前を変えてください。**（消すのはオーナー判断なので、指示をください）

### 中身の改善案

1. **表の下半分が空いています。**A6の表は題名とQRだけで、真ん中が白いままです。**「ご自由にお持ちください」の1行**を入れると、置き物ではなく配り物になります
2. **立てられない。**A6を平置きすると気づかれません。**卓上に立つ形（A6の三角POP、またはA5を折る）を1種類足す**のを提案します。生成器の紙サイズを足すだけで作れます
3. **1枚で完結させない。**いまは「QRで読む」しか出口がありません。**裏に「紙で読みたい方は電話ください」**を足すと、スマホを出さない層が拾えます
4. **施設ごとのIDは、生成器がすでに持っています。**`python3 tools/build-a6-card.py --src F7K2QX --variant akachan` のように渡すと、QRが `?src=F7K2QX` になり、カードの裏にも施設IDが刷られます。**ただし既定は `--src card` で全施設共通です。**`dist/a6/` に残っている版も全部 `card` でした。
   → **週次の閲覧数を施設ごとに出す約束（文面①）は、いまの作り方では守れません。**施設ごとにIDを振って1枚ずつ作る手順を、承諾が出る前に用意しておきます

## 4. 導線

- **いまの出口は「QR → 読本 → 末尾のクリーニング案内」の1本**です。読本を最後まで読んだ人しか当社にたどり着きません
- **カードから直接「無料点検」に行ける道を1本足す**ことを提案します。点検は `tenken.onehitter.jp` が公開済みで、申込は0件です。読み物より敷居が低い出口です
- 施設側の出口も1本足します。**「置いた施設向けのページ」**（週次の数字・カードの追加請求・撤去の連絡が1ページで済む）。いまは全部メールで、先方から見ると窓口が見えません

**優先順**：① 自動受付が返っている先（届いたのに反応が無い＝頼み方の検証になる） ② メール送信済みで反応なし ③ 未接触。
**1日あたりの本数と時間帯**：9:00〜17:00、昼（12:00〜13:30）は外す。医療機関は診療時間を避ける。

### 台本（60秒。売り込みではありません）

```
お世話になります。江戸川区でハウスクリーニングをしております、
ワンヒッターの〇〇と申します。1分だけよろしいでしょうか。

先日、{施設名}さまのお問い合わせフォーム（／お送りしたメール）で、
赤ちゃんを迎えるご家庭向けの無料の小冊子のご案内をお送りしました。
届いていますでしょうか。

（届いていない → 分かりました。宛先を教えていただければ送り直します）
（届いている  → ありがとうございます。中身はご覧になれましたか）

内容は、東京都が出している乳幼児のいる家庭向けの指針をもとに、
家の中の手入れをまとめたものです。広告は入れていません。

お願いは1つだけで、待合に置くA6のカードを10枚、
こちらの負担でお送りしたいのですが、送ってもよろしいでしょうか。

（はい → ありがとうございます。宛先とご担当者さまのお名前だけ伺えますか）
（いいえ → 承知しました。お時間をいただきありがとうございました）
```

**言わないこと**：クリーニングの料金／紹介料の12％／「お得」「キャンペーン」。**初回の電話で売らない**のが前提です。

### かけたあとに控えること（3つだけ）

1. **つながったか**（つながらない／担当者不在／話せた）
2. **届いていたか**（届いていた／届いていない／分からない）
3. **カードを送ってよいか**（はい／いいえ／検討）

この3つがあれば、「届いていないのか／届いて興味が無いのか」が分かれます。**記録は既存のGoogleフォーム**（`docs/施設カード-送信記録の仕組み.md`）から入れられます。人が手で入れる想定で作ってあります。

## 6. 順番（私の推す順）

1. **電話（10〜20本）を先にやる。**いちばん安く、いちばん早く「なぜ0件か」が分かります。文面を直すのはそのあとでも遅くありません
2. **同時に、カードの古い版を片づける**（`dist/a6/` の差し替え）。これは今日できます
3. 文面を4行版に書き換え、**印刷・郵送に変えるかをオーナーに判断してもらう**（お金が出ます）
4. 卓上に立つ形と、点検への直行の道を足す
5. 施設ごとのIDを確認・実装して、週次の数字の約束を守れる状態にする
