# ① LINEタップ：**キーイベントには登録されていません。ただし、広告のCVは落ちていません**

## 大事なところ：**Google広告のCVは、GA4のキーイベントを経由しません**

```
LINEボタンが押される
  ├→ gtag('event','line_click',…)             → GA4（キーイベントの登録は「広告に渡せるか」の話）
  └→ gtag('event','conversion',{send_to:…})   → 広告（キーイベントとは無関係）
```

**本番で撃たれていることは実測済みです**（9/21 の週次、LP4本すべて）。

```
AW-18450975194/AryNCK7n7PkcENqTjt5E
```

**キーイベントの登録は、GA4のレポートで「成果」として扱うための設定**です。
**登録しなくても、広告の数字も GA4 のイベント件数も落ちません。**

# ② `?src=ig` `?src=fb` の日別 → **未取得**（鍵なし）。**出すコマンドを作りました**

**これまでの `--daily` は日ごとの合計しか出せず、「どの日に、どの流入元から何件来たか」が出せませんでした。**
**`--by` と組み合わせられるように直しました**（`da169d0`）。

