## 4. こちらで判断したこと（変えたければ言ってください）

| 判断 | 理由 |
|---|---|
| **氏名・電話・メールは先方に渡さない**（`_rt.cname`/`ctel`/`cemail` は空） | 任意項目で、成果の特定は注文番号だけでできる。渡せばお客様の個人情報を社外のASPへ出すことになる。返信メールで**先に宣言**しています |
| **提携設定は「自動提携」のまま** | 手動提携にすると媒体様を1件ずつ審査する人が要る。**その人がいません。** レントラックスはクローズド型で審査済みなので、代わりに**紹介文の注意事項を細かく書く**ほうを選びました |
| **タグは `/mizumawari/` だけに出す** | 登録済みの掲載先が1本だけのため |
| **紹介文にGoogleクチコミの件数を書かなかった** | 社内資料で **23件** と **24件** に割れています（`docs/アフィリエイト-レントラックス.md` と `docs/レントラックス-提出物の下書き.md`）。**根拠と合わない数字は先方の却下条件（誇大表現）に触れます。** どちらが正しいか分かれば足します |
