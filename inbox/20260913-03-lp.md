## ⚠️ 訂正：`?v=1` のURLは **noindex** です

クエリを付けたURLには、CMSが自動でこれを入れます。

```html
<meta name="robots" content="noindex,follow">
<link rel="canonical" href="https://one-hitter.jp/privacy_policy/">
```

トップページでも同じでした（`/?v=1` にも noindex が付く）。
パラメータ違いのURLが重複して登録されないようにするための、CMSとしては真っ当な作りです。

**そのため、先ほどの私の案内は誤りでした。**

| 用途 | クエリ付きURL |

| **人が中身を目で確かめる** | **OK。これは問題ありません** |
| Search Console に登録申請する | **ダメ**（noindex を申請することになる） |
