# 入れたもの

`tools/derive-soushin-keitou.py` の `meigi_hyou()` が使う `saishin()` を関数に出しました。

```python
def saishin(L):
    saidai = max(c[0] for c in L)                                  # いちばん新しい施工日
    sonohi = {MEIGI[c[3]] for c in L if c[0] == saidai}            # その日の名義を全部集める
    return ("本舗" if "本舗" in sonohi else sonohi.pop()), str(saidai)
```

- **同じ日に自社と本舗の両方 → 本舗**
- **「本舗 → 後日 自社」で自社を採る原則は変えていません。** 変わるのは**同じ日**のときだけです
- 和真さんの原文と、その理由（**その日の自社行は追加分の起票で、現場は本舗案件**）を
  関数のコメントに残しました

**`meigi_hyou()` を使っている全ツールに、そのまま効きます**
（`meigi_check.py` → `sms-honpo-3tsu.py`／`sms-jisha-batch.py`／`meigi-fuitchi-hold.py`／`line_client.py`）。
