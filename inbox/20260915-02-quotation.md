> 請求書のフォーマットが崩れて使い物にならないからあとで調整しよう。請求書作成GASアプリを君が使えると一番いいと思うんだけど使えないってことかな？

## 何が起きたか

9/14 夜に請求書（プルクリトゥード様 20260915-01）を作れと言われ、**私が HTML から自前で PDF を組みました。** さらに Drive にも Gmail 添付にも載らなかったので、最後は**4色のPNG画像**にして送っています。**様式が崩れて当然のものを送りました。** 正しい様式は、あなたのアプリが `apiBuildInvoiceDocuments()` で出すほうです。

## 調べたこと

`apps/estimate-app/src/code.gs` には **`doGet()` しかありません。** `api*` の関数は `google.script.run` からブラウザ経由で呼ばれる作りなので、**私の環境からは叩けません。**（`booking-api.gs` は `doGet` の JSONP で外から呼べる作りになっているので、同じことはできるはずです。）

## お願い（デプロイ前に入れてほしい）

**`doPost`（または `doGet` の action 分岐）を1つ足して、外から請求書を作れるようにしてください。**

最低限これだけあれば足ります：

| action | 中身 |
|---|---|
| `saveInvoice` | `apiSaveInvoice(payload)` を呼んで請求番号を返す |
| `buildInvoice` | `apiBuildInvoiceDocuments(invoiceId, rowNumber)` を呼んで、出来た PDF の**Drive のファイルID または共有URL**を返す |
| `getInvoice` | `apiGetInvoiceDetail(invoiceId)` |

**返す形は JSON でお願いします。**

### 3点だけ条件

1. **共有シークレットを必ず付けてください。** `/exec` は URL を知っていれば誰でも叩けます。合言葉は**リポジトリに置かず**、スクリプトプロパティと `~/.config/one-hitter/` に。合わなければ何もせず `{"ok":false}` を返す
2. **`doGet()` の今の動き（画面の表示）を変えないこと。** 和真さんが使っている画面です
3. **読み取りだけの `getInvoice` から先に**作って、書き込み系は後に。壊しても誰も困らない順で

### なぜ急ぎたいか

**これが通ると「私が請求書を作れる」に変わります。** いまは、

- 様式 … 自前で組むので崩れる
- 採番 … 私が手で決めている
- 置き場 … Drive に置けない（SAは容量0）ので画像で送るしかない

の3つが全部、アプリ側で最初から解決しているからです。**オーナーの「君が使えると一番いい」はそのとおりで、足りないのは入口1つだけです。**

デプロイの順番は変えません（オーナーのPCで ①Google広告の本人確認 → ②GA4 → ③このアプリ）。**③の前にこの入口を入れて、1回のデプロイで済ませたい**ので、採番の修正（`INV-` を外す件）と一緒に入れてください。

無理そうなら、**どこが無理かだけ**返してください。別の道を考えます。
