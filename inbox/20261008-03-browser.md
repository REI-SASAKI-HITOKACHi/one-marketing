【オーナー承認済み（10/8）】公式サイトのブログ一覧の崩れを直すCSSを、CMSに貼ってください（3分ほど）

原因と見え方：ブランチ claude/lp-outline-presentation-8fahl3 の cms/blog-list-fix/（README.md・before-after.jpg）
オーナー原文（10/8 lpのチャット）：「ブログ一覧のCSS反映していいよ」「ブラウザ担当へ依頼した方がはやいでしょ？そうして」

■ 手順
1. https://one-hitter.jp/_sys/ にログイン（認証情報ドキュメント第5節）
2. 「リソース」→「フォント」＝ https://one-hitter.jp/_sys/contents/resource/1018/ を開く
3. **貼る前に控え**：「共通CSS」欄（common_css_url）の中身を全部コピーして、手元に保存（約5万字。戻すとき用）
4. 同じ欄の**いちばん最後にある </style> の、すぐ前**に、下の「貼るCSS」を全部貼る。**今ある中身は消さない**（保存すると欄の中身が丸ごと置き換わるので、消すとサイト全体の見た目が崩れます）
5. 保存
6. 確認：https://one-hitter.jp/blog/ をPCで開いて、カードが「画像が上・文字が下」になり、題名が3行までで「MORE」と重ならないこと。スマホでも1列で崩れないこと。TOPページ（https://one-hitter.jp/）の見た目が変わっていないこと
7. 終わったら lp に返信（スクショ1枚あると助かります）

■ 戻し方
- 貼った部分（「/* --- 2026-10-08 ブログ一覧の崩れの修正」から「/* --- /ブログ一覧の崩れの修正 --- */」まで）を消して保存。または手順3の控えに丸ごと戻す

/* --- 2026-10-08 ブログ一覧の崩れの修正（依頼 20261008-03-lp）--------------------------
   原因：テーマ（data-lib 29505）はカードを「左に画像50%・右に本文」の横並びで作っている
   （article が display:flex の横向き、題名は position:absolute、a に padding 4rem）。
   上のブロックで一覧を3列のグリッドにしたが、カードの向きを縦に直していなかったため、
   幅 200px ほどの列に画像と本文が横並びになり、画像が細い帯に、題名がはみ出して MORE と重なった。
   ここでカードを縦（画像が上・文字が下）に組み直し、題名を3行で切る。
   対象は一覧の本体（.-w-blog_main）だけ。右の「NEW」の小さい一覧は触らない。
------------------------------------------------------------------------------------ */

  display: block; height: 100%; padding: 0 !important; background: none !important;
}

  display: flex !important; flex-direction: column !important;
}
