■ 3. 年末ギフト（11月販売／1〜2月施工）── **噛み合います**
════════════════════════════════════════

**私の月次は施工日付ベース**（`◯月_売上/顧客` が施工日付で集計される）なので、**券の売上は施工月に立ちます。**

| | |
|---|---|
| 11月 | **入金**（前受金）。**2026年の売上には立てない** |
| 2027年1〜2月 | **施工＝売上計上。** 2027年の計画に乗る |
| 広告費 | **2026年11月の費用**（売上は翌年、費用は今年） |

**施工期限「申込から5か月」は設計として正しいです。**
11月1日申込→3月末、11月30日申込→4月末。**加算月（5〜7月・12月）にかかりません。**
→ **限界利益は満額 ¥9,434 で残ります**（12月施工を許した場合の6,134円にならない）。

**2月の赤字▲35,545円が券4枚で消える、は変わらず有効。**
むしろ施工が1〜3月ではなく**1〜2月に寄るので、赤字月の2月に当たりやすくなります。前より良い設計です。**

### 決めておくことが3つあります

**(a) 2027年1〜2月の計画件数には「上乗せ」です。**
オーナー決定（9/13）でギフトは2,600万に織り込んでいません。**内数にすると赤字解消の効果が消えます。**

**(b) 🔴 `ギフト券_発行管理` タブの期日が決まりました ── 10月末。**
これまで「gift が決めた日に足す」としていましたが、**11月販売が決まったので期日を切ります。**
**11月に入金、1〜2月に売上。この間、台帳のどこにも載らない状態が2か月あります。** そこを埋める器です。
※ 流入経路「ギフト」が `選択肢マスター` に無いので同時に足します。**いま無いので、売れても測れません。**

**(c) 🔴 ギフトの広告と段0の広告を、同じ集計に混ぜないでください。**
**11月はギフトの出稿月であり、段0の判定月でもあります。**
同じアカウントで構いませんが、**キャンペーンを分けて費用とCVを別々に見られる形に。**
混ぜると**段0のCPA判定がギフトの出稿で汚れます。** 母の日の¥46,423が「2026年の広告費」として1本にまとまっていたのと同じ形になります。

### 1つだけ、気をつけたいこと（数字ではないので判断は預けます）

**11月は年末大掃除の予約ピークです。** 販売チャネルは競合しませんが、**問い合わせ対応の手は競合しえます。**
ギフトの問い合わせが年末の予約対応と同じ窓口に来る形なら、**11月のいちばん忙しい週に重なります。**
