## 結論：**オンラインで前払いを受け取る手段は、いまありません**

リポジトリと過去の記録を当たりましたが、**お客様からの入金経路として記録があるのは「現地精算」と「請求書＋銀行振込」だけ**です。カード決済・コード決済の契約の記録はありません。**「無い」と断定するのではなく「記録が見つからない」**とだけ言っておきます。オーナーに確認する項目に入れました。

いずれにせよ、**ギフトは贈る人が前払いする商品なので、請求書＋振込では成立しません**（贈る側に振込を待たせる時点で買われません）。**新規のオンライン決済契約が要ります。これはお金を使う判断なので、オーナーです。**

## それより、企画書の数字に効く話があります

**決済手数料を入れると、あなたが見つけた「差が322円しかない」が、マイナスになります。**

| | |
|---|---:|
| エアコン1台 | 10,780円 |
| 決済手数料（**3.6%で仮置き・要確認**） | **−388円** |
| 限界利益 9,822円 − 388円 | **9,434円** |
| CPA上限 | 9,500円 |
| 差 | **−66円** |

**手数料を入れた時点で、CPA上限どおりに使うと1件あたり66円の赤字です。**

つまり §8.5 を空けたまま「差が322円」で議論すると、**判断を誤ります。**

- **3.6% は仮置きです。** Stripe・Square の国内カード決済の標準的な水準ですが、私はいま実際の見積を取っていません。**「仮置き・未確認」と明記して使ってください**
- 5月（繁忙期加算で限界利益 6,522円）だと手数料込みで **6,134円**。CPA上限 9,500円とは比較になりません。**母の日5月テストの不利が、さらに開きます**

## 企画書の進め方

**決済契約が決まるまで待たないでください。** §5.4 は「**未契約。候補と手数料率は仮置き（要確認）**」と書いて、**手数料を入れた数字で §8 を書き直してください。**それで v1 は確定にできます。

**あなたの「初回1件で回収する売り方にしない」という結論は、手数料を入れると、もっと強く正しくなります。** 根拠が1つ増えたと思ってください。
