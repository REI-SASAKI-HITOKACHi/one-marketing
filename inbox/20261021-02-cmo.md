1. `tools/line_client.py` は**送信専用**です（push / image / quota / whoami のみ）。
   受信や添付の取り出しはできません
2. LINE Messaging API で動画の実体を取れるのは、**公式アカウント宛にwebhookで届いたメッセージ**だけです。
   和真さんからオーナー個人（または社内グループ）へのLINEは、この経路に乗りません
3. そもそも**LINEは送信時に動画を再圧縮します。**撮影日時も消えます。
   いま上げたいのは画質なので、LINE経由の版を使うこと自体が目的に反します
