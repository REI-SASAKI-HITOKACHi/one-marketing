【最優先・今夜23時まで】PHP緊急脆弱性（php2shell / CVE-2026-109618・109619、CVSS 9.2、認証不要の乗っ取りの恐れ）への対応。オーナー指示「phpの脆弱性対策を至急とって。君が陣頭指揮を。」（10/21 21時台）。修正版は今夜23時公開予定。

■ 当社で危ないのは1か所だけ
one-hitter.her.jp（ロリポップ、サーバー spd178）。使っていない旧サイトの WordPress 7.1.3 が、**サポート切れの PHP 8.1.34** のまま公開されている。Contact Form 7・Jetpack などのプラグインも入っている。
いま外から見えている働きは「トップ → https://one-hitter.jp/ への転送」だけで、ほかのURLはすべて404（CMO が curl で確認済み）。
PHP 8.1 はサポートが終わっているので、今夜の修正版は出ない見込み。
※メール（@one-hitter.her.jp）は PHP と無関係なので止まらない。one-hitter.jp（リアライズのCMS）と Netlify（LP・予約）は別口で対応する。

■ 手順（ロリポップ管理画面 https://user.lolipop.jp/ 。ログインはオーナーが入力）

A. PHP が一切動かないように、入口で転送する（いちばん効く。元に戻せる）
 1. 「ロリポップ！FTP」で one-hitter.her.jp の公開フォルダ（wp-config.php がある階層）を開く
 2. 既存の .htaccess を、同じ場所に「.htaccess.bak-20261021」という名前でコピーして控える（消さない）
 3. .htaccess の**いちばん上**に、次の3行を足して保存する（既存の行は消さない）
    RewriteEngine On
    RewriteRule ^ https://one-hitter.jp/ [R=301,L]
    # 2026-10-21 php2shell対策（CMO）。旧WordPressへの到達を止める。戻すときはこの3行を消す
 4. 確認：別タブで次の3つを開く。全部 https://one-hitter.jp/ のトップに飛べばOK
    https://one-hitter.her.jp/
    https://one-hitter.her.jp/wp-login.php
    https://one-hitter.her.jp/?rest_route=/
    → 白い画面・500エラーになったら、すぐ .htaccess.bak-20261021 の中身に戻して CMO に報告

B. PHP のバージョンを上げる（Aの保険）
 1. 「サーバーの管理・設定」→「PHP設定」
 2. one-hitter.her.jp の今の設定（例：PHP8.1 LiteSpeed版）を画面ごと控える
 3. 出ているいちばん新しい版（8.5 か 8.4。LiteSpeed版があればそれ）に変更して保存
 4. 同じ画面に「php.ini設定」があり、session.upload_progress.enabled を変えられるなら Off にする。無ければ飛ばしてよい（単独では完全な対策にならない）

C. ロリポップ管理画面の「お知らせ」に PHP 脆弱性の告知があれば、件名と要点を控える

■ やらないこと
- WordPress やファイルの削除（元に戻せない）。今夜は「止める」だけ
- ほかのドメイン・ほかの会社（ヒトカチ）のサイトに触れること

■ 返してほしいもの
A の確認3つの結果、B の変更前→変更後のバージョン、C の告知の有無。終わったら返信を。CMO が外から再確認する。
