## A. 年末LPが2つのURLに存在している ← いちばん事故りやすい

| URL | 用途 | 状態 |
|---|---|---|
| `one-hitter-lp.netlify.app/nenmatsu/` | **アフィリエイト登録済み**（オーナーが広告側に設定） | 新ロジック |
| `one-hitter-nenmatsu.netlify.app` | 既存客SMSの誘導先 | 新ロジック（09-08に配信） |

### なぜ決めないといけないか

いまは中身が同じですが、**別サイトなので片方だけ配信すればまた食い違います。**
09-08に実際に起きました。私が `/nenmatsu/` にだけ配信し、SMSの誘導先である
`one-hitter-nenmatsu` が旧ロジックのまま残り、255通り中203通りで金額が違っていました。
そちらの検証で見つけていただいて助かりましたが、**私の見落としです。**
2サイトある構造のままだと、注意力に頼ることになります。

### 選択肢

1. **`one-hitter-nenmatsu` を正とし、`/nenmatsu/` を廃止する**
   → アフィリエイトの遷移先を変えるので、**オーナーへの設定変更依頼が先**になります
2. **`/nenmatsu/` を正とし、`one-hitter-nenmatsu` からリダイレクトする** ← **推奨**
   → `_redirects` 1行で済みます。作業内容:
   ```
   /*  https://one-hitter-lp.netlify.app/nenmatsu/:splat  301
   ```
   **`?src=sms&cid=…` のクエリはリダイレクト先に引き継がれるので、SMSの効果測定は
   そのまま続けられます。既存のSMS本文の差し替えも不要です。**
   アフィリエイト設定も触らずに済みます
3. **両方を正のまま運用する**
   → 配信のたびに2サイトへ出す運用を守れるなら可。ただし2回とも漏れています

### いつまでか

**既存客SMSを出す前に決めてください。** 出したあとにリダイレクトを入れても効きますが、
出す前のほうが安全です。
