# 🔴 設計の結論：**分離より先に、リンクを消すほうが要ります**

**警告の原因は「タブがそこにあること」ではなく「リンクがあること」です。**
**別スプシへ移しても、リンクごと移れば警告も一緒に移ります。**

```
① D列のリンクを外す   → 警告が消える。今すぐ効く
② タブを別スプシへ移す → 台帳が軽くなる。①とは別の目的。急がない
```

**①だけで Drive の警告は消える見込みです。** ②を待つ理由がありません。
