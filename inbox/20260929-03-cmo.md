## 和真さんの増える手順（1行）

> **初回だけ、こちらから送る専用リンクをスマホで1回開く。以後は入力も操作も不要（消えたら同じリンクをもう一度開くだけ）。**

## なぜ必要か

いまは**URLを知っている人なら誰でも、過去見積のお客様の氏名・住所・電話番号を見られます。**画面側の関数に鍵がありません。
URLは 9/26 から掲示板（git）と `data/haifu-urls.json` にも書かれているので、**URLを秘密として扱う守り方はもう成り立ちません。**

## 設計（独立レビューの批判を反映済み）

| 決めたこと | 理由 |
|---|---|
| **人ごとの鍵**（和真さん用・オーナー用…を別々に発行） | 1つの合言葉だと、1人だけ止められない。**誰が見たかもログに残せる** |
| 鍵は**ランダムな長い値**（人が覚える言葉ではない） | 総当たりが現実的に不可能になる |
| **締め出し（ロックアウト）は付けない** | GAS では相手を区別できないので、失敗回数は全員で1つ。**誰かがわざと間違え続けるだけで、和真さんまで締め出される。**鍵が長ければ締め出しは要らない。失敗は記録だけ |
| 鍵はリンク（`…/exec#key=…`）で渡し、スマホに記憶させる | 入力不要。`#` 以下はサーバーに送られない |
| 読んだらすぐ**アドレス欄から鍵を消す** | 閲覧履歴・ブックマークに鍵が残らないように |
| **過去見積検索・見積作成・請求など、画面の関数すべて**に鍵を要求（マスタの読み込みも含む） | マスタには取引先の宛先メールや担当者一覧も入っている |
| 画面から使っていない古い関数3つは**削除** | 入口を減らす |
| **URLは変えない。doPost も止めない** | 条件どおり。既存の4本を新しいバージョンに差し替えるだけで効く |
| 鍵が未設定なら**全部拒否**（fail closed） | 外部APIと同じ考え方 |

**オーナーの操作**：エディタで `adminAddUiKey('和真')` を1回実行 → 出てきたリンクを和真さんに LINE で送る。止めたいときは `adminRevokeUiKey('和真')`。

## 1つだけ不確かなこと：**iPhone で記憶が消えないか**

GAS の画面は Google の別ドメインの枠の中で動くので、**iPhone の Safari は、この種の保存をしばらく使わないと消すことがあります**（ITP という仕組み）。
消えても**同じリンクをもう一度開けば戻ります**が、頻繁に消えると現場が面倒です。

**これは実機でしか分かりません。**和真さんのスマホの機種とブラウザ（iPhone／Android、Safari／Chrome）を教えてください。
頻繁に消えるようなら、ホーム画面に追加する形など、別の持たせ方を考えます。
