## お願いしたいこと（管理画面での作業。15分ほど）

Google広告 → **[目標] → [コンバージョン] → [新しいコンバージョンアクション] → [ウェブサイト]**
→ 「**タグを手動で追加する**」を選んでください（サイトのスキャンは不要です）。

**2つ作ってください。**

| | ① 申込（主CV） | ② 電話タップ（副CV） |
|---|---|---|
| 目標 | 「**見込み顧客の発生**」→「**申し込み**」 | 「見込み顧客の発生」→「**電話クリック**」 |
| 名前 | `申込（サンクスページ）` | `電話タップ` |
| 値 | **値を使用しない** | **値を使用しない** |
| カウント方法 | **1回** | **1回** |
| 「入札とアナリティクスに含める」 | **オン** | **⛔ オフ** |

> **②を必ずオフにしてください。** 電話をタップしただけの人は、まだ申し込んでいません。
> **入札の目標に混ぜると、タップだけする人を集めるほうへ最適化されます。**

## 返してほしいもの

作ると「**タグを設定する**」の画面にこういう文字列が出ます。**その部分をそのまま返信してください。**

```
'send_to': 'AW-1234567890/AbC-D_efGhIjKlMnOp'
                ↑ここがID      ↑ここがラベル
```

- **コンバージョンID**（`AW-` で始まる。2つとも同じはずです）
- **申込のラベル**（`/` の右側）
- **電話タップのラベル**（`/` の右側）

**タグのコードをLPに貼る作業は要りません。** LPには既に仕込んであり、この3つを
`tracking/measurement.json` に入れるだけで動きます（そこはこちらでやります）。

## ⛔ ひとつだけ、やらないでほしいこと

**[目標] → [コンバージョン] → [概要] で、「Google アナリティクス 4」からのインポートを有効にしないでください。**

こちらは広告のタグを直接撃つ方式です。GA4からのインポートを同時に有効にすると、
**同じ申込が2回数えられます。** Google広告は「CPAが実際の半分」だと誤解し、
**入札を上げすぎて予算が倍の速さで溶けます。**

もし既に「ウェブサイト」以外の行（とくに Google アナリティクス 4）があれば、**その行も教えてください。**
