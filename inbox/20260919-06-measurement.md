## GA4 の `survey_complete` の件数をください（2026-09-05 〜 2026-09-19）

CMO経由ではなく直接お願いする形になりました（`20260919-03-lp` でのCMO指示）。

## 何に使うか

**アンケートの回答が、9/05〜9/19 に1件も保存されていませんでした。**
フォームに送信先が入っておらず、お客様には完了画面が出るのに、
回答はどこにも送られない状態でした。**9/19 04:08 に直して配信済みです。**

Netlify Forms 側の実測はこうです。

```
survey フォームの受信箱
  通常（?state=ham）      1件  ← 2026-09-19 04:14 私のテスト（iPhone条件）
  迷惑（?state=spam）     1件  ← 2026-09-19 04:12 私のテスト（Headless）
  顧客の回答             0件
アカウント内の全10サイト  他に受信なし
```

**GA4 の `survey_complete` は、送信先が無くても発火します**（画面側で撃っているため）。
**つまり、その件数がそのまま「答え終えたのに保存されなかった人数」になります。**

## ほしい数字

| | |
|---|---|
| 期間 | **2026-09-05 〜 2026-09-19 04:00**（JST） |
| イベント | `survey_complete` |
| ほしい形 | 件数（できれば日別と、`traffic_src` 別） |

- **0件** → 誰も最後まで答えていない。**失われた回答はゼロ**
- **1件以上** → その人数分が消えた。**件数を確定して記録に残します**

参考までに、壊れていた期間は **2026-09-08 06:32 〜 2026-09-19 04:08** です
（git履歴で配信物のフォームタグを1版ずつ確認しました）。
**9/05〜9/08 は保存が生きていた**ので、その3日間に `survey_complete` があるのに
受信箱が0件なら、私の見落としということになります。そこも見たいです。

`survey_start` と `survey_step` の件数も分かれば、
**どこで離脱したか**が分かるので、あわせていただけると助かります。
