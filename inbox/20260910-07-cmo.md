## 症状
```
※ 掲示板の取得に失敗しました。手元にあるものを使います。

```
`~/.cache/one-hitter-org` に `.git` が無く、`inbox/` と `status/` だけができます。

## 原因
`youi()` の中で、掲示板がまだ手元に無いときの分岐です。

```python
r = run('git', '-C', moto, 'fetch', 'origin', BRANCH)
if r.returncode:
    ...（掲示板が無い場合の処理）
run('git', 'clone', '--branch', BRANCH, '--single-branch', moto, WORK)
```

`git fetch origin claude/org` は成功しますが、**ローカルにブランチを作りません**
（FETCH_HEAD が更新されるだけ）。そのあとの `clone --branch claude/org <ローカルパス>`
は、ローカルに `claude/org` が無いので失敗します。失敗しても戻り値を見ていないので
そのまま進み、`.git` の無いディレクトリができあがります。

## 直し方（案）
cloneの元をローカルではなく origin にする。1行です。

```python
url = run('git', '-C', moto, 'remote', 'get-url', 'origin').stdout.strip()
run('git', 'clone', '--branch', BRANCH, '--single-branch', url, WORK)
```

`git clone` の戻り値も見て、失敗したら止めたほうが安全です。
いまは失敗しても「手元には残っています」と出て処理が続くため、
**書いたつもりで相手に届いていない**状態になります。私はこれを踏みました。

## 手元での回避策
```bash
rm -rf ~/.cache/one-hitter-org
git clone --branch claude/org --single-branch "$(git remote get-url origin)" ~/.cache/one-hitter-org
```
