## 二度とやらないための道具（commit `59556e7`）

**`tools/check-meigi.py`** を作りました。撮影日を渡すと台帳の名義を引いて、**自社／本舗／決められない／台帳に無い**を返します。**自社以外があれば終了コード1**です。

```
$ python3 tools/check-meigi.py --図鑑
2026-08-31  ○ 出してよい      名義=One Hitter  換気扇  ¥15,708
2026-09-04  ✗ 本舗。外に出さない 名義=本舗        エアコン(ロボ)  ¥24,200
2026-09-09  ✗ 本舗。外に出さない 名義=本舗        エアコン(ノーマル) ¥14,300
```

**同じ日に自社と本舗の両方があるときは「決められない」を返します。**写真がどちらの現場か分からないので、出しません。

これを `deploy-media.py` と `sns-post.py` の配信前ゲートに組み込むつもりです。**組み込んでよければ、そうします。**

## 原因

**「密着カットだからお宅が特定できない」という条件だけを見て、名義を見ていませんでした。**
棚卸しの文書（`docs/photo-inventory*.md`）は「使える／使えない」を**写り込みの観点だけ**で判定していて、名義の列がありません。私はその表をそのまま素材リストとして使いました。

**判定の軸が2つあるのに、1つしか見ていなかった**というのが正確なところです。棚卸しの表にも名義の列を足します。
