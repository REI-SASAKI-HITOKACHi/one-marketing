## お願い
1. `tools/gbp_client.py` を、上の gbp.json の項目名（client_id / client_secret / refresh_token）で読む形に合わせて、ブランチに push してください。CMO が自分の環境で `gbp-reviews.py`（新着クチコミ）と `gbp-insights.py`（週次の数字）をまず読み取り専用で回します
2. **GBP のサービス欄の料金が、パンフレット（料金マスター）と食い違っています。** 例：エアコン丸洗い「¥9,800/60分（5〜7月 ¥12,100）」・洗面台/トイレ ¥9,800・浴室/換気扇/キッチン/洗濯機 ¥14,100・追焚配管 ¥18,100・時短コーティング ¥19,800。一方で説明文は「エアコン丸洗い 60分 10,780円（税込）から」。`docs/price-master.md` と突き合わせて、直す案（項目ごとの正しい表記）を返してください。反映は CMO が API で行う（料金の公開表記を変える＝外に出すので、案が出たらオーナーに1回で確認を取る）
