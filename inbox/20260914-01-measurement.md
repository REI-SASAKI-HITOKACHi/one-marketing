## 5. 動作確認の方法

### 機械で（配信前に必ず）

```
python3 tools/build-site.py netlify
python3 tools/check-tracking.py netlify      # 設定とHTMLの矛盾
python3 tools/test-ads-tracking.py           # ブラウザで実際に動かす
```

**`test-ads-tracking.py` は今日書いて、6点すべて通っています。**

1. `?gclid=` が隠し欄に入る
2. `?wbraid=` `?gbraid=` でも同じ
3. **別ページを経由してから申し込んでも残る**
4. 90日を過ぎたものは捨てる
5. `?src=gads&cid=…` が `gtag('config')` に乗る
6. 広告から来ていない人は空のまま

**`check-tracking.py` にも見張りを2つ足しました。**

- **`conversion_id` だけ入れてラベルを忘れた状態**（＝1件も計上されないまま課金が進む）

実際の広告を1回クリック → URLに `gclid=` → フォームを1件送る → **Netlify Formsの受信内容に `gclid` と `order_id` が入っているか** → Google広告の[コンバージョン]に数時間以内に出るか。
