# 決定：**年末2026に前倒しします**

賛成です。**ただし条件を1つ足させてください。これが無いと数字が壊れます。**

## 🔑 条件：**「贈る月」と「施工する月」を分けて設計する**

**12月は繁忙期加算（+3,300円）の対象月です**（対象は5・6・7・12月）。
§3.4 で加算は当社負担と決めているので、**12月に施工すると1件あたりの限界利益がこう落ちます。**

| 施工月 | 限界利益 |
|---|---:|
| 加算なし月（1〜4月・8〜11月） | **9,434円** |
| **加算月（12月）** | **6,134円（−35.0%）** |

**ギフトは、贈る月と施工する月を分けられます。** 券型でも予約代行型でも、
**受け取った人が使う時期は後ろにずらせる。**

| 設計 | 1件あたり |
|---|---:|
| 全部12月施工 | 6,134円 |
| 半分が12月・半分が1〜2月 | 7,784円 |
| **全部1〜2月施工** | **9,434円** |

**しかも1〜2月は、こちらにとって最良の月です。**
④ の月別目標（中立）は **1月5件・2月5件で年間の底**。稼働率も最も低い。
**2月は保守シナリオで赤字月**でもあります。**埋める価値がいちばん高い月に、施工を落とせます。**

> **「年末に贈って、年が明けて落ち着いてから、プロが入る」**
> ── 情景としても無理がありません。むしろ年末は誰の家も慌ただしい。

**だから設計はこうします。**

| | |
|---|---|
| **売る** | **11月中旬〜12月下旬**（贈答の山。④ の月別目標も11月18件がピークで、12月13件より多い） |
| **施工** | **12月〜2月。1〜2月に寄せる**（加算を避け、年間の底を埋める） |
| 情景 | 帰省の前後に、親の家をきれいにする |

## 準備期間について、経営企画室と食い違ったので裁定します

経営企画室から**「準備は2.5か月ではなく約1か月」**という指摘が来ています。
根拠は `docs/nenmatsu-plan.md` の「**年末大掃除は12月に売るものではなく10月と11月に売るもの。
検索の立ち上がりが10月中旬、予約のピークが11月**」。

**これは採りません。理由を書きます。**

> **それは「清掃サービス」の需要カレンダーであって、「ギフト」のものではありません。**
> **贈り物は、贈る機会の直前に買われます。**
> 大掃除を自分のために頼む人は、**作業日から逆算して10月に動く。**
> 人に贈る人は、**渡す日から逆算して11月下旬〜12月に動く。**

**＝あなたの「11月中旬〜12月下旬に売る」で正しい。準備は約2か月です。**

### ただし、経営企画室の案は捨てません。**併用します**

向こうの §7 に「**年末は売らずに測る**」という案があります。
**年末LPにギフトの入口だけ置いて、クリックと問い合わせを取る。広告費0円。**

**これを「10月中旬の無料の入口」として足します。**

| | 時期 | 費用 |
|---|---|---|
| **測る** | **10月中旬〜**（年末LPに入口だけ） | **¥0** |
| **売る** | 11月中旬〜12月下旬 | 広告費 |
| **施工** | 12月〜2月。**1〜2月に寄せる** | |

**やらない理由がありません。**
**広告費0円で「いつから需要が動くか」の実測が1本手に入る**ので、
**11月中旬に出稿する判断そのものが、推測ではなく数字で決まります。**

もし10月中旬の入口で反応が早く立つようなら、**出稿を前倒しする根拠になります。**
経営企画室の言い分が正しかった、という結論もありえる。**それを測ってから決める形にしました。**
