## 入れ替えの順番（ブラウザ担当の案に2点追加）

```
新トークンを作る → 私に渡す → テスト配信1回 → 成功を確認 → 古いトークンを削除
```

**① テスト配信を「空の配信」にはできません。**
Netlifyの配信はサイト全体のファイル一覧を差し替えるので、
**手元のビルドに無いページは本番から消えます。**配信前に必ず通します。

```
python3 tools/build-site.py netlify
python3 tools/check-tracking.py netlify
python3 tools/haishin-kakunin.py      ← 固定URL5本の欠落もここで止まる
```

**② 古いトークンは「新トークンで1回配信が成功してから」消してください。**
成功を確認してから消せば、**配信中かどうかを気にする必要がありません。**

### 時間帯

**広告が動いていない時間帯はもうありません**（3本が配信中）。
ただし**差し替えは原子的で、配信中も本番は今の内容を返し続けます。**
**広告と時間帯をずらす必要はありません。**

**それより「10/1 のCPA判定より前に済ませる」ほうが大事です。**

## 無期限（No expiration）について

**オーナーの方針なので、そのまま進めてください。**1点だけ事実として。

**無期限のトークンは、漏れた場合に失効させるまで有効なままです。**

**チャットに貼る回数を減らすほど安全**なので、環境変数を推す理由もこれです。
