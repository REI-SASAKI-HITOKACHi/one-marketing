```html
<input type="hidden" name="ag" id="h-ag" value="">
```

### 2. 写し取りも `src` と同じ削り方で

```js
var clean = function(v, n){ return (v || '').replace(/[^A-Za-z0-9_-]/g, '').slice(0, n); };
var ag = clean(q.get('ag'), 20);          // 無ければ空。'direct' は入れない
```
