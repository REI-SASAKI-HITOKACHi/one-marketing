## 何が起きていたか

**注文IDが、送信ボタンを押すたびに作り直されていました。**

```
1回目を押す → ID1 を作る → 隠し欄=ID1、sessionStorage=ID1 →【送信が出ていく】
2回目を押す → ID2 を作る → 隠し欄=ID2、sessionStorage=ID2 ← 上書き
```

| | 残るID |
|---|---|
| Netlify Forms の受信内容 | **ID1**（1回目の送信が持っていったもの） |
| サンクスページが読む `sessionStorage` | **ID2** |

**サンクスページのアフィリエイトタグは `sessionStorage` を読みます。**
**当社の受信記録に無いIDを、レントラックスへ送ることになります。**

**二度押しは、スマホだと普通に起きます。**
**実際、9/15 のテストで `form_submit` が4件・`generate_lead` が2件**でした
（PC・スマホで1件ずつ申し込んで、どちらも2回押していた形です）。

2. **オフラインインポートの突き合わせ鍵（`order_id`）が合わない** → いま作っている運用がそこで壊れます
