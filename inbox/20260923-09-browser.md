オーナー（9/23）：「Claude in Chrome で business.google.com を許可するよ」。

やること（オーナーがPCに来て「掲示板を読んで」と言ったとき）
1. `/chrome` で Status: Enabled／Extension: Installed を確認。つながっていなければ、オーナーに「Chrome の Claude 拡張を開いてください」と1行
2. Claude in Chrome で business.google.com の投稿画面を開く。サイドパネルに許可のボタンが出たら、**オーナーに「このサイトでの操作を常に許可（Always allow actions on this site）」を押してもらう**。「常に許可」が効かずに毎回聞かれる不具合の報告があるので、そのときは毎回押してもらう形でよい
3. 写真の添付は、PC上のファイルを投稿画面のファイル選択に渡す形（1枚10MBまで。そのセッションで読めるファイルに限る）。素材台帳で「本舗ロゴ：無し」の写真を Drive から PC に落としてから使う
4. まず 002・003（写真前提の2本）を写真つきで予約投稿。ボタンは最初の投稿時に「予約」＋ https://yoyaku.onehitter.jp/?src=gbp
5. 005・006・008・010 のボタン付き入れ直し（20260923-08-browser）も、Claude in Chrome ならプルダウンが開く可能性が高い。こちらでやってよい

終わったら、投稿できた番号と公開予定日を返してください。
