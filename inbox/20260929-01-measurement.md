# ChatGPT Ads（フォースリー）：計測・アフィリエイトの立場から

結論：**書面で条件を出してもらう方針に賛成。** そのうえで、**「レントラックスの提携パートナーとして入ってもらえるか」を最初に聞く**のがいちばん安全です。そうなれば、成果地点（決済完了）、1件あたりの報酬、承認・却下、重複の排除が、今の仕組みのまま使えます。**計測タグの追加もありません。**

## 先に：公開情報で確かめたこと（9/29 にWeb検索で確認）
- ChatGPT の広告は、**回答の下に「スポンサー」と表示して出す枠**です。OpenAI は「広告は回答に影響しない」と明言しています。対象は無料版と Go プランの利用者だけで、健康・政治などの話題では出ません
- 日本での提供は 2026年5〜6月に発表されました。日本の取り扱いパートナーとして、電通デジタル・博報堂DY ONE・サイバーエージェントの名前が報道に出ています
- OpenAI の課金は、**表示ごと（CPM）とクリックごと（CPC）**。成果報酬で買う仕組みは、**OpenAI の側には見当たりません**
- 計測の方法は、OpenAI が出しているピクセル（ブラウザで動くタグ）とサーバー連携の2つ。日本の広告主が自分でピクセルを作れるかどうかは、**確認できていません**
- 「利用者約4,400万人」という数字は**検証していません**

→ ここから言えること：**「完全成果報酬」は、フォースリーが広告費を立て替えて、成果の報酬で回収する形**だと考えられます（推定）。そうなると、先方には**成果を多めに数えたい動機**があります。下の条件は、この前提で組んでいます。

## 1. 成果地点と重複計上
- 成果地点は**決済完了**（レントラックスと同じ）。「申込」「電話タップ」「LINE追加」「ページを見た」は成果にしない。申込のうち、スパムやキャンセルの割合は無視できません（GA4 の form_complete は 44件中42件がスパムでした）
- **成果と認めるのは、当社の受付番号（OH-…）が付いていて、しかも台帳で決済が完了している申込だけ**。先方の管理画面の数字では払いません
- **流入元は当社の仕組みで判定します**：広告の遷移先URLに `?src=chatgpt` を付けてもらい、予約_Web の `src` 列で数えます。src が付いていない申込は成果の対象外です
- **重複**：同じ申込に Google 広告のクリックID（gclid/gbraid）が付いている場合や、レントラックス経由と重なる場合の扱いを、契約書面に書いてもらう。当社の提案は「最後にクリックした経路1つだけに成果を付ける。判定は当社の受付番号の記録で行う」。先方が「ビュー（広告を見ただけ）で成果に数える」と言うなら**不可**
- **レントラックスの提携パートナーとして入ってもらう形なら、重複排除はレントラックスの計測がやる**ので、この問題そのものがなくなります

## 2. 計測タグ
- **原則、タグは入れない方針を推します。** 理由：①LP と予約ページは lp の持ち物で、配信には check-public-page を通す必要がある ②外部にデータを送るスクリプトが1本増える（プライバシーポリシーの外部送信の記載を直す必要も出る） ③9/12 のセーフブラウジング事故の後なので、よく分からないスクリプトは入れたくない
- 成果の突き合わせは、src と受付番号の CSV を月に1回渡すことで足ります（Google 広告のオフライン取り込みと同じ考え方）
- **どうしても OpenAI のピクセルが要ると言われた場合**：①先方が OpenAI の広告アカウントを誰の名義で持つのか ②タグを出すのは OpenAI 公式のものか（先方が作った独自のタグでないか）③サンクスページ1枚にだけ入れる、の3点を書面で確認します。入れる作業は lp に依頼し、私が check-tracking と check-public-page に通します

## 3. 不正成果と承認
- 成果の承認期限は**45日以上**（決済の確認に必要。レントラックスと同じ条件）。期限を過ぎたら自動で承認になる仕組みは受けない。自動承認があるなら、却下の期限を当社が決められること
- **却下できる理由を書面に入れる**：キャンセル、決済されなかった、同じ人の重複（同じ電話番号・住所）、関係者による申込、src が無い、スパム
- **返金（すでに払った後の取り消し）**：決済後30日以内の返金・取り消しは、報酬も取り消し
- **広告の文面は事前に当社が確認する**。本舗の名前・98.8%・根拠の無い最安表示などは使わせない（使ってよいのは 98.6%（209名中206名）と、パンフレットの料金）
- 初期費用・月額固定・最低出稿額があるなら**「完全成果報酬」とは言えない**ので、その時点で不可（6番の planning と同じ意見です）
