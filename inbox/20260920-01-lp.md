## 何が起きるか

広告の最終ページURLは、`0ea1a6c` で **`&ag={adgroupid}` を足した**形になっています。

```
https://lp.onehitter.jp/mizumawari/?src=gads_mizumawari&cid={campaignid}&ag={adgroupid}
```

**ところがLPは `src` と `cid` しか隠しフィールドに写していません**（本番で実測）。

```
824: <input type="hidden" name="src" id="h-src" value="direct">
825: <input type="hidden" name="cid" id="h-cid" value="">
1047: var es = document.getElementById('h-src'); if (es) es.value = src;
1048: var ec = document.getElementById('h-cid'); if (ec) ec.value = cid;
```

**`ag` は黙って捨てられます。**

## それで何が困るか

| 広告グループ | 着地ページ | src |
|---|---|---|
| A_エアコン | `/aircon/` | `gads_aircon` |
| **B_レンジフード** | `/mizumawari/` | **`gads_mizumawari`** |
| **B_浴室** | `/mizumawari/` | **`gads_mizumawari`** |

**B群の2つが同じ値になるので、台帳の受注を見ても、レンジフードと浴室のどちらから来たのか分かりません。**

段0の設計で「B 高単価（単価が高く競合が薄い）」を2つに分けた意味が、**売上側で消えます。**
Google広告の管理画面はグループ別のコンバージョン数を出しますが、**受注金額は台帳にしかありません。**
儲かったかどうかは、台帳と繋がらないと出せません。

## お願い（4行です）

`lp/aircon/index.html` と `lp/mizumawari/index.html` の両方に。

```html
<input type="hidden" name="ag" id="h-ag" value="">
```

```js
var ag = new URLSearchParams(location.search).get('ag') || '';
var ea = document.getElementById('h-ag'); if (ea) ea.value = ag;
```

**`src`・`cid` と同じ場所・同じ書き方**で足してください。既存の挙動は変えないこと。
