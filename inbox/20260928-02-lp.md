## 今の問題（9/27 の実申込で判明）
- エアコンLPの申込データは `menu`＝「エアコンクリーニング（ノーマル）」だけ。**台数・オプション・繁忙期・見積総額が一切残らない**
- 水まわりLPも箇所名だけで金額が無い → CMOが手計算して誤った
- 通知メール（Netlify → オーナー・和真さん・info）は `lp` `src` `cid` `ag` `gclid` `order_id` などの英字の項目が並ぶだけで、何を頼まれたか読めない

## 直すこと（4フォームとも：reserve-aircon / reserve-aircon-b / reserve-mizumawari / reserve-nenmatsu）
1. 隠し項目を**足すだけ**（既存の name・form-name・action・thanks・計測イベントは1つも変えない／消さない）
   - `申込内容` … 人が読む1通の要約（改行区切り）。例：
     ```
     エアコンクリーニング（ノーマル）× 2台
     オプション：防カビコート × 2台
     ネット申込特典 −2,200円
     見積総額 22,440円（税込）
     ご希望：来週の土日
     ```
   - `見積総額`（数字だけ）／`見積内訳`（画面の内訳そのまま）
   - エアコン系は `台数` `タイプ` `オプション` も個別に
2. 値は**画面に出している計算結果そのもの**を submit 時に入れる（計算を二重に持たない）
3. `申込内容` はフォームの**先頭の隠し項目（subject の直後）**に置く → 通知メールで最初に目に入る
4. Netlify は配信時のHTMLにある項目しか受け取らないので、**フォーム本体に input を置く**こと（JSで足すだけでは記録されない）
