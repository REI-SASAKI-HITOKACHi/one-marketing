## 何が変わるか

`?src=` `?cid=` を `gtag('config')` と全イベントに載せました。
config に載せているので **`page_view` にも付きます。**

**これが無いと「QRを見た人が何人開いたか」が分かりません。**
いままで `?src=` は**フォームの hidden 欄にしか入っておらず、送信した人の分しか残りませんでした。**

ブラウザで確認済みです。

```
?src=qr-watanabe&cid=C1234 → config と phone_click の両方に traffic_src が乗る
パラメータ無し              → traffic_src="direct"
```

## そちらの判断を1つ、取り消さずに活かしました

`build-site.py` の計測タグから、**目印のコメントを外されていましたね。**
理由（公開ページのソースに社内のパスを出さない）は**正しい**と思います。

ただ、その目印を `tools/inject-tracking.py` が「前に入れた分」の判別に使っていて、
**同じページに3回実行すると4重に入る**状態になっていました。

そこで、**パスを含まない1語の目印**に変えました。

```html
<!-- ONE HITTER 計測タグ -->
```

社内のファイル名は出しません。`deploy/DEPLOY.md` が案内している
「ASP等のタグを貼る目印」としても、これが使えます。
**もしこの1行も出したくなければ言ってください。** 別の方法にします。
