# ご提案への回答

## 案2（件名に選択項目を入れる）は、**そのままだと効きません**

**理由：`input[menu]` は `エアコン` が既定で選択されています。**

```html
<input type="radio" name="input[menu]" value="エアコン" checked="checked" />
```

**営業は選択項目を触りません。既定のまま送ります。**
＝ 件名に `[エアコン]` が付くだけで、**お客様の依頼と区別が付きません。**
いまと同じ「全部同じ件名」が「全部 `[エアコン]`」になるだけです。

## 代わりに：**都道府県を件名に入れる**

**こちらは既定の選択がありません。**お客様は必ず選ぶ欄です。

**そして対応エリアは東京都・千葉県・神奈川県の3つだけです。**

| 件名の例 | 判断 |
|---|---|
| `[東京都] ホームページからのお問い合わせ` | **ほぼ確実にお客様** |
| `[神奈川県] …` | **ほぼ確実にお客様** |
| `[大阪府] …` `[丸の内]` 等 | **ほぼ確実に営業**（対応エリア外） |
| `[未選択] …` | **ほぼ確実に営業**（欄を触っていない） |

**メニューより都道府県のほうが、はるかに強い見分けになります。**
すでに集めている値なので、**追加で聞くことは何もありません。**

### あわせてやると効くこと

**`input[menu]` の `checked="checked"` を外す。**
既定を消して必須にすれば、**営業が欄を触らないことが、そのまま signal になります。**
件名に `[エアコン][東京都]` と2つ入れれば、`[未選択][大阪府]` は一目で捨てられます。

> ⚠️ **既定を外すとお客様の手間が1つ増えます。**
> 「どこを掃除してほしいか」は最初から選びたい項目なので、
> **離脱は増えないと見ていますが、断言はできません。**判断はオーナー／CMOに。

## 案1（「営業はお断り」の一言）の原稿

**効果は限定的です。**ボットには効きません。人が送る営業には少し効きます。
ただし**書いておくと、後で無視・ブロックする根拠になる**ので、置く価値はあります。

```
■ 営業・売り込みのご連絡はご遠慮ください
このフォームは、ハウスクリーニングのご依頼・ご相談の窓口です。
サービスや商品のご提案は、お返事いたしません。
```

**置き場所**：送信ボタンの直前（規約同意チェックの下）。
**フォームの冒頭に置かないこと。**お客様が最初に読む場所を、
お客様向けでない文で使うのは損です。

## 案3（何もしない）について

**週4件なら人が捨てるほうが早い、というのは合理的です。**
ただし**「99%が営業」という前提のほうが危ないと思います。**

ご指摘のとおり、**それは1%を見落とす形**です。
**都道府県が件名に出れば、その1%が目で拾えるようになります。**
**私も案2（都道府県版）を推します。**

# 追記 2026-09-21：**私の都道府県案は、実データで否定されました**

ブラウザ担当が **form_id 270 の直近30日・50件をCMSで仕分け**（個人情報は取り出さず）。

## 私の案が外れた理由

| 私の前提 | 実際 |
|---|---|
| 営業は選択項目を触らない（既定の エアコン のまま） | **逆。「その他」を選んで社名を書く**（その他45件＝90%／エアコン5件） |
| 対応エリア外の都道府県は営業 | **営業50件のうち40件（80%）が東京・千葉・神奈川**。営業会社の多くが都内にある |

**＝ 件名に都道府県を入れても8割がすり抜けます。私の案は使えません。**

**そして直近30日は50件すべて営業、お客様は0件でした。**

## 正しい見分け方：**依頼メニューの text**

CMSの通知メールで使える変数（ブラウザ担当が設定画面で確認）：

| | 変数 |
|---|---|
| 都道府県 | `[*@address_prefectures*]` |
| **依頼メニュー** | **`[*sel_text(@menu,@menu_etc)*]`** ←「その他 株式会社◯◯」まで入る |
| 件名 | `kv[notify_subject]`（現在 `ホームページからのお問い合わせ【ワンヒッター株式会社】`） |

## ⚠️ ただし「その他」で切るのは危険。**切るのは法人語**

ブラウザ担当の保留（「本物のお客様が『その他』を選ぶ割合が分からない」）は正当ですが、
**その割合を知らなくても済む切り方があります。**

**「その他」かどうかではなく、`menu_etc` に法人語が入っているかで見る。**

```
株式会社 / （株） / 有限会社 / 合同会社 / 一般社団 / Inc / Corp / LLC
```

- **営業** … 「その他 **株式会社**◯◯」→ 引っかかる
- **本物のお客様が「その他」を選んだ場合** … 「その他 窓」「その他 ベランダ」→ **引っかからない**

**＝ 325件に遡らなくても実装できます。**遡る作業はブラウザ担当の負担なので、
**この切り方なら不要**です（やる価値がある理由は下に1つだけ書きます）。

## 🔴 自動で捨てないこと。**法人からの本物の依頼が同じ形をしています**

**管理会社・不動産会社からの見積依頼は、本物のお客様で、しかも社名を書きます。**

実例（9/17〜9/19 のメール）：**株式会社プレジャー**から
「御見積依頼【グランドメゾンセンター北フロント802号室】」。
これは**実際の受注案件**で、渡辺さんが見積を出して発注書まで進んでいます。

**＝ 法人語で切るルールは「捨てる」に使えません。**

| やること | やってはいけないこと |
|---|---|
| ラベルを付ける／受信トレイをスキップする | **削除・自動返信** |
| 週1回まとめて目で流す | 見ずに消す |

**50件すべて営業でも、B2Bの1件を落とすほうが高くつきます。**
1件の受注額が数万円で、営業を50件読む手間は数分です。
