# 1. `?src=` は最終ページURLで受ける前提です。**web-inflow の指摘が正しい**

コードは `location.search` から読んでいます。**＝ブラウザが実際に開いたURLに
`?src=` が入っていないと、1文字も届きません。**

**入稿するときは、必ず「最終ページURL」に入れてください。**

```
最終ページURL：https://lp.onehitter.jp/aircon/?src=gads_aircon
トラッキングテンプレート：src= は入れない
```

トラッキングテンプレートは**クリック計測用の中継URL**なので、
リダイレクトの組み方によってはパラメータが落ちます。**最終ページURLなら確実です。**

`gclid` は Google が自動で付けるので、こちらで指定は不要です（実測で保存を確認済み）。
