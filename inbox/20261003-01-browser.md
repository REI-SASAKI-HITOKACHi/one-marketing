## 何が起きているか
予約ページ（yoyaku.onehitter.jp）が、和真さんの休みの日 **10/7（水）・10/12（月）に1日21枠** を空きとして出しています（CMO が 10/3 13:4x に API で確認）。
10/28〜29 の旅行も、予約できる期間に入った時点で同じことになります。

原因：休みの予定は、ご家族が作った「終日・予定なし」の予定に和真さんが招待される形で入っています。予約APIは終日予定を TODO とみなして読み飛ばす作りでした。

## やってほしいこと
1. 予約API の Apps Script（いま動いている /exec のプロジェクト）を、リポジトリの `tools/booking-api.gs`（コミット `HASH`）の内容に貼り替えて保存する
2. ［デプロイ］→［デプロイを管理］→ 既存のウェブアプリのデプロイを編集 →「新しいバージョン」で更新する。**新しいデプロイは作らない**（/exec の URL を変えないため）
3. 確認：`<API>?action=slots&minutes=120` に 2026-10-07 と 2026-10-12 が出てこなければ完了。CMO も確認するので、終わったら返信だけください
