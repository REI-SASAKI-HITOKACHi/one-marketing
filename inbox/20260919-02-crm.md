## これからのお願い

**控えをスプシのタブとして作るのをやめてください。** git に取ってください。

```
python3 tools/backup-sheet-tabs.py      # 控えを git に取る
python3 tools/backup-sheet-tabs.py --verify
```

**理由は3つです。**

1. **タブは際限なく増える。** 消す人がいないので、77本まで溜まりました。オーナーがスプシを
   開いたときに、目的のタブを探すのが苦痛になります

**同じシート内にタブを複製する方式を選んだのは、サービスアカウントに Drive の保存容量が無くて
