# ご提案への回答

## 案2（件名に選択項目を入れる）は、**そのままだと効きません**

**理由：`input[menu]` は `エアコン` が既定で選択されています。**

```html
<input type="radio" name="input[menu]" value="エアコン" checked="checked" />
```

**営業は選択項目を触りません。既定のまま送ります。**
＝ 件名に `[エアコン]` が付くだけで、**お客様の依頼と区別が付きません。**
いまと同じ「全部同じ件名」が「全部 `[エアコン]`」になるだけです。

## 代わりに：**都道府県を件名に入れる**

**こちらは既定の選択がありません。**お客様は必ず選ぶ欄です。

**そして対応エリアは東京都・千葉県・神奈川県の3つだけです。**

| 件名の例 | 判断 |
|---|---|
| `[東京都] ホームページからのお問い合わせ` | **ほぼ確実にお客様** |
| `[神奈川県] …` | **ほぼ確実にお客様** |
| `[大阪府] …` `[丸の内]` 等 | **ほぼ確実に営業**（対応エリア外） |
| `[未選択] …` | **ほぼ確実に営業**（欄を触っていない） |

**メニューより都道府県のほうが、はるかに強い見分けになります。**
すでに集めている値なので、**追加で聞くことは何もありません。**

### あわせてやると効くこと

**`input[menu]` の `checked="checked"` を外す。**
既定を消して必須にすれば、**営業が欄を触らないことが、そのまま signal になります。**
件名に `[エアコン][東京都]` と2つ入れれば、`[未選択][大阪府]` は一目で捨てられます。

> ⚠️ **既定を外すとお客様の手間が1つ増えます。**
> 「どこを掃除してほしいか」は最初から選びたい項目なので、
> **離脱は増えないと見ていますが、断言はできません。**判断はオーナー／CMOに。

## 案1（「営業はお断り」の一言）の原稿

**効果は限定的です。**ボットには効きません。人が送る営業には少し効きます。
ただし**書いておくと、後で無視・ブロックする根拠になる**ので、置く価値はあります。

```
■ 営業・売り込みのご連絡はご遠慮ください
このフォームは、ハウスクリーニングのご依頼・ご相談の窓口です。
サービスや商品のご提案は、お返事いたしません。
```

**置き場所**：送信ボタンの直前（規約同意チェックの下）。
**フォームの冒頭に置かないこと。**お客様が最初に読む場所を、
お客様向けでない文で使うのは損です。

## 案3（何もしない）について

**週4件なら人が捨てるほうが早い、というのは合理的です。**
ただし**「99%が営業」という前提のほうが危ないと思います。**

ご指摘のとおり、**それは1%を見落とす形**です。
**都道府県が件名に出れば、その1%が目で拾えるようになります。**
**私も案2（都道府県版）を推します。**
