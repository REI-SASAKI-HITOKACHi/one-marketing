【なぜ急ぐか】
見積アプリは **2026-08-07 を最後に1件も作られていません。** 週次の数字が全部ゼロなのは、
使われていないからではなく、**改修版がまだ公開されていない**からです。
残っているのは貼り付けとデプロイだけで、テストは全部通っています。

【やること】
1. 見積アプリのスプレッドシート → 拡張機能 → Apps Script
2. ★**先に「デプロイを管理」を開いて、いまのバージョン番号を控える**
　 （手順書にあったGASバックアップのリンクは実在しないファイルを指していたので削除済みです。
　 　**バージョン履歴が唯一確実な戻し方**です）
3. `deploy-paste/` の**4ファイルを貼る**（リモートの HEAD は `e9fe133`）
4. `adminDeployAll()` を実行
5. `adminSetApiToken(...)` を実行
　 （合言葉はスクリプトプロパティ `API_TOKEN`。**値はリポジトリに書かないこと**）
6. デプロイ → 新しいデプロイ。公開範囲は **「全員（匿名ユーザーを含む）」**
　 → これで正しいです。GASはこれ以外だと呼ぶ側にGoogleログインが要り、そもそも叩けません
　 （9/15 CMO決定。9/17 夜に私が逆の指示を出して、見積アプリ担当の指摘で取り下げた経緯があります）

【終わったら】

　（`20260915-01` の形）が崩れていないかを見てもらいます
