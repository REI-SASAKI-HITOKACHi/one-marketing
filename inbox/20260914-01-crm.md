## どこで二重になるか

販売管理費の式に代入して、打ち消し合う項を消すとこうなります（5月の例。12か月すべて同じ形）。

```
B62 販売管理費 = (F53 + F61 - F59) + K61
   F53 合計        = SUM(F2:F52) - J61
   F61 ロイヤリティ = L61 + F9+F10+F11+F12
   L61 本舗合計    = H61 + I61 + J61 - K61

 → 販売管理費 = SUM(F2:F52) + H61 + I61 + (F9+F10+F11+F12) - F59
```

`-J61` と `+J61`（L61の中）が打ち消し合うので、**この4行が2回足されます。**

| 行 | 品目 | 科目 | 金額 |
|---|---|---|---:|
| 9 | HITOWAサイト保守費用 | 広告費 | ¥4,400 |
| 10 | HITOWAサポート・アカウント管理費 | 耐久品 | ¥1,650 |
| 11 | **固定ロイ** | **個別ロイ** | ¥22,000 |
| 12 | HITOWAHPC利用料 | 広告費 | ¥22,000 |
| | | 計 | **¥50,050** |

> **planning の見立てにあった「固定ロイ22,000」も二重です。**
> 科目が「個別ロイ」なので J61 で引かれているように見えますが、
> **同じ J61 が L61 の中で足し戻されている**ため、差し引きゼロになります。

## 効いているところ

`年間成績` 28行目の販売管理費は `='◯月_支出/成績'!B62` をそのまま引いています。

- 販売管理費が月 ¥50,050 **多い**
- 営業利益・経常利益がその分 **少ない**
- 和真収入（理論値）＝営業利益×45% なので、**理論値も月 ¥22,522 ほど少なく出ている**
- 実績が入っている1〜8月だけで **¥400,400**

## 直し方（**まだ直していません**。オーナー報告の上で、の指示どおり）

1行直せば12か月ぶん片付きます。**案Aを推します。**

```
案A（推奨）  F53: =(SUM(F2:F52))-J61-F9-F10-F11-F12
案B         F61: =L61
```

F61「ロイヤリティ」は「その月に本舗へ払う総額」として他でも読まれるので、固定分を含んだままのほうが意味が通ります。F53「合計」は元々 `-J61` で二重を避ける意図があるので、**その漏れを塞ぐ**のが素直です。
