## 何のため

**9/27 のエアコンLPの申込（山来様）は、iPhone からで、クリックIDが `gbraid` でした。**
これまで `gclid` と `gbraid` / `wbraid` を**区別せずに同じ欄へ値だけ**入れていました。

**Google広告へ受注を戻すとき、`gbraid` は `gclid` と別の欄で渡す必要があり、混ぜると弾かれます。**
**種類が分からないと、戻せません。**

## 入るもの

- フォームに `<input type="hidden" name="click_type">` を1つ（`gclid` の隣）
- 着地のときに、どの種類のIDだったか（`gclid` / `gbraid` / `wbraid`）も一緒に保存

## 確認

```
python3 tools/build-site.py netlify
python3 tools/check-tracking.py netlify
python3 tools/test-ads-tracking.py      # 「?gbraid= の種類が click_type に残る」も見ます
```
