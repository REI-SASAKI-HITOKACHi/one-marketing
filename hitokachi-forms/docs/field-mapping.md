# 入力項目と 2 帳票の対応表

入力は 1 回。ここに書いた経路で 2 つの帳票に振り分けられる。
`—` はその帳票には出力しないことを表す。

## 基本情報

| 入力項目 | 適合性確認シート | 意向把握シート |
|---|---|---|
| 取扱代理店 | `取扱代理店名` | `【代理店】` |
| 募集人 | `取扱者名` | `【募集人】`＋`【所在地】``【連絡先】``【メール】` |
| 契約形態（個人／法人） | ①〜④ と 2.①〜③ の要否を切り替え | 「個人のお客さま」「法人のお客さま」の別 |
| 契約者氏名 | `契約者氏名` | `お客さま名` |
| 確認日 | `確認日` | `当初のご意向` の確認日 |
| 親権者氏名 | `親権者氏名` | — |
| 契約者からみた続柄 | `契約者からみた続柄` | — |

募集人を選ぶだけで、意向把握シート下部の代理店ブロック 5 行が埋まる。

## 適合性確認シート「１．」

| 入力項目 | 出力先 |
|---|---|
| 年齢 | `①年齢` |
| 職業 | `②職業` |
| 年収 | `③年収` と `年収×20%`（自動計算） |
| 金融資産 | `④金融資産` と `金融資産×30%`（自動計算） |
| これまで購入した金融商品 | `⑤`（■／□） |
| 保険料原資 | `⑥`（■／□） |
| リスク選好度合 | `⑦`（■／□） |
| 保障ニーズ（後述） | `⑧`（集約して■／□） |

## 適合性確認シート「２．」— 既定はすべて「はい」

**帳票に印字するのは、確認画面で確定した回答。既定はすべて「はい」**で、
法人契約では①〜③が「対象外」になる。適合性の確認は募集の場で済んでいる前提。

下の表は、入力内容から別紙の基準で計算する**参考値**の対応。この結果は帳票には
出ず、既定の「はい」と食い違うときだけ確認画面に理由として添える。

| 判定 | 判定に使う入力 | 「はい」になる条件 |
|---|---|---|
| ① 単独での判断 | 年齢／70歳以上の募集方法 | 70歳未満、または別紙＜１＞〜＜３＞の募集方法を選択済み |
| ② 職業 | 職業区分／世帯主確認 | 「左記以外」、またはパート等でも世帯主の支払能力を確認済み |
| ③ 保険料のバランス | 年収／金融資産／年間保険料／払込期間 | 下の 3 条件のいずれか |
| ④ リスクの理解 | 購入経験／説明済みチェック | 投資経験あり、または経験なしでも説明済み |
| ⑤ 保険料原資 | ア・イ・ウのチェック | ア〜ウをすべて充足 |
| ⑥ 意向 | リスク選好／保障ニーズ | リスクを許容でき、意向が a〜f のいずれかに該当 |

### 判定③ の計算（別紙より）

次のいずれかを満たせば「はい」。

1. `年間保険料 ≦ 年収 × 20%`
2. `年間保険料 × 払込年数 ≦ 金融資産 × 30%`
3. `(年間保険料 − 年収 × 20%) × 払込年数 ≦ 金融資産 × 30%`（組み合わせ）

別紙の例（年収 500 万円・年間保険料 150 万円）だと、年収の 20% は 100 万円で
150 万円を下回るため 1 は不可。不足分 50 万円 × 払込年数が金融資産の 30% 以内なら
3 で「はい」になる。`test/logic.test.js` にこの例をそのまま入れてある。

「いいえ」が 1 つでもあれば、確認画面に赤字で
**「変額保険はお客さまに適合しません。他の定額保険を提案してください」** と出る。

## 保障ニーズ — 細かいほうで 1 回だけ入力する

2 つの帳票で粒度が違う。意向把握シートのほうが細かい（8 項目）ので、
**細かいほうで入力し、適合性⑧へは自動で丸める**。逆方向はできない。

| 入力（意向把握シート 1. の 8 項目） | 適合性⑧ への集約先 |
|---|---|
| 死亡時の保障 | 死亡時の保障 |
| 病気・ケガ・介護の保障 | 病気・ケガ・がん・特定疾病・介護の保障 |
| がんなどの特定疾病に備える保障 | 同上（1 つにまとまる） |
| 子供の教育資金準備 | 貯蓄（教育資金・老後生活資金準備等） |
| 老後の生活資金準備 | 同上（1 つにまとまる） |
| 事業保障 | 事業保障・事業継承（役員の保障） |
| 従業員の福利厚生 | 福利厚生（従業員の保障） |
| 退職金に対する備え | 退職金（生存・死亡）準備 |

適合性⑧ の「その他」だけは別項目（`needsOther`）として入力する。
「その他」しか選ばれていない場合、判定⑥ は「いいえ」になる。

## 意向把握シート固有

| 入力項目 | 出力先 |
|---|---|
| 貯蓄部分 | `2.` の `当初のご意向` |
| 保険期間／保険金額／保険料／その他のご希望 | `3. その他のご希望` |
| 最終のご意向 確認日 | `最終のご意向` の確認日（空欄なら確認日と同じ） |

## 帳票に出力しない入力

判定にだけ使う。

- 職業区分（判定②）
- 世帯主・家族等の確認チェック（判定②）
- 年間保険料・保険料払込期間（判定③）
- 投資経験なしの場合の説明済みチェック（判定④）
- 保険料原資 ア・イ・ウ のチェック（判定⑤）

## 既定で非表示の項目

`項目設定` シートの `扱い` を「入力する」にすれば入力欄が出る。

| 項目 | 出力先 | 既定で隠している理由 |
|---|---|---|
| 推定のご意向（保障分野・貯蓄部分） | 意向把握 `推定のご意向` 列 | 募集人の推定に基づく提案をする場合だけ使う欄 |
| 最終のご意向（保障分野・貯蓄部分） | 意向把握 `最終のご意向` 列 | 空欄なら当初のご意向がそのまま入る |
| ご意向の変化の内容等 | 意向把握 `4.` | 提案途中で意向が変わったときだけ使う |
| 検証日・検証実施者氏名・検証結果 | 適合性 `検証欄` | 事後検証は募集後に別の人が行うため |
| 親権者氏名・続柄 | 適合性 | 契約者が未成年のときだけ使う |
