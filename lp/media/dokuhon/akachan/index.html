40〜60回

生まれたばかりの赤ちゃんが、1分間に息をする回数です。
大人は、12〜20回。

↓ 続きは3分ほど

呼吸数 40〜60回／分：MSDマニュアル プロフェッショナル版「新生児の身体診察」。成人 12〜20回／分：宮崎大学医学部附属病院

3倍。生まれたばかりの体は、大人の3倍の速さで空気を出し入れしています。

そして、その体は1日のほとんどを眠って過ごします。日本睡眠学会の資料では、生後1か月以内の新生児は1日のうち16〜17時間。1分に40〜60回の息を、1日16〜17時間、同じ部屋で。だからこの読み物は、赤ちゃんの部屋の空気が「どこを通ってくるか」から始めます。出典　日本睡眠学会「睡眠の発達」

その空気を、東京都はどの高さで測るか。子どもの部屋の空気を測るときの決まりがあります。

「同じ部屋でも高さによって濃度が違うことも考えられます｡ 3才児(身長100cm)なら60cm､赤ちゃんなら30cmのように子供の生活空間を目安に採取位置を検討しましょう｡」出典　東京都「化学物質の子供ガイドライン（室内空気編）」

赤ちゃんの空気は、床から30cm。大人が立って吸っている空気とは、別の空気です。

ここから七までは、東京都が乳幼児のいる家庭向けに出している指針とリーフレット、それにメーカーの手入れの案内を、家の場所ごとに並べ直したものです。「」の中は原文のまま。出典は各項目の下と、末尾に。書いている者のことは、七のあとで。
一

温度と湿度は、
赤ちゃんの高さで測る

まず、温湿度計を1つ。置く場所が決まっています。

「温・湿度計は、直射日光が当たらない場所に、赤ちゃんが普段いる高さに合わせて、設置しましょう。」出典　東京都リーフレット「赤ちゃんのための室内環境」

大人の目の高さではなく、寝ている赤ちゃんの高さ。上の30cmと同じ話です。

目安の数字

東京都の2つの資料で数字が少し違います。どちらもそのまま載せます。
東京都の指針 No.36東京都のリーフレット

幅があるのは、家も季節も違うからです。数字を覚えるより、測る習慣が先。東京都の指針も「温湿度計で定期的に確認する習慣をつけましょう。」と書いています。

湿度の上限は、はっきりしています。「湿度が60％を超えると、カビやダニが発生しやすくなります。」冬に加湿するなら、ここが天井です。出典　東京都「健康・快適居住環境の指針」指針No.4 湿度管理

冬に加湿するなら、この順で

  1. 測ってから「住宅内では、調理や入浴、洗濯物の乾燥などで自然と湿度が上昇していることがあるので、必ず湿度を計ってから加湿するようにしましょう。」リーフレットには「洗濯物やぬれタオルを室内に干すだけでも効果的です。」とも。出典　東京都「健康・快適居住環境の指針」指針No.4 湿度管理／東京都リーフレット「赤ちゃんのための室内環境」
  2. 水は毎日、取り替える「加湿器の水は毎日取り替え、タンク内やフィルターなどを定期的に清掃するようにしましょう。」厚生労働省も同じ：「超音波振動などの加湿器を使用するときには、毎日水を入れ替えて容器を洗浄しましょう。」出典　東京都「健康・快適居住環境の指針」指針No.5 除加湿時の衛生／厚生労働省「レジオネラ症」Q&A
  3. 入れるのは水道水「加湿器の給水には、水道水を使いましょう」。理由は「水道水に含まれる残留塩素には、消毒効果があるため」。タンクにぬめりが出たら「ぬめりを除去しましょう」。出典　東京都保健医療局「加湿器の衛生管理」（リーフレット「知っていますか レジオネラ－加湿器の衛生管理－」）
  4. しまう前に乾かす「使用終了時には乾燥させてから保管、使用再開時にはよく洗浄してから使用しましょう」。春にしまうときの話です。出典　東京都保健医療局「加湿器の衛生管理」（リーフレット「知っていますか レジオネラ－加湿器の衛生管理－」）
  5. 風を、赤ちゃんに当てない暖房も冷房も。「直接風が当たらないように、風向きを調整しましょう。」出典　東京都「健康・快適居住環境の指針」指針No.36 乳幼児の居住環境
二

換気は、
出口と入口をつくる

窓を1つ開けるだけでは、空気は動きにくい。東京都の指針は、こう書いています。

「室内の空気の流れをスムーズにするため、できるだけ対角線となるように空気の出入り口を２か所以上作りましょう。」出典　東京都「健康・快適居住環境の指針」指針No.1 換気
  1. 24時間換気は、止めない。給気口を家具でふさがない「24時間換気設備は、常に運転させることが原則です。外気を取り入れるための給気口が開いているか、また、家具などで給気口がふさがれていないかを確認しましょう。」ベビーベッドやタンスを入れたあとに、ふさいでいることがあります。出典　東京都「健康・快適居住環境の指針」指針No.1 換気
  2. 掃除のときは、窓を開ける「掃除機がけを行う際は、窓を開けて掃除機の排気を排出しましょう。」出典　東京都「健康・快適居住環境の指針」指針No.31 ダニアレルゲン
  3. 浴室と台所の換気扇は、すぐに止めない「浴室や台所など湿気が発生する場所では、換気扇はすぐには止めず、十分排気してから止めましょう。」出典　東京都リーフレット「赤ちゃんのための室内環境」
  4. 寝る前に5分「就寝前に５分程度の窓開け換気をすると、室内の湿気が逃げ、結露が軽減されます。」出典　東京都「健康・快適居住環境の指針」指針No.8 結露の防止
  5. 新しい家具が来た日は、多めに「特に、新築やリフォーム、家具の購入直後には、十分な換気、通風を行う必要があります。」出典　東京都「健康・快適居住環境の指針」指針No.36 乳幼児の居住環境
三

新しく買うものは、
洗う・乾かす・袋に入れる

出産前は、買うものが増えます。肌着、寝具、タンス、ぬいぐるみ。東京都の指針に、それぞれ一言ずつあります。

  1. 新しい肌着とパジャマは、一度水洗い「新しいパジャマや下着などはホルムアルデヒドが残留していることがありますので、水洗いしてから使用しましょう。」出典　東京都「健康・快適居住環境の指針」指針No.27 衣類・塗料など
  2. 新しいタンスは、拭いて、全部開けて、乾かす「お湯で絞ったぞうきんで拭いてから、風通しの良い所で引き出しを全部開けて乾かすと、効果があります。」ベビー用品をしまうときは「ビニール袋に入れておきましょう。」出典　東京都「健康・快適居住環境の指針」指針No.27 衣類・塗料など
  3. ぬいぐるみは、洗えるものを「ぬいぐるみを置く場合は、こまめに洗濯するか、ビニール袋に入れましょう。」出典　東京都「健康・快適居住環境の指針」指針No.31 ダニアレルゲン
  4. 防虫剤は、閉めた引き出しの中だけ「タンスや衣類の収納容器など、閉めきった狭い空間で、用法・用量を守り使うようにしましょう。」そして乳幼児の指針には「乳幼児のいる室内では、殺虫剤や防虫剤の使用は控えましょう。」出典　東京都「健康・快適居住環境の指針」指針No.28 殺虫剤・防虫剤など／東京都「健康・快適居住環境の指針」指針No.36 乳幼児の居住環境
  5. 香りは、書いてある量で柔軟剤も芳香剤も。「室内で香りの強い製品を使用する場合には、適正使用量を守り、必要以上に使用しないよう心掛けましょう。」出典　東京都保健医療局「柔軟仕上げ剤や芳香剤等の使用について」
四

水まわり：
浴室、洗面所、洗濯機

東京都のアンケートでは、過去3年にカビが生えたことのある世帯のうち、生えた場所は浴室が79.7%。押入れ・洗面所・寝室も20%を超えていました。この順に見ていきます。出典　東京都「健康・快適居住環境の指針」指針No.9 室内のカビ対策

浴室：最後に入った人がやること

  1. シャワーで流すTOTO：「最後に入浴した人が、シャワーで壁や床を洗い流し」。東京都の指針も「アカや石けんのカスはカビの絶好の栄養源ですので、使った後はよく洗い流すようにし」。出典　TOTO「浴室のまるごとお掃除」／東京都「健康・快適居住環境の指針」指針No.9 室内のカビ対策
  2. 水をかけて、温度を下げるLIXIL：「水のシャワーを浴室内にかけて「温度」を常温程度に下げてください。」出典　LIXIL Q&A「ユニットバスの洗い場の床にピンクや黒色の汚れがついた」
  3. 水気を取る「水切り用ワイパーやタオルを使って壁や床の水分をしっかり取り除くとより効果的に換気が出来ます。」出典　LIXIL Q&A「ユニットバスの洗い場の床にピンクや黒色の汚れがついた」
  4. 扉とフタを閉めて、換気扇を30分〜1時間「入浴中や入浴後は、浴室の扉をしっかり閉めて」「浴室のフタもきちんと閉めておきましょう。」時間は「入浴後は、換気扇なら30分～１時間、窓開けなら２～３時間程度以上の換気を行いましょう。」出典　東京都「健康・快適居住環境の指針」指針No.26 浴室の安全と衛生／東京都「健康・快適居住環境の指針」指針No.8 結露の防止
浴室ドアの下のゴム、天井の四隅、シャワーホースの根元、浴槽のフタの裏。月に1回、明かりをつけて。黒い点なら、塩素系のカビ取り剤。ただし七の決まりを先に。

洗面所と洗濯機

  1. 水滴を拭く「浴室の壁、流し、洗面所の回り、洗濯機の周辺などの水滴をタオルでよく拭き取りましょう。」出典　東京都「健康・快適居住環境の指針」指針No.32 カビアレルゲン
  2. 洗濯が終わったら、フタを開けておくパナソニック：「フタを開けたままにし、乾燥させておく。」脱いだ服は「洗濯機を使用するまでは洗濯機の中には、脱いだ衣類などは入れないようにしましょう。」出典　パナソニック UP LIFE「洗濯機から出る黒いカス（黒カビ）の対処法は？」（2026年2月3日）
  3. 洗剤は、書いてある量で「洗剤を入れ過ぎると、溶け残ってカビの栄養分に。」出典　パナソニック「洗濯槽の黒カビ 予防と対策」
  4. 糸くずフィルターは、洗濯のたび「洗濯のたびにお手入れをしてください。フィルターが目詰まりしていると、糸くずやほこりがフィルターにたまらず逆流し、衣類に付きやすくなります。」出典　パナソニック FAQ「【タテ型洗濯機】糸くずフィルターのお手入れ」
  5. 月に1回、槽洗浄「月に1回程度、衣類用塩素系漂白剤や次亜錠剤を使った「槽洗浄」コースでお手入れをしてください。」東芝は「洗濯・脱水槽のお手入れは1～2カ月に1回をおすすめします。」お酢やクエン酸は使わない。パナソニック：「お酢やクエン酸は、酸性のため、洗濯槽内の金属部品などを酸化させる場合があり」。出典　パナソニック FAQ「槽洗浄の頻度」／東芝ライフスタイル FAQ「洗濯・脱水槽のお手入れ」／パナソニック UP LIFE「洗濯機から出る黒いカス（黒カビ）の対処法は？」（2026年2月3日）
洗濯機槽のふちの内側を指でなぞる。洗い上がりの黒いカス。カスが付くなら、槽洗浄を1回。それでも出るなら、槽の裏側の話です（九）。

寝室：
布団、床、窓、エアコン

赤ちゃんが1日16〜17時間いる場所です。東京都の指針の数字が、いちばん多い章です。

  1. 床は3日に1回、1㎡に20秒「床の掃除機がけはできるだけ毎日行いましょう。少なくとも３日に１回は、１m2あたり20秒以上の時間をかけて丁寧に行いましょう。特に、寝室の床面への掃除機がけを頻繁に行うと効果的です。」6畳なら、ざっと3分半。出典　東京都「健康・快適居住環境の指針」指針No.31 ダニアレルゲン
  2. 掃除機の前に、拭く「掃除機がけの前に拭き掃除を行うと、掃除機の排気によるアレルゲンを含んだホコリの巻き上げが少なくなります。」順番が逆だと、舞い上がります。出典　東京都「健康・快適居住環境の指針」指針No.31 ダニアレルゲン
  3. 布団は干す。たたかない。週に1回、掃除機「布団を干した後、布団をたたくと、布団表面にダニアレルゲンが細かくなって浮き上がるため、寝ている時に吸込み、症状を悪化させることがあります。」代わりに「１週間に１回、1m2あたり20秒の時間をかけて、布団の表・裏に掃除機がけを行いましょう。」出典　東京都「健康・快適居住環境の指針」指針No.31 ダニアレルゲン
  4. 布団を敷くのは、寝る30分前に、窓を開けて「布団敷きは、就寝30分以上前に、窓を大きく開けて行いましょう。」出典　東京都「健康・快適居住環境の指針」指針No.31 ダニアレルゲン
  5. 窓の結露は拭く。家具は壁から5cm「窓などに結露した水はこまめに拭き取り」「家具を置くときは、後ろの壁と5㎝以上の空間を設けましょう。」北側の押入れは「床や側壁にスノコを置いて空気の流れをよくしましょう。」出典　東京都「健康・快適居住環境の指針」指針No.8 結露の防止

エアコン

  1. つけた瞬間の匂いを、かぐ「除湿器やルームクーラー、エアコンなどの始動時に、カビくさい臭いがしたら要注意です。」出典　東京都「健康・快適居住環境の指針」指針No.5 除加湿時の衛生
  2. フィルターは、2週間に1回「毎日使う時期は２週間に１回は清掃をしましょう。エアフィルターの清掃は、掃除機でホコリを吸引したり、汚れがひどいときは中性洗剤でつけ置き洗いを行いましょう。」季節の変わり目は「必ずフィルターを清掃してホコリを除去する」。出典　東京都「健康・快適居住環境の指針」指針No.5 除加湿時の衛生／東京都「健康・快適居住環境の指針」指針No.32 カビアレルゲン
  3. 風を、当てない「冷房のときにエアコンの風が体に長時間当たると、過剰に体温が奪われます。」出典　東京都「健康・快適居住環境の指針」指針No.36 乳幼児の居住環境

カビに、直接掃除機をかける

東京都の指針の言葉です。

「作業にあたっては、カビ（胞子）が飛散して周りに広がらないように注意してください。直接掃除機をかけると、カビの胞子をまき散らすことになるので注意しましょう。」出典　東京都「健康・快適居住環境の指針」指針No.9 室内のカビ対策

塩素系のカビ取り剤を、ほかの洗剤と一緒に使う

国民生活センターが2026年3月に出した注意です。

「塩素系洗浄剤は、必ず単独で使用しましょう。」出典　国民生活センター「住宅用塩素系洗浄剤の使い方－まぜるな危険！浴室などで事故が発生しています－」（2026年3月18日）

同じ資料の実験では、浴室でスプレーの塩素系洗浄剤と酸性洗浄剤を一緒に使うと「数分後には浴室内の塩素ガス濃度は16ppmを超えました。」使うときは「換気を十分に行い、保護具を着用しましょう。」使ったあとは「使用後は十分に水を流し、他の洗浄剤等を続けて使用することは避けましょう。」東京都の指針にも同じ注意があります：「酸性タイプの洗剤等を混ぜると、塩素ガスの発生をまねき大変危険です。」

八

フィルターの奥で、
見てきたもの

「フィルターは2週間に1回、洗っています」。そう言われたお宅のエアコンの、吹き出し口です。黒い点が並んでいました。

フィルターは入口の網です。そこを洗っても、奥の熱交換器と、風を送るファンには手が届かない。同じエアコンの、フィルターを外した奥。

この黒いのが、風の通り道に張り付いたまま、風を送っていました。分解して洗うと、こうなります。

1台分。洗う前、これはエアコンの中に貼り付いていたものです。

洗濯機も同じ構造です。洗濯物を入れる槽の外側に、もう1つ槽がある。あいだの隙間は外から見えません。四の槽洗浄をしても黒いカスが出るなら、その隙間の話です。

九

分解しないと洗えない場所と、
いつやるか

「クロカビ（クラドスポリウム）黒い斑点状のカビ。住宅のいたるところに生え、アレルギーの原因にもなる。浴室やトイレの壁・タイル目地、エアコン・加湿器・洗濯機の内部」出典　東京都「健康・快適居住環境の指針」指針No.9 室内のカビ対策

東京都の指針が挙げる「エアコン・加湿器・洗濯機の内部」のうち、加湿器は一でやれます。エアコンの熱交換器と送風ファン、洗濯槽の外側だけが、分解しないと手が届かない。一から七で書いたことは、全部その手前です。ここだけが、私たちの仕事です。

生まれてからだと、頼みにくくなります。分解した部品を並べて洗う2〜3時間を、赤ちゃんと一緒に家で待つことになる。迎える1〜2か月前、家に人が増える前が、いちばん静かに済みます。

急がなくていいか見分けるのは、五のエアコンの欄のとおり。何も見えなければ、今は急がなくていい。

書きたかったことは、ここまでです。
