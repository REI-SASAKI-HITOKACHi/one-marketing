# アンケートQRコード（現場携行用）

施工後にお客様へ提示して、その場でアンケートにお答えいただくための一式。

## ⚠️ 先に決めることがあります（重要）

QRに焼き込んでいるURLは **`https://lp.one-hitter.jp/survey/`** です。
**2026-09-05 時点で、このドメインはまだ引けません**（`lp.one-hitter.jp` は NXDOMAIN）。

紙に印刷してラミネートしたQRは、あとから中身を変えられません。
**だから、最初から最終URLで焼く必要があります。** そのために2つ必要です。

1. **T001：ネームギアで `lp` のAレコードを追加する**（ホスト名 `lp` ／ 種別 A ／ 値 `118.27.125.166`）
2. **T013：アンケートページの公開を承認する**

この2つが済むまで、印刷したQRを読み込んでもページは開きません。
**Netlifyの仮URL（`◯◯◯.netlify.app`）でQRを焼くのはやめてください。**
独自ドメインに移した時点で、配ったカードが全部死にます。

## ファイル

| ファイル | 中身 |
|---|---|
| `ONE_HITTER_アンケートQRカード_A4.pdf` | **これを印刷してください。** A4に名刺サイズ（91×55mm）が10枚 |
| `card.html` | 上のPDFの元。ブラウザで開いて Ctrl+P でも印刷できます（そちらの方がフォントが綺麗です） |
| `survey-watanabe.png` / `.svg` | 渡辺さん用のQR単体。`?staff=渡辺&src=qr` 付き |
| `survey-generic.png` / `.svg` | 担当者名なしのQR単体。`?src=qr` 付き |

SVGは拡大しても劣化しないので、大きく刷るとき（チラシ・車両・のぼり）はこちらを使ってください。

## URLに付けているパラメータ

| パラメータ | 何のため |
|---|---|
| `staff=渡辺` | アンケートのQ9が「渡辺へのメッセージ」になる。クチコミの下書きにも担当者名が入る |
| `src=qr` | QR経由の回答を、SMS経由と分けて数えるため |

**顧客IDは入れられません**（1枚のカードを全員に見せるため）。
そのためQR経由の回答では、お名前・ご連絡先の入力欄（Q10）が表示されます。
顧客台帳と確実に結びつけたい場合は、QRではなくSMS（顧客IDつきURL）を使ってください。
**QRは回答率を優先、SMSは台帳との結合を優先、という使い分けです。**

## 印刷のしかた

- **用紙**：厚手のマット紙かカード用紙。光沢紙はQRが反射して読み取りにくくなります
- **カラー／等倍で印刷してください。**「用紙に合わせる」で縮小するとQRが小さくなります
- 破線で切り分けて、**ラミネート**すると現場で長持ちします
- 印刷後、**必ず実機のスマホで1枚読み取って確認してください**

## 作り直すとき

割引率やURLを変えたら、次で作り直せます。

```bash
pip3 install segno
python3 - <<'PY'
import segno
segno.make("https://lp.one-hitter.jp/survey/?staff=渡辺&src=qr", error="h") \
     .save("lp/survey/qr/survey-watanabe.png", scale=20, border=4, dark="#14323D", light="#FFFFFF")
PY
```

誤り訂正レベルは **H（30%欠けても読める）** にしてあります。現場で汚れたり折れたりしても読めるようにするためです。

## 確認済みのこと

- QR画像2種とも、デコードして正しいURLになることを確認済み
- 生成したA4のPDFを300dpiで画像化し、**10枚すべてのQRが読み取れることを確認済み**
