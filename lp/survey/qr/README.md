# アンケートQRコード

施工後にお客様へ提示して、その場でアンケートにお答えいただくための一式。

## 運用：スマホの画面を見せる（印刷ではありません）

現場社員が **自分のスマホに画像を保存しておき、施工後にお客様へ画面を見せる** 運用です。
お客様は自分のスマホのカメラをその画面に向けるだけで開きます。

**この運用なら、URLはあとから変えられます。** 画像を1枚差し替えて保存し直すだけです。
（紙に印刷してしまうと変更できないので、そちらは今のところ使いません）

## ファイル

**まずこの2つ。現場のスマホに保存するのはこれです。**

| ファイル | 中身 |
|---|---|
| `phone-watanabe.png` | **渡辺さん用。** 1080×1920。`?staff=渡辺&src=qr` |
| `phone-generic.png` | 担当者名なし。他の社員が増えたとき用。`?src=qr` |

QRだけが欲しいとき（他の資材に載せる場合）はこちら。

| ファイル | 中身 |
|---|---|
| `survey-watanabe.png` / `.svg` | 渡辺さん用のQR単体 |
| `survey-generic.png` / `.svg` | 担当者名なしのQR単体 |

紙に刷る場合の一式も置いてありますが、**当面は使いません**。

| ファイル | 中身 |
|---|---|
| `ONE_HITTER_アンケートQRカード_A4.pdf` | A4に名刺サイズ10枚。印刷運用に切り替えるときに使う |
| `card.html` | 上のPDFの元 |

## URLについて

QRに入れているURLは **`https://lp.one-hitter.jp/survey/`** です。
**2026-09-05 時点で、このドメインはまだ引けません**（`lp.one-hitter.jp` は NXDOMAIN）。
`one-hitter.jp` の権威DNSは **ネームギア**（`ns1/ns2.namegear.co`）が持っているため、
ロリポップの管理画面ではこのレコードを足せません。

公開までに必要なのは2つ。

1. **T001：ネームギアで `lp` のAレコードを追加する**（ホスト名 `lp` ／ 種別 A ／ 値 `118.27.125.166`）
2. **T013：アンケートページの公開を承認する**

**ネームギアにログインできない場合の代替**は `docs/namegear-dns.md` を参照。
画面提示の運用ならQRの差し替えが効くので、Netlifyの仮URLで先行してもかまいません。

## URLに付けているパラメータ

| パラメータ | 何のため |
|---|---|
| `staff=渡辺` | アンケートのQ9が「渡辺へのメッセージ」になる。クチコミの下書きにも担当者名が入る |
| `src=qr` | QR経由の回答を、SMS経由と分けて数えるため |

**顧客IDは入れられません**（1枚のカードを全員に見せるため）。
そのためQR経由の回答では、お名前・ご連絡先の入力欄（Q10）が表示されます。
顧客台帳と確実に結びつけたい場合は、QRではなくSMS（顧客IDつきURL）を使ってください。
**QRは回答率を優先、SMSは台帳との結合を優先、という使い分けです。**

## 現場スマホへの入れ方

1. `phone-watanabe.png` を渡辺さんのスマホに送る（LINEでもメールでも可）
2. **写真アプリに保存**する。よく使うのでアルバムに入れておくか、お気に入りに登録
3. お客様に見せるときは **画面の明るさを上げる**。暗いと読み取りにくくなります
4. 保護フィルムの映り込みが強い端末は、少し角度をつけると読めます

**渡す前に、別のスマホで1回読み取ってみてください。**

## 作り直すとき

割引率やURLを変えたら、次で作り直せます。

```bash
pip3 install segno
python3 - <<'PY'
import segno
segno.make("https://lp.one-hitter.jp/survey/?staff=渡辺&src=qr", error="h") \
     .save("lp/survey/qr/survey-watanabe.png", scale=20, border=4, dark="#14323D", light="#FFFFFF")
PY
```

誤り訂正レベルは用途で分けています。

- **画面提示用（`phone-*.png`）は M**。汚れや折れがない前提なので、模様を粗くして
  カメラが拾いやすいことを優先しています
- **印刷用（`survey-*.png/svg`）は H**（30%欠けても読める）。汚れ・折れに耐えるため

## 確認済みのこと

- 画面提示用2種・QR単体2種とも、デコードして正しいURLになることを確認済み
- 印刷用のA4 PDFを300dpiで画像化し、10枚すべてのQRが読み取れることを確認済み
