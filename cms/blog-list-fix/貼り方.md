**ブラウザ担当の実行環境が、この欄に触れる操作を拒否しました**（下の「なぜ手で貼るのか」）。

## 貼るもの

**`cms/blog-list-fix/fix.css`（3,496字）の全文。**このフォルダに置いてあります。

## 貼る場所

```
https://one-hitter.jp/_sys/contents/resource/1018/
```

「共通CSS」の欄（`input_ci[common_css_url]`）。**2026-10-08 時点で 49,961字**あり、
**末尾はちょうど `</style>` で終わっています**（後ろに空白なし）。

**いちばん最後の `</style>` の、すぐ前**に貼ってください。

```
……（既存のCSS 約5万字）……
        ← ここに fix.css の中身を貼る
</style>        ← これが最後の行。消さない
```

⚠ **今ある中身は1文字も消さないこと。**保存すると欄の中身が丸ごと置き換わるので、
消すとサイト全体の見た目が崩れます。

**カーソルの合わせ方**：欄の中をクリック → `Ctrl+End`（末尾へ）→ `←` を8回（`</style>` の前）→ 貼り付け。
