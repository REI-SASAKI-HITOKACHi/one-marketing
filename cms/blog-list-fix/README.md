# 公式サイト ブログ一覧の崩れ（2026-10-08・依頼 20261008-03-lp）

`before-after.jpg`：左＝今の本番（2000px幅）、中＝修正CSSを当てた見え方（同じ幅）、右＝スマホ（390px）。

## 原因
1. **カードの向きが横のまま3列にされていた（題名のはみ出しと、画像が細い帯になる原因）**
   - テーマ（data-lib 29505）は、一覧のカードを「左に画像50%・右に本文」の**横並び**で作っている
     （`article{display:flex}`、`.-w-image{width:50%;margin-right:3rem}`、`a{padding:4rem}`、
     題名の箱 `.-w-blog-text.-w-pc{position:absolute;padding-top:4rem}`、`p.-w-more{position:absolute;right:0;bottom:0}`）
   - 共通の追加CSS（`<style id="codex-brand-override">`）で、一覧を **3列のグリッド**に変えたが、カードを縦に直していなかった
   - その結果、幅 約200px の列の中に画像と本文が横並びになり、画像は細い帯に、題名は absolute のまま高さを無視してはみ出し、MORE とカテゴリの札に重なった。題名 20px で1行2〜3文字
2. **赤い四角**：画像の上を赤い帯が横切る読み込み時の演出（`.-w-image::after`）。スクロールで画面に入るまで赤いまま
3. **画像がぼやける**：アイキャッチが 64×48px の種画像（browser が入れ直し中）。CSS では直らない

## 直し方（CMS で変える場所）
- **リソース 1018「フォント」の `common_css_url`**（＝ `<style id="codex-brand-override">` が入っている欄。`cms/css-audit/HOW-TO-APPLY.md` と同じ場所）
- その中身の**最後（`</style>` の直前）に `fix.css` をそのまま足す**だけ。既存のルールは消さない
  - 一覧の本体（`.-w-blog_main`）だけが対象。右の「NEW」の小さい一覧、記事ページ、ほかのページには効かない
- 戻すとき：足した部分（`/* --- 2026-10-08 ブログ一覧の崩れの修正` 〜 `/* --- /ブログ一覧の崩れの修正 --- */`）を消す

## fix.css でやること
- カードを縦（画像が上 4:3・文字が下）に。外側の 4rem の余白と背景を外す
- 題名は 17px・**3行で切る**（それ以上は「…」）。抜粋の文は出さない（3列では読めない長さになるため）
- MORE はカードの右下に固定。題名と重ならない
- 赤い帯の演出は一覧の本体では出さない
- 幅 1100px 以下は2列、768px 以下は1列（スマホはテーマのスマホ用の表示のまま、題名を3行で切る）

## 確かめたこと（本番のページに fix.css を差し込んで）
| 幅 | 画像（幅×高さ） | 題名の高さ | MORE と重ならない |
|---|---|---|---|
| 2000px | 253×190（3列） | 最大79px＝3行 | ○ |
| 1280px | 253×190（3列） | 最大79px | ○ |
| 1024px | 292×219（2列） | 最大79px | ○ |
| 390px | 281×211（1列） | （スマホ用の題名） | ○ |

## 別に直すとよいこと
- 題名の末尾の「…」は CMS が文字数で切っている（PC 約30字・スマホ約20字）。一覧の表示設定で文字数を増やせるなら、3行で切る CSS に任せられる
- アイキャッチの入れ直し（browser 作業中）が済めば、画像のぼやけも消える
