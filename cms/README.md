# 公式サイト（one-hitter.jp）の改修作業

## 分かったこと

- CMS は独自PHP製（管理UIは Material Components、リッチテキストは Jodit）。管理画面は `/_sys/`。
- **料金表は `/menu/` ではなく TOPページに描画されている。**
  `/menu/` は「SERVICE サービス詳細」への導線だけで、価格は1円も載っていない。
- 料金を生成しているのは 管理画面 → コンテンツ → アーティクル → **メニュー（アーティクルID 804）** の11レコード。
  - 編集URL: `/_sys/contents/article/804/<記事ID>/`
  - 記事ID: 1299, 1300, 1301, 1302, 1303, 1304, 1353, 1354, 1412, 1500, 1683
  - フィールド: `page[name]` / `input[h_ttl]` / `input[price]`(Joditリッチテキスト) / `input[text]` / `input[image]` / `display` / `pbd` / `ped`
  - 保存は POST に `_[action]=datastore` と `datastore[type]=article`
- **アーティクル単位の下書きは存在しない。保存＝即公開。**
  可視性は `display=0`（非公開）と公開日時の未来指定のみ。
- サイト全体の「ページ編集セッション」という下書き機構はあるが、
  **未公開セッションが87件（2022〜2026-05-31）滞留**しており、
  新しくセッションを開始すると他者の未公開作業を壊す恐れがある。使用は保留。
