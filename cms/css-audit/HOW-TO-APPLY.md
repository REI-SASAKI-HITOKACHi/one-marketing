# 注入CSSの差し替え手順（オーナー作業）

貼り付けるファイル: **`cms/css-audit/final-with-style-tag.txt`**

## 何を変えるのか

管理画面「リソース → フォント」の **「スクリプトタグ用フォントURL」** という欄に、
サイト全体へ出力される `<style id="codex-brand-override">` が入っています。
現在267KB。これを整理したものに差し替えます。

| | 現行 | 差し替え後 |
|---|---:|---:|
| 文字数 | 270,269 | 255,617 |
| ルール数 | 325 | 267 |
| `!important` | 437 | 351 |

## 変更内容

1. **どのページにもマッチしないセレクタを削除**（存在しないクラス `-w-staff` 等）
2. **後続に完全上書きされていて一度も適用されないルールを削除**
3. **差し込まれている「98.8%」を「98.6%」に統一**（3箇所）
4. **文字化けした content:（2023年・175名の記述）を空にする**（3箇所）
5. **HTML本文の「ご利用者98.8％が…」を、根拠つきの正しい一文に差し替え**（末尾に追記したブロック）

表示の計算結果は 1600 / 1280 / 760 / 390px の4条件で**差分0件**を機械検証済みです。
構文エラーもゼロ。

## 手順

1. https://one-hitter.jp/_sys/ にログイン
2. 左メニュー **リソース → フォント**
3. **「スクリプトタグ用フォントURL」** の欄を開く
4. **いまの中身を全選択してコピーし、手元のテキストファイルに保存**（← 復旧用。必ず）
5. 中身を全部消して、`final-with-style-tag.txt` の中身をすべて貼り付ける
6. 保存

## 貼り付け後に確認してほしいこと

- TOPページの見た目が変わっていないこと
- ヒーローの数字が **98.6%** になっていること
- その下の一文が「ご利用者98.6％が『他人に勧めたい会社』／※2023年1月〜2025年12月／回答209名中206名」になっていること
- スマホでも崩れていないこと

崩れていたら、手順4で保存した中身を貼り戻せば元に戻ります。
`cms/css-audit/current.css` にも変更前の全文があります。

## まだやっていないこと

- **base64画像のファイル化**（267KBのうち205KBがこれ）。
  画像のアップロード先を調査中です。これが済めば 255KB → 約50KB になります。
- スマホ版ヒーローの Pexels 直リンクの自社取り込み（同上）
- 末尾の暫定ブロックの削除。ページ編集セッションでHTML本文を直したら不要になります。
  差し替えるHTML本文はこれです:

  ```
  ご利用者98.6％が「他人に勧めたい会社」 ※2023年1月〜2025年12月／回答209名中206名
  ```
