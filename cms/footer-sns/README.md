# フッターにInstagram・Facebookのリンクを置く

作成 2026-09-11 ／ LP・サイト担当 ／ **✅ 2026-09-11 反映済み（オーナーが実施）**

> **反映確認（LP・サイト担当 2026-09-11）**
> 5ページすべてにInstagramとFacebookのリンクが1本ずつ出ています。
> **出た場所は予想どおりフッターではなく、追従バーの「SNSを見る」の中**でした。
> `<ul class="-w-sns-sub">` に Facebook → LINE → Instagram の順でテーマ標準のSVGアイコンが並び、
> `target="_blank"` もテーマ側が付けています。**フッターには出ていません。**
> CMOの判断は「場所はそのままでよい（目的は導線0件の解消）」（`20260911-05-lp` 返信）。

依頼元：掲示板 `20260911-01-lp`（ネット流入施策担当）
背景：公式サイト4ページの外部リンクが公式LINEの1本だけで、SNSへの導線が0件だった
（`docs/sns-90日運用案.md` 1-1）。CMOが「置く」と決定（`20260910-02-cmo` 返信2）。

## ✅ 入れ方が分かりました（2026-09-11）：HTMLは貼りません

**リソース5「Webサイト基本情報」に、テーマ専用のSNS URL欄が最初から用意されています。**

| 欄 | 現在値 | 入れる値 |
|---|---|---|
| `input_ci[instagram_url]` | （空） | `https://www.instagram.com/onehitter.jp/` |
| `input_ci[facebook_url]` | （空） | `https://www.facebook.com/people/One-Hitter/100084190801350/` |

編集URL: `/_sys/contents/resource/5/`（電話番号と同じ画面。**1回の保存で両方済みます**）

`line_url` が埋まっていて、公開ページの追従バーの「SNSを見る」の中に
LINEアイコンが出ています。その `<ul class="-w-sns-sub">` の中に、LINEの `<li>` の後ろへ
**空のスロットが4つ並んでいます。** 上の2欄を埋めると、ここにテーマ標準のアイコンが入ります。

### これに変えた理由

- **ページ編集セッションが要りません。** フッターのHTMLを直接触る方法だと、
  未公開セッションが86件滞留しているページビルダーに入ることになります（`../README.md`）
- 画像の追加も不要です（テーマがアイコンを持っています）
- `target="_blank"` などもテーマ側が付けます

### ⚠️ 出る場所が「フッター」ではなく「追従バーのSNS」になります

承認をもらった文面は「フッターに」でしたが、テーマの欄を使うと出るのは
**追従バーの「SNSを見る」の中**です（フッターにも出るかは、値を入れてみないと分かりません）。
依頼の目的は「公式サイトからSNSへの導線が0件」の解消（`docs/sns-90日運用案.md` 1-1）なので
達成できますが、**場所が違う点は反映後に実測して報告します。**

なお、下の「貼る内容」は**使いません**。テーマの欄が無かった場合の控えとして残します。

```html
<a href="https://www.instagram.com/onehitter.jp/" target="_blank" rel="noopener">Instagram</a>
<a href="https://www.facebook.com/people/One-Hitter/100084190801350/" target="_blank" rel="noopener">Facebook</a>
```

## 入れる場所（テーマの欄が無かった場合の控え）

フッターの `.foot-links` 相当の行の末尾。現在ここには次が並んでいます。

```
個人情報の取扱いについて　｜　公式サイト
```

**新しいブロックは作りません。** フッターの情報量を増やすと電話番号と住所が埋もれます。

## 決めたこと

- **アイコンではなく文字にしました。** CMSへの画像追加が不要で、公式サイトの他のリンクが
  全て文字なので浮きません
- `target="_blank"` と `rel="noopener"` を付けます。`noopener` が無いと、
  開いた先のページから元のタブを操作できてしまいます

## URLの確認状況

| | URL | 確認 |
|---|---|---|
| Facebook | `https://www.facebook.com/people/One-Hitter/100084190801350/` | **HTTP 200** |
| Instagram | `https://www.instagram.com/onehitter.jp/` | **HTTP 200（2026-09-11 確認）** |

2026-09-11 に両方とも 200 を確認しました。Facebook は User-Agent によって 400 を返すことが
あります（ブラウザでは開けます）ので、確認は複数の方法で行うこと。

## 後で差し替えが要るもの

- **FacebookのURLは `/people/…/数字ID/` 形式です。** オーナーがページにユーザーネームを
  付けたら短いURLに変わります。差し替えはネット流入担当から再度依頼が来ます
- **Googleビジネスプロフィールのリンクは未定。** 管理者の確定待ち（CMOが確認中）

## 二重導線の件は決着（2026-09-11）

リソース `2234`（インスタ投稿表示）とSNSリンクの二重導線について、
**CMOの判断は「両方残す」**（掲示板 `20260911-04-lp`）。
「埋め込みは見せる、リンクは行く」で役目が違うため、消す理由が出るまで触らない。

## 反映後の確認方法

```bash
curl -sS https://one-hitter.jp/ | grep -o 'href="https://www\.\(instagram\|facebook\)[^"]*"'
# Instagram と Facebook のURLが1つずつ出ること

curl -sS https://one-hitter.jp/ | grep -c 'rel="noopener"'
# SNSリンクのぶん増えていること
```
