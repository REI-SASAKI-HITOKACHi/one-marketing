### なぜ長く見つからなかったか

**`080-1755-7275` という連結した文字列は、CMSのどこにも保存されていません。**
3つの欄に分割して入っているためです。記事8件・リソース17件を全フレーム走査しても
0件だったのはこれが理由で、「HTTP取得では値が見えないから」ではありませんでした
（ブラウザで見ても0件でした）。**`1755` と `7275` で部分一致検索をかけて見つかりました。**

同じ探し方が要るものは他にもあります。住所も `address_zip1`/`zip2`/`address`/`address2` の
4欄に分かれています。**今後この手の全文検索は、区切りを含まない断片で当てること。**
