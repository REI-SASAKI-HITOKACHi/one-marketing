# `/menu/` ページの差し替え手順（オーナー作業）

貼り付けるファイル: **`cms/menu-page/paste-into-cms.html`**（約93KB）

## なぜ手作業なのか

`/menu/` の本文はページビルダーのブロックで、管理画面側に編集フォームがありません。
編集できるのはフロント側の「ページ編集セッション」だけで、これを新しく開始すると
滞留している未公開セッション86件に影響する恐れがあります。
ブラウザから開いていただくのが最も安全です。

## 事前の注意

- **貼り付ける前に、いまの中身を必ずコピーして手元に保存してください。**
  ソースモードで全選択してコピーし、テキストファイルに貼っておけば、失敗しても戻せます。
- ブロックの差し替えは即公開です。アクセスの少ない時間帯を選んでください。

## 手順

1. https://one-hitter.jp/_sys/ にログイン
2. 画面上部の **「ページ編集」** を押す
   - 滞留セッションについての警告が出ます。**既存のセッションを「再開」しないでください。**
     他の作業を壊す恐れがあります。新規で開始してください
   - 別タブでサイトが開き、その上に編集UIが被さります
3. `/menu/` へ移動
4. 本文ブロック（見出し **「水まわりからメニューにない箇所まで」** の塊）をクリックして編集状態にする
5. ツールバーの **ソースボタン（`< >`）** を押してHTMLソース表示に切り替える
6. **いまの中身を全選択してコピーし、手元のテキストファイルに保存**（← 復旧用）
7. 中身を全部消して、`paste-into-cms.html` の中身をすべて貼り付ける
8. ソースモードを解除して、表示が崩れていないか確認
9. 保存 → 公開

## 貼り付け後に確認してほしいこと

- 料金一覧の12項目が、点線の右に金額が並んでいるか
- 「メニュー詳細」が、左に価格・右に説明の2段組になっているか（PCの場合）
- スマホで横スクロールが出ないか
- 法人セクションの黒い背景が出ているか

崩れていたら、手順6で保存した元の中身を貼り戻せば元に戻ります。

## 技術的な前提（作り手向けメモ）

- このCMSのリッチテキスト（Jodit）は **`<style>` と `<script>` を除去します**。
  そのため、このファイルは**すべてインラインstyleだけで組んであります**。
  外部CSSにもリソース1018にも依存しません。
- 同じ理由で `@media` クエリと `::before` が使えないため、
  レスポンシブは flex-wrap と `clamp()` で、箇条書きの中黒は実文字で実現しています。
- フォントはWebフォントを使わず、OS標準の明朝・ゴシックで組んでいます。
  Webフォントを当てたい場合は、リソース1018に数行足せば可能ですが、
  あちらは267KBのCSSが入っていて site-wide なので、整理してからにしたほうが安全です。
- `class` は残してあります（`oh-menu-` 接頭辞）。後からCSSで調整したくなったときの取っ掛かりになります。
- 元のクラス版は `cms/menu-page/proposed-menu.html`。
  インライン版はそこから `/tmp/claude-0/cms/inline.py` で生成しています。
