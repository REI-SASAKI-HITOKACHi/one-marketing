## D. 自動割引

`auto_discount_enabled` を一時的に `TRUE` にし、`adminRefreshCache()` してから実施する。
**確認後は必ず `FALSE` に戻し、もう一度 `adminRefreshCache()` すること。**

- [ ] 1月 → 15%
- [ ] 3月 → 10%
- [ ] 9月 → 10%
- [ ] ノーマル5台 → 500円/台
- [ ] ノーマル11台 → 1,000円/台
- [ ] ロボ5台 → 1,000円/台
- [ ] 業務用2台 → 5,000円/台

## E. 変則割引 ★今回の追加機能

### 調整行

- [ ] 「＋ 値引きを追加」で行が増える
- [ ] 名称・円/%・金額・税区分を入力できる
- [ ] 定額の値引きが合計に反映される
- [ ] %の値引きが合計に反映される
- [ ] 「率の対象」を明細小計／課税対象計で切り替えられる
- [ ] 税区分「課税」にすると消費税も下がる
- [ ] 税区分「非課税」にすると消費税は変わらない
- [ ] 「＋ 割増を追加」で追加作業費などを加算できる
- [ ] 複数行を追加できる
- [ ] 削除できる
- [ ] **PDFに入力した名称がそのまま印字される**
- [ ] 金額欄が空・0の行はPDFに出ない

### 明細ごとの値引き

- [ ] メニュー行の「値引き」ボタンで入力欄が開く
- [ ] 円で入力できる
- [ ] %で入力できる
- [ ] 「値引き取消」で入力欄が閉じ、値引きが消える
- [ ] PDFで「◯◯ 値引き」の独立行として出る
- [ ] PDFのメニュー行は 単価×数量＝金額 のまま崩れていない
- [ ] 明細金額より大きい値引きを入れても、その明細の金額を超えて引かれない

### 合計を指定額に合わせる

- [ ] 金額を入れると合計が**ちょうどその額**になる
- [ ] 現在の合計より小さい額 → 端数調整（値引き）が入る
- [ ] 現在の合計より大きい額 → 端数調整（割増）が入る
- [ ] 高速代が0円でもちょうどの額に着地する
- [ ] 「解除」で元の合計に戻る
- [ ] PDFに「端数調整」の行が出る
- [ ] PDFの `小計 + 消費税 = 合計` が成立している

### ガードレール

- [ ] 手動値引きを入れると「内容確認」欄に表示される
- [ ] 手動値引きだけでは**代表者確認メールのボタンが出ない**
- [ ] 明細小計の30%以上の値引きで追加の警告が出る
- [ ] 単価未設定メニューを入れると「代表者確認の対象」欄に出て、ボタンが出る
