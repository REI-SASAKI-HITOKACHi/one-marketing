# 見積アプリの鍵：貼る手順（1枚）

2026-10-16。和真さんのスマホで「このスマホでは、まだ見積アプリを使えません」が出て現場が止まった件の直し。
コミット `caf62d2`（ブランチ `claude/quotation-app-performance-discount-7gr1e8`）。browser が嶺さんのPCで代行できる形。

## 直るもの
- 鍵をリンクの `?k=` に持たせる → ホーム画面のアイコンを押すだけで開く
- 鍵が消えたら、画面に出る欄に **6桁の暗証番号（パスワード）** を入れれば戻る。専用リンクは要らない
- 暗証番号は5回間違えると60分止まる。合計15回で、嶺さんが解除するまで止まる

## 手順（この順番で）

| # | 誰が | 何をする |
|---|---|---|
| 0 | browser | **今のバージョン番号を控える**（戻し先）。稼働中の全本数が同じバージョンか確認 |
| 1 | browser | `deploy-paste/` の4ファイル（コード.gs・Index・JavaScript・Style）を貼る |
| 2 | browser | 新バージョンを作り、**稼働中の全本数**を新バージョンに差し替える（1本でも旧版に残さない） |
| 3 | **嶺さん** | **暗証番号を決める**（和真さんにだけ伝える。掲示板・LINEグループ・リポジトリに書かない）。単純な並び（000000・123456 など）は設定できない |
| 4 | 嶺さん／browser | エディタで次を1回実行（6桁の部分は3で決めた番号）：<br>`adminSetUiPin('和真', '6桁')` |
| 5 | 嶺さん／browser | エディタで次を1回実行（URLは和真さんがいつも使っている `…/exec`）：<br>`adminAddUiKey('和真', 'https://script.google.com/macros/s/…/exec')`<br>→ 新しいリンクが出る。**LINEの個別トークで和真さんに送る**（グループには貼らない） |
| 6 | **和真さん** | 5のリンクを開き、**そのまま「ホーム画面に追加」**（古いアイコンは消す）。暗証番号は口頭かLINE個別で伝える |

- エディタの関数プルダウンが切り替わらないときは、嶺さんが手で選んで ▶ を押す
- 3〜5の関数はどれも所有者がエディタから実行するものです（画面からは動かない）

## 確かめること（和真さんのスマホ）
1. 6でホーム画面に追加し直したアイコンから開ける
2. **翌日**もそのアイコンから開ける
3. 古いアイコンなど鍵が合わない状態で開くと、暗証番号の欄が出て、入れると戻る

1 が駄目なら（アイコンにURLの鍵が残らない場合）、暗証番号が毎回の入口になります。その場合は quotation に連絡。

## 困ったとき
| 状況 | 対応 |
|---|---|
| 暗証番号を忘れた | `adminSetUiPin('和真', '新しい6桁')` で決め直す |
| 「間違いが続いたため止めています」 | 60分待つ。急ぐときは `adminClearPinLock()` |
| 「暗証番号は使えなくなっています」 | `adminClearPinLock()` を実行（合計15回間違えた状態） |
| 鍵つきリンクを他人に送ってしまった | `adminAddUiKey('和真', '…/exec')` で作り直す（前の鍵は止まる）→ 新しいリンクを送り直す。暗証番号はそのまま使える |
| 画面が「準備中」になる | 鍵が1つも無い。`adminAddUiKey` を実行 |
| 元に戻す | 控えた前のバージョンに差し替え。**ただし @8 より前（2026-09-29 のセキュリティ修正より前）には戻さない** |

詳しい仕組みは `docs/README.md` の「画面の鍵」。
