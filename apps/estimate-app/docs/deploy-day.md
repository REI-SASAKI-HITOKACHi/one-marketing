**嶺さんが在席の回に、browser が1回でまとめてやる。** 途中で止めない（コードだけ先に入れて暗証番号が未設定のまま放置しない）。所要の目安：30〜40分。

## 始める前に（browser）
- [ ] 稼働中のデプロイを一覧し、**どれが何番のバージョンか**を控える（戻し先。2026-10-12 時点は @9）
- [ ] 嶺さんが **暗証番号（6桁）を決めてある**（和真さんにだけ伝える。ここ・掲示板・グループには書かない。000000・123456 などは設定できない）
- [ ] 和真さんがいつも使っている見積アプリのURL（`…/exec`）が手元にある（掲示板・リポジトリには書かない）

## 手順 1：コードを貼って、全本数を新バージョンに（browser）
1. `deploy-paste/` の4ファイル（コード.gs・Index・JavaScript・Style）を貼る
2. 新バージョンを作る → **稼働中の全本数**をそのバージョンに差し替える（1本でも旧版に残さない）
3. ✔ 確認：デプロイ一覧で全本数が同じ新バージョン

## 手順 2：暗証番号を設定する（嶺さんのエディタで。**手順1の直後に**）
1. エディタで `adminSetUiPin('和真', '決めた6桁')` を実行
2. ✔ 確認：ログに「暗証番号を設定しました」。`adminListUiKeys()` で「暗証番号を決めている人：和真」
- 関数のプルダウンが切り替わらないときは、嶺さんが手で選んで ▶ を押す
- ※ 手順1だけで止まっても、いま鍵が使えている人は動き続ける（鍵は変わらない）。ただし、**暗証番号の欄に入れても通らない**状態なので、手順2まで続けてやり切る

## 手順 3：鍵つきのリンクを出して、和真さんに送る（嶺さんのエディタ → LINE個別）
1. `adminAddUiKey('和真', 'いつもの…/exec')` を実行 → 新しいリンクが出る（鍵が新しくなる。古い鍵・古いアイコンは止まる。**暗証番号で戻れる**）
2. LINEの**個別トーク**で和真さんに送る（グループ・掲示板には貼らない）。3行の案内文は別紙（cmo の下書き）
3. 暗証番号は**口頭か別のLINE個別**で和真さんに伝える

## 手順 4：本番マスタの13セルを直す（browser、同じ回で）
- 一覧は掲示板 `20261016-05` の返信どおり。**メニューマスタ列H**：O001=1000／O002=5000／O003=3000／O004=3000／O005=3000／O006=5000／O007=18000／M012=18000／O010=3000／O011=3000／O012=7000／M015=48000、**割引繁忙期マスタ列H**：SET_M009=5000（行番号ではなくID・メニューIDで探す）

## 失敗したとき・戻すとき
| 状況 | 対応 |
|---|---|
| 画面が開かない・おかしい | 手順1で控えた**前のバージョン**に全本数を差し替える（暗証番号の設定は残るが、旧版には影響しない）。**ただし 2026-09-29 のセキュリティ修正（@8）より前には戻さない** |
| 暗証番号を忘れた・変えたい | `adminSetUiPin('和真', '新しい6桁')` |
| 「間違いが続いたため止めています」 | 60分待つ。急ぐなら `adminClearPinLock()` |
| 鍵つきリンクを他人に送ってしまった | `adminAddUiKey('和真', '…/exec')` で作り直し、新しいリンクを送り直す |
| 価格が直らない（マスタの書き換えミス） | 該当セルを元の値に戻す（O002=5500 など）→ `adminRefreshCache()`。**コードを戻す必要はない** |
| 「準備中」と出る | 鍵が1つも無い状態。`adminAddUiKey` を実行 |

関連：鍵の仕組みは `docs/README.md`「画面の鍵」、鍵だけの手順は `docs/deploy-key-2026-10-16.md`。
