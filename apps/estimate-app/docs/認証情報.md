## 外部API（doPost）の合言葉

見積アプリを外のプログラムから呼ぶための合言葉。`docs/external-api.md` 参照。

| | |
|---|---|
| 名前 | `API_SHARED_TOKEN` |
| 置き場所① | **Apps Script のスクリプトプロパティ**（見積アプリのプロジェクト） |
| 置き場所② | **`~/.config/one-hitter/`**（呼ぶ側の手元。CMOスレッド） |
| 設定する | `adminSetApiToken('…')` をエディタで1回実行 |
| 確認する | `adminCheckApiToken()`（設定の有無だけ。値は出ない） |
| 止める | `adminClearApiToken()`（デプロイを触らずに即座に閉じる） |
| 作り方 | `openssl rand -base64 32` |
| 条件 | 32文字以上。他で使い回さない |

**未設定のあいだ、外部APIは全リクエストを拒否します。** 公開設定だけ先に済ませても実害は出ません。

### 替えるとき

1. 新しい値を作る（`openssl rand -base64 32`）
2. `adminSetApiToken('新しい値')` を実行
3. 呼ぶ側の `~/.config/one-hitter/` を更新

**2と3のあいだ、呼ぶ側は `認証に失敗しました。` を受け取ります。** 短時間で済ませること。
漏れたと思ったら、この手順でいつでも替えられます。

### やってはいけないこと

- リポジトリに書く（このファイルを含む）
- 掲示板に書く（`claude/org` も git です）
- 見積書・請求書のPDFやメール下書きに含める
- `adminSetApiToken('…')` の引数をエディタに残したままにする（**実行後に必ず消す**）

## そのほか

見積アプリが使う Google のリソースID（マスタ、帳票テンプレート、PDF保存フォルダ）は
`src/code.gs` の `APP` に直接書いてあります。**これらは秘密ではありません**
（ファイルを開ける人が既にアクセス権を持っている）。合言葉とは扱いが違います。
