網の動き

ルール（全部ここに書く）

運営（ワンヒッター）が持つのは権利。決めるのはみんな。ここに無いルールは無い。

単価の決め方
既定の取り分

1. 何を見せるか（開示の3層）

  • 全員：メニュー・エリア（区市）・日程・請求額・外部手数料・施工額・取り分率・成立したか
  • 成立した相手だけ：お客様の氏名・住所・電話・連絡事項
  • 運営も含めて誰も：お客様情報を自社の営業に使わない

2. 値決め

網は率も単価表も決めない。出す人が案件ごとに請求額と施工額を書き、網は取り分率と相場の中央値を見せるだけ。受ける人は自分の最低受け額を決めておく。

仮置き（9/26まで）：施工額の既定値は手取りの75%。 ポータルの手数料（18〜22%）と本舗ロイヤリティ（約28%）の間。石田君との相談で見直す。

3. 現場の名乗り

  • 現場では元請けの名前で名乗る。首かけカードに「○○ 協力店」と表示
  • 自社の名刺・チラシは渡さない
  • お客様から直接の再依頼が来たら、元請けに戻す。または紹介料（原則12%）を元請けに払う

4. 事故と責任

  • 参加条件：賠償責任保険に加入（証券番号を登録）
  • お客様への窓口は元請け。費用は施工者（保険で賄う）
  • やり直し訪問は施工者の負担

5. 受注停止の基準（自動判定・本人に通知）

  • 直近3か月の元請け評価の平均が ★2.5 未満
  • 直近3か月のやり直し訪問が 3件以上
  • お客様情報を自社営業に使った（1回で停止）
  • 停止と復帰は自動。判定ログは本人が見られる

数値は叩き台。投票で変える。

6. 運営（ワンヒッター）の権限

  • システムの所有・開発・運営主体・ブランドの商標を持つ
  • 手で介入できるのは緊急停止だけ。介入したら全員に理由を通知
  • 自社の案件も同じルールで出す。優先権は無い
  • 取引額に比例する手数料は取らない

6-2. 入金サイト（お金の流れ）

  • 基本は元請けがお客様から領収 → 着金後5日以内に下請けへ支払う
  • 案件を出すとき、お客様からの入金予定日と下請けへの支払予定日を必ず開示する。受ける人はそれを確認してから手を挙げる
  • 下請けが現場で領収する案件は、出すときにその印を付ける。受ける人は領収後5日以内に元請け分を支払うことに同意してから手を挙げる
  • お客様の入金が遅れても、元請けは支払予定日に払う（原則）。 大型案件などで難しいときは「支払が遅れる場合の申し送り」で下請けに新しい日付と理由を通知できる。ただし遅延は1件として記録され、募集時の事業者情報に「支払遅延 ○件」として全員に見える
  • 案件の完了は双方のクローズで決まる。 支払予定日に元請け・下請けの双方へURL付きの通知が届き、各自が「支払った／入金を確認した」「クレームは発生していない」等にチェックして「本案件をクローズする」を押す。どちらかが未押下の間は毎日対応依頼メールが届く
  • 請求書は成立条件から自動作成。施工日以降、当事者どちらもPDFで保存できる。システム上の保存は施工日から60日
  • 振込手数料は払う側。カード等の決済手数料が発生した案件は「外部手数料」として手取りから引く

7. お金

  • 利用料：当面ゼロ。会員10社程度・成立20件くらいから月500円程度（投票で決める）
  • 各自の取引データはいつでも自分でエクスポートできる
  • 値上げは告知の翌々月から。退会は自由

8. 決め方

  • 票の重み＝この網で受けた数＋出した数
  • 3か月に1回、ルールの数値を見直す。過程は全員に見える
