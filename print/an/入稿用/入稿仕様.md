## 3. 両方に共通

| 項目 | 内容 |
|---|---|
| PDFの箱 | MediaBox＝BleedBox＝データサイズ、**TrimBox＝仕上がりサイズ**（各辺3mm内側）を設定済み |
| フォント | すべて埋め込み済み（BIZ UDPゴシック・Zen Maru Gothic・Barlow Semi Condensed） |
| 文字・図形 | ベクター（拡大しても粗くならない） |
| トンボ | 付けていない（ネット印刷はトンボなし・塗り足し込みのPDFで受けるところが多い。求められたら付ける） |
| 色 | **RGB**。印刷所でCMYKに変換される。画面より赤（価格・赤い帯）と黄色がやや沈むことがある |
| 写真の解像度 | チラシ表の黒い水の写真は約 **200dpi**（元の写真が 1200px）。推奨の 300〜350dpi より低く、少し甘く見える可能性がある。裏の前後写真は小さく使っているので十分 |

- 紹介カードの紙が、ボールペンで書けるか
