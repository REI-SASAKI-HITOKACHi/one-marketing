
## ⚠️ 見つけて、まだ閉じていないもの

1. **`teltap` と `form_complete` を外さないこと。** 公式サイトの計測で、LPとは**別のページを別の名前で数えている**。
   外すと公式サイトの電話タップと問い合わせが数えられなくなる（`docs/measurement-audit.md`）
2. **公式サイトの `click` をキーイベントにしないこと。** UA時代の変換の仕掛けが
   **1回のタップで `click` と `teltap` の2つを撃つ**ので、両方キーイベントにすると1タップが2件になる
3. **Google広告の警告「連絡先 — メインのコンバージョンアクション 0 — 設定が不適切」を直さないこと。**
   メインに昇格させると、タップだけする人を集めるほうへ最適化される
4. **このブランチの `lp/` が、LP担当のブランチより古い。** hidden 欄（`h-src`）がこちらに無く、
   **手元のテストではフォーム側を見られない**
