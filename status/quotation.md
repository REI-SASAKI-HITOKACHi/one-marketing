## 9/20 にやったこと

### 業務用エアコンの価格：**食い違っていませんでした**（`53aac74`）

CMOから「price-master（¥27,280〜）と食い違う。出どころを教えてほしい」と指摘。
**自分の出どころは自分のコミットメッセージだけ**で、根拠になっていませんでした。**本番マスタで調べ直しました。**

| | |
|---|---|
| ¥29,800 | **定価**（税抜）。メニューマスタ `M014` の単価 |
| ¥24,800 | **2〜10台のときの1台あたり**（−¥5,000）。パンフレットの数字。`M014` の「原文価格/時間」列にそのまま保存されていた |
| ¥27,280 | **上と同じものの税込**（¥24,800×1.1）。price-master の数字 |

**3つとも同じ価格表の別の顔でした。**食い違って見えたのは、定価か割引後か・税抜か税込かを書いていなかったからです。

ついでに**自分の記録の誤りを2つ直しました。**
「2台目以降 −¥5,000」は誤り（`Calc.html` は `amount += per * l.qty` で**全台**に掛かる）。11台以上の段（−¥6,000／−¥7,000）が抜けていた。
**lp スレッドへの訂正依頼は取り下げました。**あれは直す必要がありませんでした。
