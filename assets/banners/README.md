# レントラックス提出用バナー

`python3 tools/build-banners.py` で書き出す。**画像を手で編集しないこと。**
直すときは `tools/build-banners.py` を書き換えて、もう一度走らせる。

| ファイル | 寸法 |
|---|---|
| `ONE-HITTER-300x250.png` | 300 × 250 |
| `ONE-HITTER-250x250.png` | 250 × 250 |
| `ONE-HITTER-200x200.png` | 200 × 200 |

`_src-*.html` は書き出しの元。中身を見たいとき用で、提出はしない。

## なぜ画像生成モデルを使わないか

**文字がラスタに焼き付くから。** 生成で作ると

- 1文字直すのに全部作り直しになる（先方から「エリアを入れて」と言われた時点で詰む）
- 指定した色と微妙にずれる
- 字形が崩れても気づきにくい

HTML/CSS で組んで Chromium で実寸撮影すれば、**文字はベクタで正確・色は指定値そのもの・修正は1行**。
書き出し後に実寸を機械で検査していて、1つでも違えば落ちる。

## 写真の決まり

**施工後の実写のみ。**`assets/photos/` から選ぶ。

- 🚫 **ビフォーアフター風の生成画像をつくらない。** 実際の施工でない画像を「施工例」に見える形で
  載せると優良誤認になる
- 🚫 **私物が写っているカットを使わない。** お客様のご自宅なので、シャンプーや育毛剤の商品名が
  読めるものが実際にある（`IMG_7993` など）。**設備だけが写っているものに限る**
- 2枚を左右に並べているのは、「浴室＋キッチン」のセットであることを絵で伝えるため

いま使っているもの：

| 枠 | ファイル | 中身 |
|---|---|---|
| 左 | `IMG_7987.jpg` | 浴室 アフター |
| 右 | `IMG_7985.jpg` | シンク アフター |

トリミング位置は `SHASHIN` の寄せ値（横・縦）で調整する。

## 残っている弱点（正直に書く）

**写真が弱い。** 浴室もシンクも灰色〜金属色で、小さいサイズだと「きれいになった感じ」が伝わりにくい。
`assets/photos/` に**明るい浴室のアフターで、正面から撮った1枚が無い**のが原因。

**和真さんに次の現場で1枚お願いするのが、いちばん効く改善です。**
（浴室全体が入る位置から、明かりを点けて、正面から1枚）
