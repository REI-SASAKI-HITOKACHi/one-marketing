# 現場で撮った動画の置き場（このPC）

和真さんが撮った施工動画を、**このフォルダに入れると編集できます。**
中身（動画そのもの）はgitに入れません（`.gitignore` 済み）。このREADMEだけ追跡します。

## Drive からここへ持ってくる

元は Drive の **施工動画_一次格納**
（`1RzlaV8-dlPvG5wPJYxinTiFYxmUO5kbx`／https://drive.google.com/drive/folders/1RzlaV8-dlPvG5wPJYxinTiFYxmUO5kbx ）。

**Drive から直接は取れません。** Drive MCP はファイルの中身を base64 の文字列にして渡す作りで、
動画はもちろん、写真1枚（2〜3MB）でも通りません。**人の手かツールで、ここへ落とす必要があります。**

| | 方法 | 手間 | 備考 |
|---|---|---|---|
| **A** | **「Google ドライブ（パソコン版）」で同期し、同期先からここへコピー** | 1回だけ | **推し。** 今後ずっと効く |
| B | ブラウザでダウンロードして、ここへ置く | 毎回 | — |
| C | サービスアカウントの鍵を置き、`python3 tools/drive_client.py sync 1RzlaV8-dlPvG5wPJYxinTiFYxmUO5kbx assets/videos-raw` | 1回＋鍵の判断 | 写真の原寸（4032x3024）も同時に解決する |

2026-10-21 時点で**どれも未実施**です。CMO へ `20261021-02-cmo` で判断を仰いでいます。

## ファイル名

**変えないでください。** 撮影日時がファイルの中（メタデータ）に残っているので、
どの現場のものかを機械的に突き合わせられます。
LINE を経由した版は撮影日時が消え、さらに再圧縮で画質が落ちているので使いません。

## 入ったあとにやること

1. 中身の棚卸し（撮影日・長さ・解像度・写り込みの判定）。
   写真と同じように、1本ずつ見て `docs/` に記録を残す
2. 使えるカットを `data/ad-reels.json` の台本に差し込む
3. `python3 tools/build-ad-reels.py` で組み立てる

編集でできること（`imageio-ffmpeg` 同梱の ffmpeg 7.1 で実測確認済み）：
切り出し・つなぎ・速度変更・9:16への切り抜き・色調整・手ブレ補正（`vidstab`）・
現場音の抜き出しと音量調整・BGMとの混ぜ合わせ。

詳しくは `docs/動画広告-品質を上げる方法の調査-2026-10-18.md`。
